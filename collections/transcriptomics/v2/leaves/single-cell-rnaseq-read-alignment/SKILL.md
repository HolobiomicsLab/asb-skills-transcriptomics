# single-cell-rnaseq-read-alignment

## Summary

Align single-cell RNA-Seq reads to the genome with STAR using TE-aware multi-mapping settings (--winAnchorMultimapNmax 100, --outFilterMultimapNmax 100, --outSAMmultNmax 1) so that downstream tools like SoloTE can quantify transposable element expression from BAM files.

## When to use

Use when scRNA-Seq FASTQs must be aligned to hg38/mm10 for downstream TE expression analysis with SoloTE or scTE, where multi-mapping reads across repetitive elements must be retained rather than discarded.

## When NOT to use

- When the analysis target is gene-level expression only and no TE quantification is planned — standard STAR/CellRanger default multi-mapping filtering is then appropriate.
- When input is already a BAM or a gene+TE expression matrix; this skill covers only the FASTQ-to-BAM alignment step.
- When the input is a simulated dataset generated with Minnow where alignment settings are already prescribed by the benchmark protocol.

## Inputs

- scRNA-Seq FASTQ reads (e.g., from APP/PS1 AD mouse model, murine two-cell stage, or early gastric cancer datasets)
- Reference genome FASTQ index for STAR (hg38 or mm10)
- Downstream TE annotation in SoloTE BED format (chr, start, end, locus|Subfamily:Family:Class|strand ID, score) generated by SoloTE_RepeatMasker_to_BED.py from the UCSC mm10 RepeatMasker rm.out file

## Outputs

- BAM alignment files per sample, retaining uniquely mapped reads with MAPQ >= 255 and one reported alignment per multi-mapping read

## How to apply

Align reads with STAR configured for repetitive-element analysis: set --winAnchorMultimapNmax 100 and --outFilterMultimapNmax 100 so reads mapping to up to 100 loci (typical for multi-copy TEs) are not filtered, and --outSAMmultNmax 1 so each multi-mapping read is reported once in the BAM. The resulting BAM files can come from either STAR or CellRanger and are the direct input to SoloTE (SoloTE_pipeline.py --bam) or scTE. Locus-level TE assignment inside SoloTE relies on the MAPQ field: reads with MAPQ >= 255 (uniquely mapped) are summarized at locus level, while multi-mapping reads fall back to family-level summarization. For the APP/PS1 AD mouse model workflow, mm10 alignment feeds a combined gene+TE matrix compatible with Seurat normalization, clustering, UMAP, FindAllMarkers, and edgeR pseudobulk differential expression.

## Related tools

- **STAR** (Spliced aligner used to map scRNA-Seq reads to hg38/mm10 with TE-aware multi-mapping options (--winAnchorMultimapNmax 100, --outFilterMultimapNmax 100, --outSAMmultNmax 1) producing BAMs for SoloTE)
- **CellRanger** (Alternative standard scRNA-Seq processor whose BAM output can be used directly by SoloTE instead of STAR)
- **SoloTE** (Downstream consumer of the aligned BAM; selects reads not assigned to genes and summarizes TE expression using MAPQ thresholds) — github.com/bvaldebenitom/SoloTE
- **BEDTools** (Dependency of SoloTE used to assess overlap of unassigned reads with the TE annotation BED) — https://github.com/arq5x/bedtools2/releases
- **Samtools** (Required dependency (v1.16+) available in PATH for BAM handling during the SoloTE pipeline) — http://www.htslib.org/download/

## Examples

```
python SoloTE_pipeline.py --threads N --bam BAMfile --teannotation mm10_SoloTE.bed --outputprefix APPPS1 --outputdir SoloTE_out
```

## Evaluation signals

- BAM files contain multi-mapping reads with a single reported alignment (--outSAMmultNmax 1), rather than being absent as under default STAR filtering
- Uniquely mapped reads carry MAPQ >= 255 so SoloTE can assign them to TE loci; verify MAPQ distribution before running SoloTE_pipeline.py
- Downstream sanity check: running SoloTE on the STAR BAMs with the mm10 RepeatMasker-derived BED reproduces the paper's outcomes, e.g., 71 marker TEs (adj. P <= 0.05, avg log2FC >= 1) and 9 disease-upregulated TEs including Arthur1B, RLTR14-int, MMVL30-int in the APP/PS1 model
- The BAM must be compatible with Samtools v1.16+ and BEDTools v2.29.2+, the SoloTE dependencies
- scTE comparison on the same BAMs should yield family-level (metagene) matrices — a check that alignment retained enough multi-mapping reads for family-level fallback

## Limitations

- Short 100 nt 3'-end 10X reads cannot uniquely map all TEs (Supplementary Figures 4 and 5), so locus-level resolution is capped by read length and 3'-bias; TEs acting as alternative transcription start sites cannot be detected.
- SoloTE benchmarking showed higher false positives and false negatives for young TEs (divergence <= 10% from consensus), the most problematic class for genomic-location assignment.
- In organisms with a greater proportion of transpositionally-active TEs, most copies may be genetically intact and multi-mapping, degrading locus-level assignment.
- EM-allocation of multi-mapping reads on 3' end 10X data has not yet been assessed; TE-derived isoform analysis is not integrated.
