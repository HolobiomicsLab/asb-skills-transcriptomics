# sequencing-technology-cross-platform-classification-evaluation

## Summary

Benchmark protocol from scCancer2 (Bioinformatics, btae028) for comparing a supervised tumor-microenvironment annotation framework against baselines (scPred, OCLR, multinomial, Scibet, CHETAH, scmap, SingleCellNet) on six scRNA-seq datasets spanning five major cell types and three sequencing technologies, scoring prediction accuracy, computational efficiency, and model complexity.

## When to use

Use when benchmarking cell-type annotation classifiers across multiple scRNA-seq datasets generated by different sequencing technologies, to compare accuracy, computational efficiency, and model complexity per method per dataset.

## When NOT to use

- The goal is fine-grained subtype annotation or cross-reference label-similarity mapping on one dataset, not cross-technology method benchmarking (use runCellSubtypeClassify / similarityCalculation instead).
- The datasets lack trusted level-1 reference labels in metadata, so accuracy cannot be computed against ground truth.
- The task is malignant vs non-malignant cell identification, which uses the pretrained xgboost bulk/scRNA reference model with a 0.5 threshold, not the five-type annotation benchmark.

## Inputs

- Per-study Seurat objects (.RDS) for the six benchmark datasets with level-1 reference cell-type labels in metadata
- Normalized expression matrix (Seurat assay 'RNA' @data; LogNormalize, scale.factor 10000)
- Package-shipped cellSubtypeTemplates.rds subtype templates and marker files (genes.path from system.file("txt", package = "scCancer"))

## Outputs

- accuracy_table.csv with one accuracy entry per method per benchmark dataset across the three sequencing technologies
- Predicted cell-type labels per method (rough five-type labels and fine labels from runCellSubtypeClassify)
- Per-method computational-efficiency (runtime) and model-complexity comparison, ranked as in Fig. 2B / Section 3.2

## How to apply

Load each benchmark dataset as a Seurat object via readRDS (per-study .RDS files keyed by study label, e.g. Ma2022, Zhang2019, Lu2022) and take the LogNormalize (scale.factor 10000) expression matrix from the 'RNA' assay @data slot. Run scCancer2's predCellType to assign rough labels, merge 'T.cells.CD4' and 'T.cells.CD8' into 'T.cells' with gsub, and intersect predictions with the five-type list (T.cells, Myeloid.cells, B.cells, Fibroblast, Endothelial). Run each baseline (scPred, OCLR, multinomial, Scibet, CHETAH, scmap, SingleCellNet, XGBoost) on the same six datasets targeting the same five major types so the comparison is controlled for cell-type set. For fine-label runs use runCellSubtypeClassify with dropout.modeling = FALSE and unknown.cutoff = 0.3 against the package-shipped cellSubtypeTemplates.rds. Compute per-method accuracy against the level-1 reference labels in each dataset's metadata, stratified by dataset and sequencing technology, and record runtime and model size alongside accuracy before assembling accuracy_table.csv in the layout of Fig. 2B / Section 3.2.

```
t.results <- predCellType(expr@assays[["RNA"]]@data); expr$Cell.Type <- t.results$type.pred
```

## Evaluation signals

- accuracy_table.csv contains exactly one accuracy entry per method per benchmark dataset across the three sequencing technologies.
- Per-method accuracy ranking reproduces the ordering reported in Fig. 2B / Section 3.2 of the article.
- All predicted labels, after merging T.cells.CD4/CD8 and intersecting, fall within the five-type list: T.cells, Myeloid.cells, B.cells, Fibroblast, Endothelial.
- Each method's runtime and model complexity are recorded next to accuracy so efficiency/complexity can be ranked alongside accuracy.
- Fine-label runs used dropout.modeling = FALSE and unknown.cutoff = 0.3, and the outputs (fine-labels.RDS, similarity-matrix.RDS) exist per dataset.

## Limitations

- No software version numbers are stated for R, scCancer, Seurat, or xgboost, complicating exact reproduction.
- No repository URL or accession IDs are provided for the benchmark HCC scRNA-seq datasets (Ma2022, Zhang2019, Lu2022, Zheng2017, Sun2021, Liu2023, Losic2020, Ma2021) in the methods.
- Merging T.cells.CD4 and T.cells.CD8 into 'T.cells' discards CD4/CD8 subtype information, and predictions are restricted to the five-type default list.
- The benchmark comparison is reported at the level of a figure/table (Fig. 2B); the article states results indicate reliability without per-parameter sensitivity details.
