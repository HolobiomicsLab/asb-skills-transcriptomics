# pathway-database-querying

## Summary

Retrieves functional term-gene annotations from Gene Ontology (via biomaRt/Ensembl) and six pathway databases (KEGG, Reactome, Biocarta, PID:NCI-Nature, Panther, PharmGKB via graphite) so that predicted ligand-receptor interaction pairs from InterCellar's function-verse can be annotated with biological functions and pathways.

## When to use

Use when a table of enriched int-pairs from a cell-cell interaction analysis needs functional/pathway annotation of its ligand-receptor pairs, e.g. in InterCellar's function-verse.

## When NOT to use

- Input is not pre-computed ligand-receptor interactions — InterCellar's workflow builds on CCI data generated by supported tools rather than raw scRNA-seq counts
- The goal is de novo pathway enrichment of a gene list rather than annotating specific interaction pairs in the function-verse

## Inputs

- Table of enriched int-pairs (predicted ligand-receptor interactions) from a cell-cell interaction dataset (e.g. CellChat, CellPhoneDB, ICELLNET, or SingleCellSignalR output)
- Gene identifiers of int-pair partners, including all members of multi-subunit complexes

## Outputs

- functional_annotation_ranked_terms.csv — table of functional terms ranked by the number of annotated int-pairs (occurrence)

## How to apply

Load the table of enriched int-pairs from the CCI dataset into InterCellar's function-verse. Query Gene Ontology through Ensembl using the biomaRt R package to retrieve GO term-gene annotations, and query KEGG, Reactome, Biocarta, PID:NCI-Nature, Panther, and PharmGKB through the graphite R package to retrieve pathway term-gene annotations. Annotate a functional term to an int-pair only when ALL components of the int-pair — including members of multi-subunit ligand or receptor complexes — are enriched by that term. Rank functional terms by occurrence, i.e. the number of int-pairs annotated with each term, and write the ranked table to functional_annotation_ranked_terms.csv.

## Related tools

- **InterCellar** (Interactive R/Shiny platform whose function-verse consumes the enriched int-pair table and applies term-to-int-pair annotation and ranking) — https://github.com/martaint/InterCellar
- **biomaRt** (R package used to query Gene Ontology through Ensembl for GO term-gene annotations)
- **graphite** (R package used to query pathway databases KEGG, Reactome, Biocarta, PID:NCI-Nature, Panther, and PharmGKB for pathway term-gene annotations)

## Examples

```
InterCellar::run_app( reproducible = TRUE )
```

## Evaluation signals

- functional_annotation_ranked_terms.csv exists and contains ranked functional terms with their annotated int-pair counts
- Every int-pair-term assignment satisfies the all-components-enriched rule, including members of multi-subunit complexes
- Both annotation sources are represented: GO terms retrieved via biomaRt/Ensembl and pathway terms from KEGG, Reactome, Biocarta, PID:NCI-Nature, Panther, and PharmGKB via graphite
- Term ranking reflects occurrence, i.e. the number of int-pairs annotated with each term

## Limitations

- A functional term is assigned only when all partners of the interaction (or all members of a gene complex) are enriched by that term, so terms enriching only one partner are dropped
- InterCellar supports only a limited set of input CCI tools (CellChat, CellPhoneDB, ICELLNET, SingleCellSignalR); extension to other published tools is planned future work
- The run should be launched with reproducible = TRUE to ensure results are reproducible across R sessions
