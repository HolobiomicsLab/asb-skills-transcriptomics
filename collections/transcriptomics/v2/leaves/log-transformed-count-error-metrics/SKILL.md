# log-transformed-count-error-metrics

## Summary

Decompose the overall imputation error gtMSEall between an imputed scRNA-seq matrix and the ground truth on the log10(count+1) scale into component mean squared errors gtMSEnz, gtMSEbiol, and gtMSEtech attributable to nonzero, biological-zero, and technical-zero entry classes.

## When to use

Use when evaluating imputation accuracy on masked scRNA-seq data and you need to attribute ground-truth MSE to nonzero entries, biological zeros (true zeros), and technical zeros (masked nonzero values).

## When NOT to use

- No ground truth matrix exists (e.g., the mouse brain example where the ground truth is set to the same as the input) — error decomposition against true values is then meaningless.
- The data have not been log10(count+1) transformed — the imputed output and error metrics are defined on that scale, so raw-count comparisons would be inconsistent.
- You need to distinguish biological from technical zeros at imputation time — LATE/TRANSLATE assume all zeros are missing values and always impute zeros with a nonzero value; this decomposition only evaluates results post hoc.

## Inputs

- Ground truth count matrix in hd5 format (example.hd5; 10,000 genes x 10,000 cells)
- Masked input matrix in hd5 format (example.msk90.hd5, generated by masking 90% of example.hd5)
- Imputed matrix in hd5 format (step2/imputation.step2.hd5), on the log10(count+1) scale

## Outputs

- mse_metrics.csv containing gtMSEall, gtMSEnz, gtMSEbiol, gtMSEtech, and the zero proportions p0 and q0

## How to apply

Load the ground truth (example.hd5), the masked input (example.msk90.hd5), and the imputed output (step2/imputation.step2.hd5) with pandas/tables, confirming all matrices are on the log10(count+1) scale and share layout (cells x genes). Use numpy to classify entries into three classes: nonzero ground-truth entries, biological zeros (zero in ground truth T), and technical zeros (zero in input X but nonzero in T, produced by masking 90% of example.hd5); record the zero proportions p0 and q0. Compute closed-form mean squared errors between the imputed matrix Y and ground truth T over each class: gtMSEall, gtMSEnz, gtMSEbiol, and gtMSEtech. Validate the decomposition by checking that the p0/q0-weighted combination of gtMSEnz, gtMSEbiol, and gtMSEtech reconstructs gtMSEall. Write the four metrics plus p0 and q0 to mse_metrics.csv with pandas.

## Evaluation signals

- The p0/q0-weighted sum of gtMSEnz, gtMSEbiol, and gtMSEtech exactly reconstructs gtMSEall (decomposition identity holds).
- All three matrices (ground truth, masked input, imputed) are verified to be on the log10(count+1) scale with the same layout (cells x genes).
- The recorded zero proportions p0 and q0 are consistent with the 90% masking rate used to generate example.msk90.hd5.
- mse_metrics.csv contains exactly the eight values: gtMSEall, gtMSEnz, gtMSEbiol, gtMSEtech, p0, q0 with finite nonnegative entries.
- Each entry is assigned to exactly one of the three classes and the class sizes sum to the total number of matrix entries.

## Limitations

- LATE and TRANSLATE assume all zeros are missing values and always impute zeros with a nonzero value; distinguishing biological zeros from technical zeros is not implemented in the methods themselves.
- Work is still needed to better handle biological zeros without sacrificing accuracy on technical zeros.
- Hyperparameters were manually tuned; systematic hyperparameter tuning (as implemented in DCA) was not explored, so reported MSE values depend on manual choices.
- When no ground truth exists, it is set to be the same as the input (e.g., Example 4 mouse brain data), so error metrics are not informative there.
