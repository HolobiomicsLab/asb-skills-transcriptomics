# blastp-gene-presence-mapping

## Summary

Maps reference gene sets (e.g., hrc/hrp T3SS genes) onto bacLIFE gene clusters via BLASTP and converts hits into a per-genome binary presence/absence table across a genus-wide pan-genome. Used to trace the distribution of known genes through a comparative-genomics cluster matrix.

## When to use

Use when you need to know which genomes in a pan-genome gene-cluster absence/presence matrix contain homologs of a defined reference gene set, using paper-standard BLASTP annotation thresholds.

## When NOT to use

- When the target is de novo lifestyle-associated gene discovery rather than mapping a defined reference gene set (use bacLIFE's machine-learning LAG prediction module instead).
- When input is raw genome assemblies and no bacLIFE clustering matrix exists yet — gene prediction (Prokka) and linclust/MCL clustering must be run first.

## Inputs

- Quality-filtered genome set (e.g., Supplementary Datasets 1 Pseudomonas genomes, CheckM >90% completeness, <5% contamination)
- bacLIFE gene-cluster absence/presence matrix (genomes x clusters)
- Gene-cluster representative protein sequences (from Prokka + linclust >90% identity / 80% coverage + MCL clustering)
- Reference protein sequences for the target gene set (e.g., 10 hrc and 16 hrp T3SS proteins)

## Outputs

- Binary per-genome presence/absence table for the reference genes (rows = genomes, columns = genes; e.g., hrc_hrp_presence_absence.tsv)
- List of gene-cluster IDs matched by BLASTP hits and the genomes in which those clusters occur

## How to apply

Load the quality-filtered genome set (e.g., Supplementary Datasets 1 Pseudomonas genomes) together with the bacLIFE gene-cluster absence/presence matrix and cluster representative protein sequences generated by the Snakemake module (Prokka gene prediction, linclust clustering at >90% identity / 80% coverage, MCL inflation 3.0). Run BLASTP searches of the reference protein sequences (e.g., 10 hrc and 16 hrp proteins) against the gene-cluster representatives, applying the paper's annotation thresholds of a minimum subject cover of 70% and a minimum sequence similarity of 40%. Map BLASTP hits back to bacLIFE cluster IDs and, via the absence/presence matrix, to all genomes harboring each hit cluster. Build a binary rows=genomes, columns=genes presence/absence table (e.g., hrc_hrp_presence_absence.tsv) with a custom R/Python script, then validate the distribution against the expected biological pattern (e.g., Fig. 4: hrc genes broad across Pseudomonas lifestyles, hrp genes nearly exclusive to P. syringae plus P. gingeri and P. mendocina strains).

## Examples

```
blastp -query hrc_hrp_reference_proteins.faa -subject bacLIFE_cluster_reps.faa -outfmt 6 -out hrc_hrp_hits.tsv; python build_presence_absence.py --hits hrc_hrp_hits.tsv --matrix gene_clusters_presence_absence.tsv -o hrc_hrp_presence_absence.tsv
```

## Evaluation signals

- Every BLASTP hit passes the annotation thresholds: minimum subject cover 70% and minimum sequence similarity 40%.
- The presence/absence table is strictly binary and its genome rows match the quality-filtered genome set from Supplementary Datasets 1.
- The reconstructed distribution reproduces the reported Fig. 4 pattern: hrc structural genes broadly distributed across Pseudomonas lifestyles while hrp genes are almost exclusive to plant-pathogenic P. syringae (plus P. gingeri and P. mendocina strains).
- Each hit cluster ID maps unambiguously to at least one genome via the bacLIFE absence/presence matrix (no orphan clusters).
- Non-syringae hrp-positive genomes are restricted to the reported set (four P. gingeri and three P. mendocina strains), consistent with the horizontal gene transfer finding.

## Limitations

- Sensitivity is bounded by the 70% subject cover / 40% sequence similarity cutoffs; divergent homologs below these thresholds will be missed.
- Presence is inferred at gene-cluster granularity, so paralogs or multiple cluster members within one genome are collapsed into the cluster-level call.
- Interpretation of hrp genes outside P. syringae as horizontal gene transfer is a hypothesis; the table itself does not establish transfer direction or mechanism.
