# transcriptome-region-overlap-counting

## Summary

Reimplements and validates RgnTX's weighted overlapping-count evaluation for transcriptome colocalization, including the isoform-ambiguity variant (overlapCountsTxIA) where each ambiguous feature contributes a c(i)/n(i) ratio clamped to [0, 1].

## When to use

Use when counting overlaps between transcriptome region sets or between isoform-ambiguous genomic features and transcriptome regions of interest (ROI), and when RgnTX's overlapCountsTx / overlapCountsTxIA measures must be reproduced or verified.

## When NOT to use

- The features already have a known isoform association — use the non-IA path (overlapCountsTx with permTestTx / permTestTx_customPick) instead of the isoform-ambiguity averaging.
- The analysis is genome-based and transcriptome annotation/heterogeneity is irrelevant — genome-level tools like LOLA, GREAT or GenomeRunner are the intended comparison there.
- The goal is p-value/z-score estimation rather than the raw colocalization measure — the permutation machinery (permTestTx family, shiftedZScoreTx, Benjamini-Hochberg correction) is a separate skill built on top of these counts.

## Inputs

- GRanges/GRangesList region set RS1 (e.g. randomized regions from randomizeTx with type='mature'/'CDS', or m6A site GRanges from extdata/m6A_sites_data.rds)
- TxDb transcriptome annotation (TxDb.Hsapiens.UCSC.hg19.knownGene) and exonsBy/cdsBy objects
- Regions of interest generated by a customPick_function (e.g. getCDS, getStopCodon) or an explicit RS2 region set

## Outputs

- Per-feature and total overlap counts (observed_overlap from overlapCountsTx / overlapCountsTxIA)
- Comparison table ia_overlap_verification.csv with columns: feature, custom IA score, overlapCountsTxIA score, per-feature c(i)/n(i) ratio
- Evaluation-function outputs consumable as ev_function_1/ev_function_2 by permTestTx, permTestTx_customPick or permTestTxIA_customPick

## How to apply

Load RgnTX with TxDb.Hsapiens.UCSC.hg19.knownGene in R and build a region set (RS1) using randomizeTx (e.g. 100 regions of width 100 over chosen trans.ids, type='mature') or a real feature set such as m6A sites from m6A_sites_data.rds. For features without isoform ambiguity, count overlaps directly against the ROI with the ev_function overlapCountsTx as used in permTestTx and permTestTx_customPick. For isoform-ambiguous features, implement the IA score directly from the formula: for each feature i, find the K isoforms it can align to, accumulate c(i)/n(i) where c(i) is the count of overlaps with the transcriptome ROIs and n(i) is the total count of that feature's related isoforms, and clamp each per-feature contribution to [0, 1]. Compute reference values on the same set with RgnTX's overlapCountsTxIA and assert per-feature equality within numerical tolerance, writing a comparison table (feature, custom IA score, overlapCountsTxIA score, c(i)/n(i) ratio) to ia_overlap_verification.csv. The rationale is that RgnTX uniquely averages the observed overlap over the K possible isoforms (observed_overlap_i = overlapping counts between RS1_i and ROI_i / K), which no genome-based method does.

## Related tools

- **RgnTX** (Provides overlapCountsTx / overlapCountsTxIA evaluation functions, randomizeTx and the permTestTx family whose observed overlaps this skill reproduces and validates) — https://github.com/yue-wang-biomath/RgnTX
- **R** (Implementation environment for the custom IA overlap-score formula and the CSV comparison script)
- **TxDb.Hsapiens.UCSC.hg19.knownGene** (UCSC hg19 transcriptome annotation (exonsBy, cdsBy) used to extract transcript backgrounds and isoform structures)

## Examples

```
permTestTx_results <- permTestTxIA_customPick(RS1 = RS1, txdb = txdb, customPick_function = getStopCodon, ntimes = 50, ev_function_1 = overlapCountsTxIA, ev_function_2 = overlapCountsTx)
```

## Evaluation signals

- Every per-feature ratio c(i)/n(i) lies within [0, 1].
- The custom IA implementation matches RgnTX overlapCountsTxIA outputs exactly (within numerical tolerance) for every feature on the synthetic feature set.
- observed_overlap_i for an ambiguous feature equals the overlapping count between RS1_i and ROI_i divided by K, where K is the number of isoforms RS1_i aligns to.
- Non-ambiguous overlap counts agree with overlapCountsTx on the same RS1/RS2 pair used in permTestTx.
- The written ia_overlap_verification.csv contains all four required columns (feature, custom IA score, overlapCountsTxIA score, c(i)/n(i) ratio) with one row per feature.

## Limitations

- Isoform ambiguity is only handled by averaging over the K alignable isoforms; if the true isoform is recoverable, the IA weighting dilutes the measure (n(i) in the denominator).
- No RgnTX version number, R version, or dependency versions are stated in the article or README, so exact numerical reproducibility may depend on package version.
- Results depend on the transcriptome annotation background (UCSC hg19); the article showed that overlap counts differ significantly across DNA / exonic DNA / pre-mRNA / mRNA backgrounds restricted to 300 genes.
