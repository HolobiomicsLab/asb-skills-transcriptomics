# label-transfer-method-comparison

## Summary

Benchmark supervised single-cell cell-type label transfer by running SciBet, Seurat v3 (FindTransferAnchors/TransferData), and scmapCluster side-by-side on repeated stratified train/test splits and comparing mean classification accuracy, as in the SciBet cross-platform pancreas evaluation.

## When to use

Use when evaluating which supervised cell-type annotation method (SciBet, Seurat v3, scmap) best transfers labels across scRNA-seq datasets generated by distinct sequencing technologies.

## When NOT to use

- The task is cell-type discovery or clustering of an unlabeled dataset rather than benchmarking supervised annotation methods against known labels
- Only one dataset is available with no cross-platform or cross-dataset generalization question — SciBet alone on a single train/test split suffices
- Test data contains cell types absent from the reference and false-positive rejection via the null-dataset confidence score is the goal — that requires SciBet's conf_score/null-dataset workflow, not plain accuracy comparison

## Inputs

- Normalized scRNA-seq training and test expression matrices from datasets generated by distinct sequencing technologies (e.g. four human pancreas datasets from four techniques, GSE accessions in Supplementary Table 2)
- Cell type annotations for the training sets
- Ordered training-test dataset pair specification (e.g. 6 cross-platform pancreas pairs)

## Outputs

- Mean classification accuracy table (one row per dataset pair, one column per method: SciBet, Seurat v3, scmap), e.g. fig3a_benchmark_accuracy.csv
- Per-repeat accuracy values for each method and pair over the 50 repeats

## How to apply

Download the scRNA-seq datasets and normalize per technology: TPM plus pseudocount one with log-normalization for full-length read data, or size-factor 10,000, add one, log normalization for UMI data. For each ordered training-test pair, form stratified 7:3 train/test splits without replacement using sklearn's model_selection.train_test_split with imbalanced-learn RandomUnderSampler down-sampling, repeating the entire procedure 50 times. On each training set, run SciBet's SelectGene to rank genes by the ΔS statistic and keep the top 500 informative genes, then Learn the multinomial model with Laplace smoothing. Classify each held-out test set with SciBet's Bet, Seurat v3's FindTransferAnchors plus TransferData, and scmapCluster (ignoring unassigned cells); compute per-repeat accuracy and average over the 50 repeats into a mean accuracy matrix (e.g. 6 pairs × 3 methods written to CSV).

## Related tools

- **SciBet** (Primary classifier: SelectGene ranks genes by ΔS, Learn fits the multinomial model with Laplace smoothing, Bet classifies held-out cells) — github.com/PaulingLiu/scibet
- **Seurat v3** (Baseline label-transfer method using FindTransferAnchors plus TransferData on the same splits)
- **scmap** (Baseline method using scmapCluster, ignoring unassigned cells, on the same splits)
- **scikit-learn (sklearn)** (Provides the stratified 7:3 hold-out split via model_selection.train_test_split repeated 50 times)
- **imbalanced-learn** (RandomUnderSampler down-sampling applied to the training splits)

## Examples

```
devtools::install_github("PaulingLiu/scibet"); genes <- SelectGene(train_expr, k=50); model <- Learn(train_expr, geneset=genes[1:500], k=50); pred <- Bet(test_expr, model)
```

## Evaluation signals

- Output accuracy table contains all expected dataset pairs (e.g. 6) and exactly the 3 method columns, with all mean accuracies in [0,1]
- Mean accuracy ordering matches the reported Fig. 3a result: SciBet >= Seurat v3 > scmap on the cross-platform pancreas pairs
- Every split is stratified 7:3 train/test, repeated the full 50 times including re-running feature selection and classification
- Feature selection consistently retains the top 500 genes ranked by ΔS on each training set
- scmap's 'unassigned' cells are excluded from its accuracy calculation while SciBet and Seurat v3 accuracies cover all test cells

## Limitations

- No seed or randomization parameters were reported for the 50× repeated splits, so exact numeric reproduction of the accuracy table may vary
- scmapCluster results require excluding unassigned cells, which changes the effective evaluation set relative to the other methods
- Software versions (scikit-learn, Seurat v3 minor version, imbalanced-learn) are not specified in the article, complicating exact re-runs
