# per-class-recall-performance-benchmarking

## Summary

Benchmark a regularized multiclass logistic regression (mLR) breast-cancer intrinsic subtyping model not only by overall accuracy on a held-out TCGA test split, but by per-subtype recall (Luminal A, Luminal B, Basal, Her2-enriched, Normal-like), macro-averaged recall, and precision across competing feature spaces (filters and limmaN signatures).

## When to use

Use when comparing classifiers trained on different gene feature spaces over the five PAM50 subtypes, and you need per-class (subtype) recalls, macro-averaged recall, and precision on a held-out test split rather than aggregate accuracy alone.

## When NOT to use

- You only need a single aggregate accuracy number and class balance is not a concern — overall accuracy suffices and per-class recalls add unnecessary computation.
- Labels are not the five PAM50 intrinsic subtypes (e.g. microarray AWCA classifications of GSE4922/GSE1456) — the reported recall checkpoints (Her2-Enriched 93%, macro-recall 0.94) are specific to the TCGA RNA-seq subtype setting.
- The published subtype labels were themselves generated by PAM50 on the same gene panel — the article warns such accuracies are biased, so per-class recall benchmarking against PAM50-derived labels will overestimate Her2-enriched/Normal-like performance.

## Inputs

- TCGA RNA-seq expression matrix with PAM50 subtype labels, split into training and held-out test sets
- Fitted mLR models (Lasso/L1 and Ridge/L2) trained on candidate feature spaces (top-1000 filter spaces: Fisher, MI, Chi-squared, Spearman; limmaN spaces N=10..1000)
- List of the five intrinsic subtypes (Luminal A, Luminal B, Basal, Her2-enriched, Normal-like) for per-class recall computation

## Outputs

- Per-feature-space overall accuracy on the held-out TCGA test split
- Per-subtype (per-class) recall values, macro-averaged recall, and precision per feature space
- Aggregated accuracy and per-class recall comparison table (accuracy_metrics.csv)

## How to apply

Train Lasso/L1 and Ridge/L2 regularized multiclass logistic regression (scikit-learn) on each candidate gene space — top-1000 filter spaces from Fisher, Mutual Information, Chi-squared, and Spearman scores, plus limmaN DEG spaces (N=10..1000, e.g. limma50 with 277 genes). Estimate generalization via cross-validation on the training split, then evaluate each fitted model on the held-out TCGA test split computing overall accuracy, per-subtype recalls, macro-averaged recall, and precision. Compare against reported ranges: CV accuracy 89-95%, test accuracy 86-88%, with specific checkpoints being the Chi-squared filter's Her2-Enriched recall of 93% and limma50's 88% test accuracy with macro-averaged recall 0.94 and precision 0.70. Aggregate the accuracy and per-class recall values into a comparison table (accuracy_metrics.csv) to identify the best feature space.

## Related tools

- **limma** (Provides moderated DEG statistics used to define the limmaN gene signatures (e.g. limma50, 277 genes) whose per-class recall and test accuracy are benchmarked) — github.com/DEIB-GECO/BC_Intrinsic_subtyping
- **scikit-learn** (Trains the Lasso/L1 and Ridge/L2 regularized multiclass logistic regression models whose per-subtype recalls and accuracies are computed on the held-out TCGA test split)

## Examples

```
from sklearn.linear_model import LogisticRegression; m = LogisticRegression(penalty='l1', solver='liblinear', multi_class='auto'); m.fit(X_train_limma50, y_train); recalls = per_class_recall(m, X_test, y_test)
```

## Evaluation signals

- Test accuracies across feature spaces should fall within the reported 86-88% range and CV accuracies within the 89-95% range.
- The limma50 signature (277 genes, N=50) should reproduce the best overall TCGA test accuracy of 88% with macro-averaged recall 0.94 and precision 0.70.
- The Chi-squared filter feature space should yield a Her2-Enriched recall of 93% on the test split.
- Per-class recall vectors must contain one recall per subtype (Luminal A, Luminal B, Basal, Her2-enriched, Normal-like) for every evaluated feature space.
- accuracy_metrics.csv should contain the aggregated accuracy and per-class recall rows for all five tested gene spaces.

## Limitations

- Performances are biased because published subtype labels were themselves obtained with the PAM50 assay on the same gene panel, inflating apparent accuracy.
- The Normal-like class has undetermined clinical significance and degrades performance metrics.
- limma-derived signatures brought less convincing performances on testing in the original paper's discussion, so limmaN spaces should not be assumed superior a priori.
- Small number of training samples and large number of features limit subtyping capabilities for hard-to-recognize cases.
