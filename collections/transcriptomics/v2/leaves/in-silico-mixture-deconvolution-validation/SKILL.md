# in-silico-mixture-deconvolution-validation

## Summary

Validation skill for confirming that the de-goulash scRNA-seq deconvolution pipeline recovers a number of cell clusters equal to the number of contributing individuals in in silico balanced mixtures (M5-M9, 5 to 9 contributors), including the hardest 9-person case.

## When to use

Use when validating mixture-deconvolution performance on in silico scRNA-seq mixtures of known composition (5-9 contributors) where the ground-truth contributor count can be compared against the number of deconvoluted cell clusters.

## When NOT to use

- The mixture composition is unknown, so the ground-truth contributor count needed for validation is unavailable (use de-goulash clustering with nBclust prediction instead, clusters>1).
- The sample contains non-living or fixed cells — the 10x Genomics platform used here requires live cells for successful genetic separation.
- The mixture has more than nine contributors — this was only hypothesized to be feasible and was not experimentally tested.

## Inputs

- in silico balanced scRNA-seq mixtures M5-M9 assembled from public single-individual 10x datasets
- possorted_genome_trimmed.bam (10x cellranger BAM) per mixture
- barcodes_reduced.tsv listing cells to use
- genome.fasta (hg19 or hg38) plus regions.txt and MT.fasta/MT_regions.txt generated by process_reference.py
- config.yaml with de-goulash parameters (dp, qual, thr_cell_1/2, thresholds, UMAP settings)

## Outputs

- output/iter2/cells_merge_clusters.vcf per mixture
- cluster assignments separating cells by contributing individual
- cluster-count-versus-known-contributor-count comparison (5 through 9)

## How to apply

Assemble each in silico balanced mixture (M5-M9) from single-individual scRNA-seq data and run the de-goulash Snakemake pipeline via the geniderasmusmc/de-goulash:1 Docker image, mounting inputs at /single-cell with config.yaml and cores=4. Call SNPs on possorted_genome_trimmed.bam against genome.fasta using freebayes-parallel over the fasta_generate_regions.py regions file plus the MT reference/regions pair; filter SNPs at dp=50 and qual=60 with per-iteration minimum SNP-per-cell thresholds thr_cell_1=10 and thr_cell_2=20. Merge cells in Python using threshold_coverage=10 (total SNP coverage per cell), threshold_coverage_pos=5 (coverage per SNP per cell), and threshold_base_calling=90, then cluster with the Rscript rule using UMAP settings n_neighbors=5 and n_components=300 (clusters=0 so nBclust prediction is skipped). For each mixture, produce output/iter2/cells_merge_clusters.vcf and judge correctness by confirming the number of recovered clusters equals the known number of contributors — the 9-person mixture must separate into exactly 9 clusters.

## Examples

```
docker run -it -v /current/directory/de-goulash/:/single-cell geniderasmusmc/de-goulash:1 output/iter2/cells_merge_clusters.vcf --snakefile Snakefile --configfile config.yaml --cores 1
```

## Evaluation signals

- For each in silico mixture M5-M9, the number of deconvoluted cell clusters in output/iter2/cells_merge_clusters.vcf equals the known number of contributing individuals (5 through 9).
- The 9-person mixture separates into exactly 9 clusters (most complex case).
- SNP filtering applied with dp=50 and qual=60 and both iteration thresholds thr_cell_1=10, thr_cell_2=20 were enforced per cell.
- Cell merging thresholds respected: >=10 total coverage of selected SNPs per cell, >=5 coverage per selected SNP per cell, and >=90% base-calling agreement.
- Pipeline run reproducibly via the geniderasmusmc/de-goulash:1 Docker image with config.yaml parameters (cores=4, clusters=0 so nBclust is not invoked).

## Limitations

- Only balanced in silico mixtures of 5-9 individuals were validated here; deconvolution of >9 individuals was not experimentally tested (only hypothesized feasible depending on SNPs per cluster).
- The 10x Genomics scRNA-seq platform requires live cells, limiting application to biological mixtures containing living cells.
- Results depend on the obtained number of SNPs per individual cell cluster; very low cell numbers would require deeper sequencing that has not been empirically tested.
