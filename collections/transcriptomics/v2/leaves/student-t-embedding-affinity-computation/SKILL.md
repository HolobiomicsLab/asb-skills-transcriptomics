# student-t-embedding-affinity-computation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Computes the pairwise affinity structures that underlie EMBEDR's per-cell quality statistic (EES): Gaussian-kernel neighborhoods in the high-dimensional space and Student-t kernel affinities in each 2D embedding, which are compared per cell via Kullback-Leibler divergence.

## When to use

Use when a per-cell, local assessment of embedding quality is needed: high-D Gaussian affinities (perplexity = 10% of samples) must be paired with Student-t affinities in 2D t-SNE/UMAP embeddings to compute per-cell KL divergences for data and null embeddings.

## When NOT to use

- When the goal is a single global embedding-quality score rather than local, per-cell error estimates — EMBEDR's design goal is explicitly per-cell estimates
- When only a low-dimensional embedding exists without the original high-dimensional data, since high-D Gaussian affinities cannot be computed
- When the input dataset is non-normalized — the null-generation process feeding the comparison has not been extended to non-normalized datasets

## Inputs

- High-dimensional data matrix (e.g. mnist2500_X.txt loaded via np.loadtxt as float)
- Data 2D embeddings generated by t-SNE or UMAP
- Null 2D embeddings generated from marginally-resampled data
- Algorithm hyperparameters: perplexity (t-SNE) or nearest_neighbors (UMAP)

## Outputs

- Per-cell KL divergences for every data and null embedding
- Combined table embedr_kl_divergences.csv
- Per-cell quality statistic (EES) / EMBEDR p-values derived by comparing data divergences to the null distribution

## How to apply

Load the high-dimensional feature matrix (e.g. mnist2500_X.txt) with numpy and the pre-generated data and null 2D embeddings produced by t-SNE or UMAP. Compute Gaussian-kernel affinity neighborhoods for every cell in the high-dimensional space, setting perplexity (or nearest_neighbors for UMAP) at the EMBEDR default of 10% of the number of samples. Compute Student-t kernel affinities among cells in each 2D embedding, for both real-data and marginally-resampled null embeddings. For each embedding, calculate the KL divergence per cell between its high-dimensional affinity distribution and its low-dimensional affinity distribution; small DKL indicates the cell's neighborhood is similarly structured in both spaces. Assemble the per-cell KL divergences across all data embeddings and all null embeddings into a single table (embedr_kl_divergences.csv) so that data-embedding divergences can be compared against the empirical null distribution to yield EMBEDR p-values.

## Evaluation signals

- Per-cell KL divergences for all data and all null embeddings are assembled into a single embedr_kl_divergences.csv table
- Perplexity (t-SNE) or nearest_neighbors (UMAP) equals 10% of the number of samples unless explicitly overridden
- Well-embedded cells show small DKL between high-dimensional and low-dimensional affinity distributions; signalless (null) embeddings define the empirical null against which data embeddings are judged
- Affinity matrices and nearest-neighbor graphs are cached and reused — re-running with more embeddings (e.g. increasing n_data_embed from 3 to 5) should regenerate only the missing embeddings, not recompute affinities
- Resulting per-cell p-values color the embedding and distinguish real structure from algorithm-induced noise

## Limitations

- EMBEDR's runtime depends on the speed of current DR algorithm implementations used to generate many null embeddings
- Calculated p values have finite resolution because null distributions are computed empirically; the number of nulls bounds the lower limit of attainable p values
- No theoretical description of the tails of the null distributions or principled parameterization exists
