# int-pair-module-definition-via-umap-hierarchical-clustering

## Summary

Defines int-pair modules — groups of predicted ligand-receptor interactions with similar functional patterns — by embedding enriched interaction pairs via UMAP and grouping them with hierarchical clustering inside InterCellar's data-driven analysis.

## When to use

Use when a pre-computed CCI dataset (e.g., from CellChat) has been subset to a specific cell-viewpoint in the cluster-verse and enriched interaction pairs need to be grouped into functional modules for biological interpretation.

## When NOT to use

- The task is CCI inference itself — InterCellar builds on pre-computed ligand-receptor interactions and does not predict them
- Data are bulk RNA-seq-derived interactions (e.g., CCCExplorer territory), which lack a straightforward scRNA-seq application in InterCellar
- The CCI input was generated by a tool InterCellar does not support; supported inputs are limited to CellChat, CellPhoneDB, ICELLNET, and SingleCellSignalR

## Inputs

- Pre-computed CCI dataset from CellChat (or CellPhoneDB, ICELLNET, SingleCellSignalR) uploaded into InterCellar
- Subset of enriched ligand-receptor interaction pairs filtered to a directed outgoing viewpoint (e.g., malignant cells, Tirosh GSE72056 melanoma dataset)
- Functional annotations of interaction pairs from Gene Ontology and pathway databases (function-verse)

## Outputs

- Int-pair module assignment table (nine modules for the melanoma malignant-cell outgoing case)
- UMAP embedding of interaction pairs
- Hierarchical clustering dendrogram of interaction pairs
- Downloadable tables and figures exported from the Shiny app

## How to apply

After loading a CCI dataset (e.g., CellChat output on the Tirosh GSE72056 melanoma data) and subsetting to directed outgoing interactions of a chosen cell type (malignant cells) in the cluster-verse, annotate the enriched interaction pairs in the function-verse using Gene Ontology and pathway resources. Then run the int-pair module definition: the interaction pairs are embedded via UMAP and grouped by hierarchical clustering into modules of interactions with similar functional patterns. Inspect the resulting dendrogram/modules interactively in the Shiny app, and use the reproducible = TRUE flag so module assignments are stable across R sessions. Export the module assignment table and UMAP/hierarchy visualizations via InterCellar's download options; in the melanoma malignant-cell case, nine modules should be recovered, with module #6 grouping ECM-organization/integrin-signaling interactions (collagen/laminin genes vs integrin complexes) and module #8 containing the ANXA1 (malignant cell) & FPR (macrophage) interaction.

## Evaluation signals

- The number of int-pair modules matches the reference: nine modules for the malignant-cell directed-outgoing melanoma (GSE72056) analysis
- Module #6 groups ECM-organization/integrin-signaling interactions composed of collagen- and laminin-encoding genes interacting with integrin-complexes
- Module #8 contains exactly the ANXA1 (malignant cells) & FPR (exclusively macrophage-expressed) interaction
- Module assignments are stable across R sessions when the app is run with reproducible = TRUE
- Module assignment table, UMAP, and dendrogram exports are produced via InterCellar's download options

## Limitations

- InterCellar supports only a limited set of input tools (CellChat, CellPhoneDB, ICELLNET, SingleCellSignalR); extension to other tools is planned future work
- Predicted interactions underlying the modules await experimental validation (e.g., smFISH or flow cytometry co-occurrence)
- Prediction methods rely on different reference databases and statistical assumptions, so the module composition depends critically on the upstream CCI prediction method
