# zero-inflation-diagnostics

## Summary

Validate simulated single-cell RNA-seq count matrices by comparing them to a real reference dataset with countsimQC, checking concordance of the mean-variance distribution and the fraction of zeros per gene before trusting simulations for downstream power/robustness assessments (e.g., CTMM simulations over sequencing depth and cell number).

## When to use

Use when you have generated simulated single-cell count data (e.g., parameterized from Cuomo et al. 2020 iPSC differentiation data) and need to verify the simulation reproduces real-data droplet characteristics — particularly per-gene zero fraction (dropout) and mean-variance behavior — before using it to benchmark methods.

## When NOT to use

- When the simulated data will only be compared at pseudobulk level with no claim about single-cell count realism — zero-fraction diagnostics are only meaningful at the single-cell level.
- When no real reference dataset is available for the same tissue/technology, since the acceptance criterion is close match to real per-gene zero fraction and mean-variance behavior.

## Inputs

- Quality-controlled, normalized real single-cell count matrix (Cuomo et al. 2020 iPSC differentiation data)
- Cell-level metadata (cell, individual, cell type) for the real data
- Simulated single-cell-level count matrices generated by bin/sim, parameterized from the real data

## Outputs

- countsimqc_report.html — countsimQC comparison report of simulated vs. real per-gene distributions
- Visual assessment of concordance in mean-variance distribution and fraction of zeros per gene (as in Supplementary Fig. 10)

## How to apply

Load the quality-controlled, normalized single-cell counts and cell-level metadata (cell, individual, cell type) for the real reference — here the iPSC differentiation data from Cuomo et al. 2020 Nat Commun processed by the bin/cuomo scripts. Generate simulated count matrices using the scripts in bin/sim, orchestrated via the Snakemake Snakefile and parameterized from the real data per Supplementary Note Section 3.4. Run countsimQC in R, invoked through the Snakemake pipeline, to compare each simulated dataset against the real iPSC reference on per-gene distributions. Inspect the countsimQC HTML report for agreement in the mean-variance distribution and the fraction of zeros per gene; accept the simulation only if it closely matches the reference on both metrics, reproducing the agreement shown in Supplementary Fig. 10. Write the final comparison report to countsimqc_report.html.

```
snakemake --cores 1 countsimqc_report.html  # Snakefile rule runs countsimQC in R on simulated (bin/sim) vs. real (bin/cuomo, Cuomo et al. 2020) single-cell counts
```

## Evaluation signals

- The countsimQC report shows the simulated counts closely matching the real iPSC data in mean-variance distribution.
- The per-gene fraction of zeros in the simulated data agrees with the real iPSC reference, reproducing Supplementary Fig. 10.
- The final HTML comparison report exists at countsimqc_report.html and was produced through the Snakemake pipeline.
- The simulated matrices were parameterized from the real Cuomo et al. 2020 data per Supplementary Note Section 3.4, not from arbitrary distributions.

## Limitations

- Acceptance is based on two marginal summaries (mean-variance distribution and per-gene zero fraction); other distributional aspects of the simulation are not explicitly validated.
- The realism check is specific to the iPSC differentiation reference data (Cuomo et al. 2020); simulations validated this way may not generalize to other tissues or scRNA-seq protocols.
- CTMM itself is not reliable for sample sizes below ~50, so even validated simulations should be interpreted within that regime.
