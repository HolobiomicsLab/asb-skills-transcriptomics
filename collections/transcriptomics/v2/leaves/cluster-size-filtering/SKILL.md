# cluster-size-filtering

## Summary

Filter the large batch of CLARA k-medoids clusterings generated by Totem so that only clusterings whose every cluster contains at least five cells (min.cluster.size = 5) are retained for downstream MST construction and cell-connectivity scoring.

## When to use

Use when you have run Totem's k-medoids (CLARA) clustering many times (default 10,000 runs, k = 3-20) on a low-dimensional embedding and must drop runs that contain clusters with fewer than five cells.

## When NOT to use

- The clustering batch was generated on high-dimensional PCA input (e.g., 30 principal components) producing many 1-2 cell clusters — filter alone will not fix the underlying k-medoids instability; switch to a lower-dimensional embedding first
- The dataset mixes extremely rare and extremely prevalent cell types and you intend to manually merge clusters — min.cluster.size filtering would discard relevant rare-cell clusterings before you can merge them
- Input is a single clustering result rather than Totem's large batch of CLARA runs; the size filter is designed for the many-runs stage before MST/cell-connectivity ranking

## Inputs

- Set of clustering results from L CLARA k-medoids runs on the low-dimensional LMDS embedding (e.g., 5 dimensions) of a SingleCellExperiment object
- min.cluster.size parameter (default 5 cells per cluster)

## Outputs

- clustering_results.rds containing only retained clusterings, each with clusters of at least five cells
- Count of filtered-out clustering runs (10,000 minus retained)

## How to apply

After running Totem's RunClustering/RunCLARA functions L times (default runs = 10000) on the LMDS embedding (e.g., 5-dimensional landmark MDS from dyndimred) with k sampled from 3 to 20 and RNG seeds enabled for reproducibility, set min.cluster.size = 5 so that any clustering containing a cluster smaller than five cells is removed. Apply the filter before returning the retained clusterings (e.g., clustering_results.rds), because downstream MST construction via Slingshot and the Calinski-Harabasz/connectivity ranking should operate only on clusterings with sufficiently sized clusters. The rationale is that tiny clusters (often 1-2 cells arising from unstable k-medoids on high-dimensional PCA input or imbalanced data) produce spurious MST nodes. Validation: the number of retained clusterings equals 10,000 minus filtered-out runs, and every retained clustering contains only clusters of at least five cells.

## Related tools

- **Totem** (Provides the RunClustering/RunCLARA functions whose min.cluster.size parameter implements the cluster-size filtering of generated k-medoids clusterings) — https://github.com/elolab/Totem
- **R** (Runtime environment in which the CLARA clustering batch is generated and the min.cluster.size filter is applied before saving clustering_results.rds)
- **SingleCellExperiment** (Container for the binary_tree_1 input data and its LMDS embedding that the clustering runs operate on)
- **dyndimred** (Generates the 5-dimensional landmark MDS (LMDS) low-dimensional embedding that the CLARA runs being filtered are computed from)

## Examples

```
clustering_results <- RunCLARA(lmds_emb, runs = 10000, k = c(3:20), min.cluster.size = 5, seed = 1); saveRDS(clustering_results, "clustering_results.rds")
```

## Evaluation signals

- Number of retained clusterings equals 10,000 minus the number of filtered-out runs
- Every retained clustering contains only clusters with at least five cells (min.cluster.size = 5 criterion)
- Downstream MST construction and cell-connectivity ranking consume only the filtered clustering_results.rds object
- Re-running with RNG seeds enabled reproduces the same set of retained clusterings
- Retained clusterings span the sampled k range (default 3-20) after filtering

## Limitations

- Filtering does not address k-medoids instability with high-dimensional PCA input (e.g., 30 principal components) that produces 1-2 cell clusters — the root cause must be handled by dimensionality reduction choices
- On datasets with extremely rare and extremely prevalent cell types, k-medoids may fail such that the min.cluster.size filter discards many runs and manual cluster merging is still needed
- Totem cannot generate disconnected trajectories or trajectories with cycles, so the filter only prepares clusterings for tree-shaped trajectory MSTs
