# Dropout zero recovery quantification

## Summary

Quantifies how well an imputation/denoising method restores expression values at positions where simulated dropout noise zeroed out true counts, by comparing average recovered values against average true values at exactly those dropout zero positions.

## When to use

Use when a simulated scRNA-Seq dataset was generated by applying dropout noise to a known true count matrix (e.g., a Splatter simulation) and you need a scalar measure of imputation recovery at dropout positions.

## When NOT to use

- The dataset is real experimental scRNA-Seq data with no known true counts, so the set of dropout zero positions cannot be defined against ground truth
- The noise in the simulated data is not dropout (e.g., uniform, Gaussian, Gamma, Poisson, or negative binomial noise); use MSE between true and imputed values instead, as done for Datasets 3-7
- You only need cell-type structure recovery rather than value-level recovery at zeroed positions; average silhouette width (ASW) on the t-SNE embedding is the appropriate metric

## Inputs

- True (ground-truth) scRNA-Seq count matrix from simulation (e.g., Dataset1_true.csv / truecounts.csv, 1000 genes x 500 cells, six groups)
- Noisy count matrix with simulated dropout noise (Dataset 2)
- Imputed matrices from each method being benchmarked (AutoClass, DCA, MAGIC, scImpute, SAVER)

## Outputs

- Average recovered expression value at dropout zero positions per method
- Average true expression value at the same dropout zero positions (reference)
- Rows in a combined benchmark results table (e.g., denoising_benchmark_results.csv) alongside ASW and MSE metrics

## How to apply

Start from a simulated truth pair: a true count matrix (e.g., Splatter simulation with 1000 genes and 500 cells) and the noisy version derived by applying dropout noise, as in the paper's Dataset 2. Run the imputation method under test on the noisy matrix — for AutoClass this means calling AutoClassImpute with dropout_rate=0.3, alongside controls such as DCA, MAGIC, scImpute, and SAVER. Identify the set of matrix positions (gene x cell) that are zero in the noisy data because of dropout but non-zero in the true counts. For each method, compute the average imputed value across these dropout-zero positions and compare it to the average true expression value at the same positions; a recovered average close to (and ideally matching) the true average indicates faithful recovery. Report the recovered-vs-true averages per method alongside ASW recovery and MSE metrics in a single results table (e.g., denoising_benchmark_results.csv).

## Evaluation signals

- The average recovered value at dropout zero positions should approach the average true value at those same positions; a large gap indicates the imputation failed to lift dropout zeros
- The ratio/average should be computed on positions that are zero in the noisy data but non-zero in the true data — verify the mask excludes positions that were truly zero
- Results should assemble into the benchmark table (denoising_benchmark_results.csv) reproducing the Fig. 2 patterns, with AutoClass recovering cell-type signal better than DCA, MAGIC, scImpute, and SAVER
- Zero-recovery values should be reported alongside ASW recovery (expected roughly in the 0.2-0.5 range) and MSE for internal consistency

## Limitations

- Only applicable to simulated data where the true counts are known; real scRNA-Seq data lack ground truth for dropout positions
- Addresses only the dropout noise type (Dataset 2); for the other five simulated noise types (uniform, Gaussian, Gamma, Poisson, negative binomial) the paper instead uses MSE between true and imputed values
- Averages over all dropout zero positions mask gene- and cell-level heterogeneity in recovery quality
