# single-cell-distance-metric-computation

## Summary

Computes single-cell-level distances used by scSemiProfiler both as an active-learning signal (per-sample inference difficulty Dsc) and as a semi-profiling performance metric (normalized error EN), using Euclidean nearest-neighbor distances in a Scikit-learn PCA-reduced space.

## When to use

Use when quantifying how closely inferred (semi-profiled) single-cell data matches real-profiled ground truth, or when scoring per-sample inference difficulty Dsc to drive active-learning representative selection on a bulk+single-cell cohort.

## When NOT to use

- Only bulk data is available with no single-cell reference — the tool's deep generative model enables single-cell level deconvolution only 'provided there is a single-cell reference'
- Data modalities other than scRNA-seq (e.g., proteomics) — extension is only future work and would require algorithm adjustments and benchmarking
- Raw counts without preprocessing — the distance computation assumes library size normalization, log1p transformation, and quality-controlled cells

## Inputs

- Preprocessed bulk RNA-seq profiles for a cohort (e.g., 28-sample COVID-19 cohort, library-normalized and log1p-transformed)
- Real-profiled single-cell data for representative samples (quality-controlled: doublet removal, low-quality cell removal, log1p)
- Inferred (semi-profiled) single-cell data for target samples generated by the VAE-GAN model
- Number of principal components (100 PCs when there are more than 100 samples) and neighbor count K=1

## Outputs

- Per-sample inference difficulty values Dsc (average K=1 nearest-neighbor Euclidean distance in PCA space)
- Normalized semi-profiling error EN values across representative counts
- selection_comparison.csv (Dsc for active-learning vs passive selection at each representative count)
- error_curves.csv (normalized error for scSemiProfiler vs selection-only baseline, representatives 4 to 28)

## How to apply

Reduce the real-profiled and inferred single-cell datasets to 100 principal components with Scikit-learn PCA. For each sample, compute Dsc as the average Euclidean distance between each cell (or its representative's cells) and its K=1 nearest neighbor in the paired target sample within the PCA-reduced space, then aggregate across samples — lower Dsc means easier inference. For performance evaluation, compute the normalized error EN = (mean_difference - LB) / (UB - LB), where UB is the average single-cell difference of randomly paired samples from the PCA-reduced real-profiled data and LB is the difference between two random halves of the comprehensive PCA matrix. These distances serve as both the active-learning heterogeneity term (Db + λsc*Dsc + λpb*Dpb with λsc = λpb = 1) and the validation metric tabulated for active vs passive selection.

## Examples

```
from sklearn.decomposition import PCA; from scipy.spatial.distance import cdist; Z = PCA(n_components=100).fit_transform(X); dsc = cdist(Z_target, Z_rep).min(axis=1).mean()
```

## Evaluation signals

- Active-learning Dsc at 28 representatives is lower than passive-selection Dsc at the same count
- Passive learning needs roughly 4 additional representatives (32 total) to reach the same inference difficulty as active learning at 28
- Semi-profiling normalized error at 28 representatives is below the selection-only baseline's error at 28 representatives
- Normalized error decreases monotonically as more representatives are selected (4 to 28)
- Output files selection_comparison.csv and error_curves.csv match the Fig. 2h Source Data file

## Limitations

- The metric requires single-cell reference data; bulk-only deconvolution is not supported without it
- Interpretation is tied to the PCA-reduced space (100 PCs) and K=1 nearest neighbors; other parameterizations are not benchmarked in this article
- Validation across heterogeneous datasets is done for scRNA-seq; proteomics and other modalities are untested future work
