# STAR multi-mapping read alignment for TE expression analysis

## Summary

Aligns single-cell RNA-Seq reads to the mm10 (or other) genome with STAR using permissive multi-mapping parameters (--winAnchorMultimapNmax 100, --outFilterMultimapNmax 100, --outSAMmultNmax 1) so that reads from repetitive transposable elements are retained for locus-level TE quantification by SoloTE instead of being discarded.

## When to use

Use when quantifying transposable element expression in scRNA-Seq data, since reads from repetitive TEs must be aligned and multi-mapping reads kept to avoid losing TE signal.

## When NOT to use

- The goal is gene-level-only quantification from non-repetitive transcripts, where default STAR/CellRanger multi-mapping filtering is adequate and permissive multi-mapping adds cost
- Input is already an alignment (BAM) from CellRanger or STAR — SoloTE can start directly from that BAM without re-aligning

## Inputs

- Single-cell RNA-Seq FASTQ files (e.g., murine embryonic two-cell stage from Gene Expression Omnibus)
- Reference genome index (mm10 or other genome version)
- STAR aligner with multi-mapping parameters

## Outputs

- Sorted BAM file of aligned reads containing multi-mapping (repetitive-element-derived) alignments
- Downstream combined gene and TE expression matrix after SoloTE processing

## How to apply

Run STAR on the scRNA-Seq FASTQ files (e.g., murine two-cell stage reads from GEO, accessions in Supplementary Table 3) against the mm10 genome with the TE-aware multi-mapping options --winAnchorMultimapNmax 100, --outFilterMultimapNmax 100, and --outSAMmultNmax 1; these raise the anchor and filter multi-mapping limits so repetitive-element reads align rather than being dropped, while --outSAMmultNmax 1 emits only one alignment per read to keep the BAM tractable. The resulting BAM can come from STAR or CellRanger and is passed directly to SoloTE_pipeline.py with the RepeatMasker-derived BED annotation (generated by SoloTE_RepeatMasker_to_BED.py -g mm10), where reads with MAPQ ≥ 255 (uniquely mapped) are assigned at locus level and multi-mapping reads at family level. The output is a combined gene and TE expression matrix compatible with Seurat.

## Related tools

- **STAR** (Spliced aligner run with multi-mapping options --winAnchorMultimapNmax 100, --outFilterMultimapNmax 100, --outSAMmultNmax 1 to retain repetitive TE reads in the BAM)
- **SoloTE** (Consumes the STAR (or CellRanger) BAM plus a RepeatMasker-derived TE BED to produce a locus-specific gene+TE expression matrix) — github.com/bvaldebenitom/SoloTE
- **BEDTools** (Used by SoloTE (v2.29.2 or higher) to assess overlap of unassigned reads with the TE annotation) — github.com/arq5x/bedtools2

## Examples

```
STAR --genomeDir mm10 --readFilesIn sample_R1.fastq sample_R2.fastq --winAnchorMultimapNmax 100 --outFilterMultimapNmax 100 --outSAMmultNmax 1 --outSAMtype BAM SortedByCoordinate
```

## Evaluation signals

- STAR was invoked with all three recommended options: --winAnchorMultimapNmax 100, --outFilterMultimapNmax 100, and --outSAMmultNmax 1
- The BAM feeds SoloTE_pipeline.py with --teannotation pointing to a BED generated by SoloTE_RepeatMasker_to_BED.py for the matching genome (mm10)
- Downstream, MERVL-int and MT2-Mm show the expected 2C-marker expression pattern in 2C-like cells, confirming repetitive reads were retained
- SoloTE recovers the expected 106 marker TEs in 2C-like cells (vs 28 with scTE) at adjusted P-value ≤0.05 and log2(FC) ≥1

## Limitations

- With 3' end 10X short 100 nt reads, not all TEs can be uniquely mappable, so locus-level assignment of some young TEs is limited
- For organisms with a greater proportion of transpositionally-active TEs, most copies may be genetically intact and multi-mapping, limiting locus-specific resolution
- SoloTE's EM-allocation approach for multi-mappers on 3' end 10X data has not yet been assessed (future work)
