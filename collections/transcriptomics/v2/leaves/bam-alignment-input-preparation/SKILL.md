# bam-alignment-input-preparation

## Summary

Prepare Tiglon-ready alignment inputs by writing BAM file lists (one BAM path per line) for each alignment condition (Hisat2-only, Star-only, merged Hisat2&Star) and matching the -s strand/orientation flag to the library type before running Tiglon's labeled splice graph assembly.

## When to use

Use when running Tiglon on RNA-seq alignments: you have coordinate-sorted BAM files from Hisat2 and/or Star and must supply them as bamFiles_list text files with a library-correct strand flag.

## When NOT to use

- Alignments were produced by aligners other than Hisat(2) or Star — the current Tiglon version only accepts BAM files from these two tools
- Reads are long-read RNA-seq (PacBio or ONT) — Tiglon is not compatible with long-read datasets
- An annotation-guided assembly is required — the current Tiglon version has no option to use known transcript annotations to guide assembly

## Inputs

- Coordinate-sorted BAM alignment files produced by Hisat2 or Star
- Reference genome GRCh38 (human) or equivalent mouse genome used for alignment
- Library strandness information (paired-end first/second/unstranded or single-end forward/reverse/unstranded)

## Outputs

- bamFiles_list text files, one per condition (Hisat2-only, Star-only, merged Hisat2&Star), listing one BAM path per line
- Tiglon output directory per run containing Tiglon.gtf with assembled candidate transcripts

## How to apply

For each RNA-seq sample, create a text file (bamFiles_list) containing the path to one alignment BAM per line; Tiglon v1.1 accepts BAM files generated by Hisat(2) and Star only. Build one list per experimental condition — Hisat2-only, Star-only, and the merged Hisat2&Star set — so single-aligner runs can be ablated against the multi-aligner integration run. Select the -s strand option to match library orientation (<first>/<second>/<unstranded> for paired-end libraries, <single_forward>/<single_reverse>/<single_unstranded> for single-end), pass the list with 'Tiglon -B bamFiles_list -s <strand> -o Tiglon_outdir -p 2', and keep the default filters (min_trans_length 500, min_average_frac 0.03, min_unbalance_frac 0.03, min_gap_length 200, min_trans_cov >0) so runs are comparable. Install prerequisites (g++ with C++11, Boost >= 1.47.0, bamtools) before building Tiglon. Each run emits tiglon_outdir/Tiglon.gtf, which is the assembly scored against NCBI RefSeq annotations.

## Related tools

- **Tiglon** (Transcriptome assembler consuming the prepared bamFiles_list via -B, producing Tiglon.gtf assemblies) — github.com/yutingsdu/Tiglon
- **Hisat2** (Splice-aware aligner whose BAM mappings form the Hisat2-only input condition) — https://github.com/DaehwanKimLab/hisat2
- **Star** (Splice-aware aligner whose BAM mappings form the Star-only input condition and are merged with Hisat2 BAMs for the integrated run) — https://github.com/alexdobin/STAR
- **bamtools** (Build prerequisite for Tiglon v1.1 BAM handling) — https://github.com/pezmaster31/bamtools

## Examples

```
Tiglon -B bamFiles_list -s <first> -o Tiglon_outdir -p 2
```

## Evaluation signals

- Each bamFiles_list contains exactly one BAM path per line and Tiglon accepts it without BAM-format errors
- Tiglon runs to completion for all three conditions (Hisat2-only, Star-only, merged) and writes tiglon_outdir/Tiglon.gtf in each output directory
- Identical default filter parameters (min_trans_length 500, min_average_frac 0.03, min_unbalance_frac 0.03, min_gap_length 200, min_trans_cov >0) are used across conditions so assemblies are comparable
- The strand flag matches the library orientation, confirmed by non-degenerate assemblies on the 12 real datasets (H1–H8 human, M1–M4 mouse)
- On the human datasets the merged-alignment assembly shows ~16.11%/13.98% more correct transcripts and ~6.47%/6.91% higher precision than Hisat2-only/Star-only runs (tolerance ±0.5 percentage points)

## Limitations

- Current Tiglon accepts BAM files generated only by Hisat(2) and Star
- No annotation-guided assembly option exists in the current Tiglon version
- Not compatible with long-read RNA-seq datasets (PacBio, ONT)
