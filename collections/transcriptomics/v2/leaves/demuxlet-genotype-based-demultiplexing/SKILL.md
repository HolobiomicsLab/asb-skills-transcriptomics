# demuxlet-genotype-based-demultiplexing

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Apply demuxlet to a genome-aligned BAM file of a multiplexed PBMC scRNA-seq sample using a merged VCF to infer per-barcode genotype labels and singlet probabilities, providing ground-truth cell-containing versus cell-free labels for benchmarking cell-calling methods.

## When to use

Use when a multiplexed scRNA-seq dataset has genetically distinct individuals pooled together, and per-barcode genotype-derived labels (singlet/doublet/negative, cell-free versus cell-containing) are needed as ground truth to benchmark cell-calling methods.

## When NOT to use

- The dataset is not multiplexed across genetically distinct individuals (e.g. a single-donor sample), so genotype-based demultiplexing labels cannot be derived.
- Only HTO (cell hashing) information is available instead of genotypes; in that case HTO-derived singlet/doublet/negative labels provide the ground truth rather than demuxlet.
- The goal is ambient RNA correction or gene-expression denoising rather than cell-calling benchmark labels; demuxlet does not provide expression correction (tools such as SoupX would be needed).

## Inputs

- Genome-aligned BAM file for the multiplexed PBMC sample (SRA accession SRR5398237)
- Merged VCF file containing all samples, from the demuxlet paper-code repository
- Raw unfiltered gene-by-barcode count matrix (e.g. generated by Cell Ranger v.2 on the BAM)

## Outputs

- Per-barcode genotype labels and singlet probabilities from demuxlet, serving as ground truth for cell-containing versus cell-free droplets
- AUROC values of each cell-calling method against the demuxlet-derived ground-truth labels (e.g. written to auroc_results.csv)

## How to apply

Download the genome-aligned BAM file for the multiplexed PBMC sample from the Sequence Read Archive (SRR5398237) and the merged VCF containing all samples from the demuxlet paper-code GitHub repository (yelabucsf/demuxlet_paper_code). Run demuxlet with the merged VCF against the BAM to infer the label of each barcode (genotype assignments and singlet probabilities). These demuxlet-derived genetic-variation labels serve as ground truth for cell-containing versus cell-free droplets, against which methods such as EmptyNN, Cell Ranger v.2/v.3, EmptyDrops, and CellBender are evaluated. Finally, compute the AUROC of each method's cell/cell-free predictions against the demuxlet labels to quantify benchmark performance.

## Evaluation signals

- Reproduce the reported benchmark AUROC values against demuxlet-derived labels within reasonable tolerance: EmptyNN 96.30%, Cell Ranger v.2 82.94%, EmptyDrops 86.43%, Cell Ranger v.3 83.03%, CellBender 58.02%.
- EmptyNN should retain 6,025 cell-containing droplets on the multiplexed PBMC dataset when evaluated against the demuxlet ground truth.
- Per-barcode demuxlet output includes a genotype label and a singlet probability for each barcode, which can be binarized into cell-containing versus cell-free ground-truth classes.
- The ground-truth labels are derived solely from genetic variation (VCF genotypes matched to BAM reads), so barcodes with ambiguous or no genotype support must be handled consistently across all benchmarked methods.
- AUROC results for all methods are written to auroc_results.csv for reproducibility checks.

## Limitations

- Benchmarking ground truth is limited to genetic-variation (or cell hashing) labels; there may be high overlap in cell-calling classifications across methods, which can limit biological interpretation of method differences.
- Demuxlet labels rely on the presence of sufficient genetic variation between pooled individuals; samples without distinguishable genotypes cannot produce reliable ground truth.
- The expected-number-of-cells and total-droplets-included parameters for CellBender must be chosen manually per dataset by inspecting the barcode rank plot, which introduces a degree of subjectivity into the benchmark.
