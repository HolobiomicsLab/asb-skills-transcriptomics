# ligand-receptor-interaction-rank-aggregation

## Summary

Produce a consensus ranking of ligand-receptor interactions by applying Robust Rank Aggregation (RRA) across the per-method interaction scores generated by the seven CCC methods (CellPhoneDB, Connectome, NATMI, SingleCellSignalR, CellChat, iTALK, Cytotalk) within the LIANA framework.

## When to use

Use when multiple CCC method outputs for the same scRNA-seq dataset must be combined into a single consensus prioritisation of ligand-receptor interactions, especially when methods yield incomparable score scales.

## When NOT to use

- Methods that additionally infer intracellular processes, such as NicheNet, Cytotalk-native, and SoptSC, are not directly comparable — do not fold such method outputs into this aggregate without decoupling
- When only a single CCC method's predictions are of interest — rank aggregation is for consensus across methods, not for prioritising one method's scores
- When studying long-distance endocrine signalling, since scRNA-seq gene expression does not capture events outside the cells within the dataset

## Inputs

- Per-method ligand-receptor score tables from the 7 CCC methods (CellPhoneDB truncated mean, Connectome weight_norm, NATMI mean-expression edge weight, SingleCellSignalR LRscore, CellChat probability, iTALK logFC mean, Cytotalk crosstalk score)
- scRNA-seq expression matrix with cell-type labels (e.g. HER2+ and triple-negative breast cancer datasets)
- Ligand-receptor resource assignments per method (CellChatDB, CellPhoneDB, Ramilowski, ConnectomeDB, LRdb) as handled by LIANA

## Outputs

- Aggregated table with aggregate_rank per source-target-ligand-receptor tuple (e.g. liana_rank_aggregate.csv), values in [0, 1]
- Consensus ranking of interactions usable for downstream agreement analyses (e.g. cytokine-activity odds-ratio enrichment)

## How to apply

Load the per-method interaction score tables from LIANA (CellPhoneDB truncated mean, Connectome weight_norm, NATMI mean-expression edge weight, SingleCellSignalR LRscore, CellChat probability, iTALK logFC mean, Cytotalk crosstalk score) and harmonise score orientation so that smaller values denote stronger interactions. Convert each method's scores into ranks computed over the union universe of all interactions predicted by any method. Impute interactions missing from a given method's predictions with the maximum (worst) rank, the most conservative assignment, so missing evidence never inflates a pair's consensus. Apply Robust Rank Aggregation across the ranked columns via liana_aggregate/rank_aggregate to obtain aggregate_rank per source-target-ligand-receptor tuple; RRA extracts interactions that are preferentially highly ranked across methods rather than requiring agreement on raw score magnitudes. Write the result (e.g. liana_rank_aggregate.csv) and verify the aggregate_rank column falls in [0, 1] for all tuples.

## Examples

```
liana_aggregate(sce, resource_name='Consensus', method=c('cellphonedb','connectome','natmi','sca','cellchat','logfc','ctalk'))$aggregate_rank
```

## Evaluation signals

- aggregate_rank column is present in the output table and all values lie in [0, 1] for every source-target-ligand-receptor tuple
- Every tuple's aggregate_rank is computed over the union universe of interactions predicted by any method (no tuples dropped for method-specific missingness)
- Missing interactions carry the maximum (worst) rank, so they never receive an artificially strong consensus
- Score orientation is harmonised: for every method, smaller values denote stronger interactions before ranking
- Consensus agrees directionally with individual method prioritisations, e.g. positive trends with cytokine activities as in the CytoSig agreement analysis

## Limitations

- No gold standard exists for CCC, so the consensus cannot be judged definitively correct against biological ground truth
- Benchmarks cannot distinguish simple co-expression from actual CCC events, and using interaction counts as a communication-intensity proxy is biased by method choice
- Gene expression is a proxy of protein levels alone; processes preceding transmitter-receiver interactions (translation, secretion, diffusion) and long-distance endocrine signalling are not captured
