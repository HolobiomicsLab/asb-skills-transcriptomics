# single-cell-boolean-network-rule-inference

## Summary

Infer Boolean regulatory rules for signaling pathway topologies from scRNA-seq data using scBONITA, which also computes node importance scores, enabling executable dynamic pathway models for HIV-associated atherosclerosis (GSE198339) and Kazer et al. HIV infection data.

## When to use

Use when scRNA-seq data (log2(TPM+1)-style matrix with cell IDs and condition labels) must be converted into executable Boolean models of KEGG (or custom GRAPHML) signaling pathways to prioritize high-impact genes.

## When NOT to use

- Only a desktop computer is available with a large scRNA-seq dataset — rule inference and attractor analysis require >10G RAM and are not recommended off-cluster
- The input is already inferred Boolean rules or a node importance table rather than raw processed scRNA-seq with condition labels — use pathway analysis or attractor analysis tutorials instead
- No subpopulation/condition labels exist for the cells, since rule inference compares labeled conditions via the contrast file

## Inputs

- Processed scRNA-seq training matrix (tab or comma-delimited; rows=genes, columns=cell IDs; expression as log2(TPM+1) variant)
- Metadata/conditions matrix (rows=cells, columns=conditions, binary 0/1 entries; cell IDs matching training data columns)
- Contrast file listing pairs of condition columns to compare
- KEGG pathway identifiers (e.g. hsa00010, hsa00020) or non-KEGG networks in GRAPHML format

## Outputs

- Inferred Boolean regulatory rules per node for each pathway
- Node importance scores quantifying gene impact on signaling (used later for importance-vs-centrality correlation and cross-dataset Pearson correlation, 0.71-0.91)
- sbatch scripts and log files from the slurm queue
- Learned executable pathway models feeding pathway analysis and attractor analysis

## How to apply

Set up the scBONITA pipeline in the scBonita conda environment (Python 3.6+, C code compiled with make after setting NODE and CELL constants to dataset size), running on a SLURM system with >10G RAM. Provide three inputs in src/scBonita: a training data matrix (tab/comma-delimited, rows=features, columns=cells, first column labeled 'Genes'), a 0/1 metadata conditions file mapping cells to subpopulations, and a contrast file listing condition pairs to compare. Run pipeline.py with --fullPipeline 1, --listOfKEGGPathways (e.g. "00010" "00020"), --getKEGGPathways 1, and --organism hsa; step 1 generates sbatch files whose jobs perform rule inference and node importance calculation (step 2) automatically in the slurm queue — monitor queue and log files periodically. Rationale: scRNA-seq is assumed to sample the state space of a dynamic Boolean network in lieu of time-series data, and rules learned per subpopulation enable in silico perturbation and downstream pathway/attractor analysis.

## Examples

```
python3.6 pipeline.py --dataFile "example.csv" --fullPipeline 1 --maxNodes 20000 --separator "," --listOfKEGGPathways "00010" "00020" --getKEGGPathways 1 --organism hsa
```

## Evaluation signals

- scBONITA requires Python 3.6 or newer and the C code compiles cleanly with make after NODE/CELL are set to at least the dataset dimensions
- Step 1 generates sbatch files that enter the slurm queue and execute automatically; log files complete without dependency errors
- Inferred rules and node importance scores are produced for every pathway listed in --listOfKEGGPathways (e.g. hsa00010, hsa00020)
- Downstream sanity check: node importance scores show no significant Spearman correlation with any of six node centrality measures (all p>0.01), confirming rules carry information beyond topology
- Cross-dataset reproducibility: importance scores for matched subpopulations (cytotoxic T cells vs CD8+ T cells) correlate with Pearson r between 0.71 and 0.91

## Limitations

- Rule inference and attractor analysis need >10G RAM; not recommended on a desktop computer
- Inference quality depends on pre-classified cell subpopulations in the metadata; authors expect improvement when pure cell populations are sequenced instead of mixed PBMC subpopulations
- No time-series data is used — scBONITA assumes scRNA-seq samples the state space of a dynamic Boolean network
- Requires editing NODE/CELL constants in the C file to match dataset size before compiling with make
