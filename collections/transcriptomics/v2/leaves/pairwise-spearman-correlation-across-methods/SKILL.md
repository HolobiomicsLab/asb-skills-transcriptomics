# pairwise-spearman-correlation-across-methods

## Summary

Quantify cross-method agreement among the 11 decoupleR activity inference methods by computing pairwise Spearman correlations of regulator activity scores and median Jaccard indexes of top-5% regulator sets, for both the transcriptomics and phospho-proteomics perturbation benchmarks.

## When to use

Use when you have per-method regulator activity score matrices from decoupleR benchmarks and need to test whether different activity inference methods produce similar estimates.

## When NOT to use

- The goal is to evaluate method accuracy against perturbation ground truth (AUROC/AUPRC) rather than cross-method agreement — use the decoupleRBench evaluation pipeline instead.
- Input is raw count data or prior knowledge networks rather than already-computed per-method activity score matrices.
- Only a single inference method was run, so no pairwise cross-method comparison is possible.

## Inputs

- Per-method regulator activity score matrices from the transcriptomics benchmark (run_rna_bench.R)
- Per-method regulator activity score matrices from the phospho-proteomics benchmark (run_php_bench.R)
- Benchmark data retrieved from Zenodo record 5645208 (count table and metadata table for decoupleRBench)

## Outputs

- method_agreement_metrics.csv containing median Spearman (transcriptomics, phospho-proteomics) and median Jaccard (transcriptomics, phospho-proteomics)
- Optional Fig. 1B-style method-agreement heatmap

## How to apply

Load the per-method regulator activity score matrices generated by run_rna_bench.R and run_php_bench.R, retrieving the underlying data from Zenodo record 5645208 via Rscript R/process/get_data.R. For each omics collection, compute all pairwise Spearman rank correlations of activity scores between the 11 methods and take the median across method pairs. Separately, for each method rank regulators by activity score, retain the top 5% regulators, compute pairwise Jaccard indexes on these top-5% regulator sets across methods, and take the median. Write the four statistics (median Spearman and median Jaccard for transcriptomics and phospho-proteomics) to method_agreement_metrics.csv and optionally render a Fig. 1B-style agreement heatmap. Validate that computed medians reproduce the reported values: Spearman 0.52 (transcriptomics) and 0.65 (phospho-proteomics); Jaccard 0.23 and 0.21.

## Examples

```
Rscript R/process/run_rna_bench.R && Rscript R/process/run_php_bench.R  # then compute pairwise Spearman/Jaccard across the 11 methods
```

## Evaluation signals

- Median Spearman correlation of activities between methods equals ~0.52 for transcriptomics and ~0.65 for phospho-proteomics
- Median Jaccard index of top-5% regulator sets equals ~0.23 for transcriptomics and ~0.21 for phospho-proteomics
- method_agreement_metrics.csv contains exactly the four statistics (Spearman and Jaccard, both omics)
- All pairwise comparisons span the 11 decoupleR methods (66 method pairs per omics collection)
- Agreement heatmap visually matches the Fig. 1B style layout

## Limitations

- Despite differing activity distributions across methods, agreement is only moderate (median Spearman 0.52–0.65), so method consensus rather than any single method should be trusted
- The noise analysis (run_rna_noise.R ~6 hours, run_php_noise.R ~2 hours) and scalability analyses are separate, slower pipelines not covered by this skill
- Underlying data must be fetched from Zenodo record 5645208 before running the benchmarks
