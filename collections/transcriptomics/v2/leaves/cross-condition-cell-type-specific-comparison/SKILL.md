# cross-condition-cell-type-specific-comparison

## Summary

Compares scBONITA-derived dysregulated KEGG pathways across two conditions (e.g., pre- vs 1-year post HIV infection, and AS+ vs AS- PLWH) separately within defined immune cell subpopulations such as cytotoxic T cells and monocytes, to identify shared disease-modulated signaling pathways.

## When to use

Use when you have scRNA-seq data from two or more conditions plus pre-classified cell-type labels, and need to determine which pathway-level dysregulations (not single genes) are shared or specific to a condition within each cell type.

## When NOT to use

- Conventional over-representation analysis (ORA) on differential-expression gene lists is the goal — the paper showed ORA was inefficacious at identifying coherent molecular processes such as migration-related pathways
- Input is bulk RNA-seq without single-cell resolution or without cell-type subpopulation labels, since the comparison must be made within each cell type
- Only one condition is available and no cross-condition contrast can be defined in the contrast file

## Inputs

- Processed scRNA-seq expression matrix (genes x cells, log2(TPM+1)-style, first column 'Genes', first row cell IDs) per cell type, e.g. Kazer et al. SCP256 PBMC data
- Metadata/conditions file (rows = cells, columns = 1/0 condition labels such as pre-infection vs 1-year post-infection or cell-type labels)
- Contrast file listing the pairs of condition columns to compare
- KEGG (hsa) pathway GRAPHML networks downloaded via scBONITA setup
- Pre-classified cell-type labels for cytotoxic T cells and monocytes

## Outputs

- Per-cell-type, per-condition list of dysregulated optimized KEGG pathways
- Intersection of dysregulated pathways shared across conditions per cell type (e.g., scp256_pathway_analysis_results.csv)
- Qualitative comparison such as '5 of 19 optimized monocyte pathways dysregulated in both HIV infection and AS+ PLWH'

## How to apply

Subset the cells per cell type using pre-classified labels from the metadata file (rows = cells, 1/0 condition columns), which reduces variability and improves specificity of scBONITA-PA. Format the expression matrix as genes x cells in log2(TPM+1)-style units with a contrast file listing the condition pairs to compare, then run scBONITA rule inference per subpopulation on the specified KEGG hsa pathway topologies. Run pathwayAnalysis.py with the training data, conditions, and contrast files to score pathway dysregulation between conditions (e.g., pre-infection vs 1-year post-infection on Kazer SCP256 data; AS+ vs AS- on GSE198339). Finally, intersect the dysregulated-pathway sets across conditions within each cell type — in the paper, 5 signaling pathways in cytotoxic T cells and 5 of 19 optimized pathways in monocytes were dysregulated in both HIV infection and AS+ PLWH.

## Related tools

- **scBONITA** (Infers Boolean regulatory rules per KEGG pathway per cell type and runs pathway analysis (pathwayAnalysis.py) to flag dysregulated pathways in each condition) — https://github.com/Thakar-Lab/scBONITA
- **KEGG** (Source of hsa pathway topologies (e.g., hsa00010, hsa00020) used as the networks over which cross-condition dysregulation is scored)
- **conda** (Provides the pinned scBonita environment (spec-file) needed to run rule inference and pathway analysis reproducibly)
- **SLURM** (Executes the sbatch jobs generated by scBONITA setup for rule inference on large (>10G RAM) scRNA-seq datasets)

## Examples

```
python3.6 pathwayAnalysis.py --dataFile "data/trainingData.csv" --conditions "data/conditions.txt" --contrast "data/contrast.txt" --conditions_separator "comma" --contrast_separator "comma" --pathwayList "hsa00010"
```

## Evaluation signals

- The analysis reproduces the paper's qualitative result that cell migration pathways are dysregulated in the early stages of HIV infection
- The per-cell-type dysregulated pathway sets (cytotoxic T cells and monocytes) are consistent with the published scBONITA pathway-analysis findings for the SCP256 dataset
- The shared-pathway intersection is reportable as counts of optimized pathways, e.g., 5 pathways in cytotoxic T cells and 5 of 19 optimized pathways in monocytes
- The summary table (scp256_pathway_analysis_results.csv) contains dysregulation calls for every optimized pathway per condition per cell type
- Metadata cell IDs match expression-matrix column IDs, and contrast file conditions correspond to columns of the conditions file

## Limitations

- Small sample size (four AS+ and four AS- subjects) can limit the power of the study
- Technical limitations of scRNA-seq cause nonspecific distortions of expression and fewer detected differences across conditions; DE methods are prone to false discoveries
- scBONITA inference is expected to improve when pure cell populations are sequenced, since current data are mixed PBMC subpopulations
- Pre-classified subpopulations were used rather than scBONITA's own clustering; results may vary with clustering method
