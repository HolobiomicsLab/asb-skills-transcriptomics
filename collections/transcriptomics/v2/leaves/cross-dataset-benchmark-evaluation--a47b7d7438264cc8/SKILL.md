# cross-dataset-benchmark-evaluation

## Summary

Benchmark a cell type classifier across ordered training-test pairs built from independently generated scRNA-seq datasets, comparing against baseline methods via repeated stratified hold-out splits. Used to quantify cross-platform (e.g., full-length-read vs UMI) robustness of annotation methods.

## When to use

Use when a classifier's robustness must be benchmarked across multiple independently sequenced scRNA-seq datasets (e.g., 6 cross-platform human pancreas training-test pairs), comparing 2+ annotation methods by mean classification accuracy.

## When NOT to use

- Input is a single dataset with only one train/test split — the multi-pair repeated-splits design and cross-platform comparison cannot be meaningfully applied
- The question is about SciBet's false-positive control on unseen cell types (GSE108989 T-cell negative-control scenario) rather than method-vs-method accuracy benchmarking
- Datasets lack authoritative cell type annotations, since supervised training of SciBet, Seurat v3, and scmap all depends on ground-truth labels

## Inputs

- Annotated scRNA-seq count matrices from multiple datasets with distinct GEO accessions (e.g., four human pancreas datasets from Supplementary Table 2, generated by different sequencing technologies)
- Cell type labels for each dataset
- Ordered list of training-test dataset pairs (direction matters for cross-platform evaluation)

## Outputs

- Mean accuracy table (e.g., 6 pairs × SciBet/Seurat v3/scmap), such as fig3a_benchmark_accuracy.csv
- Per-repeat classification accuracy values averaged over 50 stratified 7:3 splits

## How to apply

Download each dataset by its GEO accession and normalize per technology: TPM plus pseudo-value one with log-normalization for full-length read data, or size-factor 10,000, add one, log normalization for UMI data. For each ordered dataset pair, form stratified 7:3 train/test splits without replacement using sklearn's model_selection.train_test_split with imbalanced-learn RandomUnderSampler down-sampling, repeating the entire procedure 50 times. Train each method on the training set — e.g., run SciBet's SelectGene to rank genes by the ΔS statistic and Learn a Laplace-smoothed multinomial model on the top 500 genes — then classify the held-out test set with all methods (SciBet's Bet, Seurat v3's FindTransferAnchors + TransferData, and scmapCluster ignoring unassigned cells). Compute per-repeat accuracy per method per pair and average over the 50 repeats to obtain a mean accuracy matrix (pairs × methods). Rationale: averaging 50 repeated splits controls for sampling variance, and ordering pairs by direction (train→test) exposes technology-shift sensitivity that within-platform benchmarks hide.

## Related tools

- **SciBet** (Method under test: SelectGene ranks genes by ΔS statistic (top 500 by default), Learn fits the Laplace-smoothed multinomial model, Bet classifies held-out cells) — github.com/PaulingLiu/scibet
- **Seurat v3** (Baseline annotation method: identifies anchors and transfers labels with FindTransferAnchors and TransferData)
- **scmap** (Baseline annotation method: classifies with scmapCluster, ignoring unassigned cells)
- **scikit-learn (sklearn)** (Provides model_selection.train_test_split for the stratified 7:3 hold-out splits)
- **imbalanced-learn** (Provides under_sampling.RandomUnderSampler for the down-sampling strategy applied during split generation)

## Examples

```
devtools::install_github("PaulingLiu/scibet"); acc <- sapply(pairs, function(p) mean(replicate(50, {tr <- train_test_split(p); Bet(test, Learn(tr, SelectGene(tr, 500))})$label == test$label))
```

## Evaluation signals

- Output table contains all dataset pairs (e.g., 6) and all method columns (SciBet, Seurat v3, scmap) with mean accuracies in [0,1]
- Method ordering reproduces the reported result: SciBet's mean accuracy ranks at or above Seurat v3's, which ranks above scmap's
- Every train/test split is stratified 7:3 and repeated 50 times; per-repeat accuracies are averaged, not single-split values
- Normalization scheme matches technology per dataset: TPM + pseudo-count one + log for full-length reads; size-factor 10,000, add one, log for UMI
- Cross-platform pairs use distinct sequencing technologies; SciBet remains robust across all ordered pairs

## Limitations

- No seed or randomization parameters are reported for the 50 repeated splits, complicating exact bit-level reproduction
- Software versions for sklearn, imbalanced-learn, Seurat v3 minor version, and scmap are not specified
- scmap results depend on ignoring unassigned cells, which changes the effective denominator vs. methods that classify every cell
- Four of the 16 benchmark datasets are only enumerated in Supplementary Table 5, not in the section body
