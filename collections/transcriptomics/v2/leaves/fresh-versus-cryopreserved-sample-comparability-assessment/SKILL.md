# fresh-versus-cryopreserved-sample-comparability-assessment

## Summary

A benchmarking skill for quantifying whether a freeze-thaw cycle (cryopreservation) compromises droplet-based 3' scRNA-seq profiling of PBMCs, by downsampling reads to equal mean reads per cell, re-running Cell Ranger, and comparing average gene-expression correlation and per-cell detection statistics.

## When to use

Use when deciding whether cryopreserved (frozen-thawed) PBMC or similar single-cell suspensions can be substituted for fresh specimens in droplet scRNA-seq profiling and cell-type classification, or when comparing two sample preparations for sequencing-depth-matched equivalence.

## When NOT to use

- The question is about biological differences between conditions rather than technical comparability of a preparation method — normalization-based differential analysis (e.g. Seurat) is the wrong frame here only when comparability, not differential expression, is the goal
- Input libraries cannot be downsampled to a common mean reads per cell (e.g. only aggregated count matrices without raw reads), since depth-matched re-counting via Cell Ranger is essential to the design
- Samples were generated with heterogeneous earlier protocols (e.g. 5 nt UMI and 5 bp Read2 libraries), confounding preparation effects with protocol differences

## Inputs

- Raw sequencing reads (FASTQ/BAM) for fresh and cryopreserved PBMC scRNA-seq libraries (e.g. SRA SRP073767)
- Precomputed gene-barcode matrices from support.10xgenomics.com/single-cell/datasets
- hg19 human reference genome for Cell Ranger/STAR alignment

## Outputs

- Matched-depth gene-barcode matrices regenerated by Cell Ranger
- Pearson correlation coefficient of average gene expression between fresh and cryopreserved cells (target r=0.96)
- downsampling_comparison.csv containing genes-per-cell and UMI-per-cell statistics with two-sided t-test P-values (expected P=0.8 and P=0.1)

## How to apply

Obtain the gene-barcode matrices and raw sequencing data for the fresh and cryopreserved preparations (here, 68k fresh PBMCs and ~3k cryopreserved Donor A PBMCs from SRA SRP073767 / support.10xgenomics.com/single-cell/datasets). Randomly downsample reads from each library (e.g. with sambamba or samtools view -s) so both datasets share the same mean reads per cell, removing depth as a confounder. Re-run the Cell Ranger counting pipeline (STAR alignment to hg19, barcode correction at posterior probability >= 0.975, 1-Hamming-distance UMI correction, MAPQ=255 non-duplicate read filter) on the downsampled reads to regenerate matched gene-barcode matrices. Compute the Pearson correlation of average gene expression between fresh and cryopreserved cells across the downsampled matrices, and separately recompute detected genes and UMI counts per cell in each preparation, testing differences with two-sided t-tests. The rationale is that equalizing depth isolates preparation effects from sequencing-depth effects before declaring comparability.

## Related tools

- **Cell Ranger Single-Cell Software Suite** (Re-run sample demultiplexing, barcode processing and single-cell 3' gene counting on downsampled reads to produce matched gene-barcode matrices) — https://www.10xgenomics.com/support/software/cell-ranger/downloads
- **STAR** (Aligns Read1 (cDNA insert) to the hg19 reference genome inside the Cell Ranger counting step)
- **Seurat** (Downstream analysis environment for the log-transformed gene-cell-barcode matrix (e.g. variable-gene selection, cell-type comparison)) — https://github.com/10XGenomics/single-cell-3prime-paper

## Examples

```
samtools view -s 0.5 fresh.bam > fresh_ds.bam && cellranger count --id=donorA_frozen_ds --transcriptome=hg19 --fastqs=frozen_fastq
```

## Evaluation signals

- Recomputed Pearson correlation of average gene expression between fresh and cryopreserved Donor A cells reproduces the reported r=0.96
- Two-sided t-test for genes per cell is non-significant (expected P=0.8)
- Two-sided t-test for UMI counts per cell is non-significant (expected P=0.1)
- Downsampled libraries have equal mean reads per cell (verified after sambamba/samtools view -s subsampling)
- Cell Ranger re-counting applied the paper's filters: barcode posterior probability >= 0.975, 1-Hamming UMI correction, MAPQ=255 non-duplicate reads

## Limitations

- Cell assignment by correlation can be low-confidence for closely related populations (e.g. cytotoxic T vs NK cells) because the difference between highest and second-highest correlations is small
- Earlier libraries used 5 nt UMI and 5 bp Read2, introducing protocol heterogeneity that can confound cross-library comparisons
- Cell counts carry 15-20% error, which contributes variability to derived per-cell and capture-efficiency comparisons
