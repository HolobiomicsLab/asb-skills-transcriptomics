# scrna-seq-fusion-candidate-statistical-testing

## Summary

Reconstructs scFusion's zero-inflated negative binomial (ZINB) regression significance testing that distinguishes true gene fusions from technical-noise background in scRNA-seq chimeric-read counts, followed by resampling-based p-values and FDR control.

## When to use

Use when a candidate fusion feature table with per-cell supporting chimeric-read counts, partner-gene expression covariates, and GC-content values must be tested against a background-noise distribution to assign p-values and FDR estimates.

## When NOT to use

- Input is raw FASTQ reads rather than an already-extracted candidate fusion count feature table — alignment and candidate calling with the scFusion.py pipeline must happen first
- Data are from 10X droplet protocols — scFusion is designed for Smart-Seq data rather than 10X
- The goal is only coarse filtering of artifact candidates via mappability or ad hoc filters rather than statistical significance testing

## Inputs

- Candidate fusion feature table with per-cell fusion candidate supporting-read counts
- Gene-expression covariates for fusion partner genes (e.g., from the Smart-Seq expression matrix)
- GC-content values near candidate fusion breakpoints
- Reference GTF annotation file (*.gtf) used upstream by pyensembl for gene metadata

## Outputs

- fusion_zinb_pvalues.csv with candidate identifiers, raw p-values, and FDR estimates
- Fitted ZINB regression parameters (logit zero-inflation component; log count-mean component with linear and spline terms)
- Resampling null distribution statistics per candidate

## How to apply

Load the candidate fusion feature table containing per-cell counts, gene-expression covariates, and local GC content near the breakpoints. Fit a zero-inflated negative binomial regression per the Methods equations 1-4: a logit link models the zero-inflation (dropout) component and a log link models the count-mean component, with linear gene-expression covariates and spline (nonlinear) terms for GC content. Compute resampling-based p-values by repeatedly refitting the model on resampled/permuted data and comparing the observed statistic against the resampling null distribution. Apply the false discovery rate control procedure across all candidate p-values to produce adjusted FDR estimates, since scFusion employs this statistical model (together with a deep-learning model) to control false positives from artificial chimeric reads generated by the heavy amplification step.

## Related tools

- **scFusion** (Pipeline whose statistical model defines the ZINB regression and resampling-based significance testing implemented here) — https://github.com/ZijieJin/scFusion
- **Python 3** (Runtime for fitting the ZINB regression and computing resampling p-values)
- **R** (Scripting environment used by the scFusion pipeline (requires R >= 3.5))
- **pyensembl** (Python module for Ensembl reference gene/transcript metadata used in building candidate features) — https://github.com/openvax/pyensembl

## Examples

```
Rscript -e 'fit <- MASS::glm.nb(counts ~ expr1 + expr2 + splines::ns(gc, df=3), data=cand); p <- resample_pvalue(fit, cand); fdr <- p.adjust(p, method="BH"); write.csv(data.frame(id=cand$id, p, fdr), "fusion_zinb_pvalues.csv", row.names=FALSE)'
```

## Evaluation signals

- Every test candidate receives a p-value in [0,1]
- Every test candidate receives a corresponding FDR estimate in [0,1]
- fusion_zinb_pvalues.csv contains candidate identifiers, raw p-values, and FDR estimates for all input candidates
- Resampling refits reproduce a null distribution broad enough that most noise candidates receive non-significant p-values (low false discovery rate as reported in simulations)
- Spline terms for GC content and linear terms for partner-gene expression are present in the fitted count-mean model per Methods equations 1-4

## Limitations

- scFusion has reduced sensitivity for fusions with low expression, as shown in the simulation, just as is the case for all RNA-based methods
- Detection power is limited for rare fusions in highly heterogeneous tumor samples
- These inherent limitations can be overcome only by sequencing more cells and/or sequencing each cell deeper
