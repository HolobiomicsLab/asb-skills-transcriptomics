# pseudobulk-dispersion-mean-analysis

## Summary

A simulation-fidelity diagnostic from the muscat paper that aggregates simulated and reference multi-sample scRNA-seq counts to pseudobulk per sample and subpopulation, then compares dispersion-mean trends to verify that simulations anchored to a reference dataset (e.g., Kang PBMC control samples, ExperimentHub EH2259) faithfully reproduce sample-to-sample variability.

## When to use

Use when validating that a scRNA-seq simulation anchored to a reference SingleCellExperiment reproduces sample-to-sample variability, specifically by checking whether pseudobulk dispersion-mean trends match between simulated and reference data.

## When NOT to use

- Data are not multi-sample scRNA-seq counts with sample and subpopulation annotations — dispersion-mean comparison of pseudobulks requires sample-level structure
- The goal is differential state testing (use pbDS/mmDS) rather than simulation fidelity assessment
- Only simulated data are available without a reference dataset to compare against

## Inputs

- Reference SingleCellExperiment (e.g., Kang PBMC control samples, ExperimentHub EH2259) with sample_id, group_id, and cluster_id colData columns
- Simulated multi-sample scRNA-seq counts generated by muscat's simData
- Raw count assay (counts) in SingleCellExperiment format

## Outputs

- Pseudobulk count matrices per sample and subpopulation (output of aggregateData)
- Dispersion-mean trend comparison between simulated and reference pseudobulks
- Mean-dropout and mean-variance relationship comparisons
- countsimqc_report.html fidelity report (via countsimQC, Supplementary File 1)

## How to apply

Load the reference SingleCellExperiment (e.g., Kang PBMC control samples via Bioconductor ExperimentHub, EH2259) and generate simulated multi-sample counts with muscat's simData, which is anchored to the reference dataset's characteristics. Aggregate both simulated and reference counts to pseudobulk per sample and subpopulation using aggregateData (sum of counts by cluster_id and sample_id). Compute mean-variance and mean-dropout relationships and compare pseudobulk dispersion-mean trends between the two datasets, confirming that simulated sample-to-sample variability tracks the reference. Optionally fold the comparative diagnostics into a countsimQC fidelity report saved as countsimqc_report.html. The analysis is judged faithful when dispersion-mean trends of pseudobulks are consistent between simulated and reference data.

## Related tools

- **muscat** (Provides simData for reference-anchored simulation and aggregateData for summing counts to pseudobulk per cluster_id and sample_id prior to dispersion-mean comparison) — https://github.com/HelenaLC/muscat
- **R** (Analysis environment in which muscat simulation, pseudobulk aggregation, and countsimQC reporting are executed)
- **Snakemake** (Workflow engine used in the paper to run simulation replicates)
- **countsimQC** (Assembles comparative diagnostics (mean-dropout, mean-variance, count distributions) between simulated and reference data into an HTML fidelity report)

## Examples

```
pb <- aggregateData(sce, assay = "counts", fun = "sum", by = c("cluster_id", "sample_id"))
```

## Evaluation signals

- Pseudobulk dispersion-mean trends of simulated data visually and quantitatively track those of the reference dataset (Supplementary Fig. 1a in the paper)
- Mean-dropout and mean-variance relationships of simulated vs. reference data are consistent as verified by countsimQC (Supplementary File 1)
- aggregateData output contains one pseudobulk value per gene per cluster_id × sample_id combination, summed over cells
- Simulated data retain the reference's sample-to-sample variability, confirming the anchor was respected by simData

## Limitations

- The simulation framework is anchored to a single reference dataset and does not yet accommodate an arbitrary number of groups or hierarchical type genes
- Other simulation scenarios of interest (e.g., different percentages of DM mixtures) were not tested, so fidelity conclusions are scenario-dependent
- Fidelity claims rest on characteristics like mean-dropout, mean-variance, and dispersion-mean trends; unmodeled features (e.g., batch effects) may not be reproduced
