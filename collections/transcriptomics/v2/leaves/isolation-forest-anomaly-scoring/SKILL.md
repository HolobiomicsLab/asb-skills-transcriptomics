# isolation-forest-anomaly-scoring

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Reconstructs scCAD's per-cluster rarity quantification: for each merged (M-)cluster, a candidate DE gene list is fed into an isolation forest to compute cell anomaly scores, and an independence score (IS) from the overlap of highly abnormal cells with the cluster flags rare cell types at threshold I=0.7.

## When to use

Use when quantifying the rarity of M-clusters after cluster decomposition/merging in scRNA-seq data, i.e., scoring how anomalous cells are on a cluster's differential genes and calling rare clusters via an independence score.

## When NOT to use

- Data has not yet gone through scCAD's cluster decomposition and merge steps — without M-cluster assignments there is no per-cluster differential gene set to score
- The goal is de novo rare-cell discovery from raw counts; filtering (genes in ≥3 cells), log-normalization with size factors, PCA (40 PCs), KNN graph (k=15), and Louvain clustering must precede this skill
- Clustering artifacts are trusted labels of biological cell types — a high IS flags statistical rarity, and the paper notes scCAD can correct rare-type annotations, so flagged clusters require biological review

## Inputs

- Preprocessed scRNA-seq expression matrix (cells x genes), e.g., h5py-loaded 1%Jurkat.h5 with 'X', 'Y', 'gn', 'cn' arrays (1540 293T cells and 16 Jurkat cells)
- M-cluster (sub-cluster) cell assignments from scCAD's decomposition/merge stage
- Optional cell names and gene names (auto-generated by scCAD if not provided)

## Outputs

- Per-cluster independence scores in [0, 1]
- Rare-cluster assignments (sub-clusters with IS_i > 0.7, returned as a list of cell indices/names)
- Candidate DE gene lists per rare sub-cluster (degs_list)
- Results file(s) such as independence_scores.csv when save_full=True

## How to apply

Load the preprocessed expression matrix (cells x genes, e.g., from 1%Jurkat.h5 via h5py) and M-cluster assignments. For each M-cluster i, compute the per-gene median difference d_k = |median(X_Ci^k) - median(X_Ci'^k)| between cells inside and outside the cluster and take the top 20 genes as the candidate set S_i. Restrict the expression matrix to S_i, fit an isolation forest (scikit-learn, e.g., version 1.0.2), and compute anomaly scores AS_j^Si = 2^(-E(h(j))/c(n)) with c(n) = 2H(n-1) - 2(n-1)/n and H(n-1) ≈ ln(n-1) + 0.5772156649 (Euler-Mascheroni constant). Rank all cells by anomaly score, take the top N_i cells as T_Ni, and compute IS_i = |T_Ni ∩ C_i| / N_i; clusters with IS_i > 0.7 (the paper's default threshold I) are flagged as rare cell clusters together with their candidate DEG lists. Write per-cluster independence scores, rare-cluster assignments, and DEG lists (e.g., to independence_scores.csv); in the packaged API these correspond to the returned score, sub_clusters, and degs_list objects.

## Evaluation signals

- All computed independence scores fall within [0, 1]
- Clusters flagged as rare are exactly those with IS_i > 0.7 (the paper's default threshold I=0.7)
- Each M-cluster's candidate gene set contains exactly the top 20 genes by inside-vs-outside median expression difference
- On the 1%Jurkat.h5 demo (1540 293T cells + 16 Jurkat cells), the flagged rare sub-cluster cells are dominated by Jurkat labels when checked against ground-truth 'Y' labels via Counter(labels[indices])
- Output file (e.g., independence_scores.csv) exists and contains per-cluster scores, rare-cluster assignments, and DEG lists when save_full=True

## Limitations

- The independence score threshold I=0.7 is a default applied across all datasets in the paper; datasets with unusual cluster structure may need recalibration
- Only clusters larger than R=1% of cells are decomposed further, so sub-1% structure below the rare_h threshold is not re-examined by this scoring step
- Random seed (default 2023) affects isolation-forest results; non-reproducibility across seeds indicates sensitivity
- Anomaly scoring depends on the quality of the candidate DE gene list — poor differential genes yield uninformative scores; the paper reports >86% of selected genes on average were rare cell type-specific in benchmarks
