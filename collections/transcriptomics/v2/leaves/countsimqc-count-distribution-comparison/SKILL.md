# countsimQC-count-distribution-comparison

## Summary

Validate the realism of simulated single-cell RNA-seq count matrices by comparing them to a real scRNA-seq reference with countsimQC, focusing on per-gene mean-variance distributions and fraction of zeros. In this paper it is the acceptance gate before using simulated counts to assess CTMM's robustness to sequencing depth and number of cells.

## When to use

Use when simulated single-cell count matrices must be checked against a real scRNA-seq reference (e.g., Cuomo et al. 2020 iPSC data) on per-gene mean-variance and zero-fraction distributions before downstream analyses.

## When NOT to use

- The input data are already aggregated to pseudobulk (OP/CTP) or otherwise normalized summary matrices rather than raw single-cell count matrices — countsimQC compares per-gene count distributions at the single-cell level
- The goal is to evaluate CTMM's statistical performance (power, calibration, bias) from the simulations rather than to validate the realism of the simulated counts themselves
- No real reference scRNA-seq dataset exists to serve as the comparison baseline, so no concordance assessment can be made

## Inputs

- Quality-controlled, normalized single-cell counts from the real iPSC differentiation reference (Cuomo et al. 2020 Nat Commun, processed via bin/cuomo)
- Cell-level metadata: cell, individual, cell type
- Single-cell-level simulated count matrices generated by the bin/sim scripts (parameterized from the real data, Supplementary Note Section 3.4)

## Outputs

- countsimqc_report.html — HTML report comparing per-gene mean-variance distribution and per-gene fraction of zeros between simulated and real data
- Accept/reject decision on simulation realism (gate before robustness simulations for sequencing depth and number of cells)

## How to apply

Load the quality-controlled, normalized single-cell counts and cell-level metadata (cell, individual, cell type) for the real iPSC differentiation data from Cuomo et al. 2020 Nat Commun, processed by the bin/cuomo scripts of the Minhui-Chen/CTMM repository. Run the simulation scripts in bin/sim (orchestrated by the repository's Snakefile via Snakemake) to generate single-cell-level simulated count matrices parameterized from the real data, per Supplementary Note Section 3.4. Then run countsimQC in R, invoked through the same Snakemake pipeline, to compare each simulated dataset against the real iPSC reference on per-gene distributions. Inspect the countsimQC report for concordance in (1) the mean-variance distribution and (2) the fraction of zeros per gene between simulated and real data, as displayed in Supplementary Fig. 10, and write the final comparison to countsimqc_report.html. Accept the simulation only if the report shows simulated counts closely matching the real iPSC data on both criteria, reproducing the agreement seen in Supplementary Fig. 10; otherwise the simulated counts must not be used for the robustness assessments.

## Examples

```
snakemake -s Snakefile  # runs bin/sim simulations and the countsimQC comparison, writing countsimqc_report.html
```

## Evaluation signals

- The countsimQC report shows simulated counts closely matching the real iPSC data in the mean-variance distribution, reproducing Supplementary Fig. 10
- The countsimQC report shows concordance in the fraction of zeros per gene between simulated and real data
- The final HTML comparison report is written to countsimqc_report.html
- The simulation is parameterized from the same real iPSC reference (Cuomo et al. 2020) processed by the bin/cuomo scripts
- The validation gate is passed before the simulated counts are used to assess CTMM's robustness to sequencing depth and number of cells

## Limitations

- Validation relies on visual/report inspection of distributional concordance (mean-variance, zero fraction); it does not by itself establish CTMM's power or calibration in the simulated settings
- Realism is assessed relative to a single reference dataset (Cuomo et al. 2020 iPSC differentiation), so conclusions may not transfer to other tissues, technologies, or cohorts (e.g., OneK1K)
- The validation step is embedded in the paper-specific Snakemake pipeline (Snakefile + bin/sim + bin/cuomo) and would need adaptation for other simulation frameworks
