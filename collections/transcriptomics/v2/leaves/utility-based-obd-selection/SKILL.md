# utility-based-obd-selection

## Summary

Stage-2 component of the TSNP two-stage nonparametric phase I/II design for immunotherapy: within the toxicity-admissible dose set, select the optimal biological dose (OBD) by maximizing a utility function U(pi_jkl_hat, omega_kl) that weights the four joint toxicity-efficacy outcomes by physician-elicited desirability scores.

## When to use

Use when running or reproducing a phase I/II immunotherapy dose-finding trial/simulation that must pick an OBD by jointly balancing binary DLT and efficacy outcomes via a utility function, after a toxicity-exploration stage has defined an admissible dose set.

## When NOT to use

- The response outcome is binary but requires long follow-up to be assessed; the article states the design 'cannot be applied directly to cases in which the response outcome requires a long follow-up time to be assessed.'
- The trial is a drug-combination study; extending TSNP to drug-combination trials is explicitly future work, not yet done.
- The goal is conventional MTD-targeting phase I monotherapy dose escalation without joint toxicity-efficacy utility-based OBD selection.

## Inputs

- Number of pre-specified increasing doses J (e.g., J = 5)
- Highest acceptable DLT rate phi (e.g., phi = 0.3) and CCD cut-off tau
- Desirability scores omega_kl on the (0,100) scale (omega_01 = 100, omega_10 = 0, elicited omega_00 and omega_11)
- Admissibility levels cT (toxicity, Fisher's exact test) and cE (efficacy futility)
- Stage-1 cohort size m and maximum total sample size (e.g., 30 with m = 6)
- Accumulated per-dose counts of joint toxicity-efficacy outcomes (no toxicity/no response, toxicity only, response only, both)
- True joint toxicity-efficacy response probabilities per dose generated by crossratio() or Gumbel() for simulation scenarios

## Outputs

- Per-dose utility values U(pi_jkl_hat, omega_kl) for doses in the final admissible set
- Final OBD recommendation (e.g., dose 4 with utility 46.67 in the illustrative trial) or a no-dose recommendation if the admissible set is empty
- Per-dose patient-assignment percentages and Monte Carlo OBD-selection percentages from simulations (e.g., 64.6% for TSNP vs 37.4% P1 and 60.0% P2 in scenario 1, phi = 0.3)
- Result tables/CSV files such as tsnp_example_trial_result.csv or tsnp_uboin_simulation_results.csv

## How to apply

First complete stage 1 (cumulative cohort design): treat cohorts starting at the lowest dose, compute isotonic toxicity estimates with the pool-adjacent-violators algorithm (PAVA), escalate if p_hat_j <= phi - tau, de-escalate if p_hat_j >= phi + tau (retaining otherwise), and build the admissible set using Fisher's exact tests with nominal level cT; if the admissible set is empty, terminate early and recommend no dose. In stage 2, iteratively update the admissible set from accumulated data, escalate if the highest tried dose j* is safe, and otherwise assign the next cohort to the dose maximizing the utility U(pi_jkl_hat, omega_kl), where pi_jkl_hat is the closed-form nonparametric MLE of the joint toxicity-efficacy probabilities under the monotonic toxicity constraint and omega_kl are desirability scores with omega_01 = 100 and omega_10 = 0 fixed and omega_00, omega_11 elicited on the (0, 100) scale. Continue until the maximum sample size is reached; at trial end, compute utility values for all doses in the final admissible set and recommend the highest-utility dose as the final OBD. Run simulations in R (from github.com/yongzang2020/TSNP) generating true joint probabilities with crossratio() or Gumbel(), and compare OBD-selection percentages and patient-assignment percentages against comparator designs such as P1 (Thall et al.) and P2 (Yin et al.) or U-BOIN.

## Examples

```
Rscript run_tsnp_stage2.R --phi 0.3 --J 5 --omega01 100 --omega10 0 --maxN 30 --m 6
```

## Evaluation signals

- Reproduced OBD-selection percentages for TSNP, P1, and P2 match Tables 1-2 values within Monte Carlo error (e.g., scenario 1, phi = 0.3: TSNP 64.6%, P1 37.4%, P2 60.0%).
- Reproduced illustrative trial matches the reported outcome: no dose declared overly toxic (all doses in the admissible set) and dose 4 attains the maximum utility of 46.67 and is recommended as the OBD.
- Under Gumbel copula scenarios (association parameter 0.2, Table 3), TSNP OBD-selection and patient-assignment percentages are comparable to U-BOIN: U-BOIN slightly better in scenarios 1-2, TSNP better in the other two.
- Isotonic estimates from PAVA satisfy the monotonic order constraint and are equivalent to the MLE of p_j under that constraint.
- Sanity checks: no patient assigned outside the admissible set in stage 2; if the admissible set becomes empty the trial terminates early and recommends no dose.

## Limitations

- The design is limited to trials in which the response outcome is binary and observable shortly after treatment initiation.
- It cannot be applied directly when the response outcome requires long follow-up to assess.
- Extension to phase I/II drug-combination trials (optimal dose combination) is future work and not yet available.
- The Shiny app providing a graphical user interface is still under development, so users currently rely on the R code.
