# covid19-epithelial-immune-communication-interpretation

## Summary

Reproduces the InterCellar COVID-19 multi-condition comparison (Fig. 5b, c): uploading CellChat-derived CCI datasets from critical vs non-critical COVID-19 patients into InterCellar, filtering the gene-verse to CXC- and CC-chemokine ligand-receptor pairs, and computing phenotype-unique int-pair/cluster-pair couplets in epithelial and immune (macrophage/NK/T cell) clusters.

## When to use

Use when you have pre-computed CellChat CCI outputs for multiple COVID-19 phenotypes (control, moderate, critical) and need to quantify chemokine couplets unique to each condition per cell cluster.

## When NOT to use

- Input is raw scRNA-seq count data rather than pre-computed, inferred ligand-receptor interactions — InterCellar's workflow builds upon pre-computed CCI data uploaded in the first step
- CCI data was generated by a tool outside InterCellar's supported set (CellChat, CellPhoneDB, ICELLNET, SingleCellSignalR), since input options are currently limited
- Only a single condition/dataset is available — the skill requires InterCellar's multi-condition comparison to define condition-unique couplets

## Inputs

- Pre-computed CellChat-derived CCI dataset files for critical COVID-19 patients
- Pre-computed CellChat-derived CCI dataset files for non-critical (control, moderate) COVID-19 patients
- InterCellar-supported CCI upload format (ligand-receptor interaction tables from CellChat, CellPhoneDB, ICELLNET, or SingleCellSignalR)

## Outputs

- Dot plots of phenotype-unique CXCL/CCL chemokine couplets per cell cluster (epithelial, macrophage/MoMa, NK, T cell) corresponding to Fig. 5b
- Pie charts summarizing proportions of unique int-pair/cluster-pair couplets favoring each condition (Fig. 5c)
- Validated percentages of unique couplets (47% epithelial, 57% immune CXCL unique to critical; 56% macrophage, 41% NK, 20% T cell)

## How to apply

Upload the pre-computed, inferred ligand-receptor interactions (CellChat-derived CCI data for critical and non-critical patients) into InterCellar as CCI datasets. In the gene-verse, use the interactive filtering options to subset interactions to the CXC- and CC-chemokine subfamilies. Run the multi-condition comparison functionality to compute int-pair and cluster-pair couplets uniquely found in each phenotype within epithelial and macrophage/NK/T cell clusters. Generate dot plots of phenotype-unique chemokine couplets per cell cluster and pie charts summarizing the proportion of unique couplets favoring each condition. The rationale is that InterCellar's multi-condition analysis highlights patterns of communication uniquely found in each condition, enabling biological interpretation without programming. Validate against the reported values: 47% epithelial and 57% immune CXCL couplets unique to critical; 56% macrophage, 41% NK, 20% T cell favoring critical.

## Evaluation signals

- Reproduced CXCL couplet proportions match the reported values: 47% unique to critical in epithelial cells and 57% in immune cells
- Reproduced proportions of unique interactions favoring the critical phenotype match 56% for macrophages, 41% for NK cells, and 20% for T cells
- Validation confirms CCL4L2 usage in MoMa, CCL7 usage in nrMa, and the absence of rMa CCL3 in COVID-19
- Output tables/figures are downloadable via InterCellar's reproducibility download options, allowing diff against the martaint/InterCellar-reproducibility repository data
- Couplet classification covers both int-pair and cluster-pair couplets uniquely found in each phenotype (control, moderate, critical)

## Limitations

- InterCellar currently supports only a limited set of input tools (CellChat, CellPhoneDB, ICELLNET, SingleCellSignalR); extension to other published tools is planned future work
- Predicted interactions await experimental validation, e.g., by single-molecule fluorescence in situ hybridization or flow cytometry co-occurrence
- Predicted interactions rely on different reference databases and statistical assumptions, so results depend on the upstream CCI inference tool
