# circrna-transcript-structure-construction-from-bsj

## Summary

Constructs circular transcript structures from back-spliced junction (BSJ) records by integrating a CircAST-compatible junction list with UCSC hg19 GTF exon annotation, optionally introducing randomly skipped exons to generate isoform variants for simulation ground truth.

## When to use

Use when back-spliced junction records (e.g., 2923 Hs68 BSJs from SRA SRR444974 in CircAST junction-list format) must be converted into full circular transcript structures on a UCSC hg19 GTF annotation.

## When NOT to use

- The goal is de novo reconstruction of full-length circRNA sequences from reads — use CircAST assembly on splice graphs instead of template-based structure construction
- The target circRNAs are intronic or intergenic — the CircAST pipeline assembles only exon-annotated circular transcripts
- Only raw FASTQ reads are available without prior BSJ detection by CIRCexplorer2/CIRI2/UROBORUS or a convertible junction list

## Inputs

- Back-spliced junction records (e.g., from SRA: SRR444974 Hs68 data) in CircAST-compatible junction-list format
- UCSC hg19 GTF gene annotation file (UCSC-compatible GTF, e.g., from hgdownload.soe.ucsc.edu)
- Optionally, isoform abundance settings for multi-condition panels

## Outputs

- Circular transcript structures (exon chains per BSJ locus) on hg19 coordinates
- Isoform variant transcripts generated by random exon skipping
- Theoretical expression abundances per circular transcript (ground truth)

## How to apply

Extract BSJ records (e.g., the 2923 Hs68 back-spliced junctions from SRA: SRR444974) and convert them into CircAST-compatible junction-list format (the format produced by CIRCexplorer2/CIRI2/UROBORUS). Map each BSJ onto the UCSC hg19 GTF annotation to define the circular transcript's exon chain between the back-splice acceptor and donor. Where multiple isoforms are required, introduce randomly skipped exons within the circular span to create isoform variants, then assign theoretical expression abundances to each circular transcript (e.g., all 2923) as ground truth for downstream simulation or quantification. Use the same GTF file for structure construction and any downstream CircAST run, as the README requires the GTF to be identical across pipeline steps.

## Related tools

- **CircAST** (Consumes the junction list and GTF; its junction-list format and UCSC-compatible GTF define the schema for constructed circular transcript structures) — https://github.com/xiaofengsong/CircAST
- **CIRCexplorer2** (Upstream tool generating circRNA back-spliced junction lists that feed structure construction)
- **CIRI2** (Alternative upstream detector of back-spliced junctions (result.txt output convertible to CircAST format))
- **UROBORUS** (Alternative upstream detector of back-spliced junctions (circRNA_list.txt output))

## Examples

```
python CircAST.py -L 100 -T 5 -G /home/***/circRNA/Gene/genes.gtf -F accepted_hits.sorted.sam -J circRNA_list.txt
```

## Evaluation signals

- Constructed transcript count matches the expected 2923 circular transcripts from the 2923 Hs68 BSJ records
- Each circular transcript's exon chain is consistent with the UCSC hg19 GTF annotation at the BSJ donor/acceptor coordinates
- Isoform variants differ only by skipped exons within the circular span, matching the 10-isoform/4-loci (NOLC1, PAFAH1B2, DHPS, EXOSC10) panel design when applied
- Junction list parses in CircAST's expected format (as produced by CIRCexplorer2/CIRI2/UROBORUS) without format-conversion errors
- Theoretical abundances assigned to every circular transcript sum consistently per condition and serve as finite ground truth for simulation

## Limitations

- Structure construction is limited to exon-annotated circular transcripts; intronic or intergenic circular transcripts cannot be represented
- Remnant linear mRNA contamination can generate false transcript structures downstream of construction
- The GTF used for construction must be identical to the one used by CircAST and upstream BSJ detectors
