# single-cell-transcriptomics-data-handling

## Summary

Handles single-cell transcriptomics data generated by dyngen — a multi-modal simulator producing single-cell, single-transcript resolution profiles together with ground-truth cell-specific regulatory networks — for downstream benchmarking tasks such as cell-specific gene regulatory network inference (CSNI).

## When to use

Use when input consists of dyngen-simulated single-cell transcriptomics profiles (e.g. the 42 dyngen datasets from 14 backbones × 3 seeds) with paired cell-specific ground-truth GRNs, for network inference benchmarking.

## When NOT to use

- The input is real experimental single-cell RNA-seq data without ground-truth cell-specific regulatory networks — quantitative AUROC/AUPR evaluation against a known GRN is not possible
- The underlying inference method requires motif data (e.g. PANDA), since dyngen provides no motif data
- The task is trajectory alignment or RNA velocity evaluation rather than cell-specific regulatory network inference

## Inputs

- 42 dyngen benchmark datasets (14 predefined backbones × 3 seeds), each with a single-cell transcriptomics profile and a cell-specific ground-truth regulatory network
- Normalised expression matrix as provided by dyngen

## Outputs

- Cell-specific inferred GRNs with top 10,000 retained interactions per cell
- Per-dataset mean AUROC and mean AUPR scores (e.g. lioness_pearson_auroc_aupr.csv with 42 rows)

## How to apply

Load each dyngen dataset containing a transcriptomics profile and its corresponding cell-specific ground-truth regulatory network; dyngen generates these by translating a gene regulatory network into reactions (regulation, transcription, splicing, translation), simulating cells with Gillespie's SSA, and emulating single-cell omics profiling from real reference datasets. Use the normalised expression data as provided by dyngen with no extra cell or feature filtering, matching parameters to tutorial vignettes. Since dyngen provides no motif data, choose a network inference method that does not require motifs (e.g. Pearson correlation as the base method for LIONESS via lionessR, rather than PANDA). Run the CSNI method per dataset, retain the top 10,000 interactions from each cell-specific inferred GRN, and compute AUROC and AUPR per cell against the ground truth; average per-cell scores into mean AUROC and mean AUPR per dataset. Write the per-dataset scores (e.g. lioness_pearson_auroc_aupr.csv) and validate 42 rows with values in [0, 1].

## Related tools

- **dyngen** (Simulator producing single-cell transcriptomics profiles and paired ground-truth cell-specific regulatory networks used as benchmark input) — https://github.com/dynverse/dyngen
- **lionessR** (Implementation of LIONESS used to infer cell-specific GRNs with Pearson correlation as the underlying method)
- **pySCENIC** (Comparison CSNI method that outperforms LIONESS on mean AUROC and AUPR in the benchmark)

## Examples

```
Rscript -e 'library(dyngen); model <- initialise_model(backbone=braitenberg); sim <- generate_dataset(model); write.csv(compute_mean_auroc_aupr(sim), "lioness_pearson_auroc_aupr.csv")'
```

## Evaluation signals

- Output CSV (e.g. lioness_pearson_auroc_aupr.csv) contains exactly 42 rows, one per dyngen dataset
- Both mean AUROC and mean AUPR columns are present and all values fall within the valid [0, 1] range
- Per-cell scores were computed before averaging into per-dataset mean AUROC and mean AUPR
- Only the top 10,000 interactions per cell were retained from the inferred cell-specific GRN
- Comparative ranking reproduces the expected ordering: pySCENIC > LIONESS > SSN on mean AUROC and mean AUPR

## Limitations

- dyngen assumes cells are well-mixed and independent from each other
- No quantitative assessment of CSNI method performance existed prior to this work; conclusions rest on simulated ground truth
- No software version numbers are reported for any tool, so exact reproducibility of versions is not documented
- LIONESS only achieves a higher AUROC than SSN on a few datasets; pySCENIC significantly outperforms it
