# clustering-benchmark-evaluation

## Summary

Benchmark a clustering method (e.g., Forest Fire Clustering) against baselines like SC3, Seurat, KMeans, GMM, DBSCAN, OPTICS, and SpectralClustering using purity scores, adjusted Rand index, silhouette scores, and one-sided Wilcoxon signed-rank tests on paired per-dataset scores.

## When to use

Use when a clustering method must be validated against baselines on datasets with known ground-truth labels (Splatter-simulated scRNA-seq, synthetic ring/half-moon/Gaussian-mixture shapes), and purity/ARI plus paired significance testing are needed.

## When NOT to use

- Input data has no reference/ground-truth labels for any dataset, so purity and adjusted Rand index cannot be computed — internal validation (FFC.validate/entropy/pval) is the wrong substitute for external benchmarks here.
- The goal is biological discovery on one real experimental dataset (e.g., PBMC or MCA cell-type assignment), not controlled method comparison against baselines.
- Data are continuous, unlabeled streams where only label-confidence metrics (posterior significance, entropy) matter and no baseline method comparison is required.

## Inputs

- Simulated scRNA-seq count matrices with known cell-type labels generated by R Splatter (discrete cell types and continuous trajectories)
- Synthetic [sample x feature] numeric matrices from sklearn/numpy: unit-circle Gaussian mixtures (sigma=0.15, sigma=0.2), ring-shaped and half-moon datasets (n=500-1000, fixed random seeds)
- Reference (ground-truth) label vectors used for data generation

## Outputs

- Purity score table (rows = methods, columns = datasets) saved as purity_scores.csv
- ARI, purity, Wilcoxon significance statistics, and per-dataset runtimes saved as benchmark_comparison_results.csv

## How to apply

Simulate benchmark data with known ground truth: discrete cell-type scRNA-seq via the R package Splatter (e.g., 20 datasets with 5 cell types) and synthetic shapes via sklearn (unit-circle Gaussian mixtures with sigma=0.15 and sigma=0.2, ring and half-moon shapes, n=500-1000, fixed random seeds). Run the method under test on each dataset — for FFC, call FFC().preprocess(X) on the [sample x feature] matrix, then fit(fire_temp=100) — and run each baseline with its default recommended settings on identical inputs. Compute sklearn.metrics.adjusted_rand_score and cluster purity against the reference labels used for data generation, assembling a methods-x-datasets purity table (e.g., purity_scores.csv). Assess significance with one-sided Wilcoxon signed-rank tests on paired per-dataset ARI values (e.g., FFC vs SC3 yielded P = 9.5e-7), and record wall-clock runtime per dataset for computational comparison. Correct application is judged by the results table reproducing reported values (e.g., GMM purity 0.5 on ring-shaped and 0.85 on half-moon data) and consistent significance outcomes.

## Related tools

- **scikit-learn (sklearn)** (Generates synthetic ring/half-moon/Gaussian-mixture benchmark datasets and provides KMeans, GaussianMixture, DBSCAN, OPTICS, SpectralClustering baselines plus adjusted_rand_score for evaluation) — https://github.com/gersteinlab/forest-fire-clustering
- **Splatter** (R package used to simulate discrete cell-type (5 types) and continuous trajectory scRNA-seq benchmark datasets with ground-truth labels)

- **R** (Runtime environment for running Splatter simulations and the SC3/Seurat baseline clusterings with default recommended settings)

## Examples

```
from sklearn.metrics import adjusted_rand_score; ari = adjusted_rand_score(true_labels, pred_labels)
```

## Evaluation signals

- purity_scores.csv exists and contains per-method/per-dataset purity values, reproducing reported anchors (GMM purity 0.5 on ring-shaped and 0.85 on half-moon data; FFC attaining top scores)
- benchmark_comparison_results.csv contains ARI, purity, Wilcoxon P-values, and runtime columns for every method and dataset
- One-sided Wilcoxon signed-rank test on paired per-dataset ARIs of FFC vs SC3 reproduces significance at P = 9.5e-7
- Identical dataset instances (same seeds, same preprocessed matrices) are fed to every method, so per-dataset ARI values are strictly paired for the signed-rank test
- Ground-truth label vector lengths match each dataset's sample count before purity/ARI computation

## Limitations

- Benchmark conclusions depend on simulated data properties; Splatter-generated discrete cell types may not reflect real experimental structure such as developmental trajectories.
- Purity and ARI require reference labels, so this evaluation cannot be applied to real datasets without curated cell-type annotations.
- Runtime comparisons are wall-clock measurements and are sensitive to implementation language differences (R baselines vs Python FFC).
