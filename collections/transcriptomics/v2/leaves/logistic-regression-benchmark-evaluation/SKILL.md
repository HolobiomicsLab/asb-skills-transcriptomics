# logistic-regression-benchmark-evaluation

## Summary

Benchmark Logistic Regression (scikit-learn, default hyperparameters) under repeated 5-fold cross-validation across all 15 non-empty feature-mode combinations (A=Ps-k-mer, B=PsM(G)D, C=PsD(G)M, D=PsM(G)M(G)M plus GC-content) to produce an ablation metrics table replicating Table 3 of the iRNA5hmC-PS paper.

## When to use

Use when you must quantify how each of several engineered feature modes (position-specific k-mer/gapped k-mer descriptors plus GC-content) contributes to classifier performance via cross-validated Accuracy, Precision, Sensitivity, Specificity, F1-Score, and MCC.

## When NOT to use

- The goal is comparing classifiers (LR vs SVM vs GNB) on a single fixed feature set rather than ablating feature-mode combinations.
- The input is already a model evaluation output or metrics table rather than a raw feature matrix.
- The task requires evaluating on an independent test set instead of cross-validation ablation.

## Inputs

- All_Features_Dataset.csv (feature matrix generated from Dataset.csv by Feature Generation.ipynb)
- Feature-mode combination specification (15 non-empty subsets of modes A, B, C, D plus GC-content)
- Group-wise feature importance selection strategy applied per combination

## Outputs

- table3_ablation_results.csv — 15-row table of Accuracy, Precision, Sensitivity, Specificity, F1-Score, MCC with standard deviations per feature-mode combination

## How to apply

Load All_Features_Dataset.csv (generated by Feature Generation.ipynb from Dataset.csv) with pandas. For each of the 15 non-empty combinations of the four position-specific feature modes A (Ps-k-mer), B (PsM(G)D), C (PsD(G)M), and D (PsM(G)M(G)M) together with the GC-content feature, assemble the feature matrix and label vector. Apply the paper's group-wise feature importance calculation strategy to select the discriminative feature subset per combination, then train a scikit-learn Logistic Regression classifier with default hyperparameters under 10-times 5-fold cross-validation. Compute Accuracy, Precision, Sensitivity, Specificity, F1-Score, and MCC (with standard deviations) from the cross-validation predictions and write the 15-row table to table3_ablation_results.csv.

## Evaluation signals

- The A+B+C+D (all four modes plus GC-content, with group-wise selection) row reproduces the paper's Table 3 values: Accuracy 78.3, Precision 78.0, Sensitivity 80.0, Specificity 79.5, F1-Score 0.78, MCC 0.56, within expected cross-validation variation.
- table3_ablation_results.csv contains exactly 15 rows, one per non-empty combination of the four feature modes.
- Every metric row includes both a mean and a standard deviation from the 10-times 5-fold cross-validation runs.
- MCC values fall roughly in the 0.4–0.6 range expected for this dataset; full-combination MCC should be the highest (~0.56).

## Limitations

- The paper reports the headline LR result on 50-times 5-fold cross-validation, whereas this ablation task specifies 10-times 5-fold cross-validation, so exact value reproduction is subject to cross-validation variation.
- Position-specific features did not combine well with existing frequency-based features in single models; the authors defer frequency + position-specific combination to future work using a feature subspace ensemble approach.
- Logistic Regression with default hyperparameters was the paper's best choice for the full feature set, but per-combination rankings may shift under different CV seeds or regularization settings.
