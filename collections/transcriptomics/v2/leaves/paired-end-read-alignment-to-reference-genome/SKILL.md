# paired-end-read-alignment-to-reference-genome

## Summary

Aligns synthetic paired-end reads (e.g., minnow's two FASTQ files) to the same mm10 reference genome used for real scRNA-seq data, so synthetic coverage can be directly compared with already-aligned real BAM files in genomic windows.

## When to use

Use when synthetic scRNA-seq reads exist as unaligned FASTQ files (e.g., minnow output) and must be placed in genomic coordinates on mm10 to compare coverage against an aligned real BAM.

## When NOT to use

- The reads are already genome-aligned, e.g., scReadSim's synthetic output is a BAM file already aligned to the reference genome
- The goal is count-level comparison using gene-by-cell UMI count matrices, which requires no read alignment

## Inputs

- Two FASTQ files containing paired-end synthetic reads (minnow output: read 1 with cell barcode and UMI, read 2 with RNA sequence)
- mm10 reference genome (chromosome size file embedded in scReadSim package)

## Outputs

- Genome-aligned BAM file of synthetic paired-end reads in mm10 coordinates
- Per-window read coverage tracks (e.g., 1000-bp bins on chromosome 1) for correlation analysis

## How to apply

In the scReadSim vs minnow benchmark, minnow consumes the synthetic gene-by-cell UMI count matrix generated by scReadSim and outputs paired-end synthetic reads as two FASTQ files; because these FASTQs lack coordinates, they must be aligned with bowtie2 to the same mm10 reference genome used by the real mouse 10x Multiome data. scReadSim's own synthetic output is a BAM file already aligned to the genome, so it needs no alignment step. After alignment, both synthetic datasets are binned (e.g., chromosome 1 into 1000-bp windows) and per-window read coverage is summed for real, scReadSim, and minnow data, enabling Spearman (0.930 scReadSim vs 0.065 minnow) and Pearson correlation computation. The rationale is that coverage similarity can only be measured when all datasets share a genomic coordinate system.

## Related tools

- **bowtie2** (Aligns minnow's synthetic paired-end FASTQ files to the same mm10 reference genome used for the real data)
- **minnow** (Produces the unaligned paired-end FASTQ synthetic reads that require alignment; fed scReadSim's synthetic gene-by-cell UMI count matrix with default parameters)
- **scReadSim** (Generates synthetic reads as a genome-aligned BAM file, serving as the already-aligned comparison arm) — https://github.com/JSB-UCLA/scReadSim

## Examples

```
bowtie2 -x mm10 -1 minnow_read1.fastq -2 minnow_read2.fastq -S minnow_aligned.sam
```

## Evaluation signals

- Spearman correlation of per-window (1000-bp, chromosome 1) read coverage between real and scReadSim synthetic data should be close to 0.930
- Spearman correlation between real and minnow synthetic data should be close to 0.065
- Aligned synthetic BAM coordinates should fall on the same mm10 chromosome size reference used for the real data
- Coverage tracks plotted per window should be directly comparable to real-data coverage in an IGV browser style (e.g., chr1:86,425,858-86,443,378 inset)

## Limitations

- minnow generates scRNA-seq reads only from annotated genes, so aligned synthetic reads cannot resemble real scRNA-seq data in intergenic regions
- The default implementation of scReadSim may generate intronic synthetic reads when extracting sequences from the reference genome, affecting downstream alignment-based benchmarks
