# chimeric-read-artifact-modeling

## Summary

Modeling of artificial chimeric reads generated by the heavy amplification step of scRNA-seq (Smart-Seq), so that gene fusions shared across multiple single cells can be distinguished from amplification artifacts using scFusion's statistical model plus a deep-learning model.

## When to use

Use when detecting gene fusions from Smart-Seq scRNA-seq FASTQ data where PCR amplification produces artificial chimeric reads that inflate false-positive fusion candidates.

## When NOT to use

- Input is bulk RNA-seq data or 10X scRNA-seq data — scFusion is designed for Smart-Seq single-cell data rather than 10X
- FASTQ files are named *_1.fq / *_2.fq — the pipeline explicitly disallows the .fq extension
- The goal is detecting fusions with very low expression or rare fusions in highly heterogeneous tumor samples — all RNA-based methods, including scFusion, have reduced sensitivity there

## Inputs

- Smart-Seq paired-end scRNA-seq FASTQ files named *_1.fastq / *_2.fastq (fq extension not allowed)
- Reference genome FASTA (e.g. hg19.fa, ~3G)
- GTF annotation file (from Ensembl, NCBI, or UCSC)
- hg19 mappability file (UCSC), optional — scFusion turns off the mappability filter if absent
- Simulated scRNA-seq FASTQ files with spiked-in chimeric fusion reads (ground truth) for benchmarking

## Outputs

- Per-cell and per-sample gene fusion calls with artifact-filtered confidence scores
- Precision, recall, and F-score metrics against simulation ground truth (e.g. benchmark_results.csv)
- Ablation comparison (deep-learning model on vs. off) quantifying the precision gain

## How to apply

Align Smart-Seq paired-end FASTQ files (*_1.fastq, *_2.fastq) with STAR (>= 2.7.2d) against hg19 with GTF annotation, process BAM files with samtools and bedtools, and run scFusion.py jointly across all single cells. Exploit the rationale that multiple cells from a sample should contain the same fusion, applying a statistical model and a deep-learning model (tensorflow/keras) to control false positives, plus a mappability filter using the hg19mappability file from UCSC. Validate by simulation (e.g. FusionSimulatorToolkit spiking 1% artificial chimeric reads into 500- or 1000-cell datasets at 2-4 million reads per cell): turning off the deep-learning model should reduce precision by roughly 0.049-0.168 while losing less than 0.04 sensitivity. Compare against bulk callers such as Arriba, STAR-Fusion, FusionCatcher, and EricScript, which on simulated single-cell data reached precisions of only 0.434-0.503 versus scFusion's 0.921.

## Evaluation signals

- On simulated single-cell data with spiked 1% chimeric reads, scFusion should reach precision ~0.921 and F-score ~0.925 at recall comparable to bulk callers whose precision stays in the 0.434-0.503 range
- Ablation check: removing the deep-learning model must reduce precision (reported gain of 0.049-0.168 when it is on) with sensitivity loss below 0.04
- Real-fusion sanity checks: invariant TCR recombinations (e.g. TRAV1-2 fusions in MAIT cells) and the recurrent IgH-WHSC1 fusion in multiple myeloma should be recovered
- File-naming and environment invariant: inputs are *_1.fastq/_2.fastq, STAR >= 2.7.2d, samtools >= 1.0, bedtools 2.29.2, R >= 3.5 with stringr, Python 3 with pyensembl, pysam, tensorflow/keras
- Repeated runs across 10 simulation replicates should yield stable precision/recall aggregated in benchmark_results.csv

## Limitations

- Reduced sensitivity for fusions with low expression, common to all RNA-based methods
- Limited detection power for rare fusions in highly heterogeneous tumor samples; overcoming this requires sequencing more cells and/or deeper sequencing per cell
- Some true events are missed: TRAJ20-TRAV1-2 was not identified possibly because it was rare in MAIT cells, and scFusion did not find WHSC1 fusions in single cells from RRMM2
