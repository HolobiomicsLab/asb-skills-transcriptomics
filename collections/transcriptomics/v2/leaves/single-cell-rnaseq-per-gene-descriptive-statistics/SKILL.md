# single-cell-rnaseq-per-gene-descriptive-statistics

## Summary

Evaluates how faithfully synthetic scRNA-seq data reproduces per-gene univariate expression distributions by comparing medians, interquantile ranges, coefficients of variation, and proportion of zero counts between original and synthetic count matrices, and visualizing failures such as bimodal genes (e.g., CD74 in PBMC4k).

## When to use

Use when comparing synthetic scRNA-seq datasets against original count matrices to quantify per-gene distribution fidelity and to expose failures such as unreproduced bimodal gene distributions.

## When NOT to use

- When the goal is clustering-quality assessment (ARI, Davies–Bouldin index, cluster proportions) rather than per-gene distribution fidelity — use the corresponding clustering evaluation skill instead.
- When the input data are already aggregated summary statistics rather than per-cell count matrices, since medians, IQRs, CVs, and zero-count proportions must be recomputed per gene.

## Inputs

- Original scRNA-seq count matrices (PBMC4k, Segerstolpe)
- Synthetic count matrices from scDBM, scVI prior, and scVI posterior per pilot size (384–2304 cells) and 30 sub-sampling replicates
- Gene names file (e.g., segerstolpe_gene_names.csv)

## Outputs

- Aggregated MAD table res_mad_descriptive_stats.csv (model x pilot size x metric)
- Exemplary-gene distribution comparison figure res_bimodality_cd74.png

## How to apply

Load the original count matrices (PBMC4k and Segerstolpe) together with the synthetic datasets generated by scDBM (Gibbs sampling), scVI prior, and scVI posterior for each pilot size (384, 768, 1152, 1536, 1920, 2304 cells). For each gene in both original and synthetic data, compute the median, interquartile range, coefficient of variation, and proportion of zero counts. Calculate the mean absolute deviation (MAD) per gene for each of the four statistics between synthetic and original data, aggregating over the 30 sub-sampling replicates per pilot size, and store the results ordered by model, pilot size, and metric. Finally, plot marginal univariate distributions of exemplary genes (e.g., CD74 from PBMC4k) comparing original against synthetic data to highlight where bimodality is lost.

## Evaluation signals

- res_mad_descriptive_stats.csv contains all four metrics (median, interquartile range, coefficient of variation, proportion of zero counts) for the three models across the six pilot sizes (384–2304 cells).
- res_bimodality_cd74.png shows that synthetic CD74 distributions in PBMC4k fail to capture the bimodal pattern present in the original data, consistent with the paper's Supplementary Fig. 3.
- MAD values are aggregated over 30 sub-sampling replicates per pilot size and ordered by model, pilot size, and metric.
- Most genes show small MADs, with the CD74 bimodality failure emerging as a documented exception rather than a systematic artifact of the computation.

## Limitations

- All approaches (scDBM, scVI prior, scVI posterior) learn the univariate distribution of most genes but frequently fail to reproduce bimodal gene distributions, exemplified by CD74 in PBMC4k.
- For 10x Genomics datasets (e.g., PBMC4k), which have higher sparsity, inference from small to larger datasets is more challenging than for Smart-seq2 (Segerstolpe) data.
- Evaluation of synthetic data quality is difficult, with sometimes ambiguous conclusions when based on multiple quality measures.
