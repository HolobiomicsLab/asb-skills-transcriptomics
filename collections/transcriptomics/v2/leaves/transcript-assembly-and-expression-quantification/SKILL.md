# transcript-assembly-and-expression-quantification

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Assembles RNA-Seq alignments into potential transcripts and quantifies their expression (TPM) so that neoantigens arising from unexpressed genes can be filtered out. This is the gene-expression module (module 4) of the TSNAD v2.0 neoantigen prediction pipeline.

## When to use

Use when RNA-Seq fastq files from a tumor sample must be aligned and quantified to gene/transcript TPM values that will filter neoantigen candidates from unexpressed genes (TPM < 1).

## When NOT to use

- When input is WES/WGS (not RNA-Seq) data — those samples are handled by the somatic-mutation modules (BWA/GATK) rather than HISAT2/StringTie.
- When the goal is gene fusion detection rather than expression quantification — TSNAD uses STAR + Arriba for fusion calls, a different module.

## Inputs

- RNA-Seq fastq files (tumor sample)
- Human reference genome (GRCh37 or GRCh38)

## Outputs

- Sorted BAM file of RNA-Seq alignments (from SAMtools)
- gene_expression_results.tsv — parseable table with transcript and gene TPM values

## How to apply

First align the RNA-Seq fastq reads for the tumor sample to the human reference genome (GRCh37 or GRCh38) using HISAT2 v2.2.1. Convert the HISAT2 SAM output to sorted BAM format with SAMtools v1.13 to reduce the storage footprint. Then run StringTie v2.1.6 on the sorted BAM to assemble the alignments into potential transcripts and quantify expression, reporting transcript and gene TPM values. The resulting gene_expression_results.tsv is a parseable table containing TPM values for transcripts/genes, and is used downstream to remove neoantigens generated by mutations in unexpressed genes (TPM < 1).

## Related tools

- **HISAT2** (Aligns RNA-Seq reads to the human reference genome (GRCh37/GRCh38) before quantification)
- **SAMtools** (Converts HISAT2 SAM output to sorted BAM format to reduce storage footprint)
- **StringTie** (Assembles RNA-Seq alignments into potential transcripts and quantifies gene/transcript expression (TPM))
- **TSNAD v2.0** (Parent pipeline that orchestrates HISAT2 and StringTie as its gene-expression analysis module) — https://github.com/jiujiezz/tsnad

## Examples

```
docker run -it -v [dir of WES/WGS]/:/home/tsnad/samples -v [dir of RNA-seq]:/home/tsnad/RNA-seq -v [output dir]:/home/tsnad/results biopharm/tsnad:latest /bin/bash
```

## Evaluation signals

- The output file gene_expression_results.tsv exists and is a parseable table.
- The table contains TPM values for transcripts/genes such that downstream filtering at the paper's TPM < 1 unexpressed-gene threshold can be applied.
- HISAT2 output was successfully converted to a valid sorted BAM file (SAMtools return code 0, BAM header present).
- The reference genome version used (GRCh37 or GRCh38) matches the one passed via the TSNAD.py -V flag so downstream modules use consistent coordinates.

## Limitations

- The TSNAD Docker image can be used both in Linux and Windows but the GitHub (source) install path is Linux-only.
- The expression filter removes neoantigens from genes with TPM < 1, so mutations in lowly or non-expressed genes will have their neoantigen candidates dropped even if potentially valid — a threshold-dependent trade-off.
- The README does not document a separate changelog or version history, so version-specific behavior changes may not be discoverable from documentation alone.
