# single-nucleotide-variant-classification-of-small-rnas

## Summary

Hierarchical classification and quantification of small RNA-seq reads into miRNAs and isomiRs with single-nucleotide precision, using tiny-count's selection rules that filter by 5′ nucleotide, length, alignment position relative to reference features, and mismatch number.

## When to use

Use when demultiplexed small RNA-seq FASTQ reads must be resolved into distinct features such as miRNAs vs isomiRs (or piRNAs vs siRNAs from the same locus) at single-nucleotide precision, rather than counted as a single aggregated miRNA category.

## When NOT to use

- Input is already a feature-level counts matrix — no read-level classification is needed
- Quantifying full-length bulk RNA-seq transcripts rather than small RNA reads (miRNAs, isomiRs, piRNAs, siRNAs, tRNA/rRNA fragments)
- The question only requires total miRNA abundance and does not need isomiR/single-nucleotide variant resolution

## Inputs

- demultiplexed small RNA-seq reads (FASTQ or FASTQ.gz)
- reference annotations in GFF3/GFF2/GTF with ID/gene_id/Parent tags
- reference genome (FASTA) with chromosome identifiers matching the annotation
- tinyRNA Run Config, Paths File, Features Sheet, and Samples Sheet

## Outputs

- collapsed FASTA files
- per-sample counts matrix of miRNA and isomiR features (counts and pipeline statistics)
- differential expression table for miRNA/isomiR features (e.g., isomir_differential_expression.csv)
- plots generated by the tinyRNA workflow

## How to apply

Align the FASTQ reads to a reference genome (or directly to small RNA/transcript sequences) and run tiny-count with user-defined hierarchical selection rules supplied via the tinyRNA Features Sheet, filtering reads by 5′ nucleotide, length, position of alignments relative to GFF3/GTF reference features, and number of mismatches; the hierarchy lets reads map to distinct classes produced from the same locus. Aggregate per-sample counts into a counts matrix of miRNA and isomiR features across all libraries, then optionally run the tinyRNA end-to-end workflow's R-based differential expression step to test feature abundance between conditions (e.g., control vs knockout) and emit a differential expression table. Rationale: hierarchical rules avoid collapsing isomiR signal into the canonical miRNA, enabling detection of variants like those upregulated in ZSWIM8-knockout libraries that conventional counting misses.

## Related tools

- **tiny-count** (performs the hierarchical classification and quantification of small RNA reads with selection rules) — https://anaconda.org/bioconda/tiny-count
- **tinyRNA** (all-in-one command-line workflow that coordinates tiny-count with pre-processing, differential expression, and plots via CWL) — https://github.com/MontgomeryLab/tinyRNA
- **R** (implements the tinyRNA differential expression statistics step applied to the counts matrix)

## Examples

```
conda activate tinyrna; tiny run
```

## Evaluation signals

- Counts matrix contains separately quantified isomiR features alongside canonical miRNA features rather than a single aggregated miRNA category
- Pipeline statistics outputs are produced for each library, consistent with the tinyRNA end-to-end run
- Selection rules demonstrably filtered on 5′ nucleotide, length, alignment position relative to reference features, and mismatch number
- Distinct small RNA classes from the same locus (e.g., piRNAs vs siRNAs) are resolved into separate features
- Differential expression table (CSV) flags isomiR features significantly upregulated in the knockout condition (e.g., ZSWIM8 knockout) that were absent from prior aggregated analyses

## Limitations

- FASTQ input files must be demultiplexed
- Reference annotations: Parent tags with multiple values are not yet supported, and FASTA chromosome identifiers are case sensitive and must match the annotation file
- Stable tinyRNA installation may fail on Apple Silicon–based systems; the development release addresses this
- An existing conda environment and its extra packages are removed when the tinyRNA installation script is rerun to update
