# autoencoder-training-on-sparse-counts

## Summary

Train an autoencoder de novo on highly sparse scRNA-seq count matrices using LATE (Learning with AuToEncoder), treating zeros as missing values and leveraging gene/cell dependence to impute them. Runs on TensorFlow 1.x with Python 3.5+ and scales to 1M+ cells on a GPU.

## When to use

Use when scRNA-seq count data are highly sparse (typically >80-95% zeros) and the goal is to recover true expression behind dropout zeros via autoencoder-based imputation with no reference dataset.

## When NOT to use

- When a labeled reference gene expression dataset is available and transfer learning initialization is desired — use TRANSLATE (pre-training + translate steps) instead of de novo LATE
- When zeros must be distinguished into biological vs technical zeros — LATE assumes all zeros are missing values and always imputes zeros with a nonzero value
- When only TensorFlow 2 is available — LATE is not compatible with TF2 and requires a TensorFlow 1.x (1.0-1.4) environment

## Inputs

- scRNA-seq count matrix in csv, tsv, or 10x Genomics h5 (sparse matrix) format with cell IDs as row names and gene IDs as columns
- 10x Genomics mouse brain h5 (example_mouse_brain_10x.h5, 10,000 genes x 10,000 cells subset, genes in rows and cells in columns) or human PBMC example.hd5 (10,000 genes and 10,000 cells)

## Outputs

- Imputed data matrix in hd5 format stored at step2/imputation.step2.hd5, on the log10(count+1) scale with the same layout as the input
- step2/ folder generated by the 'late' mode; Eval/ folder generated by subsequent analysis mode

## How to apply

Create a virtual environment with TensorFlow 1.x (1.0-1.4, e.g. 1.15) since LATE is not compatible with TF2, plus numpy, pandas, scipy, tables and sklearn. Provide a count matrix in csv/tsv or 10x Genomics h5 format with genes and cells; for 10x h5 inputs (e.g. example_mouse_brain_10x.h5) explicitly specify the orientation (genes in rows, cells in columns). The input is log10(count+1)-transformed before imputation. Run LATE via example_late.py (or example_late_10x.py for 10x h5) with -mode='late', which randomly initializes parameters and trains the autoencoder on the input dataset with no reference data; parameters can be tuned in example*.py with defaults in global_params.py. The imputed matrix is written to step2/imputation.step2.hd5 on the log10(count+1) scale with the same layout as the input; follow with example_analysis.py -mode='analysis' to summarize and visualize results.

## Examples

```
python example_late_10x.py -mode='late' -infile='../data/example_mouse_brain_10x.h5'
```

## Evaluation signals

- The 'late' mode run completes and generates the step2/ folder containing imputation.step2.hd5
- Values in the output matrix are on the log10(count+1) scale and have the same layout (genes/cells orientation) as the input
- For the 10,000 genes x 10,000 cells mouse brain subset, a GPU run completes in a few hours' order of magnitude (paper reports the 1.3M-cell dataset imputed in under 11 hours on GPU vs 53.2 hours on CPU)
- Input data was correctly log10(count+1)-transformed and the orientation of 10x h5 inputs was explicitly specified before training
- Downstream analysis mode (example_analysis.py -mode='analysis') runs on step2/ and generates the Eval/ folder without errors

## Limitations

- LATE is not compatible with TensorFlow 2; a virtual environment with TensorFlow 1.x (e.g. 1.15) and pandas 0.25.1 is required
- All zeros are assumed to be missing values and are always imputed with a nonzero value; biological vs technical zeros are not distinguished
- Hyperparameters were manually tuned; systematic hyperparameter tuning (as implemented in DCA) was not explored
- In the current version, code must run where it is stored on your computer (from the scripts/ folder)
- When no ground truth exists (e.g. mouse brain data), the ground truth is set to be the same as the input, so accuracy cannot be assessed
