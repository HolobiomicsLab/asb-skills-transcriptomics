# nucleotide-one-hot-sequence-encoding

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Encode 101-base RNAseq windows centered on putative A-to-I editing sites as 8 x 101 feature matrices — 4 one-hot channels for the reference base plus 4 channels of log2-transformed, pseudocount-normalized RNAseq nucleotide pileup frequencies — as the input format for the REDInet temporal convolutional network.

## When to use

Use when converting tabix-indexed REDItools outTables into TCN input feature vectors for A-to-I RNA editing classification, i.e. when putative editing sites need 101-nt window encoding of reference base identity and RNAseq nucleotide frequencies.

## When NOT to use

- The REDItools outTable is not yet bgzip-compressed and tabix-indexed — run 'bgzip' and 'tabix -s 1 -b 2 -e 2 -c R' first, since REDInet requires tabix-indexed input
- The downstream model does not consume 8 x 101 window matrices (e.g. RED-ML or RDDpred, which expect raw BAMs and use their own feature representations)
- Only raw RNA editing detection without prior REDItools pileup tables is needed — this skill encodes pre-computed REDItools output, it does not generate pileups

## Inputs

- bgzip-compressed, tabix-indexed REDItools outTable (generated by REDItoolDnaRna.py or REDItools3)
- GRCh37 or GRCh38 reference genome FASTA (faidx-indexed, e.g. from GENCODE release 46)
- Filter thresholds: minimum coverage (e.g. 50), minimum number of A-to-G substitutions (e.g. 3), minimum A-to-G frequency (e.g. 0.01)

## Outputs

- <output_files_prefix>.feature_vectors.tsv — encoded feature vectors for sites with complete 101-nt intervals
- <prefix>_discarded.txt — positions excluded by the coverage/substitution filters
- <prefix>_incompleates.txt — positions with missing or strand-discordant interval nucleotides (logged as '0 *' / '0 **')

## How to apply

Load a bgzip-compressed, tabix-indexed REDItools outTable (indexed with 'tabix -s 1 -b 2 -e 2 -c R') via pysam/pandas, then apply REDInet default filters: minimum RNAseq coverage 50 (--C), minimum 3 guanosines substituting adenines (--M), and minimum A-to-G substitution frequency 0.01 (--F), logging excluded positions in <prefix>_discarded.txt. For each retained site, extract the 101-nucleotide window (50 bases upstream and 50 downstream, centered on the putative editing position) from the GRCh37 or GRCh38 reference genome, discarding intervals with missing or strand-discordant nucleotides (logged as '0 *'/'0 **' in <prefix>_incompleates.txt). Encode each complete window as an 8 x 101 matrix: rows 1–4 are one-hot channels for the reference base (A, C, G, T), and rows 5–8 hold log2-transformed normalized RNAseq nucleotide pileup frequencies computed with an alpha=0.0001 pseudocount. The rationale is that REDInet treats sequencing data like audio, so per-position nucleotide frequencies across the window become the 'signal' channels fed to the TCN without needing coupled WGS/WES data.


## Evaluation signals

- The output TSV <prefix>.feature_vectors.tsv exists and each feature vector corresponds to a complete 101-nt interval rendered as an 8 x 101 feature matrix
- Only sites passing the coverage/substitution filters (cov >= 50, >= 3 G substitutions, A-to-G frequency >= 0.01) appear in the feature vectors
- Positions failing the filters are recorded in <prefix>_discarded.txt (empty file if nothing was filtered)
- Intervals with missing or strand-discordant nucleotides are excluded from the feature vectors and logged as '0 *' / '0 **' in <prefix>_incompleates.txt
- The 4 reference-base channels are one-hot per position over {A, C, G, T}, and the 4 frequency channels are log2-transformed pileup frequencies with the alpha=0.0001 pseudocount

## Limitations

- Windows with missing or strand-discordant nucleotides cannot be encoded and are discarded (logged in <prefix>_incompleates.txt), so low-coverage regions yield no feature vectors
- Multiprocessing-version imputation of missing values is a BETA feature limited to hg38/hg19 reference genomes
- Only A-to-G substitutions at sites supported by RNAseq reads are encoded; other substitution classes are out of scope
