# developmental-trajectory-cell-sorting

## Summary

Reconstructs the pseudo-temporal ordering of individual cells along the developmental trajectories generated by Mpath, by projecting cells assigned to transitions between neighbouring landmark states onto the edges of the landmark graph. This final Mpath step is what reveals phase-dependent waves of gene regulation and proliferation-to-differentiation switches during development.

## When to use

Use when a Mpath landmark graph and cell-to-landmark transition assignments are available and a pseudo-temporal ordering of individual cells along each developmental path is required for downstream dynamics analysis.

## When NOT to use

- Development processes start from multiple independent progenitor cell types — Mpath does not yet support this (planned future extension)
- Highly heterogeneous single-cell data sets where specific subset information is unknown — Mpath is not yet extended to this setting
- You need trajectory inference without pre-defined landmark states; this skill orders cells on an already-constructed Mpath landmark graph rather than building trajectories from scratch

## Inputs

- Mpath landmark graph: landmark coordinates and connecting edges (R objects from the JinmiaoChenLab/Mpath package)
- Cell-to-landmark membership/transition assignments for cells transitioning between adjacent landmark pairs

## Outputs

- cell_ordering.csv containing cell identifier, path, edge, projection position, and pseudo-time rank, with every transitioning cell appearing exactly once
- A single concatenated pseudo-temporal ordering of cells per developmental path

## How to apply

Load the Mpath landmark graph (landmark coordinates and connecting edges) together with the cell-to-landmark membership/transition assignments produced by the upstream neighborhood-based trajectory-construction stage. For each pair of adjacent landmarks, select the cells assigned as transitioning between them, then compute the orthogonal projection of each cell onto the straight edge connecting its landmark pair. Sort the cells on each edge by their projection point coordinate to obtain a local ordering, and concatenate the per-edge ordered cell segments along each developmental path to yield a single pseudo-temporal ordering (cell identifier, path, edge, projection position, pseudo-time rank). The rationale is that Mpath derives multi-branching trajectories using neighborhood-based cell state transitions (count of neighbouring cells estimates potential state transitions), so projection-and-sorting along edges converts the graph topology into a continuous pseudo-time axis, e.g. along cDC development from macrophage/DC progenitors through CDP to preDC subsets.

## Related tools

- **Mpath** (R package providing the landmark graph and cell ordering of individual cells along the developmental trajectories) — https://github.com/JinmiaoChenLab/Mpath
- **R** (Execution environment for the Mpath package used to compute projections and per-edge cell orderings)

## Evaluation signals

- cell_ordering.csv contains every cell from the transitioning set exactly once (no duplicates or omissions)
- Within each edge, cell pseudo-time ranks are strictly monotonic in the recorded projection point coordinate
- Concatenated ordering respects path topology: per-edge local orderings are concatenated consistently along each developmental path
- Applied correctly to the cDC progenitor data, reordering should recapitulate the reported switch from proliferation to differentiation during DC maturation and phase-dependent waves of gene regulation

## Limitations

- Mpath does not yet support development processes starting from multiple independent progenitor cell types (planned future extension)
- Mpath is not yet extended to highly heterogeneous single-cell data sets where specific subset information is unknown (planned future extension)
- Mpath depends on signature genes of differentiated cell types (end-stage contrasts) and FACS-sorted terminal subsets for fate prediction, so ordering quality inherits those upstream dependencies
- Demonstrated utility limited to two data sets: mouse bone marrow-derived DC progenitors and primary human myoblasts
