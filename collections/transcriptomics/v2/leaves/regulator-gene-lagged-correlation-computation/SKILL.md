# regulator-gene-lagged-correlation-computation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Compute per-pair correlations between regulator features (e.g., ATAC-seq peaks) and target genes on simulated or real bulk multi-omics counts, including lagged correlations up to lag 2, to validate that modelled activator/repressor interactions are detectable. Serves as the ground-truth validation step for regulatory interactions generated by the bulk MOSim simulation.

## When to use

Use when you have bulk RNA-seq and regulatory omics count matrices plus a ground-truth regulator–gene interaction list and need to quantify how strongly each modelled interaction manifests as a correlation.

## When NOT to use

- Data are single-cell — the article specifies Kendall's Tb correlation for single-cell gene-regulator validation rather than lagged Pearson's correlations
- Interactions were not simulated and no ground-truth regulator–gene list exists — the null random-pair background and class labels cannot be constructed
- Goal is validating temporal/co-expression patterns of gene profiles — the article instead uses k-means clustering of simulated feature profiles for that purpose

## Inputs

- Simulated bulk RNA-seq count matrix (from the MOSim mosim function)
- Simulated bulk ATAC-seq (or other regulatory omics) count matrix
- Ground-truth regulator–gene interaction list with class labels (activator, repressor, no-effect)
- Experimental group/timepoint design (for per-group and lagged correlations)

## Outputs

- Per-pair correlation table (regulator, gene, correlation value, lag, class) written to regulator_correlation_validation.csv
- Class-level summary of fraction of pairs with |correlation| > 0.9 for activator, repressor, and no-effect classes
- Random-pair null distribution of correlations (20,000 pairs)

## How to apply

Load the simulated bulk RNA-seq and ATAC-seq count matrices together with the ground-truth regulator–gene interaction list, then apply a log(x+1) transformation to the counts as described in the MOSim methods. For each regulator–gene pair, compute Pearson's correlation per experimental group, extending the calculation to lagged correlations up to a maximum lag of 2 to capture temporal delays between regulator activity and gene expression. As a null background, compute the same correlations for 20,000 random feature pairs that carry no simulated regulatory effect. Summarize per interaction class (activator, repressor, no-effect) the fraction of pairs with |correlation| > 0.9 and compare modelled pairs against the random-pair background; in the ATAC-seq example this yielded 99.4% of modelled interactions above 0.9 versus 0% of no-effect pairs. Note that Pearson's correlation is the bulk-data choice; Kendall's Tb correlation is used for single-cell data.

## Related tools

- **MOSim** (R package generating the simulated bulk RNA-seq/ATAC-seq counts and the ground-truth active regulatory relationships that this correlation validation step evaluates) — github.com/ConesaLab/MOSim
- **R** (Implementation language for the log(x+1) transformation, per-group lagged Pearson's correlations, and random-pair null computation)

## Examples

```
log_counts <- log(counts + 1); r <- cor(regulator_vec, gene_vec, method = "pearson")
```

## Evaluation signals

- Class-level summary shows ~99.4% of modelled activator/repressor interactions with |correlation| > 0.9
- 0% of no-effect (random background) pairs reach |correlation| > 0.9
- Lagged correlations were computed up to a maximum lag of 2 for every regulator–gene pair
- Null background contains exactly 20,000 random feature pairs with no simulated regulatory effects
- Correlations were computed per experimental group on log(x+1)-transformed counts, and per-pair values plus class summaries are present in regulator_correlation_validation.csv

## Limitations

- Single-cell simulation is restricted to scRNA-seq and scATAC-seq, and validation there uses Kendall's Tb rather than lagged Pearson's correlation
- Correlation strength depends on MOSim having simulated the interaction; interactions without a modelled effect will show no elevated correlation by design
- Validation of the paper's own bulk data used k-means clustering of simulated feature profiles and Pearson's correlation; deviations from the simulated design (e.g., different numbers of replicates or timepoints) may change the achievable correlation ceiling
