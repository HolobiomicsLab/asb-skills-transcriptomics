# countsimQC fidelity assessment

## Summary

Assess whether muscat's simData framework, anchored to a reference scRNA-seq dataset, faithfully reproduces the reference's characteristics by generating a countsimQC report comparing mean-dropout, mean-variance, and pseudobulk dispersion-mean relationships.

## When to use

Use when simulating multi-sample multi-group scRNA-seq data anchored to a reference SingleCellExperiment and you must verify simulation fidelity against the reference before downstream method benchmarking.

## When NOT to use

- The input is bulk RNA-seq data rather than multi-sample single-cell data with cluster_id/sample_id metadata, since muscat's simData anchoring and pseudobulk aggregation rely on cell-level structure
- The goal is differential state analysis of real data (pbDS/mmDS) rather than validating simulated data fidelity
- No anchored reference dataset is available; the simulation framework is anchored to a reference and cannot be applied de novo

## Inputs

- Reference scRNA-seq SingleCellExperiment with sample_id, group_id, and cluster_id colData columns (e.g., Kang PBMC control samples, ExperimentHub EH2259)
- Simulated multi-sample SingleCellExperiment generated by muscat::simData anchored to the reference

## Outputs

- countsimqc_report.html fidelity report comparing simulated vs. reference mean-dropout and mean-variance relationships
- Pseudobulk dispersion-mean trend comparison between simulated and reference datasets (cf. Supplementary Fig. 1a)

## How to apply

Load the anchor reference SingleCellExperiment (e.g., Kang PBMC control samples EH2259 from Bioconductor's ExperimentHub) into R, then run muscat's simData to generate simulated multi-sample counts anchored to the reference's characteristics. Aggregate both simulated and reference counts to pseudobulk per sample and subpopulation using aggregateData (fun="sum", by c(cluster_id, sample_id)). Compute and compare mean-dropout and mean-variance relationships between simulated and reference data, and compare pseudobulk dispersion-mean trends to confirm sample-to-sample variability is reproduced. Assemble the comparative diagnostics into a countsimQC fidelity report (countsimqc_report.html). The rationale, per the muscat paper, is that the simulation 'mimics various characteristics of scRNA-seq data' and must be verified faithful before it can fairly evaluate DS analysis methods.

## Related tools

- **muscat** (Provides simData to generate reference-anchored simulated multi-sample scRNA-seq counts and aggregateData to compute pseudobulks for fidelity comparison) — github.com/HelenaLC/muscat
- **countsimQC** (Assembles comparative diagnostics of simulated vs. reference count characteristics into an HTML fidelity report)
- **R** (Language in which the simulation, aggregation, and countsimQC report generation are executed)
- **Snakemake** (Workflow manager built to run simulation replicates)

## Examples

```
sim <- simData(sce, nsim = 1); pb <- aggregateData(sim, assay = "counts", fun = "sum", by = c("cluster_id", "sample_id"))
```

## Evaluation signals

- countsimQC report shows simulated data overlapping the reference in mean-dropout and mean-variance relationships (Supplementary File 1 in the paper)
- Pseudobulk-level dispersion-mean trends of simulated data match the reference (Supplementary Fig. 1a)
- Sample-to-sample variability in simulated data is visually/statistically consistent with the reference pseudobulk dispersion
- Report file countsimqc_report.html is produced and covers both simulated and reference datasets
- Simulated data retain the multi-sample multi-group structure defined by the reference's sample_id/group_id metadata

## Limitations

- The simulation framework does not yet accommodate an arbitrary number of groups or hierarchical-type genes
- Other simulation scenarios of interest, e.g. different percentages of the DM mixtures, were not tested
- Fidelity was verified against specific characteristics (mean-dropout, mean-variance, dispersion-mean); other dataset properties are not guaranteed to be reproduced
