# semi-profiling-error-normalization

## Summary

Quantifies how closely AI-generated (semi-profiled) single-cell data match real-profiled data by normalizing a single-cell difference metric between lower and upper bounds, enabling fair comparison of scSemiProfiler against selection-only baselines across representative counts.

## When to use

Use when evaluating a semi-profiling or sample-inference pipeline on a cohort (e.g., COVID-19, representative counts 4–28) and you need a normalized error EN that is comparable across datasets and baseline schemes.

## When NOT to use

- You need cell-type-level accuracy metrics only — bulk deconvolution approaches (CIBERSORTx, Bisque, DWLS, MuSiC, NNLS) operate at cell-type-level resolution and this metric is designed for true single-cell resolution comparison
- The cohort lacks paired real-profiled ground-truth single-cell data, since EN requires comparing inferred data against real-profiled data in a common PCA space
- Modalities other than scRNA-seq — the article notes extension to proteomics is future work requiring algorithm adjustments and new benchmarking

## Inputs

- Real-profiled single-cell dataset for the cohort (e.g., COVID-19 dataset, 124 samples)
- Semi-profiled single-cell data generated by the scSemiProfiler pipeline (scprocess + scinfer VAE-GAN)
- Selection-only baseline single-cell data (representatives' cells copied to target samples, no model transformation)
- Representative counts to sweep (e.g., n = 4 to 28)

## Outputs

- error_curves.csv with normalized error EN values for scSemiProfiler and the selection-only baseline across representative counts 4–28
- Per-sample nearest-neighbor difference values in the 100-PC space

## How to apply

Reduce both the real-profiled and inferred single-cell datasets to 100 principal components with Scikit-learn PCA, then compute the single-cell difference metric as the average Euclidean distance of each cell to its K=1 nearest neighbor in the paired dataset. Compute the upper bound UB as the average single-cell difference of randomly paired samples from the PCA-reduced real-profiled data, and the lower bound LB as the difference between two random halves of the comprehensive PCA matrix. Normalize via EN = (mean_difference - LB) / (UB - LB) for both scSemiProfiler output (generated by K-Means-based setup, scprocess, and VAE-GAN scinfer) and a selection-only baseline that copies each representative's cells without deep generative transformation. Repeat across representative counts (e.g., 4 to 28) to trace error curves and confirm that semi-profiling error decreases with more representatives and stays below the selection-only baseline.

## Examples

```
from sklearn.decomposition import PCA; pcs = PCA(n_components=100).fit_transform(adata.X); EN = (mean_diff - LB) / (UB - LB)
```

## Evaluation signals

- At 28 representatives, the semi-profiling normalized error must be below the selection-only baseline's normalized error at 28 representatives
- The normalized error EN of scSemiProfiler should decrease monotonically (or near-monotonically) as representative count increases from 4 to 28
- The computed EN values must match the Fig. 2h Source Data file for the COVID-19 cohort
- EN must fall within the [0, 1] range by construction, since LB and UB bracket the difference metric
- The PCA reduction must use exactly 100 components and K=1 nearest neighbors for the difference metric

## Limitations

- The tool requires a single-cell reference to perform single-cell level deconvolution
- Comprehensive benchmarking against established standards is still required for new modalities (e.g., proteomics); current methodology needs algorithm adjustments per modality
- Evaluation depends on paired real-profiled ground-truth data, which is unavailable in purely prospective semi-profiling deployments
