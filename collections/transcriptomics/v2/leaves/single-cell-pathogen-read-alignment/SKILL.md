# single-cell-pathogen-read-alignment

## Summary

A scPathoQuant-based workflow that extracts host-unaligned reads from 10x cellranger output, realigns them to a pathogen genome (viral or bacterial) with bbmap or bowtie2, and integrates pathogen UMI counts back into the 10x matrix files for Seurat-style downstream analysis.

## When to use

Use when you have 10x scRNAseq data already processed with cellranger count and need to detect, quantify, and differentiate viral or bacterial pathogen reads per cell in a single operation.

## When NOT to use

- The pathogen reads are already integrated into the host reference (e.g. a GRCh38 + EGFP/HIV integrated genome run through cellranger) — in that case cellranger calls alone suffice and no realignment is needed
- Input data is not 10x single-cell output from cellranger count (e.g. bulk RNAseq or non-10x technologies)
- The goal is de novo pathogen discovery rather than quantification against a known reference genome

## Inputs

- 10x sample output folder generated by cellranger count (contains filtered_feature_bc_matrix, raw_feature_bc_matrix, possorted_genome_bam.bam)
- Pathogen reference genome fasta file (at most 2 entries; simplified headers recommended) with optional pathogen gtf file
- Aligner choice (bbmap default or bowtie2) with optional --bbmap_params / --bowtie2_params

## Outputs

- pathogen_al_counts.csv — total reads mapping to the pathogen in each cell
- pathogen_al_gene_counts.csv — reads mapping to individual pathogen genes per cell (requires gtf)
- pathogen_copy.png, pathogen_genes.png, coveragemap.png violin plots
- pathogen_al_mapped_sort.bam(.bai) for IGV visualization and pathogen_al_mapped.fq.gz for phylogenetic/clade analysis
- Overwritten 10x matrices (filtered_feature_bc_matrix, raw_feature_bc_matrix) with pathogen counts integrated for Seurat

## How to apply

First run cellranger count against the host genome (e.g. GRCh38) to produce filtered_feature_bc_matrix and raw_feature_bc_matrix outputs. Run scpathoquant with -10x pointing at the cellranger output folder, -p2genome pointing at a folder holding the pathogen fasta (with a simplified header like >HIV_virus, since the header is used to quantify total pathogen reads) and optionally a pathogen gtf, and -p for processors; scPathoQuant pulls unmapped reads from possorted_genome_bam.bam into _tmp/, maps them to the pathogen genome with the default bbmap aligner (or -align bowtie2 with e.g. --very-sensitive --non-deterministic), and quantifies with samtools and htseq-count using the --intersection-nonempty mode. The tool integrates pathogen UMI counts and pathogen gene UMI counts back into the cellranger matrix files so filtered_feature_bc_matrix can be loaded with Read10X in Seurat. It supports up to 2 fasta entries per run, enabling differentiation of co-infecting viruses (e.g. SARS-CoV-2 plus metapneumovirus) within one sample. Optionally pass --tmp_removal to delete the large temporary _tmp/ directory, or --bbmap_params (e.g. --semiperfectmode) for aligner-specific settings.

## Examples

```
scpathoquant -10x path/to/10x/sample -op path/for/results -p 8 -p2genome path/to/pathogen/fastafilefolder
```

## Evaluation signals

- pathogen_al_counts.csv is produced and per-cell pathogen counts cross-tabulate consistently with CellRanger integrated-genome calls (e.g. 100% EGFP+HIV+ cell overlap across bbmap, bowtie2, and CellRanger methods)
- Benchmark overlap with comparator tools reproduces reported values, e.g. 672 cells / 81.3% four-tool overlap with ViralTrack, PathogenTrack, and Venus on HIV donor 2
- filtered_feature_bc_matrix loads in Seurat via Read10X and contains added pathogen/pathogen-gene features
- Co-infection test reproduces the expected per-virus pattern: both SARS-CoV-2 and metapneumovirus detected in severe COVID patient 1, SARS-CoV-2 only in patients 2 and 3
- pathogen_al_mapped_sort.bam.bai index exists and pathogen_copy.png violin plots show plausible infected-cell and UMI count distributions

## Limitations

- The -p2genome folder should contain at most 2 fasta entries, limiting the number of distinguishable pathogens per run to 2
- The fasta header is used to quantify total pathogen reads, so complicated headers must be simplified (e.g. >HIV_virus) or quantification is compromised
- Temporary _tmp/ files (including unmapped reads and barcode-UMI tables) can be large; use --tmp_removal if space is an issue
- A pathogen gtf is optional; without it, per-gene outputs like pathogen_genes_al_sort_counts.sam are not produced
