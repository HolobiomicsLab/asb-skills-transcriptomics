# sequence-copy-padding-encoding

## Summary

Encodes variable-length protein/RNA sequences for convolutional neural network input by applying the LPI-CNNCP copy-padding trick followed by high-order one-hot encoding, producing fixed-length, image-like, non-independent inputs that satisfy CNN dimensionality requirements.

## When to use

Use when protein or lncRNA sequences of variable length must be transformed into fixed-length CNN-compatible inputs for lncRNA-protein interaction prediction or similar sequence-pair classification.

## When NOT to use

- All experimental sequences already fall within the fixed length range and can be encoded directly without the copy-padding/cropping step.
- The goal is predicting a new lncRNA-protein pair (Run_LPI_CNNCP_model(Y_crop_LPI=False, N_crop_LPI=False, Independent=True)) rather than encoding sequences for cross-validation training/evaluation.
- A non-CNN classifier is used, since the copy-padding trick exists specifically to satisfy the fixed-size input requirements of the convolutional neural network.

## Inputs

- lncRNA-protein interaction training, testing, and independent testing datasets from data.zip (sequence, pair name, label)
- Sample pairs named as label+'$'+protein_tag+'$'+lncRNA_tag+'$'+protein_sequence+'#'+lncRNA_sequence (e.g. 1$3UZK-3$3UZK-A$MAHKKGLGSTRNG#GGUCAAGAUGGUA)
- Subsequence-format pairs for sequences exceeding the fixed length range (e.g. 1$2B63-B$2B63-R_1$MSDLANSEKYYDEDPYGFEDESAPITAE#CAGCACUGAUUGCGGUCGAGGUAGCUUGAUG)

## Outputs

- Fixed-length, high-order one-hot-encoded image-like feature coding matrices suitable for CNN input (generated by LPI_feature.py)
- Evaluation metrics from 10-fold cross validation (with and without cut), consolidated e.g. into evaluation_metrics.csv
- Predicted probability values written to text format (independent_predict.txt) when run in independent prediction mode

## How to apply

First apply the copy-padding trick to convert variable-length protein/RNA sequences into fixed-length sequences so they meet the input requirements of the CNN model; sequences longer than the fixed length range are handled as subsequences named in the format label+'$'+protein_tag+'$'+lncRNA_tag+'_(subsequence index)'+'$'+protein_subsequence+'#'+lncRNA_subsequence. Then transform the fixed-length sequences with high-order one-hot encoding into image-like, non-independent inputs that capture dependencies among amino acids (or nucleotides). Generate the feature coding matrices with LPI_feature.py, configure CNN hyperparameters (filter number, filter size, pooling size, neuron number of the fully connected layer, strides, Dropout) as specified in LPI_CNNCP.py, and train/evaluate on the data.zip datasets using Python 3 with Keras 2.2.4 (TensorFlow backend), scikit-learn 0.21.3, and numpy 1.17.4. Decide the run mode via Run_LPI_CNNCP_model: (Y_crop_LPI=True, N_crop_LPI=False, Independent=False) for 10-fold cross validation without cut, and (Y_crop_LPI=False, N_crop_LPI=True, Independent=False) for 10-fold cross validation with cut.

## Evaluation signals

- All encoded protein/RNA sequences are fixed-length and can be fed into the CNN without shape errors.
- Both cross-validation modes run and emit final evaluation metrics: without cut via Y_crop_LPI=True and with cut via N_crop_LPI=True.
- Metric sets from the two 10-fold cross-validation runs consolidate successfully into evaluation_metrics.csv under Python 3 / Keras 2.2.4 / TensorFlow / scikit-learn 0.21.3 / numpy 1.17.4.
- Feature coding matrices produced by LPI_feature.py match the expected image-like, non-independent encoding of amino acids or nucleotides.
- Independent prediction mode writes predicted probability values into independent_predict.txt.

## Limitations

- The copy-padding trick and fixed-length encoding only apply when CNN input requirements must be met; sequences within a fixed length range can be processed directly without cropping.
- Sequences exceeding the fixed length range must be split into subsequences with a subsequence index in the pair name, adding preprocessing overhead.
- Reproduction depends on pinned environment versions: Keras 2.2.4 (TensorFlow backend), scikit-learn 0.21.3, and numpy 1.17.4; the repository provides no changelog.
