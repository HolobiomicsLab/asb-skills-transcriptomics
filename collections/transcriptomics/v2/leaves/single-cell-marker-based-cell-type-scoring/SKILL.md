# single-cell-marker-based-cell-type-scoring

## Summary

Convert a raw gene expression matrix into a cell-type score matrix using MASI's marker-based scoring (gene2cell), which applies linearly weighted marker genes and a PlinerScore percentile threshold, enabling model-free cell-type annotation and integration of scRNA-seq data without training a probabilistic or neural model.

## When to use

Use when raw single-cell RNA-seq counts (AnnData) need standardized cell-type labels via reference-derived marker genes, especially for million-scale datasets on limited compute or when model-based methods (Seurat, Harmony, scNym, scArches) are too costly.

## When NOT to use

- Query data contains unseen cell types absent from the reference — MASI alone cannot annotate these; combine MASI with SCCAF to identify subtypes within major cell types
- The reference dataset is low-quality or mismatched in resolution — MASI's annotation accuracy depends directly on reference quality and resolution matching
- Input is already a cell-type score matrix or a feature/summary table rather than raw or normalized gene-by-cell expression counts

## Inputs

- Raw scRNA-seq counts as an AnnData object (query data, e.g. combined Wagner et al. and Farrell et al. zebrafish embryo matrices)
- Labeled reference AnnData with cell-type labels in a 'cell_type' column
- Cell-type marker dictionary (cell_markers) generated by masi.marker_identification from the reference data

## Outputs

- Cell-type score matrix (scores) usable for visualization and downstream analysis
- Ensembled per-cell cell-type labels (e.g. annotation of cells into 8 major zebrafish lineages)
- CSV of annotated cells with lineage labels (e.g. zebrafish_lineage_annotations.csv)

## How to apply

First normalize raw counts by LogNormalization (divide by total counts per cell, scale by 10,000, log-transform) with Scanpy, deliberately skipping highly variable gene selection since only identified marker genes are used. Identify cell-type markers from labeled reference data with masi.marker_identification (top 20 markers per DE test via robust rank aggregation), then convert the expression matrix to a cell-type score matrix with masi.gene2cell(ad=ad, cell_markers=cell_markers, use_weight=True), where the 1st marker contributes 100% and the Nth contributes 50% (linear discount). Suppress marker expression below the 0.25 percentile PlinerScore threshold to zero before scoring. Annotate cells by over-clustering with MACA across clustering resolutions 3, 5, 7 and neighborhood sizes 5, 10, 15 via masi.parallel(scores=scores, labels=labels, batch_size=50000), splitting large data into N batches with one MACA run per CPU core and ensembling labels (ensemble_labels).

## Related tools

- **MASI** (Core method: marker_identification, gene2cell (gene-to-cell-type score conversion), parallel/MACA-based label transfer, ensemble_labels) — https://github.com/hayatlab/MASI
- **MACA** (Over-clusters cells at resolutions 3, 5, 7 with neighborhood sizes 5, 10, 15 for multi-parameter label transfer)
- **Scanpy** (LogNormalization preprocessing of raw counts (scale factor 10,000, log-transform))
- **SCCAF** (Optional companion to identify subtypes of unseen cell types not present in the reference)

## Examples

```
scores, labels = masi.gene2cell(ad=ad, cell_markers=cell_markers, use_weight=True); annotation = masi.parallel(scores=scores, labels=labels, batch_size=50000)
```

## Evaluation signals

- Lineage-emergence timing calls match published annotations: germline at 3 hpf, epidermis at 3 hpf, notochord around 7 hpf, non-neural ectoderm separation at 12 hpf (Fig. 1b–d of the zebrafish case study)
- The PlinerScore threshold is applied at the default 0.25 percentile and suppressed marker values are zero below that percentile
- MACA parameter sweep covers all nine combinations (resolutions 3/5/7 × neighborhood sizes 5/10/15) with batch_size=50000 per CPU core
- Marker weighting respects the linear discount: 1st marker contributes 100% expression weight, Nth marker 50%
- No highly variable gene selection is performed — the gene2cell step consumes only the identified marker genes

## Limitations

- MASI alone cannot annotate unseen cell types not present in the reference; it must be combined with SCCAF for subtype discovery
- Annotation accuracy depends on reference data quality; the choice and resolution of the reference are critical to downstream analysis
- The PlinerScore threshold is documented with a variable 'X-percentile' and a default of 0.25; the value actually applied per analysis is not stated, and the number of batches N for splitting large data is unspecified
