# graph-edge-labeling-and-filtering

## Summary

Builds a labeled splice graph in which nodes are exons and edges are splice junctions, labeling each junction edge 1 or 2 (with 2 further split into 2+ and 2-) according to which aligners (e.g., Hisat2 and STAR) captured it, after filtering spurious edges with Tiglon's abundance/coverage thresholds.

## When to use

Use when integrating BAM alignments from multiple splice-aware aligners (e.g., Hisat2 and STAR) to assemble transcripts requires building a labeled splice graph with junction edges labeled by capturing-aligner agreement and filtered against spurious junctions.

## When NOT to use

- The current version of Tiglon cannot guide assembly with known transcript annotations, so do not use this labeling workflow when an annotation-guided assembly is required.
- The current version of Tiglon does not support long-read RNA-seq data (PacBio or Oxford Nanopre Technologies), so do not apply this skill to long-read BAM inputs.
- Do not apply the label scheme with only one aligner: labels 2/2+/2- encode agreement across all employed aligners and are meaningless for a single mapping.

## Inputs

- BAM alignment files produced by Hisat2 (e.g., --dta mode) for the RNA-seq sample
- BAM alignment files produced by STAR for the same RNA-seq sample
- A file listing the alignment files generated by different aligners (Tiglon input)
- Reference genome/index (e.g., human GRCh38)

## Outputs

- Merged labeled splice graph with exon nodes and junction edges carrying 'label' fields (1, 2+, 2-)
- Tiglon assembled candidate transcripts in GTF format
- Optionally, the labeled splice graph serialized per gene locus (e.g., GraphML)

## How to apply

Align the RNA-seq sample (e.g., SRR307911 against GRCh38) with Hisat2 (--dta) and STAR to obtain per-aligner BAM files. Build a per-gene-locus splice graph whose nodes are exons and edges are splice junctions weighted by read support, then filter spurious junction edges using Tiglon's parameters: min_average_frac 0.03, min_unbalance_frac 0.03, min_gap_length 200, min_trans_length 500, and min_trans_cov at its default (>0). Merge the per-aligner graphs into one labeled splice graph: label each junction edge 2 when captured by all employed aligners and 1 otherwise, refining label 2 into 2+ (identical captured reads across aligners) and 2- (otherwise), and average edge weights across aligners. The label information is what Tiglon's labeled-based dynamic path extension program exploits to recover expressed transcripts, so preserving correct labels is essential for downstream assembly.

- **Tiglon** (Merges per-aligner splice graphs into the labeled splice graph, applies the min_average_frac/min_unbalance_frac/min_gap_length/min_trans_length/min_trans_cov filtering, and assigns edge labels 1, 2+ and 2-) — github.com/yutingsdu/Tiglon

## Examples

```
tiglon --alignments aligner_bam_list.txt --min_average_frac 0.03 --min_unbalance_frac 0.03 --min_gap_length 200 --min_trans_length 500 --min_trans_cov 0
```

## Evaluation signals

- Every junction edge in the merged labeled splice graph carries a 'label' field with a value in {1, 2+, 2-}.
- On the XR_929,880.3 locus with Hisat2+STAR mappings, the label pattern matches Figure 1: the first junction (not captured by STAR) and the fifth junction (not captured by Hisat2) are labeled 1, and the remaining junctions are labeled 2.
- All junction edges retained after filtering satisfy the threshold configuration: min_average_frac 0.03, min_unbalance_frac 0.03, min_gap_length 200, min_trans_length 500, min_trans_cov >0 (default).
- Edge weights in the merged graph equal the averages of the per-aligner read-support weights for the same junction.
- Tiglon runs to completion on the BAM list file (requiring g++ with C++11, Boost >= 1.47.0, and bamtools installed) and outputs candidate transcripts in GTF format.

## Limitations

- The current version of Tiglon does not have an option for annotation-guided assemblies.
- The current version of Tiglon is not compatible with long-read RNA-seq datasets (e.g., Pacific Biosciences [PacBio] or Oxford Nanopore Technologies [ONT]).
- Tiglon currently only accepts BAM files generated by Hisat(2) and Star, so labels cannot be computed from other aligners' mappings.
