# imputation-accuracy-evaluation

## Summary

Decomposes the overall imputation error gtMSEall of an LATE/TRANSLATE-imputed single-cell RNA-seq matrix into entry-class errors gtMSEnz, gtMSEbiol, and gtMSEtech on the log10(count+1) scale, and verifies the weighted decomposition with the zero proportions p0 and q0.

## When to use

Use when an imputed hd5 matrix (e.g. step2/imputation.step2.hd5) and a ground-truth matrix (e.g. example.hd5) with a masked input (e.g. example.msk90.hd5) are available and entrywise imputation accuracy must be quantified and decomposed by zero class.

## When NOT to use

- No true ground truth exists and it is set to be the same as the input (as in the mouse brain 10x example) — error metrics against the input are not meaningful imputation accuracy.
- Only zero-classification behavior (not accuracy) is of interest — the article itself notes LATE/TRANSLATE never distinguish biological from technical zeros when imputing.
- The step2/ folder with imputation.step2.hd5 has not been generated by a LATE or TRANSLATE run yet.

## Inputs

- Ground truth matrix in hd5 format, e.g. example.hd5 (10,000 genes x 10,000 cells, log10(count+1) scale)
- Masked input matrix in hd5 format, e.g. example.msk90.hd5 (90% of example.hd5 masked)
- Imputed matrix in hd5 format at step2/imputation.step2.hd5 (same layout and scale as the input)

## Outputs

- mse_metrics.csv containing gtMSEall, gtMSEnz, gtMSEbiol, gtMSEtech, and the zero proportions p0 and q0
- Entry-class masks (nonzero set, biological zeros, technical/masked zeros) computed with numpy

## How to apply

Load the ground truth (example.hd5), the masked input (example.msk90.hd5), and the imputed matrix (step2/imputation.step2.hd5) with pandas/tables, confirming all are on the log10(count+1) scale. Classify entries with numpy into nonzero ground-truth entries (the gtMSEnz set), biological zeros (zero in the ground truth T), and masked technical zeros (zero in input X but nonzero in T), recording the zero proportions p0 and q0. Compute the closed-form mean squared errors gtMSEall, gtMSEnz, gtMSEbiol, and gtMSEtech between imputed Y and ground truth T over each entry class. Verify that the weighted decomposition using p0 and q0 reconstructs gtMSEall from the three component errors — this is the acceptance check. Finally, write the four metrics plus p0 and q0 to mse_metrics.csv with pandas.

python example_analysis.py -mode='analysis' -infile='../data/example.msk90.hd5'

## Evaluation signals

- The weighted decomposition using p0 and q0 reconstructs gtMSEall exactly from gtMSEnz, gtMSEbiol, and gtMSEtech (acceptance check).
- mse_metrics.csv contains exactly four MSE values plus the two zero proportions p0 and q0.
- All three input matrices (ground truth, masked input, imputed) are confirmed to be on the log10(count+1) scale and share the same layout.
- Recorded p0 and q0 are consistent with the masking rate (example.msk90.hd5 is generated by masking 90% of example.hd5).
- When no ground truth exists (mouse brain example), the skill must not be run because ground truth is set equal to the input.

## Limitations

- LATE and TRANSLATE assume all zeros in the scRNA-seq data are missing values and always impute zeros with a nonzero value; biological zeros are not distinguished from technical zeros during imputation, only during this evaluation.
- When ground truth does not exist it is set to be the same as the input, so error metrics become trivial (see Example 4, mouse brain data).
- Values in the imputed matrix are on the log10(count+1) scale, so metrics are not directly comparable to raw-count MSE.
