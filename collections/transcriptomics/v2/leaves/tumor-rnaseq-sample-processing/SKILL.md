# tumor-rnaseq-sample-processing

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Reconstructs TSNAD v2.0's RNA-Seq gene expression quantification module, which maps RNA-Seq reads with HISAT2 v2.2.1 to GRCh37/GRCh38 and assembles/quantifies transcripts with StringTie v2.1.6 to produce TPM values used to filter neoantigens from unexpressed genes (TPM < 1).

## When to use

Use when processing tumor RNA-Seq FASTQ files to quantify gene/transcript expression (TPM) as a prerequisite for filtering neoantigen predictions by gene expression, following the TSNAD v2.0 module.

## When NOT to use

- Input data is WES/WGS (DNA sequencing) rather than RNA-Seq — TSNAD's main neoantigen module uses Trimmomatic/BWA/GATK/Mutect2, not HISAT2/StringTie.
- The goal is gene fusion detection rather than expression quantification — that path uses STAR 2.7 aligner plus Arriba 1.1.0.
- Expression values are already quantified (a TPM table exists), so only the TPM < 1 unexpressed-gene filter is needed.

## Inputs

- Tumor RNA-Seq FASTQ files (sample pair from the TSNAD v2.0 repository distribution)
- Human reference genome GRCh37 or GRCh38

## Outputs

- HISAT2 SAM alignments converted to sorted BAM (via SAMtools v1.13)
- gene_expression_results.tsv containing transcript and gene TPM values

## How to apply

Start from the RNA-Seq FASTQ files of the tumor sample pair distributed with the TSNAD v2.0 repository. Align reads to the human reference genome (GRCh37 or GRCh38) with HISAT2 v2.2.1, then convert the HISAT2 SAM output to sorted BAM with SAMtools v1.13 to reduce storage footprint. Assemble the alignments into potential transcripts and quantify expression with StringTie v2.1.6, which reports transcript- and gene-level TPM values. The resulting expression table feeds TSNAD's expression filter, which removes neoantigens generated by mutations in unexpressed genes (TPM < 1). Note that the module output must be a parseable table (e.g., gene_expression_results.tsv) so downstream TPM-based filtering can be applied; this module is separate from the fusion-detection module, which uses STAR 2.7 plus Arriba 1.1.0.

## Related tools

- **HISAT2 2.2.1** (Maps RNA-Seq reads to the GRCh37/GRCh38 reference genome)
- **SAMtools 1.13** (Converts HISAT2 SAM output to sorted BAM format to reduce storage footprint)
- **StringTie 2.1.6** (Assembles RNA-Seq alignments into potential transcripts and quantifies transcript/gene expression (TPM))
- **TSNAD v2.0** (Integrating pipeline whose gene expression module combines HISAT2 and StringTie and applies the TPM < 1 filter to neoantigen candidates) — https://github.com/jiujiezz/tsnad

## Examples

```
python TSNAD.py -I samples/ -R RNA-seq/ -V grch38 -O results/
```

## Evaluation signals

- gene_expression_results.tsv exists and is a parseable table
- The table contains TPM values for transcripts and genes
- TPM values are low enough (many near 0) that a TPM < 1 filter for unexpressed genes is meaningful downstream
- BAM files are sorted (SAMtools conversion succeeded) before being passed to StringTie
- Reference genome version used (-V grch37/grch38) matches the genome used elsewhere in the TSNAD run

## Limitations

- TSNAD v1.0 only supports GRCh37; expression quantification must match the genome version chosen for the rest of the run (GRCh37 or GRCh38 in v2.0).
- RNA-Seq input is optional in the TSNAD docker invocation; without it, the TPM < 1 expression filter cannot be applied.
- The paper notes no TCR-pMHC binding prediction or TCR sequencing analysis is included; expression filtering alone does not guarantee neoantigen quality.
