# cross-platform-single-cell-data-processing

## Summary

A seven-step wrapper workflow (UniverSC around Cell Ranger 3.0.2) that reformats FASTQ reads and barcode whitelists from any UMI-based scRNA-seq platform into the Chromium 16 bp format so Cell Ranger can align transcripts with STAR and produce a gene-barcode count matrix.

## When to use

Use when paired-end FASTQ files (R1 barcode/UMI, R2 transcript) from a non-Chromium UMI platform must be processed with Cell Ranger, or when cross-platform scRNA-seq datasets must be integrated under identical parameters.

## When NOT to use

- Data are 5' scRNA-seq from a platform other than Chromium — the paper states these technologies are not supported at the time of writing
- Input is not UMI-based single-cell RNA-seq (e.g. full-length or bulk RNA-seq), since UniverSC targets UMI-based platforms only
- A non-wrapped, platform-specific pipeline (e.g. dropSeqPipe, zUMIs, dropEst, Kallisto/BUStools) is already configured for the technology

## Inputs

- Paired-end FASTQ files (R1 carrying cell barcode + UMI, R2 carrying transcript sequences)
- Cell Ranger-prepared genome reference (e.g. GRCh38/hg38 chromosome 21)
- Technology name and its cell-barcode whitelist (e.g. Drop-seq, ICELL8, SmartSeq3, inDrops v3, SCI-Seq, Nadia)

## Outputs

- Cell Ranger gene-barcode count matrix (GBM) generated by STAR alignment of Read 2 transcripts
- Standard Cell Ranger run outputs from the modified configuration

## How to apply

Run launch_universc.sh with a Read 1/Read 2 FASTQ pair, a Cell Ranger-prepared reference genome (e.g. GRCh38 chromosome 21), and a technology name; chemistry is auto-detected for 3' protocols. The pipeline extracts configured barcode and UMI lengths from Read 1, moves transcript sequences to the positions Cell Ranger expects, and supports inversion of UMI/barcode order and R1/R2 role swaps for technologies with inverted or R2-resident barcodes/UMIs. The technology's barcode whitelist is selected and adjusted to the Chromium 16 bp format, then substituted for the Chromium default in the Cell Ranger configuration. Cell Ranger 3.0.2 (chosen for licensing reasons) is then executed with the modified configuration, aligning Read 2 transcripts via STAR to generate the gene-barcode matrix (GBM). Correctness is judged by Cell Ranger completing and producing a gene-barcode count matrix comparable to raw GBMs deposited as supplemental data. As a third-party wrapper, it must be installed where launch_universc.sh has write access to the Cell Ranger installation (user home directory, no admin rights).

## Related tools

- **UniverSC** (Shell wrapper that curates FASTQ inputs, reformats barcodes/UMIs to Chromium 16 bp, adjusts the technology whitelist, and invokes Cell Ranger) — https://github.com/minoda-lab/universc
- **Cell Ranger 3.0.2** (Downstream engine executed with the modified configuration to align transcripts with STAR and generate the gene-barcode matrix)
- **Docker** (Containerised distribution of UniverSC ensuring consistent execution across platforms)
- **bamtofastq** (Optional pre-step to convert prior Cell Ranger BAM output back to FASTQ for re-running analysis) — https://github.com/10XGenomics/bamtofastq

## Examples

```
./launch_universc.sh --id=sample --fastqs=R1.fastq.gz,R2.fastq.gz --transcriptome=GRCh38_chr21_ref --technology=dropseq
```

## Evaluation signals

- The Cell Ranger run completes without error and emits a gene-barcode matrix (GBM)
- The reformatted R1 reads match the configured barcode and UMI lengths for the technology (16 bp Chromium format where required)
- The technology-specific whitelist correctly replaces the Chromium default in the Cell Ranger configuration
- GBMs from the same dataset processed via different technologies show matching barcode/gene sets after adjustment, with high Pearson correlation and ARI against clustering outcomes
- For Swagger-style role swaps (inverted UMI/barcode order or barcode/UMI in R2), outputs are consistent with the un-swapped reference GBM

## Limitations

- Technologies for 5' scRNA-seq other than Chromium are not supported at the time of writing
- launch_universc.sh requires write access to the Cell Ranger installation, so Cell Ranger must sit in the user's home directory (no admin install)
- Cell Ranger is pinned to version 3.0.2 due to licensing; later Cell Ranger versions change core code mainly for non-scRNA-seq analyses (scATAC-seq, TCR, BCR)
- UniverSC is a third-party tool not affiliated with 10x Genomics and calls Cell Ranger as an external dependency
