# mds-dimensionality-reduction-visualization

## Summary

Compute a multidimensional scaling (MDS) representation of pseudobulk sample profiles generated by muscat's aggregation-based differential state workflow, and visualize samples colored by cluster_id and group_id to verify that aggregated data capture subpopulation and condition structure.

## When to use

Use when aggregating single-cell counts into sample x cluster x group pseudobulks (e.g., Kang PBMC IFN-β data) and you need a low-dimensional check that pseudobulk profiles separate by cell cluster and stimulation condition before/after running pbDS.

## When NOT to use

- Input is cell-level data and the goal is cell-level mixed-model inference (use mmDS instead of aggregating to pseudobulk)
- The goal is differential detection (DD) rather than differential state visualization of aggregated counts

## Inputs

- SingleCellExperiment with colData columns sample_id, group_id, cluster_id (e.g., EH2259 Kang PBMC IFN-β anchor set from ExperimentHub, standardized via muscat::prepSCE)
- Pseudobulk object produced by muscat::aggregateData (assay 'counts', fun 'sum')

## Outputs

- MDS plot of pseudobulk samples colored by cluster_id and group_id (MDS1 separating clusters, MDS2 separating control vs. stimulated groups)
- Supporting per-cluster DS hit summary table (e.g., pbds_ds_hits.csv) at FDR < 5% and |logFC| > 1

## How to apply

First build pseudobulk profiles with muscat::aggregateData on the SingleCellExperiment (assay 'counts', fun 'sum', aggregated by cluster_id and sample_id), since MDS is computed on these aggregated sample-level profiles rather than on cell-level data. Then compute an MDS representation of the pseudobulk samples (e.g., muscat's mds/plotMDS, which wraps limma-style MDS on the aggregated log-expression matrix). Color points by cluster_id and group_id to inspect whether the leading dimensions capture biological structure: in the Kang PBMC IFN-β vignette reproduction, MDS1 separates cell clusters while MDS2 separates control versus stimulated sample groups. Use this plot as a validation artifact alongside pbDS hit counts computed at adjusted p-value < 0.05 (FDR 5%) and |logFC| > 1; agreement with vignette-reported numbers plus clear cluster/group separation confirms the pipeline (prepSCE, aggregateData, pbDS with the default edgeR engine) was applied correctly.

## Related tools

- **muscat** (Aggregates cell-level counts into pseudobulk profiles (aggregateData) and provides MDS plotting of pseudobulk samples in the DS analysis workflow) — github.com/HelenaLC/muscat
- **edgeR** (Default engine used by pbDS on the same pseudobulk data whose structure the MDS plot validates)
- **limma-voom** (Bulk RNA-seq differential engine family whose sample-level framework the MDS visualization complements on pseudobulk counts)
- **R** (Implementation environment for the muscat pseudobulk aggregation, pbDS, and MDS plotting steps)

## Examples

```
pb <- aggregateData(sce, assay = "counts", fun = "sum", by = c("cluster_id", "sample_id"))
```

## Evaluation signals

- In the MDS plot on the Kang PBMC IFN-β pseudobulk data, MDS1 clearly separates cell clusters while MDS2 separates control and stimulated sample groups
- Per-cluster DS hit counts at adjusted p-value < 0.05 (FDR 5%) and |logFC| > 1 match the muscat vignette-reported numbers
- Pseudobulk object is generated as sample x cluster x group aggregation of the 'counts' assay with fun = 'sum' before MDS is computed
- MDS points are colored by both cluster_id and group_id, so both subpopulation and condition structure are inspectable

## Limitations

- LogFC estimates were attenuated for some combinations depending on the scale of the data analyzed
- There is a potentially strong bias in statistical power toward larger cell populations, with decreased power for rarer populations
- Methods were not specifically designed for the multi-group multi-sample problem (cell-level methods)
