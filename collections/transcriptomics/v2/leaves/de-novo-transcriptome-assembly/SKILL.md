# de-novo-transcriptome-assembly

## Summary

Builds a reference-free transcriptome from Illumina RNA-Seq reads with Trinity (e.g., the H. subflexa female pheromone gland assembly, or D. melanogaster reads from SRA BioProject PRJNA527373), discarding contigs supported by fewer than 5 reads, and produces the FASTA assembly that downstream chimera-removal pipelines such as Bellerophon consume.

## When to use

Use when you have Illumina paired-end RNA-Seq reads (FASTQ) and no reference genome, and need a de novo assembled transcriptome (FASTA) to quality-assess with TransRate/BUSCO or to filter with Bellerophon.

## When NOT to use

- A reference genome is available and a genome-guided or reference-based transcript reconstruction would be more appropriate — the paper's scope is de novo assembly when no reference genome exists
- The input is already an assembled transcriptome FASTA — then skip assembly and go directly to TransRate/BUSCO assessment or Bellerophon filtering
- The goal is only to remove chimeras from an existing assembly — that is the Bellerophon filtering skill, not the assembly step

## Inputs

- Paired-end Illumina RNA-Seq FASTQ reads (e.g., H. subflexa female pheromone gland reads, or SRA runs SRR8735410/SRR8735411/SRR8735412 from BioProject PRJNA527373)
- Simulated paired-end FASTQ reads generated by Polyester's simulate_experiment_countmat (~20,370,192 / 19,995,866 / 20,045,180 read pairs)
- Reference genome annotation (NCBI RefSeq GCF_000001215.4) when simulating or classifying contigs

## Outputs

- De novo assembled transcriptome FASTA (e.g., 33,484 contigs for the SRA D. melanogaster assembly)
- Per-contig read-support counts (contigs with <5 supporting reads discarded)
- Ground-quality metrics for the unfiltered assembly (TransRate score, e.g., 0.247; BUSCO Insecta odb9 counts, e.g., 1,511 present / 91.1%, 562 duplicated)

## How to apply

Assemble the paired-end reads de novo with Trinity under default parameters, since Trinity is described as the most commonly used de novo transcriptome assembler. Discard assembled contigs supported by fewer than 5 reads, as done in both the simulated D. melanogaster experiment (Polyester-simulated read sets of ~20 million paired-end reads each) and the SRA-based assembly of SRR8735410-12 that yielded 33,484 contigs. For the H. subflexa pheromone gland transcriptome, follow the Trinity-based assembly protocol given in Appendix S1 of the paper. Record the read counts per contig so that later TPM filtering (default cut-off 1) and chimera classification are traceable. Treat the resulting FASTA as the ground assembly whose quality is established with TransRate and BUSCO (Insecta odb9 ortholog set) before any filtering.

## Related tools

- **Trinity** (De novo assembles the RNA-Seq reads into the transcriptome FASTA (default parameters; contigs with <5 read support discarded))
- **Polyester** (Simulates paired-end RNA-Seq read sets (fpkm_to_counts, create_read_numbers, simulate_experiment_countmat) used as assembly input in the benchmark)
- **TransRate** (Establishes the ground reference-free quality score of the unfiltered assembly from the reads and the assembled FASTA)
- **BUSCO** (Assesses assembly completeness using the Insecta odb9 ortholog set (present and duplicated group counts))
- **Bellerophon** (Downstream pipeline that filters the assembly (TPM cut-off 1, CD-HIT-EST 95% identity, TransRate filtering) and removes chimeras) — github.com/JesseKerkvliet/Bellerophon

## Examples

```
python Bellerophon.py --assembly Demo.fasta --left All_R1_1000.fastq --right All_R2_1000.fastq --outdir /vagrant/testrun
```

## Evaluation signals

- The assembly output is a valid FASTA whose contig count matches expectations (e.g., 33,484 contigs for the SRA D. melanogaster assembly)
- Ground TransRate score of the unfiltered assembly falls near the reported value (H. subflexa pheromone gland: 0.247, with 0.312 after Bellerophon filtering)
- BUSCO (Insecta odb9) reports completeness consistent with the reported baseline (1,511 groups present, 91.1%; 562 duplicated before filtering)
- No contigs supported by fewer than 5 reads remain in the final assembly
- Downstream Bellerophon run succeeds only if the assembly plus left/right FASTQ inputs produce bellerophon_report.txt with removed-contig counts matching reported values within run-to-run variation

## Limitations

- No tool version numbers were stated for BUSCO, TransRate, CD-HIT-EST, Trinity, or Polyester, complicating exact reproduction
- When no reference genome is available, the quality of a de novo assembled transcriptome is difficult to assess
- TransRate has backwards-compatibility problems, which is why the Bellerophon authors recommend the Vagrant VM rather than local installation
- Contigs from alternative splicing may be misclassified as chimeras and erroneously removed downstream
