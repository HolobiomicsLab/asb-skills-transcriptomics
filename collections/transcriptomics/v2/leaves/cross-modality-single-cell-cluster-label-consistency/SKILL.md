# cross-modality-single-cell-cluster-label-consistency

## Summary

Joint clustering of paired scRNA-seq and scATAC-seq samples via CoupledNMF so that cells in both modalities receive a single consistent set of cluster labels, which are then passed as O1.idx/E1.idx/O2.idx/E2.idx to sc_compreg for comparative regulatory analysis.

## When to use

Use when you have one scRNA-seq and one scATAC-seq sample from the same heterogeneous population and need linked subpopulations with identical cluster labels across both modalities before comparative gene regulatory analysis.

## When NOT to use

- Consistent cluster labels already exist from another source (e.g. known cell-type markers); the README states cnmf is not required, only consistent assignments across scRNA-seq and scATAC-seq
- Data are unpaired or from more than one donor per condition — the paper notes the approach is for one sample per condition and multi-donor extension is pending

## Inputs

- scRNA-seq count matrix and gene symbols (sample 1 and sample 2)
- scATAC-seq peak accessibility matrix and peak.bed annotation
- peak_gene_coupling_matrix.txt generated by cnmf_process_data.sh from prior_data
- prior_data directory from github.com/SUwonglab/sc-compReg (supports hg19, hg38, mm9, mm10)

## Outputs

- cnmf output object (H1, H2, cluster indices) e.g. saved as cnmf_output.rds
- Per-cell cluster labels for sample 1 and sample 2, passable to sc_compreg as O1.idx, E1.idx, O2.idx, E2.idx
- Optional joint t-SNE embedding plots from cnmf_tsne

## How to apply

Preprocess the ATAC peak annotation with cnmf_process_data.sh (genome_version hg19/hg38/mm9/mm10) to produce peak_gene_coupling_matrix.txt, then load it in R via cnmf_load_coupling_matrix to obtain the coupling matrix D with entries A_ij = R_ij+ * exp(-d_ij/d0) where d0 = 40 kb captures distance-decay of peak-gene links. Implement the CoupledNMF multiplicative updates for W1, H1, W2, H2 and run the coupled optimization over the decreasing alpha series [10000, 1000, 100, 10, 1, 0.1, 0.01, 0.001] with the corresponding beta scheme, selecting the alpha/beta combination giving the most interpretable joint factorization (this parameter selection criterion is the adaptation for 10x Genomics Chromium data, and CoupledNMF is the package default clustering method). Extract per-cell cluster labels from the factor matrices H1 and H2, ensuring consistent cluster assignment across the RNA and ATAC cells, optionally visualizing with cnmf_tsne (perplexity=100). Consistent cluster labels across modalities are the hard requirement; the README notes any consistent cluster assignments can substitute for the cnmf output.

## Examples

```
bash cnmf_process_data.sh path/to/peak.bed hg38 path/to/prior_data; D <- cnmf_load_coupling_matrix('peak_gene_coupling_matrix.txt', peak.name, symbol)
```

## Evaluation signals

- Cluster labels from H1 (RNA) and H2 (ATAC) use a consistent label set with matching cluster identities across modalities
- Stored cnmf output (cnmf_output.rds) loads in R and the indices pass directly as O1.idx, E1.idx, O2.idx, E2.idx to sc_compreg without relabeling
- cnmf_tsne joint embedding shows RNA and ATAC cells of the same cluster co-locating (joint clusters plot)
- Selected alpha/beta from [10000, 1000, 100, 10, 1, 0.1, 0.01, 0.001] yields the most interpretable joint factorization
- peak_gene_coupling_matrix.txt generated with a valid genome_version (hg19/hg38/mm9/mm10) loads via cnmf_load_coupling_matrix against peak.name and symbol

## Limitations

- Consistency of cluster labels across scRNA-seq and scATAC-seq is mandatory; inconsistent labels are invalid input to sc_compreg
- Cluster assignments need not come from CoupledNMF, but must be provided consistently for both modalities
- The paper notes the initial analysis steps (clustering, embedding, subpopulation matching) were validated against surrogate ground truth from bulk data; extension to multiple donors per condition is not yet accommodated
