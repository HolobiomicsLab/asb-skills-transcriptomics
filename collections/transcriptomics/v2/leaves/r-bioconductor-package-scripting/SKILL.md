# r-bioconductor-package-scripting

## Summary

Writing and running R/Bioconductor scripts around the ExpHunter Suite package to execute RNA-seq differential expression, co-expression, functional enrichment, and RNA-seq simulation workflows modularly from the command line.

## When to use

Use when the analysis must be performed inside R (version 4) with Bioconductor tooling — e.g. installing ExpHunterSuite via devtools, exposing its DEgenes Hunter command-line scripts, or running its simulation and expression-analysis modules on count tables.

## When NOT to use

- The count table is already a processed DEG results table and the task is only threshold-based vote filtering (e.g. applying the minimum vote cut-off, optimum threshold 2 for spike-in data) rather than running the R pipeline.
- The target environment is not R version 4 / Bioconductor — e.g. a Python-only stack, where installing ExpHunterSuite and its reactome.db dependency is the wrong route.
- The analysis concerns a single DEG method's behavior rather than running the ExpHunter Suite's multi-method integration, co-expression, or simulation modules.

## Inputs

- Gene-by-sample RNA-seq count table (output of an initial RNA-seq workflow, e.g. FASTQ-to-count mapping for spike-in data)
- Lafora disease and PMM2-CDG rare-disease model datasets
- A. thaliana reference count dataset from the R package TCC (for simulation)
- NCBI SRA download configuration (JSON credentials) for spike-in experiments

## Outputs

- simulated_counts.tsv (simulated gene-by-sample count matrix, genes as rows)
- deg_labels.tsv (ground-truth DEG labels for simulated genes)
- HTML results report generated by get_results.sh for the synthetic experiments

## How to apply

Install R (the README requires R version 4), then install devtools from CRAN and pull ExpHunterSuite from GitHub with `devtools::install_github("seoanezonjic/ExpHunterSuite", dependencies=TRUE)`. Because reactome.db exceeds 400 Mb and R's default download timeout is 60 s, extend it first with `options(timeout=1000)` or install reactome.db from source to avoid install failure. Create a script folder and run `ExpHunterSuite::install_DEgenes_hunter('install_folder')` to make the command-line scripts accessible, then `export PATH=path_to_install_folder:$PATH` (persistable in .bashrc/.bash_profile). Workflows are modular: DEG detection, co-expression module detection, functional enrichment (via reactome.db and orthologous translation for non-model organisms), and TCC-based RNA-seq data simulation, including a Naïve Bayes classifier trained on simulated data. For the published synthetic experiments, configure `launch.sh` and `get_results.sh` in the ExpHunterSuiteExamples repository with your environment and results folder — these scripts depend on Autoflow and emit a final HTML results report.

## Examples

```

```

## Evaluation signals

- The environment reports the expected Bioconductor version via BiocManager::version() (package documented against Bioconductor 3.18 vignettes).
- ExpHunterSuite installs without a reactome.db timeout failure (default getOption('timeout') is 60 s; the workaround sets options(timeout=1000)).
- After ExpHunterSuite::install_DEgenes_hunter('install_folder') and the PATH export, the DEgenes Hunter command-line scripts resolve from the shell.
- After running launch.sh and get_results.sh, a new HTML file with the results report has been generated in the configured results folder.
- For the simulation workflow, simulated_counts.tsv and deg_labels.tsv exist and the row count of simulated_counts.tsv equals the simulated gene count (e.g. 10,000 genes).

## Limitations

- reactome.db is too large (>400 Mb) and R's default 60-second download timeout can cause install failure; extend the timeout or install from source.
- The synthetic-experiment replication scripts require Autoflow to be installed on the system.
- The spike-in replication workflow requires NCBI credentials/JSON configuration for the SRA file downloader, plus an external clean&map step to convert FASTQ files into count tables.
