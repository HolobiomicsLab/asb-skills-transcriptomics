# Gene annotation overlap classification of TARs

## Summary

Classifies HMM-derived transcriptionally active regions (TARs) from scRNA-seq data as annotated TARs (aTARs) or unannotated TARs (uTARs) by overlap against refFlat-format gene annotations, quantifying how much transcriptional activity falls outside the current genome annotation.

## When to use

Use when you have groHMM-predicted TAR BED files from scRNA-seq alignments and need to partition them into aTARs vs uTARs relative to a refFlat annotation, or quantify the fraction of reads assigned to uTARs.

## When NOT to use

- Starting input is already a cellranger count matrix (use the from_cellranger workflow mode instead of re-annotating from FASTQs)
- Your analysis goal is annotating uTARs by sequence homology rather than classifying them against an existing annotation
- Only a high-quality, near-complete annotation is needed and no quantification of transcription outside annotations is desired

## Inputs

- groHMM-derived TAR BED files (strand-specific, HMM states transcribed/untranscribed)
- Genome assembly with refFlat-format gene annotations (e.g., GENCODE v30 hg38)
- Gene and TAR expression matrices generated by Drop-seq tools from STAR alignments

## Outputs

- Per-TAR classification labels (aTAR if any transcript overlap, uTAR otherwise)
- Per-dataset fraction of unique scRNA-seq reads assigned to uTARs
- Summary table (CSV) of uTAR read fractions across datasets

## How to apply

First generate strand-specific TAR predictions with groHMM (50 bp non-overlapping windows, gamma emission probabilities learned via Baum-Welch EM, merging predicted regions within 500 bp with bedtools merge -s -d 500, retaining TARs with at least 1/10,000,000 of uniquely mapped reads). Then intersect each HMM-derived TAR against refFlat-format gene annotations using rtracklayer/bedtools overlap logic: any TAR overlapping a transcript (ignoring strandedness) is labeled an aTAR; everything with no transcript overlap is a uTAR. Finally compute the relative number of unique scRNA-seq reads assigned to uTARs per cell per dataset and aggregate per-dataset fractions into a summary table. The rationale is that a high uTAR read fraction indicates the genome annotation is incomplete, as reported for gray mouse lemur (7.1%), naked mole rat (4.2%), and purple sea urchin (10.7%) versus only 2% for recent GENCODE v30 hg38 human annotation.

## Related tools

- **groHMM** (Hidden Markov model that divides the genome into transcribed and untranscribed states to produce the TARs that are subsequently classified as aTARs or uTARs) — https://bioconductor.org/packages/release/bioc/html/groHMM.html
- **rtracklayer** (R package used in the workflow to load and intersect annotation/TAR intervals for the overlap-based aTAR/uTAR classification) — https://bioconductor.org/packages/release/bioc/html/rtracklayer.html
- **Snakemake** (Workflow engine (TAR-scRNA-seq repo, from_fastqs or from_cellranger modes) that chains groHMM TAR calling, overlap classification, and uTAR fraction computation) — https://github.com/fw262/TAR-scRNA-seq

## Examples

```
bedtools intersect -u -a chr1_HMM.bed -b genes.refFlat.bed
```

## Evaluation signals

- Summary table exists in CSV format with one uTAR fraction value per dataset (six datasets in the reference study)
- Computed uTAR read fractions fall within a tolerance band around reported reference means: hg38 2%, gray mouse lemur 7.1%, naked mole rat 4.2%, purple sea urchin 10.7%
- Every TAR receives exactly one label: aTAR (any transcript overlap, ignoring strandedness) or uTAR (no overlap), with no unclassified intervals
- groHMM log 'SingleCellHMM_Run_combined_bam_HMM_features.log' shows per-chromosome HMM bed files were produced before classification

## Limitations

- groHMM R script failures (e.g., 'no lines available in input' from missing chr*_HMM.bed files) leave classification without input; manual groHMM/rtracklayer installation may be required
- groHMM has large memory demands — for Tabula Muris the combined alignment had to be downsampled to 5% of uniquely aligned reads
- Fractions are strongly dependent on organism, tissue, cell type, and developmental stage, so cross-dataset comparisons need matching contexts
