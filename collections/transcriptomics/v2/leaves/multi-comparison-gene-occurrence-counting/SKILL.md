# multi-comparison-gene-occurrence-counting

## Summary

Merges pre-computed scorecard outputs from all pairwise experimental comparisons in a main folder into a per-gene occurrence report, distinguishing genes consistently altered across experiments (e.g., SA_RS13430 appearing on 65 scorecards) from isolated, condition-specific modifications.

## When to use

Use when you have one sub-directory per pairwise experimental comparison, each with scorecard outputs, and you need a per-gene tally of how many scorecards/quadrants of interest each gene appears in across comparisons.

## When NOT to use

- Only a single pairwise comparison is being analyzed (no multi-comparison folder structure exists), so occurrence counting across experiments is meaningless
- You need the four-way plot variant, since multiple_view/overview functions apply only to the scorecard, not the four-way plot
- Input CSV has not yet been processed into per-quadrant scorecard outcomes — run scorecard_functions.scorecard and reconstruct_scorecard per comparison first

## Inputs

- Main folder path (string) containing one sub-directory per experimental comparison
- Pre-computed scorecard outputs per sub-folder (JSON/plot outcomes from scorecard_functions.scorecard and reconstruct_scorecard)
- Frequency summaries previously generated by scorecard_functions.count_frequencies

## Outputs

- CSV or Excel file listing total occurrences per gene/entry across all comparisons (e.g., gene X active in N of M comparisons)
- Optional separate report of uncommon entries (genes specific to isolated conditions)
- Summary of the number of entries/genes identified by the scorecard in each comparison

## How to apply

Point the pipeline at a main folder structured with one sub-directory per experimental comparison (each holding pre-computed scorecard outputs). First run scorecard_functions.count_frequencies(main_folder) to summarize the number of entries/genes identified by the scorecard in each comparison. Then run scorecard_functions.common_entries(main_folder), which re-uses the frequency information previously created by count_frequencies, to compute total occurrences per gene across comparisons. Optionally request the separate report of uncommon entries, i.e., genes specific to isolated conditions rather than globally altered. Save the report as CSV or Excel listing per-gene totals (e.g., gene X active in N of M comparisons). Rationale: typical four-way plots cannot merge information across multiple plots, so this occurrence counting is the library's mechanism to synthesize multiple scorecards into a single overview.

## Examples

```
scorecard_functions.count_frequencies(main_folder); scorecard_functions.common_entries(main_folder)
```

## Evaluation signals

- The output report exists in CSV or Excel format and contains per-gene occurrence counts for every scorecard region of interest
- Occurrence counts are consistent with the number of sub-folder comparisons present in main_folder (each gene total ≤ number of comparisons)
- count_frequencies was run before common_entries, since common_entries re-uses the frequency information previously created
- The report distinguishes globally changed genes (high occurrence counts) from condition-specific genes (low counts, found in the uncommon-entries report)

## Limitations

- common_entries must be called after count_frequencies because it depends on information previously created by that function
- The overview functions apply only to the scorecard, not to the four-way plot
- The accuracy of the occurrence counts depends on the thresholds (e.g., fold-change thresholds, significance level such as p ≤ 0.05) used when generating each pairwise scorecard
