# snakemake-pipeline-execution

## Summary

Executes the de-goulash Snakemake workflow inside the geniderasmusmc/de-goulash Docker image to deconvolve 10X scRNA-seq mixtures via two iterations of FreeBayes SNP calling, cell merging, and UMAP/k-means clustering, followed by a separate Snakefile_analysis step for identification.

## When to use

Use when a multi-person 10X scRNA-seq mixture (possorted_genome_bam + barcodes.tsv) must be separated into per-contributor cell clusters and genotyped VCFs via a reproducible Snakemake pipeline.

## When NOT to use

- Input is not 10X scRNA-seq output (possorted_genome_bam + barcodes.tsv) — e.g., bulk sequencing, VCFs, or other single-cell formats will not match the Snakefile inputs.
- The biological mixture contains non-living or fixed cells — the 10X platform used by this pipeline requires live cells for successful genetic separation.
- The goal is de novo SNP calling alone without cell-level mixture deconvolution — a standalone variant caller (e.g., freebayes directly) is the wrong-level tool here since this skill targets per-contributor cell clustering.

## Inputs

- possorted_genome_trimmed.bam from 10X Cell Ranger (sample_bam)
- barcodes.tsv (barcodes_reduced.txt) listing cells to use
- genome.fasta (human reference hg19/hg38)
- MT.fasta (mitochondrial sequence, same build as genome)
- regions.txt and MT_regions.txt (generated by process_reference.py / fasta_generate_regions.py)
- config.yaml with sample paths, filtering thresholds, and Snakemake settings
- For the analysis step: exome_96_remmapedto38.vcf.gz (ref_exome), 1000G_populations.txt (ref_population), and the 1000G variant calling directory

## Outputs

- output/iter2/cells_merge_clusters.vcf containing genotyped, per-cluster records for separated contributor cell clusters
- Per-cluster variant calls from iteration-2 genome-wide SNP calling used for identification and ancestry assignment
- Forensic parameters, population/ancestry assignment, haplogroup (Haplogrep) and Y-haplogroup (Yleaf v2.2) results from Snakefile_analysis

## How to apply

Run the pipeline through the provided Docker image by mounting the working directory at /single-cell: step 1 uses Snakefile with config.yaml to drive two iterations — iteration 1 calls mitochondrial SNPs with freebayes in parallel over regions generated by fasta_generate_regions.py, filters at dp=50 and qual=60, keeps cells with at least thr_cell_1=10 SNPs, merges cells in Python using threshold_coverage=10, threshold_coverage_pos=5 and threshold_base_calling=90, then clusters with the Rscript rule using UMAP (n_neighbors=5, n_components=300) and k-means; iteration 2 calls genome-wide SNPs per merged cluster against the full genome.fasta with thr_cell_2=20 SNPs per cell and re-clusters to produce output/iter2/cells_merge_clusters.vcf. Step 2 runs Snakefile_analysis with dp_2=50/qual_2=60 to match cluster SNPs against exome_96_remmapedto38.vcf.gz and 1000G population data, computing likelihood ratios and executing Haplogrep and Yleaf v2.2. Set cores=4 (or --cores 1 as in the documented docker commands) and clusters=0 to disable NbClust-based prediction of the number of clusters when the number of contributors is known. Validate by checking that the target VCF exists and that the recovered cluster count equals the known number of contributors.

## Examples

```
docker run -it -v /current/directory/de-goulash/:/single-cell geniderasmusmc/de-goulash:1 output/iter2/cells_merge_clusters.vcf --snakefile Snakefile --configfile config.yaml --cores 1
```

## Evaluation signals

- For each in silico mixture M5–M9, the number of deconvoluted cell clusters in output/iter2/cells_merge_clusters.vcf equals the known number of contributing individuals (5 through 9, including exactly 9 clusters for the 9-person mixture).
- The target file output/iter2/cells_merge_clusters.vcf exists and contains merged cluster genotype records for the separated contributor clusters.
- In the analysis step, every contributor-to-WES-reference match exceeds 90% shared SNPs, reproducing the reported matching behavior.
- Likelihood ratios for every separated contributor identification exceed the 10E+9 threshold, within the reported range 1.71E+14 to 5.00E+65.
- Imbalanced 2-person mixtures reproduce the documented degradation pattern: clean separation at 1:10–1:40, minor bleed-through at 1:60 (about five misassigned minor cells), degraded assignment at 1:80, and failure at 1:99.

## Limitations

- The 10X Genomics scRNA-seq platform requires live cells, limiting application to biological mixtures containing living cells; fixed-cell or non-living-cell platforms have not been tested.
- Deconvolution was only empirically validated up to 9 contributors and at ratios up to 1:60; more than nine individuals and fewer than ~150 cells require future empirical confirmation.
- Transferability to biological mixtures other than blood mixtures has not yet been demonstrated.
