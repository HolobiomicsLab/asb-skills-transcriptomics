# single-cell-cluster-label-mapping

## Summary

Transfers cluster labels from a ground-truth scRNA-seq dataset to synthetic observations by mapping each synthetic cell to its nearest original cell via Euclidean distance in UMAP space, enabling comparison of per-cluster cell counts between original and synthetic data.

## When to use

Use when synthetic single-cell observations must be assigned cluster identities for fidelity evaluation, and ground-truth cluster labels (e.g. from Seurat clustering on UMAP of PBMC4k or Segerstolpe data) exist only for the original cells.

## When NOT to use

- When batch correction is required: the study examined all models without batch correction capabilities, and batch effects cannot currently be learned with scDBMs
- When ground-truth cluster labels for the original data cannot be trusted (e.g. no Seurat clustering available), since label transfer propagates the assumption that mapped synthetic cells land in correct clusters
- When the goal is annotating cells with known cell-type markers rather than evaluating synthetic-data fidelity against ground-truth clustering

## Inputs

- Ground-truth cluster labels from Seurat clustering on the original dataset's UMAP representation
- UMAP embeddings of the original dataset (e.g. PBMC4k, Segerstolpe)
- UMAP embeddings of synthetic datasets generated by scDBM (Gibbs sampling), scVI prior, or scVI posterior
- Pilot-size sub-samples of 384, 768, 1152, 1536, 1920, or 2304 cells (30 repetitions per size)

## Outputs

- Cluster label assignments for every synthetic observation
- Per-cluster cell counts for original and synthetic datasets
- Mean absolute difference in cell counts per cluster per model-dataset-pilot-size combination (Table 1 structure)

## How to apply

First obtain ground-truth cluster labels for the original dataset by Seurat clustering on its UMAP representation (e.g. PBMC4k 10x Genomics or Segerstolpe Smart-seq2 data). Apply UMAP to both original and synthetic data, then for each synthetic observation compute Euclidean distances to all original observations in UMAP space and assign the cluster label of the nearest original cell. This is applied per model (scDBM sampled via Gibbs sampling, scVI sampled from prior or posterior) and per pilot size (384, 768, 1152, 1536, 1920, 2304 cells; 30 repetitions each). Once labels are mapped, tally cells per cluster in original vs. synthetic data and compute the mean of absolute differences across all clusters, as in Table 1 of the paper. The approach relies on the assumption that synthetic cells are mapped to the correct clusters, so treat mismatches near cluster boundaries as a known error source.

## Evaluation signals

- Output table contains one row per model-dataset-pilot-size combination (3 models x 2 datasets x 6 pilot sizes), matching Table 1 structure
- All absolute difference values are non-negative
- Mean absolute difference in cells per cluster decreases (or near-monotonically decreases) as pilot size increases from 384 to 2304 cells
- Mapped labels reproduce the expected overrepresentation of highly abundant cell types and underrepresentation of rare cell types, consistent with the paper's findings
- Every synthetic observation receives exactly one cluster label from the original label set (no unmapped or out-of-set labels)

## Limitations

- The method relies on the unverified assumption that synthetic cells mapped to the original data are also mapped to the correct clusters
- scVI (posterior) variant showed high variability in clustering similarity, likely due to amplifying artifacts of small datasets
- All approaches overrepresented highly abundant cell types and missed less abundant cell types, so mapped cluster proportions are biased for rare populations
- For sparser 10x Genomics datasets, inference from small to larger datasets is more challenging than for Smart-seq2
