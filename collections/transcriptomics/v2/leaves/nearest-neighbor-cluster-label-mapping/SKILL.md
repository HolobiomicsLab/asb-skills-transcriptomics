# nearest-neighbor-cluster-label-mapping

## Summary

Assigns cluster labels to synthetic scRNA-seq observations by mapping each synthetic cell to its closest original-data cell via minimum Euclidean distance in UMAP space, enabling DBI/ARI evaluation of synthetic data (scDBM, scVI-prior, scVI-posterior) against the Seurat ground-truth partition.

## When to use

Use when synthetic single-cell observations lack labels and you need ground-truth cluster assignments from a reference dataset to compute clustering-quality metrics such as the Davies–Bouldin index or adjusted Rand index.

## When NOT to use

- Synthetic data comes with its own trusted cluster assignments, so nearest-neighbor transfer to a reference partition is unnecessary
- Original and synthetic observations cannot be embedded in a common UMAP space, making Euclidean distance mapping unreliable
- Studying batch effects or batch correction — the paper explicitly excludes batch correction methods from its scope

## Inputs

- Preprocessed original scRNA-seq dataset (e.g., PBMC4k 10x Genomics or Segerstolpe Smart-seq2) with UMAP coordinates and Seurat cluster labels
- Synthetic datasets generated by scDBM, scVI-prior, or scVI-posterior for each pilot size (384, 768, 1152, 1536, 1920, 2304 cells) across 30 replicates

## Outputs

- Per-synthetic-observation cluster labels inherited from the nearest original-data cell
- Davies–Bouldin index and adjusted Rand index values per model, pilot size, and replicate (aggregated with 25th/75th-percentile boxplot hinges in dbi_ari_results.csv)

## How to apply

First reduce both original and synthetic data to a shared UMAP embedding so Euclidean distances are comparable. Apply Seurat clustering to the original data (e.g., PBMC4k or Segerstolpe) to obtain ground-truth labels and record the reference DBI of this Seurat partition as the orange-line benchmark. For each synthetic observation, find the nearest original observation in UMAP space by minimizing Euclidean distance and inherit that cell's cluster label. With the resulting synthetic partition, compute the Davies–Bouldin index on the synthetic clusters and the adjusted Rand index between synthetic and original labels, aggregating over all pilot sizes (384–2304 cells) and 30 replicates. Rationale: this mapping avoids re-clustering synthetic data and ties evaluation directly to the trusted original partition, though it assumes synthetic cells land in the correct clusters.

## Evaluation signals

- Each synthetic observation receives exactly one cluster label from the original Seurat partition (no unlabeled or self-assigned clusters)
- Reference DBI of the original Seurat clustering (orange dotted line) is present in the benchmark figures for comparison
- scVI-posterior variant shows the highest DBI/ARI variability across replicates at small pilot sizes (384–768 cells), consistent with artifact amplification
- DBI and ARI values aggregated over 6 pilot sizes × 30 replicates × 3 models (plus noisy-pilot baseline) are written to dbi_ari_results.csv with 25th/75th-percentile hinges

## Limitations

- The mapping relies on the unverified assumption that synthetic cells mapped to the original data are mapped to the correct clusters
- Synthetic-cell cluster proportions overrepresent abundant cell types and miss rare cell types, biasing downstream metric interpretation
- For sparser 10x Genomics data (e.g., PBMC4k), inference from small to larger datasets is more challenging than for Smart-seq2 (Segerstolpe)
