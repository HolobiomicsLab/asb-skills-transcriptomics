# bam-junction-read-support-quantification

## Summary

Quantifies per-splice-junction read support from coordinate-sorted Hisat2 and STAR BAM alignments and converts it into labeled splice graph edges, where each junction edge carries a read-support weight and an aligner-capture label (1, 2, 2+, 2-). This is the graph-construction backbone Tiglon uses before its label-based dynamic path extension recovers transcripts.

## When to use

Use when you have short-read RNA-seq alignments (BAM) from two or more splice-aware aligners (Hisat2, STAR) and need to quantify junction read support and assign aligner-capture labels to splice graph edges.

## When NOT to use

- Input alignments come from long-read platforms (PacBio, ONT) — Tiglon's current version is not compatible with long-read RNA-seq datasets
- BAM files were generated by aligners other than Hisat(2) or STAR — the current Tiglon version only accepts BAM files generated by Hisat(2) and Star
- The goal is annotation-guided assembly using known transcript annotations — the current version of Tiglon has no option for annotation-guided assemblies

## Inputs

- Coordinate-sorted BAM alignment files produced by Hisat2 (--dta mode) and STAR from the same RNA-seq sample (e.g., SRR307911 reads mapped to GRCh38)
- Reference genome index for each aligner (Hisat2 GFM index, STAR genome index)
- Tiglon parameter list (min_average_frac, min_unbalance_frac, min_gap_length, min_trans_length, min_trans_cov)

## Outputs

- Per-gene-locus labeled splice graph with exon nodes and junction edges annotated with read-support weights and aligner-capture labels (1, 2, 2+, 2-)
- GraphML-serialized labeled splice graph (e.g., xr_locus_labeled_graph.graphml)
- Merged candidate transcripts in GTF format (Tiglon final output)

## How to apply

Align the RNA-seq reads (e.g., SRA SRR307911 against GRCh38) independently with Hisat2 in --dta mode and with STAR to obtain one coordinate-sorted BAM per aligner. For each gene locus, build a splice graph whose nodes are exons and whose edges are splice junctions weighted by read support from the alignments. Filter spurious junction edges with Tiglon thresholds: min_average_frac 0.03, min_unbalance_frac 0.03, min_gap_length 200, min_trans_length 500, and min_trans_cov at its default (>0). Merge the per-aligner graphs into one labeled splice graph: label each junction edge 2 if captured by all employed aligners and 1 otherwise, and refine label 2 into 2+ (identical captured reads across aligners) or 2- (otherwise), averaging edge weights across aligners. The rationale is that Hisat2 and STAR each cover all exons of a transcript but neither covers all its splice junctions, so per-junction capture labels encode complementary evidence that downstream path extension exploits.

## Related tools

- **Hisat2** (Splice-aware aligner generating the per-aligner BAM whose junction read support quantifies one set of splice graph edges) — https://github.com/DaehwanKimLab/hisat2
- **Star** (Second splice-aware aligner whose BAM provides the complementary junction read-support evidence merged into the labeled splice graph) — https://github.com/alexdobin/STAR
- **Tiglon** (Builds and labels the splice graph from the multi-aligner BAMs, filtering junction edges with abundance/coverage thresholds) — https://github.com/yutingsdu/Tiglon-v.1.1
- **BamTools** (BAM toolkit used as a dependency for reading/parsing the alignment files during graph construction) — https://github.com/pezmaster31/bamtools

## Examples

```
hisat2 --dta -x GRCh38 -U SRR307911.fq.gz | samtools sort -o hisat2_SRR307911.bam
```

- Retained junction edges survive the thresholds min_average_frac 0.03, min_unbalance_frac 0.03, min_gap_length 200, min_trans_length 500
- Edge weights on merged junctions equal the average of the per-aligner read-support counts

## Limitations

- The current Tiglon version only accepts BAM files generated by Hisat(2) and Star; alignments from other mapping tools cannot be integrated
- No compatibility with long-read RNA-seq datasets (e.g., Pacific Biosciences PacBio or Oxford Nanopore Technologies ONT)
- Tiglon has no annotation-guided assembly option; known transcript annotations cannot be used to guide the graph construction
