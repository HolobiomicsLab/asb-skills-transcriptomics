# Subnetwork gene feature subsetting for classifier benchmarking

## Summary

Subsets a nonparanormal-transformed expression matrix to the genes of each extracted active subnetwork and trains a PenalizedLDA classifier to benchmark how well each subnetwork detection method's genes discriminate case vs control samples, as done for the GSE172114 COVID-19 critical vs non-critical benchmark in the SEMtree paper.

## When to use

Use when you have SEMtree/SEMgraph-extracted active subnetworks (e.g. ST/STr2z variants) and a binary-labelled expression matrix (GSE172114 critical vs non-critical), and need per-subnetwork classification accuracy and predictor-gene parsimony (Table 3).

## When NOT to use

- When you only need perturbation extraction (DRNs/DREs, ACEs) from the subnetworks and no case-vs-control discrimination benchmark — use SEMrun/SEMace instead.
- When the input is raw, untransformed expression counts — the classifier assumes the nonparanormal transform (transformData) was applied first.
- When no extracted subnetworks exist yet; feature subsetting is downstream of the SEMtree subnetwork extraction step.

## Inputs

- Nonparanormal-transformed COVID-19 RNA-seq expression matrix (GEO: GSE172114; 46 critical and 23 non-critical cases) from SEMgraph::transformData
- Binary group vector of patient status using {1: case, 0: control} (critical vs non-critical)
- Extracted COVID-19 active subnetworks from SEMtree (Steiner-tree ST/STr2z backbone and five active subnetwork detection method outputs), with genes labelled by symbol

## Outputs

- Per-subnetwork out-of-sample classification accuracy values
- Per-subnetwork count of predictor (feature) genes selected by the PenalizedLDA classifier
- classifier_accuracy.csv — the accuracy and parsimony table mirroring the Table 3 classifier block

## How to apply

First transform the RNA-seq expression matrix with SEMgraph::transformData to apply the nonparanormal (shrunk ECDF) transform, relaxing the normality assumption. Load the extracted COVID-19 active subnetworks from the upstream SEMtree sub-task — including the Steiner-tree backbone (SEmtree type = 'ST', eweight = 'pvalue') and its r2z-weighted (ST/STr2z) variants generated by the five active subnetwork detection methods. For each subnetwork, subset the transformed matrix (data.npn) to that subnetwork's genes (matching V(subnet)$name labels after org.Hs.eg.db Entrez-to-symbol conversion) and fit a PenalizedLDA penalized Fisher's discriminant classifier with the binary group vector using the {1: case, 0: control} convention (critical vs non-critical). Estimate out-of-sample accuracy per method and record the number of predictor genes selected by each classifier, then assemble the Table 3 classifier block. The expected pattern: most subnetwork methods exceed 90% accuracy, only COSINE and WGM_FC fall below (around 80%), and the ST/STr2z tree-based subnetworks give the smallest predictor gene sets.

## Related tools

- **SEMgraph** (Provides transformData for the nonparanormal (shrunk ECDF) transform of expression data and hosts the SEMtree function that generates the subnetworks used as feature sets) — https://CRAN.R-project.org/package=SEMgraph
- **PenalizedLDA** (Penalized Fisher's discriminant classifier fitted on each subnetwork's gene subset to predict critical vs non-critical status)
- **SEMdata** (Supplies the COVID-19 RNA-seq dataset (GSE172114) used for the classification benchmark) — https://github.com/fernandoPalluzzi/SEMdata
- **org.Hs.eg.db** (Gene ID conversion (Entrez to gene symbols) so subnetwork node labels match expression matrix columns for subsetting)

## Examples

```
data.npn <- SEMgraph::transformData(exprs)$data; X.sub <- data.npn[, V(subnet)$label]; fit <- PenalizedLDA(x = t(X.sub), y = group)
```

## Evaluation signals

- Most subnetwork detection methods reproduce Table 3 with classification accuracy above 90% for case vs non-case.
- Only COSINE and WGM_FC fall below 90% (around 80%) accuracy.
- The ST/STr2z tree-based subnetworks yield the most parsimonious (smallest) predictor gene sets of all methods.
- Expression matrix columns subsetted per subnetwork exactly match that subnetwork's gene labels (post org.Hs.eg.db symbol conversion).
- Group vector uses the {1: case, 0: control} convention and data were nonparanormal-transformed before fitting.

## Limitations

- Only COSINE and WGM_FC subnetworks fall below the 90% accuracy benchmark (~80%), so per-method comparison matters; pooled or averaged accuracy would mask this.
- The Discussion section text is absent from the source document, so caveats on generalization of classifier performance are not documented here.
- Performance is tied to the GSE172114 young-patient COVID-19 cohort (46 critical / 23 non-critical) and KEGG backbone; transfer to other cohorts/datasets is untested in this source.
