# transposable-element-expression-quantification

## Summary

Quantify transposable element (TE) expression per cell from single-cell sequencing data using the scTE pipeline, which assigns reads first to gene exons and then to TE metagenes, producing a cell-by-gene/TE count matrix from BAM/SAM alignments.

## When to use

Use when you have single-cell RNA-seq (or ATAC-seq) BAM/SAM alignments from Cell Ranger or STARsolo and need per-cell TE expression counts alongside gene counts, e.g. to detect cell-type-specific or branch-restricted TE expression.

## When NOT to use

- The input is already a gene/TE count matrix or feature table — scTE requires raw aligned BAM/SAM reads
- The analysis targets bulk RNA-seq read-to-TE counting with a different tool (e.g. te_counter for paired-end bulk BAMs), not single-cell barcode/UMI demultiplexing
- Only filtered Cell Ranger BAMs are available and per-cell barcode/UMI tags are absent, since unfiltered alignment files are highly recommended

## Inputs

- Unfiltered BAM/SAM alignment file from Cell Ranger or STARsolo with cell barcodes in CB/CR tags and UMIs in UB/UR tags
- Gene annotation GTF file (e.g. GENCODE vM21 for mm10, Ensembl release-103)
- TE annotation six-column BED file derived from UCSC goldenPath rmsk.txt.gz RepeatMasker table
- Prebuilt scTE index file (e.g. mm10.exclusive.idx) generated by scTE_build

## Outputs

- Cell-by-gene/TE count matrix (cells as rows, gene/TE features as columns) in CSV format
- Count matrix in .h5ad format when --hdf5 True is set
- Differential TE expression results (e.g. de_te_results.csv) after aggregation by cell type

## How to apply

Build a genome index with scTE_build from a gene annotation GTF (e.g. GENCODE vM21 or Ensembl release-103) and a TE annotation BED derived from the UCSC goldenPath rmsk.txt.gz RepeatMasker table (e.g. mm10). Run scTE on the unfiltered BAM/SAM alignment file, specifying the barcode and UMI tag names (-CB CB -UMI UB for Cell Ranger output; -CB CR -UMI UR for STARsolo output, or -CB False -UMI False for Smart-seq2-style BAMs lacking those tags). By default scTE allocates reads exclusively: TEs inside exon/UTR regions contribute only to the gene score; switch to -m inclusive to count such reads for both, or -m nointron to remove TEs inside gene introns — the nointron mode is used to test whether cell-type-specific TEs survive when intronic reads are excluded. Output the cell-by-gene/TE count matrix as CSV (default) or set --hdf5 True for .h5ad, then aggregate counts by cell type and perform differential testing with thresholds such as ≥2-fold change and FDR < 0.05.

## Examples

```
scTE -i inp.bam -o out -x mm10.exclusive.idx --hdf5 True -CB CB -UMI UB
```

## Evaluation signals

- Output count matrix exists with cells as rows and gene/TE features as columns in the requested CSV or .h5ad format
- In default exclusive mode on the GSE103221 mESC/MEF data, differential testing (≥2-fold change, FDR < 0.05) reproduces 108 significantly DE TEs including ERVB7_1-LTR_MM in ESCs and RMER10B in MEFs
- Re-running in nointron mode retains ~94 of the 108 cell-type-specific TEs, with only 14 altered
- Tabula Muris analysis recovers ~130 TE–cell-type-specific associations (L1 family members in oligodendrocytes/microglia, LTR58 in B cells, RLTR46 in hepatocytes)
- Reprogramming data show branch-restricted TE expression: ERVB7_1-LTR_MM in iPSCs, IAPEz-int in trophoblast, RLTR4_Mm in stromal, Lx in neural-like branches

## Limitations

- Multimapping TE reads are collapsed to a single TE subtype, which constrains quantification of repetitive elements; many studies exclude TEs entirely due to analysis difficulties from their repetitive nature
- The allocation mode choice matters: in default exclusive mode TEs inside exon/UTR regions contribute only to the gene, so TE specificity can be an artifact of intronic reads (14 of 108 DE TEs changed under nointron mode)
- Read assignment relies on cell barcode and UMI tags being present in the BAM (CB/UB or CR/UR); datasets like the C1/Smart-seq2 Tabula Muris lack these tags and require -CB False -UMI False with cell identity taken from BAM file names
- TE information content is lower than that of genes; TEs serve mainly as an addendum to gene information, and using TE data as enhancer information in single-cell ATAC-seq remains speculative
