# condition-specific-int-pair-identification

## Summary

Identification of ligand-receptor int-pairs uniquely found in each condition during InterCellar's multiple-conditions analysis, followed by a one-sided permutation test (1000 permutations, p < 0.05) to call condition-specific functional terms significant (e.g., critical vs moderate COVID-19).

## When to use

Use when you have CCI datasets (e.g., CellChat, CellPhoneDB, ICELLNET, SingleCellSignalR outputs) from two or more conditions and need to extract condition-unique int-pairs and test which functional terms are significantly condition-specific.

## When NOT to use

- Input is a single condition/dataset — condition-unique int-pair extraction and the permutation comparison require multiple CCI datasets
- You need to infer ligand-receptor interactions from raw scRNA-seq counts — this skill works on pre-computed CCI datasets and does not perform prediction
- You require programmatic analysis in Python or scripting beyond R — InterCellar is an interactive R/Shiny app designed for no-programming analysis

## Inputs

- Pre-computed cell-cell interactions (CCI) datasets per condition, generated by InterCellar-supported tools (CellChat, CellPhoneDB, ICELLNET, SingleCellSignalR)
- Functional annotation of int-pairs from Gene Ontology and pathway databases computed in the function-verse

## Outputs

- List of condition-unique int-pairs per condition (e.g., CD160 & TNFRSF14 unique to moderate COVID-19)
- Permutation-test p-values with significant functional terms per condition at p < 0.05 (e.g., 'inflammation mediated by chemokine and cytokine signaling pathway' in critical, 'T cell costimulation' in moderate)
- Sunburst plot of enriched terms per condition plus downloadable results table

## How to apply

Load pre-computed CCI datasets for each condition into InterCellar (e.g., critical and moderate COVID-19). In the function-verse, run functional annotation of the enriched int-pairs to assign Gene Ontology / pathway functional terms. Use InterCellar's multiple-conditions comparison to extract int-pairs uniquely present in each condition (e.g., the CD160 & TNFRSF14 pair unique to moderate COVID-19). Apply the one-sided permutation test with 1000 permutations on the condition-unique int-pairs and call functional terms significant at p < 0.05. Visualize enriched terms per condition with a sunburst plot and export both the plot and the results table for reproducibility.

- **InterCellar** (Interactive R/Shiny app performing the multiple-conditions comparison of int-pairs, permutation testing, functional annotation, and sunburst visualization) — github.com__martaint__InterCellar

```
library(InterCellar); InterCellar::run_app(reproducible = TRUE)
```

## Evaluation signals

- 'inflammation mediated by chemokine and cytokine signaling pathway' is significant in critical COVID-19 and 'T cell costimulation' is significant in moderate COVID-19 after 1000 permutations at p < 0.05
- Condition-unique int-pair lists are disjoint subsets of each condition's interactions (e.g., CD160 & TNFRSF14 appears only in the moderate set)
- Sunburst plot and results table are exported per condition, matching the paper's Fig. 6 reproducibility outputs
- The app is launched with reproducible = TRUE so results are stable across R sessions

## Limitations

- InterCellar currently supports only a limited set of input tools (CellChat, CellPhoneDB, ICELLNET, SingleCellSignalR); extension to other published tools is planned future work
- Predicted interactions await experimental validation (e.g., smFISH or flow cytometry co-occurrence), so condition-specific signals remain predictions
- Prediction methods rely on different reference databases and statistical assumptions, making upstream method choice critical for the int-pairs being compared
