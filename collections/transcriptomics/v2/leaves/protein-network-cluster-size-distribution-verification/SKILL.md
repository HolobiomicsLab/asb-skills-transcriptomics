# protein-network-cluster-size-distribution-verification

## Summary

Verifies MCL graph clustering of the combined FAVA protein association network by reproducing the reported 341 clusters (inflation 1.5) and the 130 clusters with five or more nodes, then running Cytoscape stringApp 2.0 enrichment on those clusters across seven annotation categories.

## When to use

Use when a weighted protein association network edge list (e.g. from a favapy run) must be partitioned into functional clusters with MCL and the resulting cluster count and size distribution must be validated against published numbers before enrichment analysis.

## When NOT to use

- The network has not yet been generated by the upstream favapy run — clustering an unvalidated or differently filtered edge list will not reproduce the 341/130 reference numbers.
- The goal is enrichment on all clusters regardless of size — this skill restricts downstream enrichment to clusters with five or more nodes.
- The clustering target is a co-expression network from raw scRNA-seq rather than a FAVA-inferred protein association network in latent-space correlation form.

## Inputs

- Combined FAVA protein association network edge list (interactions in both directions: proteinA-proteinB and proteinB-proteinA)
- MCL inflation parameter (1.5)
- Minimum cluster-size cutoff for downstream analysis (5 nodes)

## Outputs

- MCL cluster assignment per protein (341 clusters, 130 with >=5 nodes)
- Cluster-size distribution table
- enrichment_table_S1.tsv — stringApp enrichment results for all seven categories in Supplementary Table S1 column structure

## How to apply

Load the combined FAVA network edge list produced upstream, ensuring each interaction appears in both directions (proteinA-proteinB and proteinB-proteinA). Run MCL with the inflation parameter set to 1.5 to partition proteins into functional clusters. Compute the cluster count and cluster-size distribution and check against the reported reference values: 341 total clusters, of which 130 contain five or more nodes. Only clusters of size >=5 proceed to downstream analysis: import the clustered network into Cytoscape with stringApp 2.0 and run enrichment across the seven categories (Pathways, UniProt Keywords, Cellular Compartments, Tissues, Biological Processes, Molecular Functions, Diseases), exporting results as a TSV matching the Supplementary Table S1 column layout.

## Related tools

- **favapy** (produces the upstream combined FAVA protein association network edge list that is clustered) — https://github.com/mikelkou/fava
- **MCL** (graph clustering of the FAVA network with inflation 1.5 into 341 functional clusters)
- **Cytoscape stringApp 2.0** (import of the clustered network and enrichment analysis on clusters with >=5 nodes across seven annotation categories)
- **Python** (computes the cluster count and cluster-size distribution and validates against reported values)

## Examples

```
mcl favava_combined_network.edges --abc -I 1.5 -o clusters_inflation1.5.tsv
```

## Evaluation signals

- MCL clustering (inflation 1.5) reproduces exactly 341 clusters
- Cluster-size distribution shows 130 clusters containing five or more nodes
- Enrichment table contains results for all seven annotation categories: Pathways, UniProt Keywords, Cellular Compartments, Tissues, Biological Processes, Molecular Functions, Diseases
- enrichment_table_S1.tsv column structure matches Supplementary Table S1
- Each interaction from the favapy edge list is present in both directions (proteinA-proteinB and proteinB-proteinA) before MCL is run

## Limitations

- Validation is exact-match against reported values (341 clusters, 130 with >=5 nodes); deviations may reflect differences in the upstream FAVA network rather than MCL settings
- Clusters with fewer than five nodes are excluded from enrichment, so small modules are not characterized
- stringApp enrichment depends on the seven supported annotation categories and Cytoscape stringApp 2.0 availability
