# rare-cell-clustering-method-benchmarking

## Summary

Benchmark a rare-cell clustering method (SCISSORS) against Seurat/Louvain, GiniClust3, CellSIUS, k-means, hierarchical, DBSCAN, and Leiden on simulated scRNA-seq data with ground-truth labels, scoring each method by ARI, NMI, and median per-cell silhouette on cosine distance over PCA embeddings.

## When to use

Use when a new rare-cell or subcluster clustering method must be validated for label-recall superiority on simulated scRNA-seq data with known ground-truth cell-type labels, comparing ARI/NMI/silhouette against clustering baselines.

## When NOT to use

- Data has no ground-truth labels and no simulation basis is possible — ARI/NMI label recapture cannot be computed, so only internal metrics remain
- The question is which clustering resolution a single method should use on one real dataset (use MultiK/getClusters-style resolution selection instead of cross-method benchmarking)
- Inputs are not per-cell scRNA-seq count matrices from a Seurat-standard pipeline (e.g. already-aggregated feature tables or bulk expression) — the silhouette-on-PCA comparison is undefined

## Inputs

- Simulated scRNA-seq count matrices with retained ground-truth cell-type labels, generated by subsampling/mixing Zilionis 2019 human lung cancer and Baron 2016 human normal pancreas references across varied cluster numbers, rare-cell proportions, and dropout levels
- Seurat preprocessed objects (NormalizeData, FindVariableFeatures vst 2000 features, ScaleData, RunPCA) per simulation
- Cluster label assignments from each competing method on the same simulations

## Outputs

- Method-by-metric results dataframe (ARI and NMI vs. ground truth per method per simulation)
- Per-cell silhouette scores computed on PCA embeddings with cosine distance (cluster::silhouette with CosineDist input)
- Two-sided Wilcoxon rank-sum p-values comparing the focal method against each competitor
- ggplot2 Fig. 2a-c panels: ARI/NMI bar plots and silhouette violin plots with geom_signif significance bars; silhouette figure saved as Sil_Scores.pdf

## How to apply

Generate simulation datasets by subsampling and mixing reference cells (Zilionis 2019 human lung cancer, Baron 2016 human normal pancreas) across parameter combinations varying cluster number, rare-cell proportion, and dropout, retaining the ground-truth labels. Preprocess every simulation with the standard Seurat pipeline: NormalizeData, FindVariableFeatures with selection.method='vst' and nfeatures=2000, ScaleData, RunPCA. Run the method under test in completely unsupervised mode (SCISSORS with silhouette-score-driven reclustering) and each competitor (Seurat/Louvain, GiniClust3 Gini/Fano consensus, CellSIUS, k-means, hierarchical, DBSCAN, Leiden) on the identical simulations. Assemble a method-by-metric results dataframe with dplyr; compute ARI and NMI of each method's clusters against ground truth, and per-cell silhouette scores via cluster::silhouette using CosineDist on the PCA embeddings. Test differences between the method under test and each competitor with two-sided Wilcoxon rank-sum tests, then render comparison panels (ARI/NMI bars, silhouette violin plots with geom_signif significance bars) in ggplot2. Rationale: simulation against ground truth is the only setting where label-recapture (ARI/NMI) can be measured directly, and silhouette on cosine distance over PCA space quantifies internal cluster coherence in the same space all methods share.

## Evaluation signals

- SCISSORS must show the highest ARI and NMI against ground-truth labels across the simulation parameter grid from both reference datasets
- SCISSORS must achieve the highest median silhouette score across methods on cosine distance over PCA embeddings
- Each pairwise difference between SCISSORS and a competitor must be statistically significant under the two-sided Wilcoxon rank-sum test as reported in the paper
- Ground-truth labels must be retained for every simulated cell despite subsampling, mixing, and dropout perturbations
- All methods must run on identical simulations and identical Seurat preprocessing (same PCA) so ARI/NMI/silhouette comparisons are apples-to-apples

## Limitations

- Small differences in analysis and parameter choice can greatly alter scRNA-seq clustering results, so benchmark conclusions are sensitive to the preprocessing parameters (e.g. nfeatures = 2000, dims = 1:10) fixed across methods
- Silhouette estimation of cluster heterogeneity and reclustering are bounded by the initial broad clustering (initial.resolution = 0.4 in the README workflow); extremely low-abundance cells remain subtle contributors toward global metrics
- Benchmark is grounded in two reference datasets (human lung cancer, human normal pancreas); generalization to other tissues or sequencing platforms is not directly demonstrated
