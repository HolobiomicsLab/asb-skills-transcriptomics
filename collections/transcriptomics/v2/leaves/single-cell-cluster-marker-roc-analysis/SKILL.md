# single-cell-cluster-marker-roc-analysis

## Summary

ROC/AUC-based marker analysis for single-cell clustering results, using the ClonoCluster Find_Markers_ROC wrapper around ROCR to compute AUCs for cluster markers (marker fidelity) and reorganization markers (genes whose expression predicts cluster rearrangement between transcriptome-only and hybrid clusters).

## When to use

Use when you have a count matrix plus cluster assignments (e.g., ClonoCluster hybrid clusters across alpha values) and need to quantify marker sensitivity/specificity via AUC or identify reorganization markers (reorg-AUC > 0.80).

## When NOT to use

- The goal is differential expression testing with p-values rather than ROC-based marker classification accuracy — use a DE framework instead
- Cell IDs in the barcode table do not exactly match those in the count matrix — the analysis would mispair cells and barcodes
- No cluster assignments exist yet; hybrid clusters must first be generated by running clonocluster over the alpha range

## Inputs

- Normalized or scaled gene-by-cell count matrix (e.g., mycountmatrix.tsv, retrievable from a Seurat object)
- Table of unique cell IDs and assigned barcodes (e.g., mybarcodetable.tsv)
- Cluster-assignment table from clonocluster(pca, bt, alpha = seq(0, 1, by = 0.1), beta = 0.1, res = 1), one assignment per cell per alpha value

## Outputs

- Per-cluster and per-alpha AUC tables (e.g., marker_fidelity_auc.tsv, *_auc_linclust.txt)
- Reorganization marker list at reorg-AUC > 0.80 (reorg_markers.csv, *_auc_barcodes.txt)
- Marker fidelity heatmap (pheatmap) and top-marker boxplots per alpha level

## How to apply

Load the normalized/scaled gene-by-cell count matrix and cluster-assignment table with data.table::fread, verifying cell IDs match between tables. For each dataset and clustering level (alpha = 0, low alpha ~0.1–0.3, high alpha ~0.6–0.9, alpha = 1), run Find_Markers_ROC(dl, cm), which uses ROCR to compute ROC AUCs for all candidate cluster markers; compute the median top-marker AUC per alpha level to assess marker fidelity against the transcriptome-only (alpha = 0) baseline. To find reorganization markers, compute the reorg-AUC quantifying how well each gene's expression predicts rearrangement between paired transcriptome-only and hybrid clusters, then filter at reorg-AUC > 0.80. Validate that all AUCs fall within [0.5, 1] and that hybrid alpha medians are comparable to the alpha = 0 baseline for most datasets. Write per-cluster AUCs and per-alpha medians to files such as marker_fidelity_auc.tsv or reorg_markers.csv, optionally rendering heatmaps with pheatmap.

## Related tools

- **ClonoCluster** (Provides Find_Markers_ROC wrapper and hybrid cluster assignments whose markers are scored by ROC AUC) — https://github.com/leeprichman/ClonoCluster

## Examples

```
clust <- clonocluster(pca, bt, alpha = seq(0, 1, by = 0.1), beta = 0.1, res = 1); aucs <- Find_Markers_ROC(dl, cm)
```

## Evaluation signals

- All computed AUC values fall within [0.5, 1]
- Median top-marker AUC at hybrid alpha values is not significantly different from the transcriptome-only (alpha = 0) baseline for most datasets
- Known exceptions are reproduced: decreased fidelity for cardiomyocyte-directed iPSCs (0.69/0.79 vs 0.94) and low-dose vemurafenib samples, where cell fate is extrinsically determined
- Reorganization marker filter yields reorg-AUC > 0.80 genes whose top enriched gene sets (WebGestaltR, FDR < 0.05) include ribosomal/translation and extracellular matrix terms
- Output files (e.g., marker_fidelity_auc.tsv, reorg_markers.csv) contain one AUC entry per candidate marker per cluster/alpha level with matching cell IDs across inputs

## Limitations

- Marker fidelity can drop at high alpha for extrinsically determined systems (cardiomyocyte-directed iPSCs, low-dose vemurafenib), so fidelity equivalence is not guaranteed
- No reliable method exists to identify a priori which experimental systems have intrinsic determinants of cell fate and would benefit from clonal weighting
- Further testing of homogeneity of functional properties within clusters is required to determine which clustering methods most closely match biological distinctions
