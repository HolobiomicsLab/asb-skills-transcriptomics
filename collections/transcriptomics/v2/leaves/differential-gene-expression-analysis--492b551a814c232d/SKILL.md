# differential-gene-expression-analysis

## Summary

Marker gene identification module from the SCISSORS framework: a candidate gene list is generated by one-vs-background differential expression for a target cluster or subcluster, then filtered by expression percentile to retain only genes of high specificity to the target cell type.

## When to use

Use when a Seurat scRNA-seq object with annotated clusters/subclusters (e.g. PBMC3k) needs cluster-specific marker genes, and genes expressed in any non-target cluster must be excluded from the marker set.

## When NOT to use

- The input is a bulk RNA-seq or pre-computed feature table rather than a per-cell Seurat object with cluster labels — the method relies on comparing one annotated cluster against background clusters.
- The goal is differential expression between two defined conditions or groups, not identifying genes specific to a single cluster/subcluster — the specificity filter discards genes expressed in the top percentile of any non-target cluster.
- Clusters are heterogeneous and have not yet been reclustered (e.g. via SCISSORS silhouette-score-driven reclustering), so the 'target subcluster' is not a valid comparison unit.

## Inputs

- Processed scRNA-seq Seurat object with cluster annotations (e.g. PBMC3k object from SeuratData, normalized and PCA-reduced)
- Target cluster or subcluster identity label
- Set of background (non-target) clusters or closely related subclusters
- Adjusted expression-percentile cutoff (default: top 10%)

## Outputs

- Candidate marker gene list from Wilcoxon rank-sum differential expression (positive markers only)
- Specificity-filtered marker gene table (genes absent from the top expressed percentile of every non-target cluster)
- markers_filtered.csv file

## How to apply

Start from the processed Seurat object prepared with NormalizeData, FindVariableFeatures (vst selection of 2000 features), ScaleData, and RunPCA, since SCISSORS is wrapped around Seurat and integrates into existing Seurat pipelines. Build the candidate marker list by running Wilcoxon rank-sum differential expression (FindAllMarkers with test.use = 'wilcox' and only.pos = TRUE) comparing the target cluster or subcluster against background clusters — the rest of the clusters, or other closely related subclusters. For each candidate gene, quantify its expression percentile across the non-target clusters. Remove from the candidate list any gene that ranks within the top 10% (user-adjustable) expressed percentile of any non-target cluster, yielding the specificity-filtered marker set. Write the filtered table to markers_filtered.csv.

## Examples

```
markers <- FindAllMarkers(pbmc, test.use = "wilcox", only.pos = TRUE)
```

## Evaluation signals

- Every gene in the filtered set falls below the top 10% expressed percentile in each non-target cluster (i.e. no gene ranks in the top expressed percentile of any background cluster).
- All retained markers are positive markers: each came from FindAllMarkers run with only.pos = TRUE, so the target cluster shows upregulation relative to background.
- The specificity-filtered table was serialized as markers_filtered.csv with the expected gene-by-statistics columns.
- The candidate list was generated with the Wilcoxon rank-sum test (test.use = 'wilcox') against background or closely related subclusters, not an unpaired global test.
- Retained genes show high expression percentile in the target cluster, consistent with the paper's reported markers of high specificity to the cell type.

## Limitations

- The exclusion threshold (top 10% expressed percentile) is user-adjustable; stricter or looser cutoffs change which shared but biologically relevant markers are discarded.
- Genes highly expressed in any non-target cluster are removed even if they are meaningful markers, so the method yields maximally specific rather than maximally discriminative marker sets.
