# personalized-genome-alignment-with-star

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Align RNA-seq reads to haplotype-modified personal genomes with STAR as Step 1 of the PAIRADISE pipeline (personalization, mapping, and assignment), enabling allele-specific read assignment for ASAS detection.

## When to use

Use when detecting allele-specific alternative splicing (ASAS) from RNA-seq fastq data and reads must be assigned to alleles via alignment to haplotype-modified personal genomes rather than a generic reference.

## When NOT to use

- SNPs of interest are located within or too distant from alternative exons, since allele-specific read assignment requires a heterozygous SNP outside the alternative exon but close enough to be detected on the same RNA-seq read
- The goal is standard differential splicing between conditions rather than allele-specific alternative splicing within individuals (use the rMATS paired model instead)
- Working with genomes too small for STAR's intended scope — STAR is tested with default parameters for human and mouse genomes and mammal genomes require at least 16GB of RAM

## Inputs

- Sample FASTQ files (.gz) in the data directory's input/ subdirectory
- Genotype VCF files, one per chromosome, in genotype/ subdirectories matching sample names
- Reference genome files in genome/: hg19.fa, Homo_sapiens.GRCh37.75.dna.primary_assembly.fa, Homo_sapiens.Ensembl.GRCh37.75.gtf, Human_AG_all_hg19_v2.txt
- sample_name.txt manifest (sample IDs, sample names, RNA-seq read lengths)

## Outputs

- Allele-assigned reads per sample (personalized-genome alignments from Step 1)
- qsub files for all five PAIRADISE pipeline stages generated by run_preprocess.py
- Downstream merged count table feeding the PAIRADISE statistical model (Step 5)

## How to apply

Generate the qsub files with scripts/run_preprocess.py using the sample_name.txt manifest (sample IDs, sample names, RNA-seq read lengths), the population name, and the data directory. Submit pairadise_step1_<sample>.qsub for every sample with h_vmem=90G; this performs personalization, mapping, and assignment, aligning reads to both versions of the haplotype-modified personal genomes with STAR (runtime 2-5 hours per sample for the Geuvadis CEU dataset). Require that any read assigned to a specific haplotype is uniquely aligned to both haplotype-modified genomes at the same location; if a read contains multiple SNPs, assign it by majority voting or discard it on a draw. Only after Step 1 finishes for all samples proceed to Step 2 (joint annotation) and downstream counting, merging, and PAIRADISE statistical modeling.

## Related tools

- **STAR** (Spliced aligner used to map RNA-seq reads to haplotype-modified personal genomes in PAIRADISE Step 1 (personalization, mapping, and assignment); requires >= 2.6.0a) — https://github.com/alexdobin/STAR
- **PAIRADISE** (Pipeline and statistical framework that wraps the personalized alignment step and later tests one SNP at a time for ASAS at FDR <= 10%) — https://github.com/Xinglab/PAIRADISE
- **rPGA pipeline** (Defines the personalization procedures followed to build the haplotype-modified personal genomes used for alignment)

## Examples

```
qsub -cwd -l h_vmem=90G qsub_files/pairadise_step1_NA12843.qsub
```

## Evaluation signals

- Step 1 qsub for each sample completed within the documented 2-5 hour runtime range (Geuvadis CEU) at h_vmem=90G
- Every read assigned to a specific haplotype aligns uniquely to both versions of the haplotype-modified personal genomes at the same location
- Multi-SNP reads are assigned by majority voting or discarded when there is a draw, with no ambiguous assignments retained
- Downstream output table contains the 19 documented columns and, after Steps 2-5, per-population significant event counts at FDR <= 10% match the reported conservative results (CEU 91, FIN 82, GBR 75, TSI 71, YRI 143)

## Limitations

- Step 1 can take a long time to run (2-5 hours per sample for the CEU dataset)
- Mammal genomes require at least 16GB of RAM, ideally 32GB, for STAR alignment
- The paper's ASAS results are intentionally conservative; allowing sigma_i1 = sigma_i2 would increase significant events (e.g., 91 to 153 in Geuvadis CEU)
- Reads must be aligned to both haplotype-modified personal genomes uniquely at the same location to be assigned; non-unique alignments are filtered
