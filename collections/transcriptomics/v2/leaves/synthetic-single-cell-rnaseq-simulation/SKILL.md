# synthetic-single-cell-rnaseq-simulation

## Summary

Generate synthetic single-cell RNA-seq count matrices with Splatter using simulation settings from the CellRouter supplement, then benchmark reconstructed trajectories against baseline algorithms (Monocle 1/2, DPT, Wishbone, Waterfall) using correlated-gene counts and lag-1 autocorrelation along pseudotime (Supplementary Fig. 4g,h).

## When to use

Use when a trajectory-inference method must be evaluated on controlled synthetic scRNA-seq data with known structure, using gene-expression smoothness metrics along pseudotime rather than only qualitative figure comparison.

## When NOT to use

- The question is about real biological data such as the Paul et al. (Cell 2015) mouse myeloid progenitor dataset — use the experimental-data CellRouter workflow instead of the synthetic benchmark
- The method under test was not among the compared trajectory algorithms (CellRouter, Monocle 1/2, DPT, Wishbone, Waterfall) and the correlation/autocorrelation metrics do not apply to its output

## Inputs

- Splatter simulation parameter settings from the CellRouter manuscript supplement
- Synthetic single-cell RNA-seq count matrices generated by Splatter
- Trajectory outputs from CellRouter and baselines (Waterfall, Monocle 1, Monocle 2, Wishbone, DPT)

## Outputs

- Per-method counts of genes with expression correlated along the reconstructed trajectory
- Per-method lag-1 autocorrelation distributions of gene expression along pseudotime
- Side-by-side comparison figure replicating Supplementary Fig. 4g,h (supplementary_fig4gh_comparison.png)

## How to apply

Install the R dependencies required by CellRouter ('reshape','reshape2','pheatmap','tsne','igraph','ggplot2','mclust','grid','Rtsne','cccd') plus Vennerable, source the CellRouter class, and point the 'libdir' variable at the Java libraries inside the CellRouter folder. Simulate count matrices with Splatter using the simulation settings described in the manuscript supplement. Run CellRouter on the simulated data by identifying subpopulations via learning the data structure with community detection and reconstructing high-resolution multi-state trajectories between subpopulations; run Waterfall and Monocle 1 (linear trajectories), Wishbone (single branch point), Diffusion Pseudotime (requires a priori number of branches), and Monocle 2 on the same matrices. For each method, count genes with expression correlated along the reconstructed trajectory and compute the lag-1 autocorrelation of gene expression along pseudotime, then plot the two distributions per method side by side as in Supplementary Fig. 4g,h.

## Evaluation signals

- The reproduced figure qualitatively matches Supplementary Fig. 4g,h in layout (correlated-gene counts and lag-1 autocorrelation distributions side by side per method)
- CellRouter recovers at least as many correlated genes as each baseline method on the simulated data
- CellRouter achieves lag-1 autocorrelation of gene expression along pseudotime comparable to or better than the baselines (smoother trajectories)
- All listed R packages installed and the CellRouter class sourced with a valid 'libdir' path to the Java libraries before running
- All six methods (CellRouter, Waterfall, Monocle 1, Monocle 2, Wishbone, DPT) are run on the identical Splatter-simulated count matrices

## Limitations

- Simulation settings for Splatter are described only in the manuscript supplement; parameter-level detail is not given in the main text or README
- Validation is qualitative (figure match) plus relative metric comparison; the GitHub README does not provide the synthetic-data benchmark script
- The comparison covers only the baseline algorithms named in the manuscript; DPT additionally requires the a priori number of branches as input
