# Spearman correlation gene ranking

## Summary

Rank genes per cell type by computing Spearman correlation between OnClass cell-type probability vectors and gene expression profiles, selecting the top 20 marker genes per Cell Ontology term, including unseen terms. This reproduces the OnClass marker gene identification strategy from the Nature Communications 2021 paper (DOI 10.1038/s41467-021-25725-x).

## When to use

Use when you have OnClass prediction probability matrices (e.g. pred_Y_seen.released.npy, pred_Y_all.released.npy) plus single-cell expression data and need to identify or validate marker genes for seen and unseen Cell Ontology terms.

## When NOT to use

- The Cell Ontology cannot distinguish topologically identical unseen cell types (siblings with the same parents in the Cell Ontology graph), so this ranking cannot yield distinct markers for such sibling terms.
- The task requires correcting batch effects in the presence of many unseen cell types — such methods are not yet developed per the paper's discussion.
- Input is a raw unannotated scRNA-seq matrix without OnClass prediction probability vectors; run the classification workflow first.

## Inputs

- OnClass prediction probability matrices (pred_Y_seen.released.npy, pred_Y_all.released.npy) from run_generate_pretrained_model.py
- Annotated single-cell gene expression matrix (e.g., all FACS cells from Tabula Muris Senis)
- Cell Ontology files from the figshare deposits
- Curated marker gene sets for AUROC validation

## Outputs

- Ranked gene list per cell type (top 20 marker genes per Cell Ontology term, seen and unseen)
- Marker-gene-based cell type predictions (Figure 5d,e,f, Extended Data Figure 7)
- Per-cell-type AUROC values stratified by seen/unseen terms and by dataset (Muris FACS, Muris droplet)

## How to apply

Load the OnClass prediction matrices (pred_Y_seen.released.npy and pred_Y_all.released.npy) generated by run_generate_pretrained_model.py together with the annotated single-cell expression data (e.g., all FACS cells from Tabula Muris Senis) and the Cell Ontology files. Using run_marker_genes_identification.py, compute the Spearman correlation between each cell type's predicted probability vector in pred_Y_all and each gene's expression profile to rank all genes per cell type, then select the top 20 genes per cell type, mirroring OnClass's precomputation strategy. Next run run_marker_gene_based_prediction.py to build marker-gene-based cell type predictions (Figure 5d,e,f, Extended Data Figure 7). Finally, evaluate the identified markers against curated marker gene sets by computing AUROC per cell type, stratifying seen vs unseen terms per dataset.

## Evaluation signals

- Each cell type receives exactly 20 ranked marker genes after the Spearman correlation ranking step.
- AUROC values against curated marker gene sets fall in the reported ranges: 0.87–0.97 for seen cell types, 0.87 for unseen types in Muris FACS, and 0.82 for unseen types in Muris droplet.
- The prediction matrices used are the released intermediates pred_Y_seen.released.npy and pred_Y_all.released.npy from run_generate_pretrained_model.py, not re-trained ad hoc outputs.
- Marker genes are computed on all FACS cells from Tabula Muris Senis, matching the paper's precomputation strategy.
- Marker gene identification succeeds for unseen Cell Ontology terms (terms with no annotated cells in the training data), confirming ontology-based generalization.

## Limitations

- OnClass cannot distinguish topologically identical unseen cell types, such as siblings with the same parents in the Cell Ontology graph, so their marker rankings may be indistinguishable.
- The Cell Ontology was not developed specifically for scRNA-seq and likely misses cell types and cell states, limiting coverage of rankable terms.
- Preliminary results on extending the ontology with new data-driven nodes are only in Supplementary Table 1 and not thoroughly investigated.
