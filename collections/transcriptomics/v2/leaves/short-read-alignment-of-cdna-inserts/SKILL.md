# short-read-alignment-of-cdna-inserts

## Summary

Aligns the cDNA-insert read (Read1) from 10x Genomics droplet single-cell 3' sequencing reads to a reference genome (hg19 for human, mm10 for mouse) with STAR, keeping only confidently mapped alignments (MAPQ=255) as a prerequisite for gene-barcode UMI counting.

## When to use

Use when raw FASTQ files from droplet scRNA-seq (e.g. SRA SRP073767, 2x75 paired-end NextSeq500 output) must be converted into per-cell gene counts and Read1 must first be placed on a reference genome.

## When NOT to use

- Input is already an aligned BAM or a processed gene-cell count matrix — alignment would be redundant
- Data were generated by a non-droplet scRNA-seq protocol whose read structure does not place the cDNA insert in Read1
- Mouse or other non-human samples without the matching reference genome (mm10 for mouse, hg19 for human) prepared

## Inputs

- Raw paired-end FASTQ files from droplet scRNA-seq libraries (e.g. deposited under SRA accession SRP073767, sequenced 2x75 on Illumina NextSeq500)
- Reference genome for STAR indexing: hg19 (human), mm10 (mouse), or the ERCC reference for synthetic RNA samples

## Outputs

- Sorted BAM file of Read1 alignments against the chosen reference genome
- Set of confidently mapped alignments (MAPQ=255) feeding the gene-barcode UMI count matrix (gene_barcode_matrix.csv)

## How to apply

Identify Read1, the read containing the cDNA insert (Read2 carries the sample index/barcode information), and align it to the appropriate reference genome with STAR — hg19 for human cells, mm10 for mouse cells. Build or obtain the appropriate STAR genome index and run the alignment on the demultiplexed FASTQs. Filter the resulting alignments to retain only confident mappings defined as MAPQ=255, discarding multi-mapped or ambiguously placed reads; this MAPQ threshold is the paper's criterion for 'confidently mapped'. The retained alignments are then passed downstream so that only confidently mapped, non-PCR-duplicate reads with valid barcodes and UMIs contribute to the gene-barcode matrix. In practice this step is performed inside the Cell Ranger Single-Cell Software Suite, which performs sample demultiplexing, barcode processing and single-cell 3' gene counting; the standalone STAR step reproduces its alignment component.

## Related tools

- **STAR** (Aligns Read1 (the cDNA insert) to the appropriate reference genome (hg19/mm10); confident MAPQ=255 alignments are kept for gene-barcode matrix generation)
- **Cell Ranger Single-Cell Software Suite** (Production pipeline that performs sample demultiplexing, barcode processing and single-cell 3' gene counting, including the Read1 alignment step) — https://www.10xgenomics.com/support/software/cell-ranger/downloads

## Examples

```
STAR --genomeDir hg19_star_index --readFilesIn Read1.fastq.gz --readFilesCommand zcat --outSAMtype BAM SortedByCoordinate --outSAMmapqUnique 255
```

## Evaluation signals

- All alignments used downstream carry MAPQ=255 (confidently mapped); any MAPQ<255 alignments must be excluded from count generation
- Reference genome matches sample species: hg19 for human cells, mm10 for mouse cells, ERCC reference for synthetic RNA samples
- Resulting gene-barcode matrix counts derive only from confidently mapped, non-PCR-duplicate reads with valid barcodes and UMIs
- Alignment rate and mapped-read fraction should be consistent with the ~68k PBMC and ~250k single-cell datasets processed in the paper

## Limitations

- Only reads mapped at MAPQ=255 are retained; ambiguous or multi-mapping reads are silently discarded and never contribute counts
- Some earlier libraries used 5 nt UMI and 5 bp Read2 instead of the standard structure, introducing protocol heterogeneity that affects which read contains the cDNA insert
- The Cell Ranger source is provided for informational purposes only; 10x does not support building, modifying or running it — use the official release binaries
