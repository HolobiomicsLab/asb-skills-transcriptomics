# spearman-correlation-cost-function

## Summary

Per-node cost function in CAPITAL's tree alignment: each candidate match between nodes of two pseudotime trajectory trees is charged gamma = 1 minus the Spearman correlation of their gene-expression profiles, replacing mutual-nearest-neighbor cell matching with a rank-correlation-based penalty.

## When to use

Use when implementing or re-implementing CAPITAL's dynamic-programming tree alignment and you must score candidate matched nodes between two branched trajectory trees by expression similarity rather than nearest-neighbor cell pairing.

## When NOT to use

- The pseudotime structure is a complex graph with cycles or disconnected components — CAPITAL in its present form deals only with trajectory trees computed from the input datasets
- You need cell-level integration rather than cluster/tree-level comparison — Scanorama or Seurat-style mutual-nearest-neighbor alignment in a low-dimensional space is the appropriate alternative
- The two datasets have very different global topological structure, where CAPITAL's alignment accuracy was shown to degrade in benchmarking

## Inputs

- Gene-expression profiles (e.g. cluster centroid expression vectors) for nodes of two pseudotime trajectory trees, one per scRNA-seq dataset
- Candidate node-pair matchings generated by the tree-alignment dynamic-programming recursion (Equations 2–8)
- Gap penalty parameter delta (set to 1 for deleted/inserted subtrees in CAPITAL)

## Outputs

- Per-node cost value gamma(u,v) = 1 − Spearman correlation for each candidate matched node pair (range 0–2)
- Minimum total alignment cost (optimal tree-alignment distance) between the two trajectory trees
- Argmin traceback node mapping between the two trajectory trees

## How to apply

For each candidate node pair (u from tree 1, v from tree 2), compute gamma(u,v) = 1 − Spearman correlation of their gene-expression profiles (cluster centroids), e.g. via scipy.stats.spearmanr; because Spearman's rho lies in [−1, 1], gamma ranges from 0 (identical profiles) to 2 (perfectly anti-correlated). Use this gamma as the match cost inside CAPITAL's dynamic-programming recursion over all node pairs and child sets (Equations 2–8), charging the fixed gap penalty delta = 1 for unmatched (deleted/inserted) subtrees, so the recursion returns the minimum total alignment cost plus the argmin traceback mapping. The Spearman choice is deliberate: unlike Scanorama or Seurat, which calculate mutual nearest neighbors in a low-dimensional space, CAPITAL computes Spearman's correlation between cluster-level profiles, making the node cost cheap, order-sensitive, and robust to expression scale. Validate gamma and the full recursion on hand-checkable toy trees (single lineages, simple branchings) where the optimal distance and mapping are known by inspection.

## Examples

```
from scipy.stats import spearmanr; gamma = 1 - spearmanr(profile_u, profile_v).correlation
```

## Evaluation signals

- gamma(u,u) = 0 for a node compared against an identical expression profile, and gamma ∈ [0, 2] since Spearman's rho is bounded in [−1, 1]
- Aligning a tree to itself (all profiles identical) must yield total alignment cost 0 with an identity node mapping under gamma and delta = 1
- On single-lineage toy trees, the recursion's distance and mapping must agree with hand-computed expectations, and the traceback must match each node at most once
- Simple branching toy trees built from the packaged CAPITAL synthetic datasets (capital.dataset.synthetic_dataset1/2) should give the expected minimum cost when solved by inspection
- Substituting the Spearman-based gamma should reproduce CAPITAL's published behavior on synthetic and bone marrow datasets rather than MNN-style matching

## Limitations

- CAPITAL in its present form can deal only with trajectory trees (including single lineages) and not complex graphs such as cycles or disconnected graphs
- Part of the CAPITAL algorithm for computing a trajectory as a minimum spanning tree may not be the best method
- Alignment accuracy of CAPITAL for datasets with different global topological structure degraded in benchmarking tests
- The DP recursion was not validated in isolation in the original work, so hand-checkable toy trees are needed to confirm the cost function and traceback
