# mean-dropout-mean-variance-comparison

## Summary

Fidelity check that verifies simulated multi-sample scRNA-seq data (generated by muscat's simData) reproduce key characteristics of the reference dataset, namely mean-dropout and mean-variance relationships plus pseudobulk dispersion-mean trends, summarized in a countsimQC report.

## When to use

Use when a simulation anchored to a reference scRNA-seq dataset (e.g., Kang PBMC control samples via ExperimentHub EH2259) must be validated for faithful reproduction of mean-dropout, mean-variance, and sample-to-sample variability characteristics.

## When NOT to use

- When the goal is differential state testing on real data (use pbDS/mmDS instead of simulation fidelity diagnostics)
- When no reference anchor dataset exists to compare simulated data against, since fidelity is defined relative to the reference's characteristics

## Inputs

- Reference SingleCellExperiment anchored dataset (e.g., Kang PBMC control samples via Bioconductor ExperimentHub, EH2259)
- Simulated multi-sample scRNA-seq counts from muscat simData
- Pseudobulk count matrices per sample and subpopulation from aggregateData

## Outputs

- countsimqc_report.html (countsimQC comparative fidelity report)
- Mean-dropout and mean-variance relationship comparisons (Supplementary File 1)
- Pseudobulk dispersion-mean trend plots (Supplementary Fig. 1a)

## How to apply

Load the reference SingleCellExperiment (e.g., Kang PBMC control samples from Bioconductor's ExperimentHub, EH2259) and run muscat's simData to generate simulated multi-sample counts anchored to the reference. Aggregate both simulated and reference counts to pseudobulk per sample and subpopulation using aggregateData. Compute and compare mean-dropout and mean-variance relationships between simulated and reference data, and compare pseudobulk-level dispersion-mean trends to capture sample-to-sample variability. Assemble the comparative diagnostics into a countsimQC fidelity report saved as countsimqc_report.html. The skill is applied correctly when the simulated data's diagnostic relationships visually and quantitatively track the reference, as verified by countsimQC and dispersion-mean plots.

## Related tools

- **muscat** (Provides simData to generate simulated multi-sample scRNA-seq counts anchored to the reference dataset and aggregateData to compute pseudobulk counts per cluster_id and sample_id) — https://github.com/HelenaLC/muscat
- **R** (Execution environment for the Bioconductor-based simulation and comparison workflow)
- **Snakemake** (Workflow engine used to run simulation replicates in the muscat evaluation)

## Examples

```
pb <- aggregateData(sce, assay = "counts", fun = "sum", by = c("cluster_id", "sample_id"))
```

## Evaluation signals

- countsimQC report shows simulated mean-dropout relationship overlapping the reference dataset's relationship
- countsimQC report shows simulated mean-variance relationship matching the reference (Supplementary File 1)
- Pseudobulk dispersion-mean trends of simulated data track those of the reference (Supplementary Fig. 1a)
- Simulated data preserve sample-to-sample variability evident in the reference pseudobulks
- countsimqc_report.html is produced and contains side-by-side simulated vs. reference diagnostics

## Limitations

- The simulation framework does not yet accommodate an arbitrary number of groups or hierarchical type genes
- Other simulation scenarios of interest (e.g., different percentages of DM mixtures) were not tested
- Fidelity is only as good as the single anchor dataset; characteristics not captured by mean-dropout, mean-variance, and dispersion-mean summaries may not be validated
