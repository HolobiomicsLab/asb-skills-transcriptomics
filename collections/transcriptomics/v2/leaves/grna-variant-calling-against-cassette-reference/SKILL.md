# grna-variant-calling-against-cassette-reference

## Summary

Call mutations in gRNA molecules by comparing GiRAFR-derived UMI-cell barcode consensus sequences to the designed gRNA cassette reference (oligo_pool_plasmid.fa) using variant.call_gRNA_variant, encoding variants in a CIGAR-like string format. This quantifies mutant gRNA burden, e.g. the 28.4% mutant fraction remaining after min_reads=2 consensus filtering in the in-house CROP-seq library.

## When to use

Use when you have a filtered gRNA BAM from a single-cell CRISPR screen (e.g. CROP-seq) and need to detect which gRNA molecules carry mutations versus the designed oligo pool, beyond the intact-only assignment Cell Ranger provides.

## When NOT to use

- Input is raw FASTQ or an unfiltered gRNA BAM — the workflow requires the secondary-alignment-removed, onlyMappedToGrnaChrom BAM from utils.gRNA_bam_filter first
- Goal is detecting CRISPR-Cas9-induced DNA editing in the genome (deletions passing cutsite) — GiRAFR handles that in its separate editing-effect analysis mode, not via cassette-reference variant calling
- Goal is assigning gRNAs to cells or counting UMIs per cell (min_umi thresholding) — that is the downstream assign_gRNA.assign_gRNA_to_cell step, not variant calling

## Inputs

- Filtered gRNA alignment BAM (gRNA.sorted.mapped.removedSecondaryAlignment.onlyMappedToGrnaChrom.bam) produced by utils.gRNA_bam_filter
- Filtered CellRanger-corrected cell barcode list
- oligo_pool_plasmid.fa reference FASTA of designed gRNA sequences (generated by prepare.py from oligo_pool.csv)
- oligo_pool_plasmid_structure.gtf structural annotation of the gRNA cassette (generated by prepare.py)

## Outputs

- consensus.sequence.gRNA.txt — most read-supported sequence per UMI-cell barcode combination after min_reads filtering
- Per-consensus mutation calls encoded in CIGAR-like string format, distinguishing intact vs mutant gRNA molecules
- Mutant gRNA molecule fraction (e.g. 28.4% for the in-house CROP-seq library)

## How to apply

First run consensus_sequence.generate_consensus_sequence_gRNA on the filtered BAM (gRNA.sorted.mapped.removedSecondaryAlignment.onlyMappedToGrnaChrom.bam) with the CellRanger-corrected cell barcode list, taking the most read-supported sequence per UMI-cell barcode combination and setting min_reads=2 so UMIs supported by fewer than 2 reads are discarded as sequencing errors. Generate the cassette reference with prepare.py to produce oligo_pool_plasmid.fa and oligo_pool_plasmid_structure.gtf from the oligo_pool.csv (oligo_name and sequence columns, no header). Then call variant.call_gRNA_variant on the consensus sequence file against this reference, comparing each consensus to the plasmid oligo pool with the structure GTF annotation and encoding variants in a CIGAR-like string format. Finally compute the fraction of mutant consensus sequences — for the in-house CROP-seq gRNA library this reproduces the reported 28.4% mutant gRNA molecules surviving consensus filtering. This mutation-aware calling matters because Cell Ranger labels gRNAs with a single mutation (1 Hamming distance) as intact, yet mutant gRNAs are dysfunctional.

## Related tools

- **GiRAFR** (Python/pysam package whose variant.call_gRNA_variant function compares consensus gRNA sequences to oligo_pool_plasmid.fa with structure GTF annotation; consensus_sequence.generate_consensus_sequence_gRNA builds the per-UMI-cell-barcode consensus with min_reads filtering) — https://github.com/FunctionalEpigeneticsLab/GiRAFR

- **samtools** (Used by utils.gRNA_bam_filter to split/produce the filtered gRNA BAM (removing secondary alignments and off-cassette-chromosome reads) that feeds consensus generation) — https://github.com/FunctionalEpigeneticsLab/GiRAFR

## Examples

```
variant.call_gRNA_variant('consensus.sequence.gRNA.txt', 'oligo_pool_plasmid.fa', 'oligo_pool_plasmid_structure.gtf')
```

## Evaluation signals

- The computed mutant gRNA molecule fraction after min_reads=2 consensus filtering matches 28.4% for the in-house CROP-seq gRNA library
- Consensus file (consensus.sequence.gRNA.txt) contains one most-read-supported sequence per UMI-cell barcode combination, with UMIs supported by fewer than 2 reads discarded
- Variant calls are encoded in the CIGAR-like string format relative to oligo_pool_plasmid.fa, using oligo_pool_plasmid_structure.gtf annotation
- prepare.py outputs (oligo_pool_plasmid.fa, oligo_pool_plasmid.gtf, oligo_pool_plasmid_structure.gtf) exist and match the two-column oligo_pool.csv (oligo_name, sequence, no header)
- Mutations called per consensus remain stable when the upstream BAM equals gRNA.sorted.mapped.removedSecondaryAlignment.onlyMappedToGrnaChrom.bam (secondary alignments and non-gRNA-chromosome reads removed)

## Limitations

- min_reads defaults to 1; the 28.4% mutant figure depends on setting min_reads=2 — the default would retain sequencing-error molecules and inflate the mutant fraction
- Head-to-head comparison across published studies is unfeasible because studies use ad hoc customized pipelines and fixed thresholds
- Fine-grained appraisal of which gRNA mutation types and locations are tolerable or damaging was beyond the scope of the study
- Accurate gRNA assignment and mutation detection require specific defined read depths to be attained; low gRNA UMIs can reflect low expression or low detection rates and impact accuracy
