# batch-effect-removal-across-protocols

## Summary

Jointly clusters and removes batch effects in multi-protocol scRNA-seq data (e.g., Fluidigm C1, SMART-seq2, CEL-seq, CEL-seq2) using DESC, an unsupervised deep embedding algorithm whose iterative self-learning gradually removes batch effects without requiring explicit batch labels, as long as technical differences are smaller than true biological variation.

## When to use

Use when combining scRNA-seq count matrices generated by different library-preparation protocols or batches, and the goal is cell-type clustering with batch effect removed in a single joint analysis (measured by ARI and cell-type classification accuracy).

## When NOT to use

- Technical differences across batches are larger than true biological variations — DESC only gradually removes batch effects when technical differences are smaller than biological ones.
- You have only a single batch/protocol and no batch effect to remove — a simpler clustering approach suffices and the iterative self-training offers no advantage.
- You require explicitly batch-aware modeling that incorporates batch information as input (e.g., scVI or BERMUDA) — DESC does not explicitly require or consume batch labels.

## Inputs

- Combined scRNA-seq UMI count matrix (cells x genes) spanning multiple library-preparation protocols, e.g., Fluidigm C1, SMART-seq2, CEL-seq, CEL-seq2
- Reference cell-type labels for the cells (e.g., alpha, beta and other pancreatic islet cell types)

## Outputs

- Cluster assignments and per-cell soft clustering probability matrix from DESC
- Adjusted Rand Index of clusters versus reference labels
- High-confidence cell assignments (via maximum assignment probability) and cell-type classification accuracies (e.g., alpha and beta cell accuracies)
- Batch-removed low-dimensional embedding of the joint data

## How to apply

Preprocess the combined count matrix in Scanpy: divide UMI counts per gene per cell by total UMIs in the cell, multiply by 10,000, and log1p-transform; select highly variable genes with filter_genes_dispersion (n_top_genes=1000); standardize genes with sc.pp.scale (max_value=6). Train DESC (Keras/TensorFlow backend) starting with stacked autoencoder pretraining to a low-dimensional embedding, initialize cluster centers with Louvain clustering on the bottleneck-layer features, then iteratively minimize the KL divergence between soft Student's t-distribution assignments and the auxiliary target distribution, stopping when the fraction of cells changing cluster between consecutive steps falls below tol = 0.005. Obtain soft cluster assignment probabilities per cell, compute the Adjusted Rand Index against reference cell-type labels, and use the maximum assignment probability to identify high-confidence cells for cell-type classification accuracy. Because DESC does not use pairwise batch correction, results do not depend on the order in which batches are included.

## Examples

```
import scanpy as sc; adata = sc.read_h5ad('pancreas_four_protocols.h5ad'); sc.pp.normalize_per_cell(adata, counts_per_cell=10000); sc.pp.log1p(adata); sc.pp.filter_genes_dispersion(adata, n_top_genes=1000); sc.pp.scale(adata, max_value=6)
```

## Evaluation signals

- ARI against reference cell-type labels should be computed; on the four-protocol pancreatic islet data DESC achieves ARI = 0.945, versus MNN 0.629, scVI 0.696, BERMUDA 0.484, Scanorama 0.537.
- Alpha and beta cell classification accuracies from maximum soft-assignment probabilities should reach ~96.5% and ~98.3% respectively on the islet data.
- Iterative training must terminate via the stabilization criterion: proportion of cells changing cluster between two consecutive steps < tol = 0.005.
- Per-cell soft assignment probabilities should be well-formed (each row a distribution over clusters) and the number of clusters should match the Louvain initialization.
- Batch mixing can be assessed via regional KL divergence of nearest-neighbor batch composition (K = 5 x number of batches, repeated 200 iterations on randomly chosen cells).

## Limitations

- DESC removes batch effects only when technical differences across batches are smaller than true biological variations.
- Paper results require tensorflow < 2.0 (desc 2.0.3); the desc package requires Python 3.5.x or 3.6.x, and reproducibility of paper results depends on the older Tensorflow 1.x backend.
- Because DESC is not pairwise-based it avoids order-of-batch-correction dependence, but it does not explicitly incorporate batch information, unlike scVI or BERMUDA.
- Supplementary details (default hidden layers/nodes in Supplementary Table 2 and autoencoder hyperparameters in Supplementary Table 3) are needed for full reproduction and were not available in the main text.
