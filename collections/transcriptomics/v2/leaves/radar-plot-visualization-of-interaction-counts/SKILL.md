# Radar plot visualization of interaction counts

## Summary

Use InterCellar's multiple-condition comparison module to compute, for each cell type, the relative number of interactions with all other clusters per condition and render radar plots that overlay condition-specific communication profiles (e.g. control vs moderate vs critical COVID-19) for direct shape comparison.

## When to use

Use when you have pre-computed ligand-receptor interaction (CCI) datasets from ≥2 conditions (e.g. control, moderate, critical COVID-19) and need to compare per-cell-type communication profiles to spot condition-specific partners such as mast cells or NKT-p.

## When NOT to use

- Input CCI data was produced by a tool outside InterCellar's supported set (CellChat, CellPhoneDB, ICELLNET, SingleCellSignalR) — InterCellar currently supports only a limited set of input tools
- You need to infer ligand-receptor interactions de novo — InterCellar builds on pre-computed, inferred interactions and does not perform prediction itself
- Only a single condition is available — the radar-plot comparison is a multiple-condition analysis highlighting patterns uniquely found in each condition

## Inputs

- Pre-computed, inferred ligand-receptor interaction datasets (CCI data) for each condition, generated by InterCellar-supported tools (CellChat, CellPhoneDB, ICELLNET, SingleCellSignalR)
- COVID-19 control, moderate, and critical CCI datasets from the martaint/InterCellar-reproducibility repository

## Outputs

- Radar plots overlaying per-condition relative interaction-number profiles for each cell type
- Downloadable tables of relative interaction counts per cell type per condition

## How to apply

Load each pre-computed CCI dataset (one per condition) into the InterCellar Shiny app, which builds its workflow on uploaded, inferred ligand-receptor interactions. In the multiple-condition comparison module, compute for each cell type the relative number of interactions with all other clusters within each condition. Render radar plots that overlay the per-condition profiles (e.g. control, moderate, critical) for each cell type so that condition-specific communication shapes are directly comparable. Interpret profile shifts as partner rewiring: in the COVID-19 case, both immune cells (MoMa, nrMa, CTL, Treg) and epithelial cells (ciliated, secretory) showed higher numbers of interactions with MC and NKT-p cells in critical cases. Use the reproducible=TRUE flag so results are stable across R sessions, and download tables/figures to collect and finalize results.

## Related tools

- **InterCellar** (R/Shiny app whose multiple-condition comparison module computes relative interaction numbers per cell type and renders radar plots) — martaint/InterCellar
- **InterCellar-reproducibility** (Provides the pre-computed control/moderate/critical COVID-19 CCI datasets used to reproduce the Fig. 4b radar plots) — martaint/InterCellar-reproducibility

## Examples

```
R -e 'library(InterCellar); InterCellar::run_app(reproducible = TRUE)'
```

## Evaluation signals

- Each radar overlay contains one polygon per condition (control, moderate, critical) for every inspected cell type
- Relative interaction numbers are computed per cell type within each condition and are comparable across the overlaid conditions
- In the COVID-19 reproducibility case, the critical-condition polygon shows elevated values for MC and NKT-p partners relative to control/moderate for immune (MoMa, nrMa, CTL, Treg) and epithelial (ciliated, secretory) cell types
- App was launched with InterCellar::run_app(reproducible = TRUE), so re-running the session reproduces the same plots

## Limitations

- InterCellar supports only a limited set of input tools; extension to other published tools is planned future work
- Radar plots reflect predicted interactions that still await experimental validation (e.g. smFISH or flow cytometry co-occurrence)
- Prediction methods underlying the input CCI data rely on different reference databases and statistical assumptions, making method choice critical for the plotted counts
