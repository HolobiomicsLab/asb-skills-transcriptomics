# seurat-clustering

## Summary

Seurat clustering is applied to the preprocessed original scRNA-seq datasets (PBMC4k, Segerstolpe) to obtain ground-truth cluster labels, which serve both as the reference partition for the Davies–Bouldin index benchmark and as the label source for computing adjusted Rand index against synthetic data.

## When to use

Use when you need a reference (ground-truth) clustering partition on original scRNA-seq data to benchmark synthetic datasets via DBI and ARI, or when labeling synthetic cells by nearest-original-cell mapping in UMAP space.

## When NOT to use

- When batch correction is required — the authors explicitly excluded batch correction and note that batch effects cannot currently be learned with scDBMs
- When the goal is annotating cell types rather than producing an unlabeled clustering partition for DBI/ARI benchmarking
- When the pilot sample is not representative of the target dataset, since ground-truth labels mapped onto synthetic cells rest on the assumption that synthetic cells map to the correct clusters

## Inputs

- Preprocessed original scRNA-seq count matrices for PBMC4k and Segerstolpe (prepared via data_preparation_*.Rmd)
- Gene names and HVG files (e.g. segerstolpe_gene_names.csv, segerstolpe_hvg.csv)
- Synthetic datasets generated by scDBM, scVI-prior, scVI-posterior, and the negative-binomial noise baseline

## Outputs

- Ground-truth cluster labels for each cell in the original dataset (e.g. segerstolpe_hvg_clustering.csv)
- Reference Davies–Bouldin index of the Seurat partition on the original data
- Cluster labels assigned to synthetic observations via nearest-neighbor mapping in UMAP space

## How to apply

First, run the repository's R data-preparation scripts (data_preparation_PBMC.Rmd, data_preparation_segerstolpe.Rmd) to preprocess the original datasets and export gene names, highly variable genes (e.g. segerstolpe_hvg.csv), and cluster labels. Apply UMAP dimensionality reduction followed by Seurat clustering to the preprocessed original data to obtain the ground-truth partition, and record the reference DBI of this Seurat partition (the 'orange dotted line' in the paper's figures). Assign each synthetic observation generated by scDBM or scVI the cluster label of its nearest original observation by minimizing Euclidean distance in UMAP space, so that DBI can be computed on synthetic partitions and ARI between synthetic and original labels. The reference DBI acts as a fixed benchmark line: clustering quality of synthetic data (including the negative-binomial noise baseline) is judged relative to this Seurat clustering of the original data.

## Related tools

- **Seurat** (R package used to cluster the original PBMC4k and Segerstolpe data, yielding the reference partition and its DBI benchmark) — https://github.com/MTreppner/scDBM-paper
- **UMAP** (Dimensionality reduction applied before clustering; UMAP space is also used to map synthetic cells to nearest original cells to inherit cluster labels)
- **Julia** (Language (1.5.0) in which the Pluto notebooks run the DBI/ARI benchmarking that consumes the Seurat cluster labels) — https://github.com/MTreppner/scDBM-paper

## Evaluation signals

- The reference DBI of the original Seurat clustering must be recorded and included as a benchmark line (the orange dotted line) in all DBI comparison plots
- Cluster label files (e.g. segerstolpe_hvg_clustering.csv) must be exported by the data-preparation scripts and align 1:1 with cells in the preprocessed count matrix
- Each synthetic observation must receive exactly one cluster label via the minimum-Euclidean-distance mapping in UMAP space, with no unmapped cells
- The Seurat partition on the original data should yield a DBI clearly below that of the negative-binomial noise baseline for the benchmark to be meaningful
- DBI and ARI values aggregated in dbi_ari_results.csv should include boxplot hinges at the 25th and 75th percentiles across the 30 replicates per pilot size

## Limitations

- The approach relies on the unverified assumption that synthetic cells mapped to the original data are assigned to the correct clusters
- Seurat clustering provides the fixed reference partition; synthetic-data quality is judged relative to it, but evaluation of synthetic data quality via multiple measures can be ambiguous
- All models were examined without using potentially available batch correction capabilities, so clustering reflects uncorrected data
