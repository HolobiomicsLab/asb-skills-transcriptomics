# multi-aligner-ablation-comparison

## Summary

Ablation benchmark that quantifies the benefit of Tiglon's integration of multiple aligner mappings by running Tiglon separately on Hisat2-only, Star-only, and merged Hisat2&Star BAM lists across the 12 real RNA-seq samples (H1-H8 human, M1-M4 mouse), then scoring each Tiglon.gtf assembly against NCBI RefSeq for correct transcripts and precision.

## When to use

Use when you must measure whether integrating alignments from multiple splice-aware aligners (e.g. Hisat2 and Star) improves genome-guided transcriptome assembly versus single-aligner mappings on the same paired-end/single-end RNA-seq datasets.

## When NOT to use

- The goal is to compare Tiglon against other assemblers (StringTie2, Scallop, StringTie2-Merge) rather than to ablate the aligner-integration strategy itself
- Input alignments come from aligners other than Hisat(2) or Star — the current Tiglon version only accepts BAM files generated by Hisat(2) and Star
- Reads are long-read RNA-seq (PacBio/ONT) or you need annotation-guided assembly — the article explicitly states Tiglon does not support these

## Inputs

- bamFiles_list text file per condition (Hisat2-only, Star-only, merged Hisat2&Star), one alignment BAM path per line, for 12 real RNA-seq samples (H1-H8 H. sapiens, M1-M4 M. musculus)
- Hisat2- and Star-generated sorted BAM alignments for each sample
- Reference transcript annotations (NCBI RefSeq, e.g. GRCh38 human) for scoring assemblies
- Strandness/orientation specification per sample (paired-end or single-end)

## Outputs

- Tiglon_outdir/Tiglon.gtf transcript assembly per condition per sample
- Per-assembly counts of correct transcripts and assembly precision vs. NCBI RefSeq
- ablation_improvements.csv with per-species-group percentage improvements in correct transcripts and precision of merged vs. single-aligner assemblies

## How to apply

Prepare one bamFiles_list text file per condition (Hisat2-only, Star-only, merged Hisat2&Star), listing alignment BAMs one per line for each of the 12 real samples. Run Tiglon identically on each list with 'Tiglon -B bamFiles_list -s <strand> -o Tiglon_outdir -p 2', choosing -s to match library orientation (<first>/<second>/<unstranded> for paired-end; <single_forward>/<single_reverse>/<single_unstranded> for single-end) and keeping default filters (min_trans_length 500, min_average_frac 0.03, min_unbalance_frac 0.03, min_gap_length 200, min_trans_cov >0). Collect each run's Tiglon_outdir/Tiglon.gtf assembly and score it against the reference transcript annotations (NCBI RefSeq) to count correct transcripts and compute precision per condition. For each species group, compute percentage improvements of the merged-alignments assembly over the Hisat2-only and Star-only assemblies and write them to ablation_improvements.csv; validate against the reported values (human: 16.11%/13.98% more correct transcripts and 6.47%/6.91% higher precision; mouse: 9.19%/7.26% and 12.17%/10.05%) within a tolerance such as +/-0.5 percentage points. The rationale is that Hisat2 and Star alignments each cover all exons of some RefSeq transcripts but neither alone covers all splice junctions, so label-based integration should recover transcripts single-aligner runs miss.


## Evaluation signals

- Human group merged-vs-single improvements match the reported values within tolerance (e.g. +/-0.5 pp): 16.11%/13.98% more correct transcripts and 6.47%/6.91% higher precision
- Mouse group merged-vs-single improvements match reported values: 9.19%/7.26% more correct transcripts and 12.17%/10.05% higher precision
- Each Tiglon run used identical parameters across conditions: -s strand setting per library, default min_trans_length 500, min_average_frac 0.03, min_unbalance_frac 0.03, min_gap_length 200, min_trans_cov >0
- Every condition produced a Tiglon_outdir/Tiglon.gtf for all 12 samples (8 human, 4 mouse) and was scored against the same NCBI RefSeq reference
- ablation_improvements.csv contains one row per species group per comparison (merged vs Hisat2-only and merged vs Star-only) for both metrics

## Limitations

- The current Tiglon version only accepts BAM files generated by Hisat(2) and Star, so the ablation is restricted to these aligners
- Tiglon has no option for annotation-guided assemblies, and it is not compatible with long-read RNA-seq datasets (PacBio, ONT)
- Reported improvements are average effects across sample groups; individual samples may deviate, so a stated tolerance (e.g. +/-0.5 percentage points) is required for validation
