# oligo-structure-mutation-localization

## Summary

Build a read-supported consensus sequence for each UMI+cell-barcode combination in a gRNA alignment BAM (discarding low-support UMIs so sequencing errors are not propagated), then call mutations of each consensus against the reference cassette oligo_pool_plasmid.fa and localize them relative to the structures annotated in oligo_pool_plasmid_structure.gtf using a CIGAR-like encoding.

## When to use

Use when a filtered gRNA BAM (gRNA.sorted.mapped.removedSecondaryAlignment.onlyMappedToGrnaChrom.bam) must be collapsed to per-UMI consensus gRNA sequences and mutations must be localized against a known oligo-pool cassette structure.

## When NOT to use

- When the goal is detecting CRISPR-Cas9-induced genomic editing effects (cutsite deletions) in transcriptome data — that is GiRAFR's separate editing-effect analysis mode, not gRNA mutation localization.
- When input is raw Cell Ranger output without the filtered gRNA BAM and barcode list — the consensus collapse requires the upstream gRNA bam file filtration step (utils.gRNA_bam_filter).
- When the oligo pool reference (oligo_pool_plasmid.fa / oligo_pool_plasmid_structure.gtf) has not been built — prepare.py must generate these first.

## Inputs

- gRNA.sorted.mapped.removedSecondaryAlignment.onlyMappedToGrnaChrom.bam (filtered gRNA alignment BAM)
- unzipped filtered cell barcode list
- oligo_pool_plasmid.fa (reference cassette FASTA generated by prepare.py)
- oligo_pool_plasmid_structure.gtf (cassette structure GTF generated by prepare.py)

## Outputs

- consensus.sequence.gRNA.txt (consensus sequence per UMI/gRNA)
- consensus.seqeunce.gRNA.all_umi.txt
- consensus.bam and Non-consensus.bam
- consensus.sequence.gRNA.variant.txt (semicolon-separated structure annotations with CIGAR-like mutation strings)
- all.MT.txt (mutation-detail file)

## How to apply

First collapse the filtered gRNA BAM with pysam: reads whose cell barcodes appear in the unzipped filtered barcode list are grouped by UMI+cell-barcode combination, and the most read-supported sequence becomes that UMI's consensus; UMIs supported by fewer than min_reads reads (task uses 2; tool default in ConfigFile is 1) are discarded so sequencing errors are excluded, producing consensus.sequence.gRNA.txt, consensus.seqeunce.gRNA.all_umi.txt, consensus.bam and Non-consensus.bam. Then run variant.call_gRNA_variant comparing each consensus sequence to the reference cassette oligo_pool_plasmid.fa and locating mutations relative to the structures in oligo_pool_plasmid_structure.gtf. Differences are encoded in a CIGAR-like string where digits denote exact matches, nucleotides denote mutated bases, and bracketed counts denote insertion/deletion/substitution events, with hard-clip (H) tokens excluded; the semicolon-separated structure annotations in consensus.sequence.gRNA.variant.txt use commas to separate mutation events and a digit for the distance to the structure start. Rationale: requiring read support (>= min_reads, here 2) per UMI prevents sequencing errors from becoming consensus gRNA sequences, which would otherwise inflate apparent mutant gRNA fractions.

## Examples

```
from girafr import variant; variant.call_gRNA_variant('consensus.sequence.gRNA.txt', 'oligo_pool_plasmid.fa', 'oligo_pool_plasmid_structure.gtf')
```

## Evaluation signals

- consensus.sequence.gRNA.variant.txt exists and is non-empty after the run
- Each mutation annotation is a well-formed CIGAR-like string consistent with the oligo_pool_plasmid_structure.gtf structure annotation — no hard-clip (H) tokens, and insertion/deletion/substitution counts match the bracketed digits
- No UMI in consensus.sequence.gRNA.txt is supported by fewer than min_reads (>= 2 in the task setting) reads in consensus.bam
- Structure annotations in consensus.sequence.gRNA.variant.txt are semicolon-separated with comma-separated mutation events and a leading digit giving distance to the structure start
- all.MT.txt mutation-detail records reconcile with the per-consensus variant strings (digits = exact matches, nucleotides = mutated bases)

## Limitations

- The min_reads default of 1 in ConfigFile would let sequencing errors become consensus sequences; the task setting requires raising it to 2, and UMIs below the threshold are silently discarded
- The pipeline has fixed, ad hoc thresholds (min_reads, min_umi); head-to-head comparisons between studies using customized pipelines and fixed thresholds are unfeasible, and specific defined read depths are needed for accurate mutation detection
- Finer appraisal of which mutation types and locations are tolerable or damaging was declared beyond the scope of the study
