# arcsin-logit-transformation-accuracy-comparison

## Summary

A Scanpro benchmarking skill that simulates proportion-change datasets with sim_scanpro and compares the accuracy of arcsin versus logit transformations across bootstrapped pseudo-replicate counts, identifying the 5–8 pseudo-replicate accuracy sweet spot on unreplicated data.

## When to use

Use when evaluating Scanpro on unreplicated single-cell proportion data and you must decide between arcsin and logit transformations, or choose how many pseudo-replicates the bootstrapping should use.

## When NOT to use

- The cluster of interest is supported by less than 2% of all cells in the experiment — benchmarking showed such clusters produce unstable results and bootstrapping has limited benefits for rare cell types
- The dataset contains true biological replicates for all conditions — use the replicated Scanpro setting directly rather than bootstrapping-based transformation comparison
- You lack experimental validation for interpreting bootstrapping results — bootstrapping-derived calls are indications only and require caution

## Inputs

- AnnData object (h5ad, e.g. scanpro_tutorial.h5ad) with sample, cluster, and conds metadata columns and seven cell-type clusters
- Simulated proportion-change datasets generated by sim_scanpro (three of seven clusters changed, 100 simulations per replicate count from 2 to 14)

## Outputs

- out.results objects per run from the scanpro function
- Per-cluster detection accuracy table as a function of replicate count (saved as simulation_accuracy.csv)
- Accuracy curves comparing arcsin vs logit transformations
- Per-cluster p-value boxplots produced with out.plot(kinde='boxplot')

## How to apply

Load a base AnnData template with sample, cluster, and conds metadata columns holding seven cell-type clusters, then generate simulated proportion-change datasets with sim_scanpro, marking three of seven clusters as changed and producing 100 simulated datasets per replicate count from 2 to 14. Run the scanpro function (samples_col='sample', clusters_col='cluster', conds_col='conds') in both the replicated setting and the bootstrapped pseudo-replicate setting, invoking run_stats with the anova and t_test backends under arcsin and logit transformations. Retrieve out.results for each run and compute per-cluster detection accuracy (fraction of correctly called changed clusters) as a function of replicate count. Compare arcsin versus logit accuracy across 5–14 pseudo-replicates and inspect per-cluster p-value distributions, especially for the rare Changed3 cluster (<2% of cells). The rationale is Scanpro's iteration-based bootstrapping simulates pseudo-replicates for non-replicated datasets, so transformation choice and pseudo-replicate count directly control accuracy.

## Examples

```
from scanpro import scanpro; out = scanpro(adata, clusters_col='cluster', conds_col='conds')  # samples_col=None triggers bootstrapping; then out.results, out.plot(kinde='boxplot')
```

## Evaluation signals

- Replicated-setting accuracy curve falls within the reported 0.6–0.97 range
- The 5–8 pseudo-replicate accuracy sweet spot is visible: bootstrapping accuracy peaks there and decreases with more or fewer pseudo-replicates
- arcsin slightly outperforms logit in accuracy across 5–14 pseudo-replicates
- Changed3 cluster (<2% of cells) shows its characteristic assignment-rate behavior in per-cluster p-value boxplots
- Consolidated accuracy table is produced (simulation_accuracy.csv) with per-cluster accuracy as a function of replicate count

## Limitations

- Clusters supported by less than 2% of all cells produce unstable results
- Bootstrapping has limited benefits when handling rare cell types
- Bootstrapping-based results should be interpreted with caution and require additional experimental validation; lack of replicates per se is not advisable
