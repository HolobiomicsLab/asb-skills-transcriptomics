# umap-dimensionality-reduction

## Summary

Apply UMAP dimensionality reduction to preprocessed scRNA-seq data (PBMC4k, Segerstolpe) to obtain a low-dimensional space in which ground-truth Seurat cluster labels can be defined and synthetic observations from scDBM/scVI can be mapped to original cells for downstream benchmarking.

## When to use

Use when preprocessing scRNA-seq count data (e.g., PBMC4k or Segerstolpe) for clustering-based evaluation of synthetic data, or when synthetic observations need cluster labels assigned via nearest-neighbor mapping in a reduced space.

## When NOT to use

- When the goal is batch correction or integration of scRNA-seq data — the authors explicitly excluded batch effects and examined all models without batch correction capabilities
- When evaluating synthetic data quality by per-gene distribution statistics or cluster proportions rather than clustering metrics — UMAP mapping is specific to the DBI/ARI label-transfer workflow

## Inputs

- Preprocessed original scRNA-seq count matrices (PBMC4k, Segerstolpe) with gene names and cluster label files (e.g., segerstolpe_gene_names.csv, segerstolpe_hvg.csv, segerstolpe_hvg_clustering.csv)
- Synthetic datasets generated by scDBM, scVI-prior, and scVI-posterior from pilot sub-samples of 384–2304 cells (30 replicates each)

## Outputs

- UMAP embedding of the original data with Seurat cluster labels and reference DBI
- Cluster labels assigned to each synthetic observation via nearest-neighbor mapping in UMAP space
- Per-replicate DBI and ARI values aggregated into dbi_ari_results.csv

## How to apply

Apply UMAP to the preprocessed original datasets to build the reference embedding, then run Seurat clustering on the original data to obtain ground-truth cluster labels and the reference Davies–Bouldin index (plotted as the orange dotted line in the paper's benchmark figures). For each synthetic dataset generated by scDBM, scVI-prior, or scVI-posterior (pilot sizes 384–2304 cells, 30 replicates), map every synthetic observation to its closest original observation based on Euclidean distance in UMAP space and assign that cell's cluster label. This UMAP-based label transfer is the key decision point enabling computation of the Davies–Bouldin index on synthetic partitions and the adjusted Rand index against the original labels. The approach relies on the unverified assumption that synthetic cells mapped to the original data land in the correct clusters, which is why embedding quality directly conditions the validity of all clustering metrics.

- **UMAP** (Dimensionality reduction of original data providing the Euclidean space for cluster-label transfer to synthetic observations)
- **Seurat** (Clustering of original data in the UMAP embedding to define ground-truth labels and reference DBI)

## Evaluation signals

- Each of the ~4608 synthetic observations (models × pilot sizes × 30 replicates) receives exactly one cluster label from the nearest original observation in UMAP space
- The reference DBI of the original Seurat clustering (orange dotted line) is computed once and serves as the lower-bound benchmark for all synthetic DBI values
- scVI-posterior synthetic data show the highest across-replicate variability in DBI and ARI at small pilot sizes (e.g., 384 cells), consistent with the reported finding
- dbi_ari_results.csv contains boxplot hinges at the 25th and 75th percentiles aggregated over all models, pilot sizes, and replicates
- Synthetic datasets are generated at the size of the original study regardless of pilot size (384–2304 cells), so the mapping target is always the full original UMAP embedding

## Limitations

- The approach relies on the unverified assumption that synthetic cells mapped to the original data are mapped to the correct clusters
- Inference from small to larger datasets is more challenging for sparser 10x Genomics datasets (PBMC4k) than Smart-seq2 (Segerstolpe)
- Evaluation of synthetic data quality via clustering metrics can be ambiguous, with sometimes conflicting results across multiple quality measures
