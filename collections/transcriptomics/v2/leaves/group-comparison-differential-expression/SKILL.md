# group-comparison-differential-expression

## Summary

Performs BloodGen3 group comparison analysis by statistically testing every module's constitutive genes between a Test_group and Ref_group, then expressing results at the module level as the percentage of genes increased or decreased. This is the core quantitative step of the fixed-module-repertoire workflow that feeds fingerprint grid visualization.

## When to use

Use when a normalized, non-log2 blood transcriptome matrix (e.g., GSE13015/EH5429 from ExperimentHub) with sample annotation must be compared between two sample groups to get per-module percent-increase/decrease values.

## When NOT to use

- The expression matrix is already Log2 transformed — the README states data should not be Log2 transformed because the functions transform it internally
- The goal is single-sample fingerprinting relative to a reference — use the Individualcomparison/Individual_df workflow instead of Groupcomparison
- The data are not human blood transcriptome profiles — the BloodGen3 repertoire is specifically designed for human blood and other tissues or species would require a separate framework

## Inputs

- Normalized expression data matrix, NOT Log2 transformed, genes as rows (valid Gene Symbols), Sample IDs as columns (e.g., SummarizedExperiment EH5429 from ExperimentHub query on 'GSE13015')
- Sample annotation dataframe with a Sample ID column matching data.matrix column names and a group annotation column (e.g., 'Group_test' with values like Sepsis/Control or SLE/Control)
- Module membership annotation from the fixed BloodGen3 repertoire (Module_listGen3/Gen3_ann)

## Outputs

- Group_df dataframe of module-level results expressed as the percentage of genes increased or decreased per module (or Group_limma when using the limma variant)
- Fingerprint grid plot PDF generated by gridplot at cutoff = 15, with modules shaded only where the module-level percentage meets or exceeds the cutoff
- Optional per-module comparison tables (e.g., duplicate_gene_handling_comparison.csv) when comparing handling variants

## How to apply

Load the normalized expression matrix (rows = valid Gene Symbols, columns = Sample IDs) into a SummarizedExperiment container — for the reference example, GSE13015 retrieved as EH5429 via ExperimentHub query — keeping it non-log2 since BloodGen3Module functions transform it internally. Run the Groupcomparison function with fold-change cutoff FC = 1.5, p-value cutoff pval = 0.1 with FDR = TRUE (Benjamini-Hochberg), specifying Group_column (e.g., 'Group_test'), Test_group (e.g., 'Sepsis' or 'SLE'), and Ref_group (e.g., 'Control'); alternatively use Groupcomparisonlimma for limma-based testing. The function annotates the matrix with membership in the 382 modules / aggregates A1–A38 of the fixed repertoire, runs per-gene statistical tests, and aggregates results at the module level as the percentage of constitutive genes increased or decreased. Feed the resulting Group_df (or Group_limma dataframe) to gridplot with the default visualization cutoff of 15% (adjustable 0–100%) to render the fingerprint grid PDF. Duplicate genes (388 of 14,168 probes) may be kept in every module they belong to or disregarded — either handling yields essentially comparable module-level results.

## Examples

```
Group_df <- Groupcomparison(GSE13015, sample_info=NULL, FC=1.5, pval=0.1, FDR=TRUE, Group_column="Group_test", Test_group="Sepsis", Ref_group="Control")
```

## Evaluation signals

- The Group_df output contains a row per module with percent-increase and percent-decrease values computed with FC = 1.5, pval = 0.1, FDR = TRUE
- gridplot produces a PDF in the specified working directory where each aggregate row A1–A38 shades modules only at module-level percentages ≥ the 15% visualization cutoff
- Input matrix row names are valid Gene Symbols and sample annotation column names exactly match the values passed to Group_column, Test_group, and Ref_group
- Varying the duplicate-gene handling (388/14,168 probes assigned to all their modules vs. excluded) changes module-level percentages only minimally
- SLE vs Control comparison reproduces an interferon-dominated signature (A28) plus increased A27/A29/A35 and decreased A1–A3 modules when using Test_group='SLE', Ref_group='Control'

## Limitations

- The default visualization cutoff of 15% can be changed to any value between 0 and 100%, but shading below the cutoff hides sub-threshold module changes
- Duplicate probes (388 of 14,168) map to multiple modules; although handling choice has very little impact on results, a handling option must still be chosen for gene-level RNA-seq inputs
- Groupcomparison requires a t-test or limma statistical backend; results depend on the chosen FC and pval/FDR cutoffs (reference values: FC = 1.5, pval = 0.1, FDR = TRUE)
