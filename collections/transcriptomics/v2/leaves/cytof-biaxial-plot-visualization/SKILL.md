# cytof-biaxial-plot-visualization

## Summary

Render biaxial plots of single-cell CyTOF data on supervised HSS-LD axes generated by HSS-LDA, optionally merging HSS-LDs from separate label models (e.g., cell-cycle and cell-line) so a single ggplot2 embedding preserves multiple known sources of variance.

## When to use

Use when mass-cytometry (CyTOF) single-cell data must be visualized on interpretable, supervised axes that separate a priori labels such as cell type, cell-cycle phase, or experimental time point, e.g., reproducing a Figure 3H biaxial plot.

## When NOT to use

- Class labels are unknown or an unbiased view of the data is preferable — supervised LDA axes are inappropriate there
- More than 100 input dimensions (HSS feature selection becomes infeasible) or a very large number of populations, where HSS-LDA performance suffers
- Preservation of local data structure is the priority — LDA maximizes class separability at the expense of local structure and does not capture non-linear relationships

## Inputs

- CyTOF expression matrix (cells as rows, protein markers as columns), e.g., arcsinh-transformed marker intensities
- One or more a priori label vectors per cell (e.g., cell-cycle phase, cell line, experimental time point)
- Trained hsslda model output object containing HSS-LDA-model (with $scaling) or the HSS-LDA-result dataframe with HSS_LD columns

## Outputs

- ggplot2 biaxial scatter plot of HSS_LD1 vs HSS_LD2 colored by class label (e.g., figure3h_biaxial.png)
- Optional merged HSS-LD feature dataframe combining LD axes from multiple label models for downstream UMAP embedding

## How to apply

Run hsslda::runHSS(x = expression matrix with cells as rows and markers as columns, y = class labels, score.method = 'euclidean') once per label of interest and inspect the returned ElbowPlot to identify the optimal feature set. Project cells onto the linear discriminants with makeAxes(df = data, co = model$scaling) or read the HSS-LD columns from the returned HSS-LDA-result dataframe. For two labels (e.g., cell-cycle and cell line), merge the HSS-LD columns from both runs into one feature dataframe with dplyr before plotting or feeding UMAP. Render the biaxial plot with ggplot2 using ggplot(lda.df, aes(x = HSS_LD1, y = HSS_LD2, color = labels)) + geom_point(), saving e.g. figure3h_biaxial.png. Because LDA axes are non-stochastic and generated specifically to separate the labeled groups, the biaxial plot should show class separation while retaining within-class biological structure (e.g., a G0-to-G2 trajectory).

## Related tools

- **hsslda** (R package that runs hybrid subset selection plus LDA (runHSS) and projects cells onto HSS-LD axes (makeAxes) for the biaxial plot) — https://github.com/mamouzgar/hsslda
- **MASS** (Provides lda() to fit an LDA model without HSS when scaling coefficients are needed for makeAxes)
- **ggplot2** (Renders the biaxial plot of HSS_LD1 vs HSS_LD2 colored by class label)
- **dplyr** (Merges HSS-LD columns from separate label models into a single combined feature dataframe before plotting or UMAP)
- **CyTOF** (Mass cytometry data modality (∼50 parameters on millions of cells) whose expression matrix supplies the visualization inputs)

## Examples

```
hss.result = runHSS(x = train.x, y = train.y, score.method = 'euclidean', downsample = FALSE); lda.df = hss.result$`HSS-LDA-result`; ggplot2::ggplot(lda.df, ggplot2::aes(x = HSS_LD1, y = HSS_LD2, color = labels)) + ggplot2::geom_point()
```

## Evaluation signals

- Elbow plot from runHSS identifies the optimal feature set before the final LDA model is fit
- Cells cluster separately by cell line on the biaxial plot while a G0-to-G2 cell-cycle trajectory is preserved within each cell line (expert visual review of the rendered figure)
- LD axes are non-stochastic: re-running the pipeline on the same inputs yields reproducible axis positions, unlike stochastic embeddings
- HSS-LDA-result dataframe contains all initially inputted markers, class labels, and linear discriminants from the optimal model
- Proportion-of-trace output of the LDA model indicates the leading LDs (e.g., LD1 ≈ 0.79, LD2 ≈ 0.19 in the example) dominate the plotted variance

## Limitations

- HSS enriches for features useful for separating multiple classes and may disregard features only useful for separating a single class; relevant colinear features may not all be selected
- HSS-LDA may not perform well when a large degree of heterogeneity exists within a given class or as the number of populations increases
- Features selected by HSS are differentially expressed by one or more labeled classes and require follow-up analysis for the nature and statistical significance of the differences
- While LDA can manifest some degree of crowding, the problem is largely avoided because axes are specifically generated to separate cell groups of interest
