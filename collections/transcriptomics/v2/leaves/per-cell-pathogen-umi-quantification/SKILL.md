# per-cell-pathogen-umi-quantification

## Summary

scPathoQuant takes host-unaligned reads from cellranger count 10x output, remaps them to a pathogen reference (default bbmap, alternative bowtie2), quantifies per-cell total pathogen reads and gene-level UMI counts with htseq, and writes the pathogen counts back into filtered_feature_bc_matrix/raw_feature_bc_matrix so Seurat can consume them. It replaces running a second CellRanger pass with a combined host+pathogen reference.

## When to use

Use when you have 10x scRNA-seq data from an infected sample for which cellranger count has already run against the host genome, and you need per-cell pathogen read and UMI counts appended to the 10x matrices for downstream single-cell analysis.

## When NOT to use

- Input is raw FASTQ with no cellranger count output — scPathoQuant consumes the 10x output folder generated by cellranger count, not unprocessed reads
- Host and pathogen alignment is already complete (e.g. cellranger run against a combined GRCh38 + SARS-CoV-2 reference) — a second SPQ pass adds remapping redundancy
- The goal is de novo viral genome assembly or clade calling rather than per-cell quantification — scPathoQuant only emits pathogen_al_mapped.fq.gz as a starting point for such downstream analyses

## Inputs

- 10x output folder from cellranger count run against the host genome (possorted_genome_bam.bam, filtered_feature_bc_matrix, raw_feature_bc_matrix)
- Pathogen reference genome FASTA (header used for total pathogen read quantification, should be simplified, e.g. > HIV_virus)
- Optional pathogen GTF annotation file for gene-level UMI counts (e.g. SARS-CoV-2 GCF_009858895.2 gtf)
- Alignment parameters for bbmap or bowtie2 (e.g. --semiperfectmode, --very-sensitive --non-deterministic)

## Outputs

- pathogen_al_counts.csv — total pathogen reads mapping to each cell
- pathogen_al_gene_counts.csv and pathogen_genes_al_sort_counts.sam — per-cell pathogen gene UMI counts (htseq)
- Overwritten filtered_feature_bc_matrix and raw_feature_bc_matrix with pathogen counts/gene counts appended
- pathogen_al.bam, pathogen_al_mapped.bam, pathogen_al_mapped_sort.bam (+ .bai) and pathogen_al_mapped.fq.gz for IGV visualization or phylogenetics
- pathogen_copy.png, pathogen_genes.png, coveragemap.png violin plots
- _tmp/ intermediates: unmmaped.bam, unmmaped.sam, barcodes_umi_read_table.csv, unmapped.fq.gz

## How to apply

First run cellranger count on each sample against the host genome (e.g. GRCh38) so scPathoQuant can consume the output folder via its -10x parameter. scPathoQuant then uses samtools to pull host-unaligned reads from possorted_genome_bam.bam into _tmp/, recording barcodes and UMIs in barcodes_umi_read_table.csv, and aligns those reads to the pathogen fasta (and optional gtf) supplied via -p2genome — using bbmap by default (e.g. --bbmap_params='--semiperfectmode') or bowtie2 (e.g. --bowtie2_params='--very-sensitive --non-deterministic'). htseq (non-default --intersection-nonempty) quantifies per-cell total pathogen reads into pathogen_al_counts.csv and, when a gtf is provided, per-cell gene counts into pathogen_genes_al_sort_counts.sam. The pathogen UMI counts and gene counts are then integrated back into the filtered_feature_bc_matrix and raw_feature_bc_matrix, and violin-plot summaries (pathogen_copy.png, pathogen_genes.png, coveragemap.png) plus BAM/FQ artifacts (pathogen_al_mapped_sort.bam, pathogen_al_mapped.fq.gz) are emitted; pass --tmp_removal to delete the large _tmp/ directory. To validate against a combined host+pathogen cellranger run, build a second reference with the pathogen fasta header simplified (e.g. > SARS-CoV-2) and compare per-cell counts.

## Examples

```
scpathoquant -10x path/to/10x/sample -op path/for/results -p 8 -p2genome path/to/pathogen/fastafilefolder --bbmap_params="--semiperfectmode"
```

## Evaluation signals

- pathogen_al_counts.csv exists and contains per-cell pathogen read counts for every cell barcode
- The pathogen-integrated filtered_feature_bc_matrix loads successfully via Seurat Read10X with pathogen counts/features appended
- For the Ravindra et al. 2021 HBEC SARS-CoV-2 benchmark, positive-cell counts match 4,279 / 13,998 / 26,935 at 1/2/3 dpi identically across CellRanger, SPQ bbmap, and SPQ bowtie2
- Kendall rank correlations between SPQ (bbmap or bowtie2) UMI counts and CellRanger combined-reference UMI counts are high, with bbmap slightly higher; results reported in sars2_cell_counts.csv
- Sorted alignment artifacts (pathogen_al_mapped_sort.bam and its .bai index) are produced and viewable in IGV

## Limitations

- The _tmp/ directory of intermediate files (unmmaped.bam, unmapped.fq.gz, etc.) can be very large; use --tmp_removal if disk space is an issue
- The pathogen fasta header is used to quantify total pathogen reads, so complicated headers must be simplified (e.g. > HIV_virus) or counts will be misleading
- Without a pathogen gtf file, only total per-cell pathogen read counts are produced — pathogen gene-level UMI counts and pathogen_genes.png are not generated
- Default alignment parameters are used unless overridden via --bbmap_params or --bowtie2_params, and htseq runs with the non-default --intersection-nonempty setting
