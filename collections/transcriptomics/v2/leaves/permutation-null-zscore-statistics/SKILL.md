# permutation-null-zscore-statistics

## Summary

Computes permutation-test statistics (p-value, z-score, shifted z-score, Benjamini-Hochberg adjusted p-value) for transcriptome colocalization analysis by comparing an observed overlap count against the null distribution of random overlaps generated by RgnTX's transcriptome-aware randomization.

## When to use

Use when you need to quantify whether colocalization between two transcriptome region sets (e.g. miCLIP-seq m6A sites and stop codon regions) is statistically significant, via a permutation-derived null distribution, p-value, z-score and shifted z-score.

## When NOT to use

- When regions have unambiguous transcript isoform association and you need the plain permTestTx/permTestTx_customPick null model rather than the TxIA (isoform ambiguity) randomization.
- When you need an exact-test colocalization statistic (binomial, Fisher's exact, chi-square as in GREAT/LOLA/GenomeRunner) rather than a permutation-based null distribution.
- When the analysis background is the whole genome rather than transcriptome space — genome-based nulls produce significantly different overlap distributions from transcriptome-based nulls.

## Inputs

- RS1 region set (GRanges) — query features such as miCLIP-seq m6A methylation sites (from RgnTX extdata m6A_sites_data.rds, 500-region subset or full 9181 sites)
- RS2 region set or customPick_function (e.g. getStopCodon, getCDS) generating the regions of interest from TxDb.Hsapiens.UCSC.hg19.knownGene
- ntimes permutation count and ev_function_1/ev_function_2 (overlapCountsTx or overlapCountsTxIA) settings

## Outputs

- observed_overlap (weighted overlapping count, e.g. ~804.93 for full m6A vs stop codon test)
- random_overlap_list (null distribution of random overlaps; mean ~365.28 in the m6A/stop-codon case)
- permutation p-value and z-score per test
- shifted z-scores from shiftedZScoreTx when shifting regions of interest
- Benjamini-Hochberg adjusted p-values when multiple tests are run (e.g. written to permtest_txIA_m6A_results.csv)

## How to apply

Run a permutation test (permTestTx, permTestTx_customPick, or permTestTxIA_customPick for region sets lacking isoform association) with ntimes permutations, using overlapCountsTx/overlapCountsTxIA (weighted overlap for the IA variant) as evaluation functions. The test computes the observed overlap, collects random_overlap over ntimes randomized region sets, then derives the p-value and z-score from the random_overlap_list versus the observed overlap. For positional-shift questions, apply shiftedZScoreTx to compute shifted z-scores as regions are moved over mRNA space (exons). When running tests on many region groups (e.g. m6A sites shuffled into independent groups of 100 regions), adjust p-values with Benjamini-Hochberg correction to reduce false positives. Verify the result by checking that the observed weighted overlap substantially exceeds the mean random overlap (e.g. ~804.93 vs ~365.28 for the 9181-site m6A dataset vs stop codons on hg19).

## Examples

```
permTestTx_results <- permTestTxIA_customPick(RS1 = m6A_sites_data[1:500], txdb = TxDb.Hsapiens.UCSC.hg19.knownGene, customPick_function = getStopCodon, ntimes = 50, ev_function_1 = overlapCountsTxIA, ev_function_2 = overlapCountsTx)
```

## Evaluation signals

- Observed overlap must exceed the mean random overlap from the null distribution (m6A vs stop codon full-dataset benchmark: 804.93 observed vs ~365.28 mean random).
- P-value and z-score are computed from random_overlap_list vs observed_overlap across ntimes permutations — confirm both are present in the returned permTestTx results object.
- When multiple tests are run (groups of 100 m6A regions), BH-adjusted p-values must be applied and false positives reduced relative to raw p-values.
- TxIA results should differ from genome-based method results — RgnTX's novel testing modes are expected to return distinct and more significant results on m6A data.
- Shifted z-score trajectories from shiftedZScoreTx should be inspectable/visualizable as described in the README.

## Limitations

- No R version or dependency versions are specified for reproducing the statistics.
- No version number is stated for RgnTX, and no changelog is available, so exact null-model behavior across releases is unverified.
- Null distributions differ significantly between genome and transcriptome backgrounds even on the same 300 genes, so z-scores are not comparable across background choices.
