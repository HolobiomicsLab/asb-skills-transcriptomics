# cite-seq-multimodal-embedding-generation

## Summary

Generate integrated embeddings of multimodal single-cell omics data (e.g. CITE-seq RNA and ADT) using SnapCCESS, an unsupervised ensemble deep learning framework that creates snapshots of multimodality variational autoencoder embeddings for downstream consensus clustering of cells.

## When to use

Use when CITE-seq or other multimodal single-cell data (same cells measured across modalities, e.g. RNA + ADT matrices) needs integrated embeddings to cluster cells into major and minor cell types.

## When NOT to use

- The data are single-modality (e.g. scRNA-seq only) with no second modality measured across the same cells — SnapCCESS integrates data modalities and is designed for multimodal input.
- You want a supervised classifier of known cell types rather than an unsupervised clustering framework — SnapCCESS is unsupervised and labels are used only for ARI evaluation.
- You need recommended hyperparameters out of the box — the README states the tutorial 'doesn't recommend the best parameters for your datasets'; you must consult the paper.

## Inputs

- List of modalities measured across the same cells (e.g. CITE-seq RNA and ADT matrices), arranged features-by-cells before preprocessing in the R wrapper
- Cell type annotation files (major and minor label sets) for ARI evaluation
- Combined PyTorch data loader (Python API) used by the training routine

## Outputs

- Snapshots of multimodality variational autoencoder embeddings of cells
- Consensus clustering of cells (generated by coupling embeddings with a clustering algorithm)
- ARI values comparing ensemble clustering against major/minor cell-type labels (e.g. ari_ensemble_comparison.csv)

## How to apply

Install the snapccess Python package via pip (pip install snapccess --index-url https://pypi.org/simple) or the SnapCCESS R wrapper via remotes::install_github, then configure reticulate to the Python environment (e.g. SnapCCESS::install_SnapCCESS(envname='SnapCCESS', method='conda')). Provide a list of modalities measured across the same cells — each modality arranged as features by cells before preprocessing in the R wrapper (the Python API expects the combined PyTorch data loader used by the training routine). Generate snapshots of multimodality embeddings with variational autoencoders using epoch=1 and an ensemble of snapshots; the paper shows an ensemble of 50 snapshots improves clustering of both major and minor cell types relative to a base ensemble of 1 across six datasets, including the Ramaswamy CITE-seq data. Couple the embeddings with a clustering algorithm to produce the consensus clustering, and evaluate with adjusted Rand index (ARI) against cell-type label sets. Best hyperparameters vary by dataset; the tutorial does not recommend parameters, so consult the paper for dataset-specific settings.

## Evaluation signals

- ARI of the ensemble (size 50, epoch=1) consensus clustering against minor cell-type labels should match or improve on the base (size 1) ARI and be consistent with values reported in the paper.
- The ensemble-of-50 configuration should outperform the base-of-1 configuration in both the major and minor partitions of cell types, as reported across all six datasets in the paper.
- Embeddings must integrate all supplied modalities measured across the same cells (e.g. RNA and ADT from CITE-seq) without cell-order mismatch between modalities.
- Figures should render the MAIT-NKT population highlighted in the Ramaswamy CITE-seq embedding, consistent with Figure 3 and Supplementary Fig. S3.

## Limitations

- The tutorial does not recommend best parameters for your datasets; for the datasets used in the paper, parameters are listed in the paper and must be looked up there.
- The Python package depends on PyTorch; GPU acceleration is optional and depends on the local PyTorch/CUDA or PyTorch/ROCm installation.
- SnapCCESS can be coupled with various clustering algorithms, but the choice and evaluation against ground-truth labels (ARI) is left to the practitioner.
