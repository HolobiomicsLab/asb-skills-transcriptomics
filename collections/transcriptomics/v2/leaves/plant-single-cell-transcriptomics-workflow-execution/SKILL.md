# plant-single-cell-transcriptomics-workflow-execution

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Executes the scPlant ecosystem's end-to-end plant single-cell analysis workflow, from pre-processing a Seurat object through cell-type-specific gene regulatory network (GRN) construction with MINI-EX and cross-tool validation against SCENIC, e.g. reproducing the Arabidopsis root atlas regulon comparison.

## When to use

Use when a plant scRNA-seq Seurat object must be run through a reproducible Nextflow-based GRN pipeline (MINI-EX) and its cell-type-specific regulons compared against SCENIC predictions, e.g. recovering bZIP44 (companion cells) and ANAC030 (xylem).

## When NOT to use

- Input is raw FASTQ or an unprocessed count matrix without cell-type annotations — pre-processing and annotation (QCfun, RunSeurat, cell-type annotation modules) must be completed first
- The organism is not a plant — MINI-EX and the scPlant GRN module are designed for plant scRNA-seq data and plant TF/motif resources (PlantTFDB, TAIR10)
- Only bulk transcriptomics data are available — this skill targets single-cell atlases; scPlant's deconvolution module (decomposeBulk) is the appropriate path for bulk data

## Inputs

- Pre-processed Seurat object (.rds) with cluster (e.g. seurat_clusters) and celltype metadata columns
- MINI-EX input files generated by MINIEX_preprocess.R from the Seurat object
- miniex.config with generated input paths
- SCENIC regulon results from the prior GRN task (for Jaccard comparison)
- cisTarget databases / motif resources (e.g. TAIR10, JASPAR/PlantTFDB-derived)

## Outputs

- Per-cluster cell-type-specific regulons in the regulons_output directory
- Top regulons per cluster ranked by BordaRank_MINIEX
- regulon_jaccard_similarity.csv (Jaccard similarity of top 30 regulons per cluster vs SCENIC)
- Regulon enrichment visualizations (Figure 6E-6F, Supplemental Figure 3) and signal-to-noise ratio comparison MINI-EX vs SCENIC

## How to apply

First produce MINI-EX input files from the pre-processed Seurat object using the scPlant auxiliary script distributed on Figshare (Auxiliary data and codes for scPlant), specifying the cluster and celltype metadata columns. Configure miniex.config with the generated input paths and install the Nextflow and Singularity requirements, then run the MINI-EX Nextflow pipeline (DSL2) to obtain per-cluster regulons in the regulons_output directory. Inspect results with scPlant visualization functions (enrich_exp_hmp, topRegulons_MINIEX, BordaRank_MINIEX) to extract the top regulons per cluster by Borda ranking. Quantify agreement with SCENIC by computing Jaccard similarity of the top 30 regulons per cell cluster and saving regulon_jaccard_similarity.csv. Validate by confirming recovery of known cell-type-specific TFs (bZIP44 for companion cells, ANAC030 for xylem cells in the Arabidopsis root atlas) and that MINI-EX regulon enrichment shows a higher signal-to-noise ratio than SCENIC (Figure 6E-6F, Supplemental Figure 3).

## Related tools

- **scPlant** (Framework providing the auxiliary preprocessing script (MINIEX_preprocess.R) and MINI-EX result visualization functions (enrich_exp_hmp, topRegulons_MINIEX, BordaRank_MINIEX)) — https://github.com/compbioNJU/scPlant
- **MINI-EX** (Nextflow DSL2 pipeline that infers cell-type-specific gene regulatory networks from plant scRNA-seq data; run as `nextflow -C miniex.config run miniex.nf`) — https://github.com/VIB-PSB/MINI-EX
- **Seurat** (Provides the pre-processed Seurat object input with cluster and celltype metadata consumed by MINIEX_preprocess.R)
- **pySCENIC** (Reference GRN inference tool whose regulons are compared against MINI-EX results via Jaccard similarity) — aertslab/pySCENIC
- **create_cisTarget_databases** (Used to construct the cisTarget motif/ranking databases required for the gene regulatory network workflow) — https://github.com/aertslab/create_cisTarget_databases

## Examples

```
Rscript MINIEX_preprocess.R --seuratObj SeuratObj.rds --cluster seurat_clusters --celltype celltype -o INPUTS && nextflow -C miniex.config run miniex.nf
```

## Evaluation signals

- regulon_jaccard_similarity.csv shows non-zero Jaccard overlap of top-30 regulons between MINI-EX and SCENIC per cell cluster
- bZIP44 is recovered among companion-cell regulons and ANAC030 among xylem regulons in the Arabidopsis root atlas, matching SCENIC predictions
- MINI-EX regulon enrichment exhibits a higher signal-to-noise ratio than SCENIC, consistent with Figure 6E-6F and Supplemental Figure 3
- The MINI-EX Nextflow run completes and populates regulons_output with per-cluster regulon files
- topRegulons_MINIEX and BordaRank_MINIEX return a ranked regulon list for every cluster in the Seurat object

## Limitations

- Cross-tool agreement is quantified only on the top 30 regulons per cluster via Jaccard similarity; agreement is consistency-based, not exhaustive
- MINI-EX requires Nextflow and Singularity as external dependencies and a dual-licensed codebase (open-source/proprietary), which may constrain some deployment environments
- Validation anchors (bZIP44, ANAC030) are specific to the Arabidopsis thaliana root atlas (Zhang et al., 2019); other datasets need their own expected regulon references
