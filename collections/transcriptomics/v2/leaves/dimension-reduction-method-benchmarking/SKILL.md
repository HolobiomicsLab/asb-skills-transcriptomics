# dimension-reduction-method-benchmarking

## Summary

A benchmarking protocol that quantitatively compares latent-space visualizations of temporal single-cell expression data — TCM vs t-SNE, diffusion map, diffusion pseudotime, Wishbone, Monocle and TSCAN — using Hartigan's dip statistics of the last-time-point cell distributions across 11 scRNA-seq datasets.

## When to use

Use when evaluating which dimension reduction method best separates subpopulations of cells within the final time point of temporal single-cell expression datasets, especially for trajectory-visualization benchmarking.

## When NOT to use

- The dataset lacks a complete time index, or the time index is not correlated with the underlying dynamic expression pattern (TCM's stated requirement)
- The goal is annotating the biological meaning of clusters rather than benchmarking separation quality — TCM requires further pathway analysis for interpretation
- Input is not temporal single-cell expression data with time-point labels (e.g. static feature tables or bulk RNA-seq)

## Inputs

- Temporal scRNA-seq gene-by-cell count matrices (e.g. guo, guo2, loh, trapnell, iPSC, petropoulos, deng from scDatasets)
- Cell-by-time-point binary time.table matrices (colData(sim)$time.table)
- Simulated temporal scRNA-seq data generated by sim.rnaseq.ts

## Outputs

- Method-by-dataset matrix of Hartigan's dip statistics for last-time-point cells (dip_scores.csv)
- 2D latent-space embeddings from each of the 7 compared methods per dataset

## How to apply

Load the 11 temporal scRNA-seq count matrices and cell-by-time-point binary time tables via the scDatasets package (guo, guo2, loh, trapnell, iPSC, petropoulos, deng) plus simulated data from sim.rnaseq.ts(N = 2000, M = 500, n.lineage = 5, n.time.points = 5). Filter and preprocess counts with X <- preprocess(X), and for t-SNE and diffusion map baselines scale and log-transform with X.log <- scale(log(X + 1)). Fit each method to every dataset: tcm(X, time.table = time.table) for TCM, Rtsne(t(X.log))$Y for t-SNE, and diffuse(dist(t(X.log)))$X[, c(1, 2)] for diffusion map, plus diffusion pseudotime, Wishbone, Monocle and TSCAN on the same inputs; for large datasets (~10,000 cells) use stochastic variational inference (batch.size = 2000, mc.cores = 4). For each method-dataset pair, extract the 2D latent coordinates of cells at the last time point via the time.table binary indicator matrix and apply Hartigan's dip test (diptest package) to each coordinate distribution to quantify within-time-point multimodality. Tabulate dip scores into a method-by-dataset matrix (dip_scores.csv) and judge success by whether TCM attains the highest dip score as reported.

## Related tools

## Examples

```
library(tcm); X <- preprocess(X); mf <- tcm(X, time.table = time.table); X.log <- scale(log(X + 1)); y <- Rtsne(t(X.log))$Y
```

## Evaluation signals

- dip_scores.csv is a complete method-by-dataset matrix (7 methods x 11 datasets) with no missing cells
- TCM attains the highest Hartigan's dip score on all 11 datasets, consistent with the reported finding
- For t-SNE and diffusion map baselines, counts were identically preprocessed with X.log <- scale(log(X + 1)) before embedding
- Last-time-point cells are subset via the binary time.table indicator matrix, not ad-hoc metadata filtering
- TCM explains a high share of non-temporal variance (reported average 78.6% across the 11 datasets), indicating reduced crowding

## Limitations

- Subpopulations within each time point are usually indistinguishable on t-SNE and diffusion map latent spaces because minor expression differences are dominated by temporal differences — the dip score corrects for this bias but methods may look tied on easy datasets
- TCM requires complete time indices correlated with the underlying dynamics, so the benchmark cannot fairly cover unsampled or drifting temporal annotations
- Large datasets (e.g. 10,000 cells) require stochastic variational inference (~15 mins on Intel Xeon 2.6GHz) and a fixed seed (e.g. set.seed(1)) for reproducibility
