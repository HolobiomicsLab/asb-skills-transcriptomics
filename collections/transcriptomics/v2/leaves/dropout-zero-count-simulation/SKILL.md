# dropout-zero-count-simulation

## Summary

Simulates single-cell expression data with controlled dropout (extra zero counts) to benchmark gene co-expression network inference methods like scLink against correlation- and model-based baselines under known ground-truth topologies.

## When to use

Use when benchmarking network inference methods on synthetic scRNA-seq data where excess zero counts (dropout) must be introduced at controlled rates, or when ground-truth power-law/hub network topologies are needed for AUPRC/AUROC evaluation.

## When NOT to use

- Analyzing a real single-cell dataset without known ground-truth network topology — simulated AUPRC/AUROC validation does not apply
- The input is already a sparse count matrix and the goal is network inference itself (e.g., running sclink_net) rather than benchmarking method accuracy under dropout
- Evaluating methods that require direction-aware (regulatory) networks, since scLink edges are based on statistical dependencies and do not have directions

## Inputs

- Real single-cell read count matrix (e.g., GEO GSE114727) used to estimate per-gene means and standard deviations as simulation parameters
- Ground-truth connectivity matrices with power-law and hub-based block-diagonal topologies generated by ldstatsHD
- Number of simulation repeats (50) and dropout rates rho in {0.07, 0.10, 0.13, 0.16}

## Outputs

- Simulated sparse single-cell expression datasets with controlled zero-inflation per dropout condition
- Per-repeat and aggregated AUPRC/AUROC summary table (simulation_auprc_auroc.csv) comparing scLink, glasso, PIDC, GENIE3, and thresholded Pearson/Spearman networks against ground truth

## How to apply

Estimate per-gene expression means and standard deviations from a real single-cell count matrix (e.g., GSE114727) to parameterize the simulation. Use ldstatsHD to generate block-diagonal connectivity matrices with power-law and hub-based topologies, then sample multivariate Gaussian expression data for each of ~50 repeats. Introduce extra zero counts at dropout rates rho in {0.07, 0.10, 0.13, 0.16}, and include a no-extra-sparsity control where the zero-introduction step is skipped. Infer networks on each simulated dataset with competing methods (scLink via sclink_net, glasso, PIDC, GENIE3, thresholded Pearson, thresholded Spearman), compare adjacency matrices against the true connectivity, and compute AUPRC and AUROC per repeat per setting before aggregating to a summary table (e.g., simulation_auprc_auroc.csv).

## Related tools

- **scLink** (Primary method under evaluation; sclink_net infers the sparse co-expression network on each simulated dataset) — https://github.com/Vivianstats/scLink
- **R** (Implementation environment for the simulation, zero-inflation, and evaluation pipeline; scLink is an R package installed from CRAN) — https://github.com/Vivianstats/scLink
- **glasso** (Baseline Gaussian graphical model method benchmarked against scLink on the simulated sparse data)
- **PIDC** (Baseline method using partial information decomposition to quantify gene dependencies on simulated datasets)
- **GENIE3** (Baseline tree-ensemble regression method benchmarked on simulated co-expression networks)

## Examples

```
install.packages("scLink"); sim <- ldstatsHD::...; sclink_net(dat, genes)
```

## Evaluation signals

- In the aggregated AUPRC/AUROC table, scLink attains the best AUPRC in every power-law and hub-based condition (reproducing Figure 2C-D and Figure S3 pattern)
- Generic glasso should not beat thresholded Pearson correlation in the simulated settings
- All methods, especially Pearson/Spearman correlation, should improve on the no-extra-sparsity control relative to the dropout conditions
- Per-condition aggregation covers exactly 50 repeats for each topology and dropout rate combination
- AUPRC and AUROC are computed by comparing each inferred adjacency matrix against the true connectivity matrix for every repeat and setting

## Limitations

- Edges identified by scLink are based on statistical dependencies and do not have directions; regulatory, co-regulatory, and functionally coordinated edge types cannot be distinguished using only gene expression data
- Dropout rates evaluated are limited to rho in {0.07, 0.10, 0.13, 0.16} plus a no-extra-sparsity control; other sparsity regimes are untested here
- Imputed single-cell data may remain much sparser than bulk data, so bulk-data network methods may perform poorly even after imputation
