# ckg-to-gene-annotation-mapping

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Maps compressed k-mer groups (CKGs) from scSimClassify to gene annotations by resolving k-mer membership via the CKG look-up table with the Bio package, enabling comparison of CKG features against gene expression features such as intersecting shared genes between top-ranked features of tree-based classifiers.

## When to use

Use when you have CKG cell features (reference-free k-mer groups) plus a CKG look-up table and need to interpret CKGs at gene level, e.g. to overlap them with gene expression feature rankings.

## When NOT to use

- Input is already a gene-level feature table with no CKG look-up table available (k-mer-to-gene resolution is impossible)
- The goal is pure classification accuracy rather than biological interpretation of CKG features

## Inputs

- CKG cell matrix (cells x compressed k-mer group features) from the cell matrix generation module
- Gene expression matrix with cell labels
- Cell labels (targets) for the intra-dataset experiments
- CKG look-up table mapping k-mer ids to CKG membership
- k-mer / gene annotation resources accessible via the Bio package

## Outputs

- Top-10 CKG features ranked by tree-based feature_importances_
- Top-10 GE features ranked by tree-based feature_importances_
- shared_genes.csv listing shared gene identifiers and the CKG/GE features they are assigned to

## How to apply

Train tree-based classifiers (RandomForest/GradientBoosting from sklearn) on both the CKG cell matrix and the gene expression matrix using the provided cell labels as targets, then rank features by feature_importances_ and select the top-10 from each representation. Use the CKG look-up table (generated by selecting informative k-mers and simhashing k-mer vectors into fingerprints) to resolve which k-mers compose each selected CKG, and map those k-mers to gene annotations with the Bio package. Intersect the gene annotations of the top-10 CKG features with the top-10 GE features to identify shared genes. Write the resulting overlap (shared gene identifiers and their assigned features) to shared_genes.csv with pandas.

## Examples

```
rf = sklearn.ensemble.RandomForestClassifier().fit(X_ckg, labels); top10 = X_ckg.columns[np.argsort(rf.feature_importances_)[-10:]]
```

## Evaluation signals

- shared_genes.csv exists and contains gene identifier and feature annotation fields
- Every listed shared gene appears in the annotation sets of both the top-10 CKG and the top-10 GE feature lists
- Top-10 lists are derived from feature_importances_ of sklearn tree-based models, not arbitrary ordering
- Each selected CKG is resolvable to k-mers via the CKG look-up table before gene mapping
- Large proportion of shared genes between CKG and GE top-10 sets is the expected outcome reported by the source task

## Limitations

- CKGs are reference-free, so gene mapping depends on resolving k-mer membership through the look-up table; k-mers from incomplete or insufficient reference genomes may not map to any annotated gene
- Gene-level interpretability is post hoc: CKGs group k-mers with similar abundance profiles rather than being defined by genes
