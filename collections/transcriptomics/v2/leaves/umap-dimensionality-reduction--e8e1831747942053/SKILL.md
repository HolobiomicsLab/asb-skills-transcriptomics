# umap-dimensionality-reduction

## Summary

Incorporates clonal barcode information into the dimensionality-reduction step prior to UMAP visualization via the Warp Factor parameter s (0–10), which warps each cell's principal component values toward the mean PC value of its clone cluster before running UMAP on the modified matrix.

## When to use

Use when single-cell scRNA-seq data has per-cell clonal barcode assignments and you want 2D UMAP embeddings in which cells sharing a barcode progressively coalesce as clone influence is tuned up.

## When NOT to use

- The data have no clonal barcode assignments — with no clone clusters the warp transformation is undefined and plain UMAP on the unmodified PCA should be used instead
- The goal is hybrid transcriptome/clone clustering rather than 2D visualization — use the ClonoCluster α-weighted graph clustering instead of PC warping
- Barcodes label full-lineage phylogenies (e.g., CRISPR-Cas9 genome editing or imaging-based family trees), which the study did not address

## Inputs

- Normalized or scaled count matrix of barcoded cells (gene-by-cell) from a Seurat object or file
- Deposited PCA matrix of 25 PCs generated by irlba_wrap
- Two-column barcode table with cell IDs ('rn') and assigned barcodes ('Barcode')

## Outputs

- 2D UMAP embedding tables per warp factor value, combined into a single TSV (umap_warped_embeddings.tsv) with a 'warp' column
- Warped PC matrices Ms for each s value

## How to apply

Load the deposited PCA matrix (25 PCs from irlba_wrap on the normalized/scaled count matrix) and the two-column barcode table (columns 'rn' and 'Barcode') with data.table::fread. Group cells by Barcode and compute the mean PC value vector Mb for each clone cluster, then apply the warp transformation Ms = M − (s/10)(M − Mb), which shifts each cell's PCs toward its clone-cluster mean by fraction s/10 (s = 0 leaves the PC matrix unmodified; s = 10 makes clone-cluster variation the only variation). Run UMAP on each warped matrix using ClonoCluster's engage_warp, which wraps uwot/umap_matrix, for s in {0, 5, 10} (or the full 0–10 range). Combine the per-warp 2D embedding tables into a single table with a 'warp' column via data.table::rbindlist and save as umap_warped_embeddings.tsv.

## Examples

```
umap_wf0 <- engage_warp(pca, bt, 0)
```

## Evaluation signals

- The s = 0 embedding matches default UMAP of the unmodified PCA matrix (warp is a no-op at s = 0)
- Cells sharing the same barcode progressively coalesce in the embedding as s increases toward 10
- At s = 10, clone-cluster variation is the only variation in the data — cells in the same clone cluster collapse to the same PC position
- Combined output table contains a 'warp' column and one embedding per tested s value, saved as umap_warped_embeddings.tsv
- Input PCA matrix contains 25 PCs as produced by irlba_wrap(cm, npc = 25)

## Limitations

- The appropriate degree of clone weighting (here s, analogously α in ClonoCluster) may differ between endpoint and transitional systems and requires case-by-case evaluation
- Warp Factor addresses clonal barcodes only; full-lineage tracing data such as CRISPR-Cas9 genome editing or imaging-based family trees were not addressed, though the approach could be adapted to weight by phylogenetic distance
- Software version numbers other than R (>= 3.6) are not stated, so exact uwot/UMAP versions are unverified
- Twin analysis (barcoded twin cells in different local environments) is a critical control that should accompany interpretation but was not part of the presented analyses
