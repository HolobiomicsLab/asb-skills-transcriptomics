# blood-transcriptome-cohort-clustering

## Summary

A workflow for clustering whole blood transcriptome cohorts by their module/aggregate-level activity fingerprint, using the fixed BloodGen3 repertoire of 382 modules (grouped into aggregates such as A28) to compute the percentage of increased/decreased constitutive genes per module and visualize cross-cohort structure as a fingerprint heatmap.

## When to use

Use when multiple blood transcriptome cohorts or disease/physiological states need to be compared and grouped by shared immune-response patterns, e.g. to test whether a state like acute HIV infection forms its own cluster via aggregate-level fingerprints.

## When NOT to use

- The expression data are not from human blood — the BloodGen3 repertoire is specifically designed for human blood transcriptome profiling; other tissues or species require separate frameworks
- The input matrix is already Log2-transformed — the README states the data.matrix 'should not be Log2 transformed' because functions transform it internally
- The goal is de novo module discovery rather than benchmarking against a fixed repertoire — this skill annotates with the fixed Gen3 module list, it does not re-cluster genes

## Inputs

- Normalized human blood expression matrix (genes as rows, Sample IDs as columns, valid Gene Symbols, NOT Log2-transformed)
- Sample annotation dataframe with a Sample ID column matching data.matrix and a group annotation column (e.g. Group_test) naming disease/physiological states
- Fixed BloodGen3 module membership list (Module_listGen3/Gen3_ann) mapping 14,168 transcripts to 382 modules and their aggregates

## Outputs

- Module-level dataframe (Group_df or Group_limma) with percentage of increased/decreased constitutive genes per module
- Aggregate-level summary for the 27 multi-module aggregates (e.g. A1-A8 lymphocyte-associated, A34-A38 erythroid/inflammation) as percentage of genes increased or decreased
- Fingerprint heatmap PDF generated by fingerprintplot, with rows split by aggregate and cohorts arranged by hierarchical clustering

## How to apply

Load normalized (un-Log2-transformed) expression data plus sample annotation into R with BloodGen3Module attached, e.g. GSE13015 fetched via ExperimentHub entry EH5429; the package transforms the data internally. Annotate the expression matrix with module membership from the fixed repertoire (Module_listGen3/Gen3_ann), grouping the 382 modules into their parent aggregates (e.g. A28). For each cohort run Groupcomparison (t-test) or Groupcomparisonlimma with FC = 1.5, pval = 0.1, FDR = TRUE, specifying Group_column, Test_group and Ref_group, to obtain the percentage of increased/decreased constitutive genes per module, then summarize at the aggregate level for the 27 multi-module aggregates. Generate the cross-cohort fingerprint heatmap with fingerprintplot using cutoff = 15 (percentage of genes changed, adjustable 0-100), rowSplit = TRUE, Group_column for cohort grouping, and Aggregate aggregation, writing a PDF to the working directory; hierarchical clustering of the heatmap rows/columns then reveals the cohort structure. Rationale: the fixed repertoire provides a stable module vocabulary so cohort activity can be benchmarked within and across patient cohorts rather than re-deriving modules per cohort.


## Evaluation signals

- The fingerprintplot PDF exists in the working directory and the heatmap is row-split by aggregate with the requested Group_column grouping
- Hierarchical clustering of the aggregate-level heatmap separates acute HIV infection into its own cluster with the remaining 14 reference states in a second cluster
- Aggregate rows show the expected biology: A34-A38 inflammation/myeloid aggregates suppressed and A1-A8 lymphocyte aggregates increased in the relevant states; A28 shows marked increases in SLE, influenza, HIV and tuberculosis
- All module/aggregate values are percentages of increased or decreased constitutive genes bounded between 0 and 100, with visualization cutoff applied at 15%
- Groupcomparison outputs were computed with the documented thresholds FC = 1.5, pval = 0.1, FDR = TRUE (BH method)

## Limitations

- The BloodGen3 repertoire is specific to human blood transcriptome data and was constructed at the probe level on Illumina HT12 v3 BeadArrays, which pre-dates RNA sequencing
- 388 out of 14,168 probes are duplicate genes found in different modules, so a handling choice for duplicates is required (the authors report little impact since these concern only a small minority of genes)
- The repertoire is not a ground truth: some aggregates are heterogeneous in functionality and functional annotation titles confer subjectivity; the annotation map is expected to keep evolving while the framework stays fixed
