# directed-knn-graph-construction

## Summary

Builds the directed k-nearest-neighbor graph used by scQA's Cluster Constructor (CC) module, computed on the quantitative cell-landmark matrix Q2 from the LC2 module with Pearson correlation similarity and density-scaled out-neighbor counts (0.1n for n<10,000 cells; 0.05n for n≥10,000).

## When to use

Use when clustering single-cell RNA-seq data with scQA and a directed cell-cell graph over the LC2-derived quantitative representation is needed as the substrate for seed generation and label propagation.

## When NOT to use

- Q2 has not been generated yet — the graph is defined on the LC2 output, not on raw gene expression or on the binary Q1 matrix
- The task calls for an undirected cell-cell graph or a graph built on the qualitative (LC1) representation — scQA's CC module specifically uses the matrix generated by LC2
- The number of cell types must be fixed a priori — scQA's label propagation obviates a predetermined cluster count

## Inputs

- Quantitative cell-landmark matrix Q2 (cells x landmarks) produced by the LC2 module
- Pre-processed scRNA-seq expression matrix of cells * genes without row/column names (per scQA README)

## Outputs

- Directed k-nearest-neighbor graph over cells with per-node out-neighbor sets and Pearson correlation edge similarities
- Per-node density values (average similarity to neighbors) consumed by seed generation

## How to apply

After LC1 and LC2 have produced the qualitative (Q1) and quantitative (Q2) cell-landmark matrices, compute pairwise Pearson correlation similarity between cells on Q2. Build a directed graph where each node (cell) receives out-edges to its nearest neighbors: give each node 0.1n out-neighbors when n<10,000 cells, and 0.05n out-neighbors when n≥10,000 (scQA CC module, Algorithm 3). This graph supports subsequent density computation (average similarity to neighbors), seed selection, and two-hop directed path similarity scoring in label propagation (Eq. 10), so edge directionality and the per-node out-degree must be preserved. The graph is only the scaffold — final cluster labels come from the downstream propagation step and are written to labels.txt.

## Related tools

- **scQA** (Provides the CC module (Algorithm 3) that constructs the directed kNN graph on the LC2-derived matrix and performs the downstream seed generation and label propagation clustering) — https://github.com/LD-Lyndee/scQA

```
git clone https://github.com/LD-Lyndee/scQA.git && cd scQA && ./make && ./main xin_matrix.txt o
```

## Evaluation signals

- Each node's out-degree equals 0.1n for n<10,000 cells or 0.05n for n≥10,000, and edge similarities are Pearson correlations computed on Q2 rows
- Grouping cells by identical Q1 row vectors and computing density as average neighbor similarity yields seed candidates whose group-maximum densities set the threshold beta
- Label propagation converges and the final per-cell labels are written to labels.txt (README-declared output)
- Running the compiled binary with the default binning parameter ('o') completes without error on a cells * genes matrix lacking row/column names

## Limitations

- Retaining only 2000 highly variable genes excluded some informative genes, which propagates into the landmark matrices underlying the graph
- Genes may be misclassified in LC1 and LC2 due to high dimensionality, degrading Q2 quality
- Small clusters may be pruned; clusters that have assimilated others must be protected from re-merging, requiring the merging guard in the CC stage
- Out-neighbor scaling (0.1n vs 0.05n) must match dataset size — using the wrong regime changes graph connectivity
