# concordance-index-survival-model-validation

## Summary

Validates a prognostic risk-score model by computing Harrell's concordance index (C-index) across independent survival cohorts and comparing it against a control model, as done for the TimiRS melanoma model built from CD8-Tem-derived marker gene pairs.

## When to use

Use when a Cox/LASSO-derived risk score from marker gene pairs must be validated in independent cohorts and its predictive performance (C-index) compared to a control model.

## When NOT to use

- The dataset lacks matched survival information or has too few events — the article notes TimiGP requires a large gene expression dataset with matched survival data to identify prognostic gene pairs, so C-index validation is underpowered
- You only need deconvolution-based cell-type abundance estimates rather than a prognostic model of marker gene pairs (e.g., inputs suited to xCell or CIBERSORTx)

## Inputs

- MPS (Marker Pair Score) matrices for each validation cohort, generated by TimiGenePair with logical pairwise comparison (1 = gene A expression > gene B expression)
- LASSO Cox regression coefficients derived from the training cohort (TCGA SKCM06)
- Preprocessed expression matrices (log-transformed, gene-wise median normalized via TimiPrePropress on CD8-Tem markers)
- Filtered clinical survival data (event and time-to-event, quality-checked via TimiCheckEvent) for GSE65904, GSE22155, GSE54467, GSE53118, GSE8401

## Outputs

- Per-patient TimiRS risk scores for each validation cohort
- Harrell's C-index per cohort (expected range 0.621–0.659) with TimiRS-control comparison
- High-/low-risk patient stratification with Kaplan-Meier/log-rank survival separation results
- Assembled results table (e.g., timirs_validation_results.csv) with C-index values, control-model comparison, and interaction-level stratification

## How to apply

Apply LASSO-penalized Cox regression coefficients (glmnet, alpha = 1) fitted on a training cohort (e.g., TCGA SKCM06 Cox-selected prognostic marker pairs) to the Marker Pair Score (MPS) matrices of independent validation cohorts to compute per-patient risk scores. For each cohort, compute Harrell's C-index for the model and for a control model built from marker pairs not associated with the enriched cell-cell interactions. Stratify patients into high- and low-risk groups by median risk-score split and confirm survival separation with Kaplan-Meier/log-rank tests. In the TimiGP melanoma case, the TimiRS model built from the top 21 CD8-Tem-derived IMGPs must yield a C-index of 0.621–0.659 across the five validation cohorts (GSE65904, GSE22155, GSE54467, GSE53118, GSE8401), exceed the TimiRS-control C-index, and outperform the control model in patient stratification.

## Related tools

- **TimiGP** (R package providing TimiPrePropress, TimiCheckEvent, TimiGenePair, and related functions to build the MPS matrices and preprocess cohorts used in the risk-score validation) — https://github.com/CSkylarL/TimiGP
- **survival** (R package used for Cox regression fitting and Harrell's C-index / Kaplan-Meier survival analysis of the TimiRS risk score)
- **R** (Execution environment for glmnet (alpha = 1) LASSO Cox model fitting and application of coefficients to validation-cohort MPS matrices)

## Examples

```
res <- TimiPrePropress(rna, marker, info); mps <- TimiGenePair(res); fit <- glmnet(t(mps_train), Surv(time, event), family="cox", alpha=1); risk <- as.vector(t(mps_valid) %*% coef(fit, s="lambda.min"))
```

## Evaluation signals

- TimiRS C-index lies within the reported 0.621–0.659 range across all five validation cohorts (GSE65904, GSE22155, GSE54467, GSE53118, GSE8401)
- TimiRS C-index exceeds the TimiRS-control C-index (control built from marker pairs not associated with the 19 enriched cell-cell interactions)
- The 19 identified cell-cell interactions stratify overall survival (log-rank significant) in all five datasets with median risk-score split
- MPS matrices are binary logical comparisons (1 = gene A expression > gene B expression) computed from log-transformed, gene-wise median-normalized expression
- Clinical data pass TimiCheckEvent filtering (valid event and time-to-event fields) before C-index computation

## Limitations

- TimiGP requires a large gene expression dataset with matched survival information to effectively identify prognostic gene pairs; the power of the survival analysis is determined by sample size, number of events, and quality of survival information
- Since cell-cell interactions are identified by enrichment analysis, sensitivity to a specific interaction depends on the number of corresponding marker genes; cell types with fewer marker genes are less likely to be identified
- No wet-lab experiments were performed to validate the important findings, raising uncertainty about the reliability of the cell-cell interaction inference
