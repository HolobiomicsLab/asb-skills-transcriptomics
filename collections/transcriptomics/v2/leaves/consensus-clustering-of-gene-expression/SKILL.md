# consensus-clustering-of-gene-expression

## Summary

Gene-wise consensus clustering (ConsensusClusterPlus, kmeans, euclidean distance) applied across multiple curated PDAC RNAseq datasets to test whether published subtype signatures like the Bailey ADEX set are confounded by non-PDAC-specific gene subsets, and to quantify gene-set overlaps (e.g., Immunogenic vs pancreatic progenitor and ADEX signatures).

## When to use

Use when validating whether a published gene signature is PDAC-specific: cluster genes (not samples) across two or more curated bulk RNAseq datasets and measure cross-signature overlap fractions to expose tissue-nonspecific or contaminant gene subsets.

## When NOT to use

- Input data are single-cell profiles rather than bulk RNAseq — the pdacR platform houses only bulk analyses and cannot fully separate cellular populations
- Datasets come from mixed platforms (bulk RNA-seq plus microarrays) and you intend to merge them into one clustering input — the authors found aggregation 'introduced more problems than it solved'
- The analysis goal is clustering samples/patients into subtypes (e.g., basal-like vs classical) rather than decomposing a gene signature at the gene level

## Inputs

- Parsed PACA-AU RNAseq dataset in pdacR list format ($ex, $sampInfo, $featInfo, $metadata)
- Parsed Moffitt RNAseq dataset in pdacR list format ($ex, $sampInfo, $featInfo, $metadata)
- Bailey ADEX gene signature (gene SYMBOLs) from the pdacR gene_lists object
- Immunogenic and pancreatic progenitor gene signatures from the pdacR gene_lists object

## Outputs

- Three classified gene lists: ACC-specific, pancreas-nonspecific, and generally nonspecific ADEX genes
- Fig. 3a ADEX-partition panel and Fig. 3d Immunogenic-overlap panel (ggplot2 figures)
- Results table reporting Immunogenic vs progenitor (26%) and Immunogenic vs ADEX (9%) overlap fractions

## How to apply

Load parsed PDAC expression datasets (PACA-AU RNAseq and Moffitt RNAseq) from the pdacR data/ directory, each following the $ex/$sampInfo/$featInfo/$metadata list format. Pull the Bailey ADEX, Immunogenic, and pancreatic progenitor signatures from the pdacR gene_lists object (gene SYMBOL identifiers, generated by R/parse_gene_lists.R). Run ConsensusClusterPlus in gene-wise mode — i.e., transpose the standard usage so genes are the objects being clustered — using the kmeans algorithm with euclidean distance, separately on each dataset, to see which ADEX genes group with adrenal/ACC-expressed genes versus pancreas-expressed genes. Classify each ADEX gene as ACC-specific, pancreas-nonspecific, or nonspecific from its cross-dataset cluster membership and save the three gene lists. Then compute the percent overlap of the Immunogenic gene set against the pancreatic progenitor and ADEX signatures; the paper reports 26% and 9%, which serve as reproduction targets.

- Fig. 3a (ADEX partition) and Fig. 3d (Immunogenic overlap) panels render as named output files
- Datasets were loaded in the required $ex/$sampInfo/$featInfo/$metadata list format with gene identifiers as SYMBOLs

## Limitations

- Bulk transcriptomic data limit the ability to fully separate cellular populations, so gene-subset assignments reflect bulk confounding rather than cell-type-resolved expression
- pdacR datasets span multiple platforms (bulk RNA sequencing and microarrays), adding complexity to batch correction; datasets were therefore clustered separately rather than merged
- Consensus clustering must be run separately on each dataset (PACA-AU and Moffitt) and genes classified by cross-dataset cluster membership, since datasets cannot be robustly merged
