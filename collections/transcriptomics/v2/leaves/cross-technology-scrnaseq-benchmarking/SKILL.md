# cross-technology-scrnaseq-benchmarking

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Benchmarks reference mapping of scRNA-seq query cells generated by different 10x protocols (3'v1, 3'v2, 5') onto a pre-built reference atlas, quantifying whether the mapper corrects platform-specific batch effects via LISI before/after projection.

## When to use

Use when query scRNA-seq data from multiple sequencing technologies/protocols must be mapped onto a shared reference atlas and you need to quantify batch-effect correction with a cell-type mixing metric such as LISI.

## When NOT to use

- The query contains novel cell states absent from the reference — projections from a fixed model may be misleading; compare unsupervised clustering to mapping results first
- The query and reference come from drastically different platforms (e.g. Smart-seq2 to 10x) where performance declines due to differing UMI distributions and sequencing depth
- The reference atlas was built with a data-tailored integration strategy incompatible with integration-dependent mappers — ProjectSVR's integration-agnostic formulation is the point of this benchmark, not a generic integration workflow

## Inputs

- Query Seurat object containing PBMCs from three 10x protocols (3'v1, 3'v2, 5') with per-cell protocol labels (query_hPBMCs.seurat.slim.qs)
- Pre-trained reference model RDS file (model.disco_pbmc.rds, DISCO PBMC)
- Slim Seurat reference atlas (DISCO_hPBMCs.seurat.slim.qs)

## Outputs

- Query cells projected into the reference UMAP space (ref.umap reduction) with map-quality metrics (mapQ.p.adj, mean.knn.dist)
- Pre- vs post-mapping LISI comparison table (lisi_comparison.csv)
- Mean LISI benchmark value for the cross-protocol mapping (~2.30 vs baseline ~1.06)

## How to apply

Label each query cell with its protocol of origin (3'v1, 3'v2, 5') as the batch covariate and compute LISI on the uncorrected low-dimensional embedding to establish a pre-mapping baseline (e.g. mean LISI ~1.06). Load a pre-trained reference model (model.disco_pbmc.rds from Zenodo record 8350732), the reference atlas (DISCO_hPBMCs.seurat.slim.qs from record 8350746), and the query data (query_hPBMCs.seurat.slim.qs from record 8350748). Run ProjectSVR::MapQuery with add.map.qual = TRUE and ncores = 10 so gene-set activity scores are computed internally per the model's stored gss.method, projecting query cells into the reference ref.umap reduction. Filter mapped cells with MapQCPlot cutoffs (mapQ.p.adj < 0.1 and a mean.knn.dist threshold) to retain well-mapped cells, then recompute LISI on the projected ref.umap embeddings; success is a mean LISI (~2.30) that exceeds the uncorrected baseline and is comparable to competing mappers (Symphony, scArches, ProjecTILs, Seurat V4).

## Examples

```
seu.q <- ProjectSVR::MapQuery(seu.q, model, reference, ref.umap = "ref.umap", add.map.qual = TRUE, ncores = 10)
```

## Evaluation signals

- Mean LISI across the three 10x protocols on the projected ref.umap embedding (~2.30) exceeds the uncorrected baseline (~1.06)
- Post-mapping performance is comparable to leading reference mapping methods (Seurat, scArches, Symphony, ProjecTILs) as in Figure 3 / Table 2 of the benchmark
- Well-mapped cells pass map-quality filters: mapQ.p.adj < 0.1 and mean.knn.dist below the chosen cutoff (e.g. < 1.6 or < 2)
- Comparison table lisi_comparison.csv is produced with pre- and post-mapping values matching the reported benchmark values
- Reference model version matches the pre-built model table (DISCO PBMC, version 0.2)

## Limitations

- Performance declines when projecting across platforms (e.g. Smart-seq2 to 10x) due to differing UMI distributions and sequencing depth (Table S5)
- Projections may be misleading for query cells containing novel states absent in the reference; users must compare unsupervised clustering to mapping results to detect inconsistencies
- Reference building time is ~O(Nc^2), requiring subsampling to 4000-10,000 cells; independent SVR models per UMAP dimension neglect correlations among embedding dimensions
