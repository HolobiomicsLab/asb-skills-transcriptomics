# go-enrichment-signature-comparison

## Summary

Compares GO/Reactome enrichment results between two single-cell cohorts by identifying each cell type's top 100 signature genes with SCANPY, running enrichment with GSEApy, and quantifying overlap of enriched terms. In the scSemiProfiler study this tests whether the semi-profiled COVID-19 cohort reproduces biomarker discovery from the real-profiled cohort (95/100 overlap of top-100 CD4 signature genes, hypergeometric p = 9.10e-196).

## When to use

Use when two single-cell cohorts must be compared at the pathway/signature level — e.g., validating that inferred or semi-profiled data reproduces GO/Reactome enrichment from real-profiled data.

## When NOT to use

- Input is bulk RNA-seq without cell-type-resolved signatures — bulk deconvolution to single-cell resolution (scSemiProfiler deconvolution mode) is required first
- The goal is to rank cell types by proportion rather than compare pathway enrichment of gene signatures
- No matched reference cohort exists to compare enriched terms against

## Inputs

- Semi-profiled single-cell cohort (e.g., COVID-19 data generated by scSemiProfiler, task_001 output)
- Real-profiled ground-truth single-cell cohort for the same samples
- Cell-type annotations for both cohorts
- GO and Reactome gene sets (GSEApy gene set libraries)

## Outputs

- Top-100 cell-type signature gene lists per dataset (SCANPY)
- GO/Reactome enrichment term tables per cohort (GSEApy)
- Overlap statistics of enriched terms between cohorts (e.g., 95/100, hypergeometric p-value)
- Rows in downstream_fidelity.csv summarizing enrichment agreement

## How to apply

For each cohort (e.g., semi-profiled vs. real-profiled COVID-19 samples), first preprocess with library size normalization, log1p transformation, and highly variable gene selection, then use SCANPY to identify the top 100 cell-type signature genes (task_005 also uses top 50 positive/negative markers with RRHO plots). Run GO and Reactome enrichment on each signature gene list with GSEApy, treating the real-profiled cohort as ground truth. Record the overlap of enriched terms between datasets and test its significance (expected: 95/100 overlap for CD4 signature genes with hypergeometric p = 9.10e-196). Assemble the overlap statistics into downstream_fidelity.csv alongside the RRHO summaries, CellChat correlation (0.996), and pseudotime correlation (0.809), and check each value against the reported Fig. 3 agreement tolerances.

## Related tools

- **SCANPY** (Identifies top 100 cell-type signature genes (and top 50 positive/negative markers for RRHO) in both semi-profiled and real-profiled datasets) — https://github.com/mcgilldinglab/scSemiProfiler
- **GSEApy** (Runs GO/Reactome enrichment on the signature gene lists from each cohort)
- **SciPy** (Hypergeometric test for significance of enriched-term overlap (p = 9.10e-196))
- **scSemiProfiler** (Generates the semi-profiled cohort whose enrichment fidelity is being evaluated against the real-profiled cohort) — https://github.com/mcgilldinglab/scSemiProfiler


## Evaluation signals

- Enriched-term overlap between real- and semi-profiled cohorts is 95/100 for top-100 CD4 signature genes
- Hypergeometric p-value of the overlap is 9.10e-196
- Enrichment output contains the reported GO terms from the paper
- Recorded statistic falls within tolerance of the reported Fig. 3 agreement value when written to downstream_fidelity.csv
- RRHO plots built from hypergeometric-test p-values of ranked marker lists show concordant marker ranking between cohorts

## Limitations

- Skill requires a single-cell reference; semi-profiling fidelity depends on the deep generative model having representative samples selected by active learning
- Enrichment overlap is cell-type specific (reported for CD4); other cell types may show different agreement levels
- Interpretation depends on the gene set library chosen (MSigDB curated sets / Reactome), which can shift enriched-term lists
