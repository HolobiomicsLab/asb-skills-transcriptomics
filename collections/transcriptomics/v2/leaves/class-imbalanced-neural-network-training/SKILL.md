# class-imbalanced-neural-network-training

## Summary

Retrains the CLOUDe neural network classifier on highly unbalanced 'redundant-skewed' or 'unique-skewed' OU-simulated expression training data, then evaluates whether it retains power (redundant recall) and accuracy on a balanced test set.

## When to use

Use when testing robustness of the CLOUDe neural network classifier to class imbalance: training data are skewed toward 'Redundant' or 'Unique' classes, but evaluation must occur on a balanced test set.

## When NOT to use

- The goal is a balanced-training baseline rather than an unbalanced-data robustness assessment
- The chosen architecture is extreme gradient boosting, random forest, or support vector machine instead of the multi-layer neural network
- The task is to predict evolutionary parameters (theta1, theta2, log10(sigmaSq/(2*alpha))) — use PredictorCVnn/CLOUDePredictNN rather than the classifier functions

## Inputs

- Unbalanced training set ('redundant-skewed' or 'unique-skewed') generated by GenerateTrainingData from an OU process with the empirical file as reference
- Empirical input file in CLOUDe format (space-delimited, N+1 rows x 3m columns, e.g., EmpiricalData.data with N=100 deletion events at m=6 tissues)
- Balanced test set of deletion events with known 'Redundant'/'Unique' labels

## Outputs

- Optimal hyperparameters written to training_prefix.nn.num_layers.classifier_cv
- Fitted neural network classifier saved as training_prefix.nn.num_layers.classifier.hdf5 (TensorFlow HDF5)
- Per-deletion-event predicted classes (test_prefix.nn.num_layers.classifications) and class probabilities (test_prefix.nn.num_layers.probabilities)
- Power (redundant recall) and overall accuracy on the balanced test set (target: 96.65% power, 96.35% accuracy)

## How to apply

Load CLOUDe in R with source("CLOUDe.R") after installing dplyr, mvtnorm, tensorflow, and keras, then generate the highly unbalanced 'redundant-skewed' and 'unique-skewed' training sets with GenerateTrainingData, simulating expression evolution under an Ornstein–Uhlenbeck process with the empirical expression file (e.g., EmpiricalData.data) as reference. Run ClassifierCVnn with num_layers in {0,...,5}, five-fold cross-validation, log10(lambda) over 7 evenly spaced points in [-3, 3], gamma over 3 evenly spaced points in [0, 1], batch size 50, and 50 epochs to select optimal lambda, gamma, and number of hidden layers. Fit the neural network classifier conditional on the optimal hyperparameters and save the model in TensorFlow HDF5 format. Apply CLOUDeClassifyNN to the balanced test set to output predicted classes and class probabilities per deletion event. Compute power (redundant recall) and overall accuracy on the balanced test set and compare against the reported 96.65% power and 96.35% accuracy; the CLOUDe NN should outperform the other architectures under this imbalance.

## Examples

```
source("CLOUDe.R"); ClassifierCVnn(5, 50, 50, -3, 3, 7, 0, 1, 3, "training_prefix")
```

## Evaluation signals

- Retrained unbalanced-data NN classifier achieves power and accuracy within a few percentage points of the reported 96.65% power and 96.35% accuracy on the balanced test set
- Output files (classifications and probabilities per deletion event) exist and contain per-gene class labels and probabilities
- Power is computed specifically as redundant recall on the balanced test set, not as overall accuracy
- The cross-validation output file records the optimal lambda, gamma, and number of hidden layers selected by smallest validation loss
- Training used the specified grid: num_layers 0–5, seven log10(lambda) points in [-3, 3], three gamma points in [0, 1], batch size 50, 50 epochs

## Limitations

- Reported performance (96.65% power, 96.35% accuracy) is specific to CLOUDe's neural network; other architectures may degrade more under skewed training
- Only two skew regimes ('redundant-skewed' and 'unique-skewed') are covered; other imbalance patterns are untested
- Hyperparameter tuning of the neural network is time-consuming, and training is required only for the neural network and extreme gradient boosting (SVM and random forest train on-the-fly)
