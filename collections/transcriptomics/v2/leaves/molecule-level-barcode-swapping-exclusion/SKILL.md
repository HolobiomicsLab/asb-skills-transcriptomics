# molecule-level-barcode-swapping-exclusion

## Summary

A computational method to exclude individual molecules that have swapped between samples in 10x Genomics droplet scRNA-seq experiments by removing molecules sharing the same UMI, cell barcode, and aligned gene combination across samples, then re-calling cells with emptyDrops. It addresses artefactual swapped cell libraries generated by barcode swapping on patterned flow-cell sequencers such as the HiSeq 4000 (~2.5% swapped reads).

## When to use

Use when droplet-based 10x Genomics count matrices sequenced on a patterned flow-cell instrument (HiSeq 4000/X, NovaSeq) contain multiplexed samples and artefactual swapped cell libraries are suspected.

## When NOT to use

- Data were sequenced on non-patterned flow-cell instruments (e.g. HiSeq 2500), where the swapping fraction is negligible
- The dataset is plate-based (Smart-seq2) rather than droplet-based; the plate-data regression approach for estimating swapping fraction is the appropriate method there
- Only one sample is present, so cross-sample UMI/cell-barcode/gene sharing cannot be assessed

## Inputs

- Molecule information files / count matrices from multiplexed 10x Genomics droplet scRNA-seq samples (e.g. ArrayExpress E-MTAB-6854, mm10-aligned)
- Sample-to-library demultiplexing assignments including expected barcode combinations

## Outputs

- Molecule-excluded count matrices per sample with swapped molecules removed
- Corrected cell calls from emptyDrops (FDR 0.01, minimum 1000 UMIs)
- Per-sample counts of called cells lost and fraction of cell libraries no longer called as cells

## How to apply

Load the droplet count/molecule information (e.g. E-MTAB-6854 mouse epithelial data mapped to mm10) into R with DropletUtils, and establish baseline cell calls on uncorrected data using emptyDrops with an FDR threshold of 0.01 and a minimum cell size of 1000 UMIs. Then remove molecules that share the same combination of UMI, cell barcode, and aligned gene across samples, assigning each ambiguous molecule to its majority (80%) sample of origin. Re-run emptyDrops (FDR 0.01, minimum 1000 UMIs) on the molecule-excluded matrices to obtain corrected cell calls. This molecule-level approach is preferred over cell exclusion (removing all barcodes shared between samples) because cell exclusion can incorrectly discard genuine cell libraries. Finally, quantify cells lost per sample to judge the extent of swapping-driven artefacts.

## Related tools

- **DropletUtils** (R/Bioconductor package used to load droplet count matrices or molecule information files, identify cells from empty droplets (emptyDrops, FDR 0.01, minimum 1000 UMIs), and support removal of barcode-swapped pseudo-cells) — https://github.com/MarioniLab/DropletUtils

## Examples

```
library(DropletUtils); swapped <- swappedDrops(mol.info.files, min.frac = 0.8); calls <- emptyDrops(counts(swapped), fdr.threshold = 0.01)
```

## Evaluation signals

- Re-running emptyDrops (FDR 0.01, minimum 1000 UMIs) on corrected matrices should reproduce the reported pattern: nearly all called cells lost from affected samples (e.g. B1/B2 in the mouse epithelial HiSeq 4000 data)
- Approximately 2.5% of cell libraries from other samples should no longer be called as cells, matching the estimated ~2.5% barcode-swapped read fraction on the HiSeq 4000
- Uncorrected vs corrected emptyDrops calls should be compared per sample; loss of cell calls should be concentrated in swapped samples rather than uniformly distributed
- Ambiguous molecules (same UMI, cell barcode, aligned gene across samples) must be fully assigned to a majority (80%) sample of origin — no ambiguous molecules should remain unassigned

## Limitations

- Cell exclusion (removing all barcodes shared between samples) can incorrectly discard genuine cell libraries; molecule-level exclusion mitigates this but relies on the 80% majority-of-origin assignment
- Estimates are specific to patterned flow-cell instruments; the ~2.5% swapped fraction applies to the HiSeq 4000 and should not be assumed for other machines
- Key details of the molecule exclusion method are deferred to Supplementary Note 6, which may be unavailable in some copies of the paper
- Barcode swapping may generate complex but artefactual cell libraries that appear biologically meaningful if swapping is not detected
