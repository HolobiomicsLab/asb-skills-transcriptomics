# ligand-receptor-perturbation-scoring

## Summary

Computes Connectome's per-edge 'perturbation score' for a differential connectome as the product of the absolute normalized log2 fold-changes of the ligand and receptor between test and control conditions, yielding an always-positive magnitude of perturbation ranging from 0 to Infinity.

## When to use

Use when comparing two Seurat/Connectome connectomes (e.g., IFN-stimulated vs control PBMCs) and you need a sign-agnostic per-edge magnitude of perturbation from ligand.norm.lfc and recept.norm.lfc values.

## When NOT to use

- You only have a single condition/connectome with no paired test-and-control edge set — DifferentialConnectome requires exactly the same edges present in both connectomes
- You need the direction (up vs down) of the perturbation, not just its magnitude — the perturbation score is always positive and discards sign
- Either the ligand or receptor log2 fold-change is missing/NA for an edge, since the score is a product of both and cannot be computed

## Inputs

- Thresholded differential connectome table (diff.sub) from DifferentialConnectome with ligand.norm.lfc and recept.norm.lfc columns and source.ligand / target.receptor cell-gene annotations
- Two Connectome objects (test and control) generated by CreateConnectome on Seurat objects split by condition (e.g., ifnb.list via SplitObject(ifnb, split.by = 'stim'))

## Outputs

- Per-edge perturbation scores written to perturbation_scores.csv, keyed by source cell, ligand, target cell, and receptor, ranging from 0 to Infinity

## How to apply

Run SplitObject on the ifnb Seurat object by 'stim', call FindMarkers per cell type to get ligand/receptor log fold-changes, then combine the stim and control connectomes with DifferentialConnectome (which requires exactly the same edges in both, so every edge has a reference and a test value). For each edge in the resulting diff.sub table, compute perturbation.score = abs(ligand.norm.lfc) * abs(recept.norm.lfc); the score is always positive by design, increases with the magnitude of ligand and receptor log fold-change in either direction, and is zero when either partner is unchanged. Restrict to edges passing the DifferentialScoringPlot thresholds (min.score = 1, min.pct = 0.1, infinity.to.max = T) so scores correspond to the paper's differential scoring heatmap. The same always-positive perturbation score is what CircosDiff leverages for differential circos visualization.

## Examples

```
diff.sub$perturbation.score <- abs(diff.sub$ligand.norm.lfc) * abs(diff.sub$recept.norm.lfc)
```

## Evaluation signals

- Every computed perturbation score is non-negative (score >= 0), since it is a product of absolute log fold-changes
- All retained edges have both ligand.norm.lfc and recept.norm.lfc present (no NA) before scoring
- Per-edge values match the perturbation-score heatmap (third aligned panel) from DifferentialScoringPlot run with min.score = 1, min.pct = 0.1, infinity.to.max = T
- Scores increase monotonically with |ligand.norm.lfc| and |recept.norm.lfc| in either direction, and are exactly zero when either partner is unchanged
- The test and control connectomes contain identical edge sets, so every edge has both a reference and a test value

## Limitations

- Strongly paired ligand and receptor expression (and hence a high perturbation score) is not direct evidence of cell–cell communication
- Suspension-based single-cell sequencing does not preserve spatial histologic information, so spatial proximity of candidate perturbed interactions cannot be verified
- The score is magnitude-only: it treats up- and down-regulation identically and ranges from 0 to Infinity rather than being bounded
