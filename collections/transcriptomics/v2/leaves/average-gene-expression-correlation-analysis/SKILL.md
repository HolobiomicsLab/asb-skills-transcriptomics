# average-gene-expression-correlation-analysis

## Summary

Quantifies how well two scRNA-seq preparations (e.g. fresh vs cryopreserved PBMCs) match by computing the Pearson correlation of average gene expression across gene-barcode matrices, complemented by t-tests on per-cell genes and UMI counts, to judge whether sample handling compromises profiling.

## When to use

Use when two single-cell 3′ gene-expression datasets differ by a handling variable (freeze-thaw, library prep) and you must show equivalence of average expression and per-cell sensitivity (genes/UMIs) before downstream cell-type classification.

## When NOT to use

- The libraries differ in sequencing depth and you cannot downsample to equal mean reads per cell — depth confounds the correlation and per-cell counts
- Input is single-cell data from a non-droplet platform whose gene-barcode matrices were not generated by Cell Ranger-style 3′ counting, so sensitivity metrics are not comparable

## Inputs

- Gene-barcode matrices (fresh PBMC library, e.g. 68k PBMCs from the 10x datasets site)
- Gene-barcode matrices (cryopreserved Donor A PBMC library)
- Raw sequencing data (BAM/FASTQ from SRA SRP073767) for read downsampling
- hg19 human reference genome for Cell Ranger re-counting

## Outputs

- Pearson correlation coefficient of average gene expression between the two preparations
- Genes-per-cell and UMI-per-cell group statistics with two-sided t-test P-values
- downsampling_comparison.csv containing the correlation and comparison statistics

## How to apply

Obtain the gene-barcode matrices for both preparations (e.g. the 68k fresh PBMC and ~3k cryopreserved Donor A PBMC datasets from SRA SRP073767 or support.10xgenomics.com/single-cell/datasets), then randomly downsample reads with sambamba or 'samtools view -s' so both libraries share the same mean reads per cell. Re-run Cell Ranger counting (STAR alignment to hg19, barcode correction at posterior probability >= 0.975, 1-Hamming UMI correction, MAPQ=255 non-duplicate reads only) on the downsampled reads to regenerate matched matrices. Compute the Pearson correlation of average gene expression between preparations, log-transforming the gene-cell-barcode matrix as done for Seurat input in the paper. Finally, recompute genes and UMI counts per cell in each preparation and test differences with two-sided t-tests, writing the r value and P-values to a comparison table (downsampling_comparison.csv).

## Examples

```
samtools view -s 0.25 -b fresh_pbmc.bam > fresh_ds.bam; cellranger count --transcriptome=hg19 --sample=fresh_ds; cor(mean_fresh, mean_cryo, method="pearson")
```

## Evaluation signals

- Recomputed Pearson correlation of average gene expression reproduces the reported r=0.96 between fresh and cryopreserved Donor A PBMCs
- Two-sided t-test on genes per cell is not significant (reported P=0.8)
- Two-sided t-test on UMI counts per cell is not significant (reported P=0.1)
- Both downsampled libraries share the same mean reads per cell after 'samtools view -s' downsampling
- Cell Ranger re-count applies the paper's filters: posterior probability >= 0.975 barcode correction, 1-Hamming UMI correction, MAPQ=255 non-duplicate reads only

## Limitations

- Equivalence of aggregate metrics (r=0.96, non-significant t-tests) does not resolve low-confidence cell-type assignments, e.g. cytotoxic T vs NK cells where correlation differences were small
- Earlier libraries used 5 nt UMI and 5 bp Read2, introducing protocol heterogeneity that can bias cross-library comparisons
- Cell capture (~50%) and 15–20% error in cell counts add variability to per-preparation cell counts
