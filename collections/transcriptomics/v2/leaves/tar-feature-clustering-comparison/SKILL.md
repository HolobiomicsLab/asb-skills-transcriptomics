# tar-feature-clustering-comparison

## Summary

Quantifies whether reads outside gene annotations (uTARs) carry cell-type-specific structure by computing silhouette coefficients of aTAR-, uTAR-, and gene-expression-based clustering on 2D UMAP coordinates and comparing them per sample, reproducing Fig. 2b of the TAR-scRNA-seq paper.

## When to use

Use when you have 2D UMAP embeddings of single cells in gene, aTAR, and uTAR feature spaces plus cell-type labels, and need to test whether non-annotated transcribed regions separate cell types as well as annotated genes.

## When NOT to use

- Input is raw FASTQ or unaligned Cell Ranger output — run the TAR-scRNA-seq Snakemake workflows (from_fastqs / from_cellranger) and groHMM TAR calling first to obtain TAR expression matrices
- You need genome-wide TAR discovery or uTAR homology annotation rather than a quantitative comparison of clustering quality across feature spaces
- You lack cell-type labels — silhouette coefficients require a predefined partition; without Seurat cluster labels this comparison cannot be computed

## Inputs

- 2D UMAP coordinates per cell for gene, aTAR, and uTAR feature spaces across the 11 samples
- Cell-type labels from Seurat KNN graph clustering on the first 10 PCs of gene expression
- TAR single-cell expression matrices generated by the TAR-scRNA-seq Snakemake workflows (from_fastqs or from_cellranger)

## Outputs

- Table of silhouette coefficients with one row per sample and columns for gene (blue), aTAR (red), and uTAR (maroon) silhouette values
- Per-sample comparison of uTAR vs gene-based silhouette values reproducing Fig. 2b

## How to apply

Load the 2D UMAP coordinates for each of the 11 samples in all three feature spaces (gene, aTAR, uTAR), together with the cell-type labels obtained from Seurat KNN graph clustering on the first 10 principal components of the gene-expression data. For each sample and each feature type, run scikit-learn's silhouette_score with Euclidean distance on the 2D embedding, using the gene-based cluster labels as the ground-truth partition. Assemble a table with one row per sample and columns for silhouette values of gene expression (blue), aTARs (red), and uTARs (maroon), matching the layout of Fig. 2b. Judge success by whether uTAR silhouette values closely track gene-based values for the samples where the paper reports agreement (e.g., mouse spleen, lemur lung, naked mole rat spleen, sea urchin embryo), reflecting that uTAR reads accurately separate cell types. The degree of uTAR information content is organism-, tissue-, cell-type-, and developmental-stage-dependent, so disagreement for some samples is an expected outcome, not necessarily a failure.

## Related tools

- **groHMM** (Hidden-Markov-model TAR caller that divides the genome into transcribed/untranscribed states, producing the aTAR and uTAR features whose clustering quality is compared here) — https://bioconductor.org/packages/release/bioc/html/groHMM.html
- **Seurat** (Defines the reference cell-type labels via KNN graph clustering on the first 10 principal components of gene expression)
- **UMAP** (Provides the 2D embedding on which silhouette coefficients are computed with Euclidean distance for all three feature types)
- **TAR-scRNA-seq (Snakemake workflows)** (Generates the single-cell expression matrices for all transcriptionally active regions (aTARs and uTARs) used as alternative feature spaces) — https://github.com/fw262/TAR-scRNA-seq

## Examples

```
from sklearn.metrics import silhouette_score; s_ut = silhouette_score(umap2d_ut, gene_knn_labels, metric='euclidean')
```

## Evaluation signals

- Silhouette table contains values for all 11 samples across all three feature types (gene, aTAR, uTAR)
- For samples the paper reports agreement on (mouse spleen, lemur lung, naked mole rat spleen, sea urchin embryo), uTAR silhouette values closely track gene-based silhouette values
- aTAR silhouette values show close agreement with gene-expression silhouette values across samples
- Silhouette is computed with scikit-learn silhouette_score using Euclidean distance on the 2D UMAP embedding, not on high-dimensional PCA space
- Cluster labels are the gene-annotation-based Seurat KNN graph clusters (first 10 PCs), identical across the three feature-space comparisons

## Limitations

- The degree of relevant information in uTARs is strongly dependent on organism, tissue, cell type, and stage of development, so uTAR/gene agreement is not universal across all 11 samples
- Silhouette is computed on 2D UMAP coordinates, so it measures separation on the visualization embedding rather than in high-dimensional expression space
- groHMM must be correctly installed for TAR calling; a failed groHMM run yields empty chr*_HMM.bed files and downstream errors in rule calcHMMrefFlat
