# subsampled-pilot-dataset-replicate-aggregation

## Summary

Aggregates cluster-proportion fidelity metrics over repeated sub-samples of a pilot dataset: for each pilot size (384–2304 cells) and each generative model (scDBM, scVI prior, scVI posterior), the per-cluster absolute differences between synthetic and original cell counts are averaged over 30 repetitions to yield a single mean absolute difference, mirroring Table 1 of the paper.

## When to use

Use when you need to quantify convergence of synthetic-data cluster proportions toward ground truth as pilot size grows, and must collapse many stochastic sub-sampling repetitions into one stable summary value per model–dataset–size combination.

## When NOT to use

- You need absolute clustering-similarity metrics (ARI or Davies–Bouldin index) rather than per-cluster proportion differences
- The synthetic data are not mapped to original-data clusters via UMAP-space Euclidean distance, so there is no common cluster labeling between original and synthetic cells
- Only a single pilot sub-sample is available without repetition, since the skill's core is averaging over the 30 repetitions to damp stochastic variability

## Inputs

- Ground-truth Seurat cluster labels for the original dataset (PBMC4k or Segerstolpe), stored as cluster-label files (e.g. segerstolpe_hvg_clustering.csv)
- 30 random sub-samples (pilot datasets) of 384, 768, 1152, 1536, 1920, and 2304 cells each
- Synthetic datasets generated by scDBM, scVI (prior), and scVI (posterior) from each pilot sub-sample
- UMAP coordinates of the original data used for nearest-neighbor label mapping

## Outputs

- A Table-1-style matrix of mean absolute differences in cell counts per cluster, with one value per model (scDBM, scVI prior, scVI posterior), dataset (PBMC4k, Segerstolpe), and pilot size
- Per-cluster absolute count differences for each of the 30 repetitions (intermediate values before averaging)

## How to apply

Extract small pilot datasets from the original data by random sub-sampling where each cell is drawn with equal probability, at sizes 384, 768, 1152, 1536, 1920, and 2304 cells, repeating 30 times per size. Train the generative model (scDBM via Gibbs sampling, or scVI sampling from prior or posterior) on each sub-sample and generate synthetic data at the size of the original study (PBMC4k or Segerstolpe). Assign cluster labels to synthetic observations by mapping each synthetic cell to its nearest original observation based on Euclidean distance in UMAP space, with ground-truth labels from Seurat clustering on the original data. For each model, dataset, and pilot size, tally cells per cluster in original and synthetic data, compute absolute differences across all clusters, and average these over the 30 sub-sampling repetitions to obtain one mean absolute difference per combination. The rationale for averaging is that individual sub-samples are stochastic and scVI (posterior) in particular shows high variability, so only the repetition-averaged values reveal the trend of cluster proportions becoming more similar to ground truth with increasing pilot size.

## Evaluation signals

- Output table contains exactly one row per model-dataset-pilot-size combination (3 models × 2 datasets × 6 pilot sizes)
- All aggregated difference values are non-negative, since they are means of absolute differences
- Mean absolute differences decrease (or near-monotonically decrease) with increasing pilot size, consistent with the reported convergence of cluster proportions toward ground truth
- Averaged values stabilize across the 30 repetitions; residual high variance in the scVI (posterior) variant is expected and attributed to amplifying artifacts of small datasets
- Highly abundant cell types show overrepresentation and less abundant types underrepresentation in early/low pilot sizes, matching the paper's qualitative finding

## Limitations

- The mapping of synthetic cells to original-data clusters relies on the unverified assumption that synthetic cells mapped to the original data are mapped to the correct clusters
- All approaches overrepresent highly abundant cell types and miss less abundant cell types, so low-abundance cluster differences may be dominated by missed cell types
- For 10x datasets (higher sparsity, e.g. PBMC4k), inference from small to larger datasets is more challenging, so aggregation results for these datasets may converge more slowly
