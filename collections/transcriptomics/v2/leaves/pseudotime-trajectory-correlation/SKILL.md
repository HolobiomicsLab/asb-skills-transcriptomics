# pseudotime-trajectory-correlation

## Summary

Validates that a semi-profiled single-cell cohort (generated by scSemiProfiler) reproduces the pseudotime trajectories of the real-profiled cohort by running Monocle3 on shared UMAP coordinates and correlating grid-averaged pseudotime values. This is one of the downstream-fidelity checks from the COVID-19 cohort study.

## When to use

Use when comparing two single-cell cohorts (e.g., AI-generated/semi-profiled vs. real-profiled) to verify that developmental or disease-progression trajectories are preserved, via Monocle3 pseudotime computed on shared UMAP coordinates.

## When NOT to use

- Input is bulk RNA-seq or a precomputed cell-type-level deconvolution result — no single-cell resolution means pseudotime cannot be computed (bulk methods are limited to cell-type-level resolution)
- The two cohorts lack a shared UMAP embedding or comparable cell-type structure, so identical root placement is impossible
- You need cell-cell interaction strength comparison or gene-set enrichment fidelity — those are separate analyses (CellChat correlation, GSEApy RRHO), not pseudotime correlation

## Inputs

- Semi-profiled single-cell cohort (e.g., produced by scSemiProfiler's VAE-GAN in silico inference)
- Real-profiled (ground-truth) single-cell cohort of the same samples
- Shared UMAP coordinates computed consistently across both cohorts
- Cell-type annotations consistent between cohorts

## Outputs

- Pseudotime values per cell for both cohorts (Monocle3)
- 20-by-20 grid-averaged pseudotime matrix over the UMAP space for each cohort
- Pearson correlation coefficient between the two pseudotime grids (target ~0.809)
- Entry in downstream_fidelity.csv

## How to apply

Run pseudotime analysis with Monocle3 on both the semi-profiled and real-profiled cohorts, critically using the shared UMAP coordinates so both datasets share the same embedding. Place trajectory roots at identical UMAP positions in both datasets — this is the key decision point, since divergent root placement would invalidate the comparison. To reduce cell-level noise, average the pseudotime values over a 20-by-20 grid spanning the UMAP space, converting per-cell trajectories into a comparable spatial summary. Compute the Pearson correlation between the two pseudotime grids; the study reports a target agreement of 0.809 for the COVID-19 semi-profiled cohort. Record the resulting correlation, together with RRHO overlap summaries and enrichment/interaction statistics, in downstream_fidelity.csv.

## Related tools

- **scSemiProfiler** (Produces the semi-profiled single-cell cohort whose trajectory fidelity is being validated against the real-profiled cohort) — github.com/mcgilldinglab/scSemiProfiler

## Evaluation signals

- Pearson correlation between semi-profiled and real-profiled 20x20 grid-averaged pseudotime matrices falls near the reported value of 0.809
- Trajectory roots are placed at identical UMAP positions in both cohorts (documented reproducibility check)
- Both datasets share the same UMAP coordinates before Monocle3 is run — no independent re-embedding
- Results assembled in downstream_fidelity.csv fall within tolerance of the reported Fig. 3 agreement values (pseudotime 0.809 alongside enrichment overlap 95/100, p=9.10e-196 and cell-cell interaction correlation 0.996)
- UMAP visualization and cell type proportions of the semi-profiled cohort closely resemble the real-profiled ground truth before trajectory comparison

## Limitations

- Pseudotime correlation (0.809) is the weakest of the reported fidelity metrics compared to cell-cell interaction correlation (0.996) and the 95/100 GO signature-gene overlap, so grid-level agreement tolerances must account for residual trajectory divergence
- scSemiProfiler requires a single-cell reference to perform single-cell level deconvolution, so no reference or representative profile means no semi-profiled cohort to test
- No software versions stated for scSemiProfiler or dependencies; pseudotime values depend on root placement and UMAP coordinates, making the comparison sensitive to these choices
- Extension to modalities beyond scRNA-seq (e.g., proteomics) is only future work and would require algorithm adjustments
