# regulon-enrichment-visualization

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Visualize and cross-validate cell-type-specific regulons inferred from plant scRNA-seq data by inspecting MINI-EX pipeline results with scPlant functions (enrich_exp_hmp, topRegulons_MINIEX, BordaRank_MINIEX) and quantifying agreement with SCENIC via Jaccard similarity of top regulons per cell cluster.

## When to use

Use when MINI-EX or SCENIC regulons have been inferred on a plant single-cell atlas and you need to rank top regulons per cluster, render enrichment heatmaps, and quantify cross-tool regulon consistency.

## When NOT to use

- Input is raw count data that has not been pre-processed with the scPlant auxiliary script (MINIEX_preprocess.R) and no regulons have yet been inferred
- The organism is not covered by available cisTarget/TF-motif resources — MINI-EX targets scRNA-seq gene regulatory network inference in plants
- You need a single-tool regulon list without cross-tool validation or enrichment visualization (use topRegulons_MINIEX alone rather than the full comparison workflow)

## Inputs

- MINI-EX per-cluster regulons from the regulons_output directory
- SCENIC/pySCENIC regulons from a prior gene regulatory network task
- Pre-processed Seurat object with cluster (seurat_clusters) and celltype metadata
- MINI-EX input files generated by MINIEX_preprocess.R into INPUTS

## Outputs

- Top regulons per cell cluster ranked by Borda ranking (topRegulons_MINIEX, BordaRank_MINIEX)
- Regulon enrichment heatmaps (enrich_exp_hmp)
- regulon_jaccard_similarity.csv — Jaccard similarity of top 30 regulons per cell cluster vs SCENIC
- Signal-to-noise ratio comparison of MINI-EX vs SCENIC regulon enrichment (Figure 6E-6F, Supplemental Figure 3)

## How to apply

After running the MINI-EX Nextflow pipeline (nextflow -C miniex.config run miniex.nf) to obtain per-cluster regulons in the regulons_output directory, inspect results with scPlant visualization functions: use enrich_exp_hmp for regulon enrichment heatmaps, and topRegulons_MINIEX / BordaRank_MINIEX to extract the top regulons per cluster by Borda ranking. To validate cross-tool consistency, compute Jaccard similarity of the top 30 regulons per cell cluster against the regulons inferred by SCENIC (pySCENIC) and save the result as regulon_jaccard_similarity.csv. Verify known cross-tool anchors — bZIP44 among companion-cell regulons and ANAC030 among xylem regulons on the Arabidopsis root atlas — and compare the regulon enrichment signal-to-noise ratio between MINI-EX and SCENIC, reproducing Figure 6E-6F and Supplemental Figure 3. MINI-EX is expected to show a higher signal-to-noise ratio than SCENIC, which is the key differentiator between the two tools' regulon outputs.

## Related tools

- **MINI-EX** (Nextflow DSL2 pipeline that infers cell-type specific gene regulatory networks from plant scRNA-seq data; its regulons_output is the object visualized and compared) — https://github.com/VIB-PSB/MINI-EX

## Examples

```
Rscript MINIEX_preprocess.R --seuratObj SeuratObj.rds --cluster seurat_clusters --celltype celltype -o INPUTS && nextflow -C miniex.config run miniex.nf
```

## Evaluation signals

- bZIP44 is recovered among companion-cell regulons and ANAC030 among xylem regulons in both MINI-EX and SCENIC outputs on the Arabidopsis root atlas
- regulon_jaccard_similarity.csv shows non-trivial Jaccard overlap of top-30 regulons per cell cluster between MINI-EX and SCENIC
- MINI-EX regulon enrichment exhibits a higher signal-to-noise ratio than SCENIC, matching Figure 6E-6F and Supplemental Figure 3
- enrich_exp_hmp heatmaps render per-cluster regulon enrichment consistent with the Borda-ranked topRegulons_MINIEX output
- The regulons_output directory exists and contains per-cluster regulon files for every cluster in the Seurat object's seurat_clusters metadata

## Limitations

- Comparison anchors (bZIP44, ANAC030) are specific to the Arabidopsis thaliana root atlas (Zhang et al., 2019); other datasets require their own validated regulon anchors
- MINI-EX is dual-licensed (proprietary and open source models), which may constrain redistribution of derived pipelines
- The signal-to-noise advantage of MINI-EX over SCENIC is an empirical observation reported for this dataset, not a guaranteed property for every plant single-cell dataset
