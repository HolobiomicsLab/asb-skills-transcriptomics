# regulator-activity-score-matrix-analysis

## Summary

Analyze per-method regulator activity score matrices produced by decoupleR perturbation benchmarks (transcriptomics and phospho-proteomics) to quantify cross-method agreement and weighted vs. unweighted mode-of-regulation effects.

## When to use

Use when you have activity score matrices (regulators × methods) from decoupleRBench runs and need to reproduce manuscript-level agreement statistics such as median Spearman correlations, Jaccard overlap, or Wilcoxon weight tests.

## When NOT to use

- Input is raw count tables or metadata rather than already-inferred activity score matrices — build those first with decoupleRBench (run_rna_bench.R / run_php_bench.R).
- You need AUROC/AUPRC benchmark evaluation itself rather than post-hoc agreement or weights comparisons — use the decoupleRBench evaluation pipeline with its downsampling strategy instead.
- The goal is to evaluate a new method's predictive performance rather than characterize agreement among the 11 existing decoupleR methods.

## Inputs

- Per-method regulator activity score matrices from the transcriptomics benchmark (run_rna_bench.R)
- Per-method regulator activity score matrices from the phospho-proteomics benchmark (run_php_bench.R)
- Benchmark data retrieved from Zenodo record 5645208
- Paired weight/no-weight performance scores per method across dataset/regulator combinations

## Outputs

- method_agreement_metrics.csv with four statistics (median Spearman transcriptomics and phospho-proteomics; median Jaccard transcriptomics and phospho-proteomics)
- Fig. 1B-style cross-method agreement heatmap (optional)
- weights_comparison.tsv with paired per-method performance deltas
- wilcoxon_weights_test.json with test statistic and P-value

## How to apply

Load the per-method activity score matrices generated by run_rna_bench.R and run_php_bench.R, with the underlying data retrieved from Zenodo record 5645208. For each omics collection, compute all pairwise Spearman rank correlations of activity scores across the 11 methods and take the median across method pairs; separately, rank regulators per method, retain the top 5%, and compute pairwise Jaccard indexes on those top-5% regulator sets, taking the median. For the weights comparison, pair each weight-leveraging method's perturbed-regulator recovery score computed with weights against the same score computed without weights across all dataset/regulator combinations, compute per-method deltas, and run a one-sided Wilcoxon signed-rank test (stats::wilcox.test, alternative='greater'). The rationale is that decoupleR methods differ in activity distributions but should show structural agreement, and that methods leveraging the sign/weight of network interactions are expected to perform better when weights are used.

## Related tools

- **decoupleR** (Framework that generates the regulator activity scores and the unified method set being compared across the transcriptomics and phospho-proteomics benchmarks) — https://www.bioconductor.org/packages/release/bioc/html/decoupleR.html
- **decoupleRBench** (R package that produces the benchmark results (activity scores and recovery scores) that this analysis consumes) — https://github.com/saezlab/decoupleRBench
- **R** (Language used to run the benchmarks (run_rna_bench.R, run_php_bench.R), compute correlations/Jaccard indexes, and run the Wilcoxon signed-rank test)
- **Python** (Alternative decoupler implementation for inferring activity scores in the same unified framework) — https://github.com/saezlab/decoupler-py

## Examples

```
Rscript R/process/run_rna_bench.R && Rscript R/process/run_php_bench.R
```

## Evaluation signals

- Reproduced median Spearman correlation of activities between methods equals ~0.52 for transcriptomics and ~0.65 for phospho-proteomics
- Reproduced median Jaccard index on top-5% regulator sets equals ~0.23 (transcriptomics) and ~0.21 (phospho-proteomics)
- Reproduced one-sided Wilcoxon signed-rank P-value for the weights comparison is below 2.2e-16, confirming weight-leveraging methods perform better with weights (Supplementary Fig. S4)
- method_agreement_metrics.csv contains exactly the four expected statistics (2 Spearman medians + 2 Jaccard medians)
- wilcoxon_weights_test.json contains a non-null statistic and P-value with alternative='greater'

## Limitations

- Methods differ in activity distributions, so correlation-based agreement reflects rank structure rather than absolute score comparability.
- The noise and scalability analyses are computationally expensive (~6 hours for run_rna_noise.R, ~2 hours for run_php_noise.R).
- True positive classes in the benchmark are limited by regulators covered in perturbation experiments, requiring a downsampling strategy for AUROC/AUPRC.
