# umi-deduplication-benchmarking

## Summary

Benchmark UMI deduplication tools (UMI-tools, STARsolo, cellranger) for scRNA-seq against a known ground-truth gene-by-cell UMI count matrix generated by scReadSim from the mouse 10x single-cell Multiome dataset, evaluating both accuracy and computational efficiency.

## When to use

Use when synthetic scRNA-seq reads with known ground-truth UMI counts are available and you must rank UMI deduplication tools by accuracy and runtime, reproducing the scReadSim Nature Communications 2023 benchmark (Fig. 4a-d).

## When NOT to use

- Benchmarking isoform-level tools (isoform abundance or alternative splicing events) — scReadSim provides gene-level UMI ground truths only and is explicitly not recommended for this
- Using cellranger in default mode without include-introns=false, since scReadSim's default implementation may generate intronic synthetic reads that distort the comparison
- Real (non-simulated) scRNA-seq data where no ground-truth UMI count matrix exists, making accuracy validation impossible

## Inputs

- Synthetic paired-end scRNA-seq FASTQ reads generated by scReadSim (RNA-seq modality, mouse 10x single-cell Multiome data)
- Ground-truth gene-by-cell UMI count matrix from scReadSim
- Reference annotation (e.g. gencode.vM10.annotation.gtf) and mm10 reference genome
- Deduplicated count matrices output by UMI-tools, STARsolo, and cellranger

## Outputs

- Six summary statistics per tool vs ground truth (gene-wise mean, variance, coefficient of variance, zero proportion; cell-wise zero proportion and library size)
- Gene-wise and cell-wise Pearson correlation and Kendall's tau per tool
- Mean Euclidean UMAP distance per tool (PCA top 30 PCs, umap::predict projection)
- Runtime table across 5 cell numbers (1219-19508) and 5 sequencing depths (1.2M-20.1M reads)
- Ranked accuracy and efficiency verdict: UMI-tools top accuracy, STARsolo fastest

## How to apply

Generate synthetic paired-end FASTQ reads and the ground-truth gene-by-cell UMI count matrix by deploying scReadSim (default genome-based setting) on the RNA-seq modality of the mouse 10x single-cell Multiome dataset, training the count simulator scDesign2. Run UMI-tools, STARsolo, and cellranger (with include-introns set to false, since scReadSim's default may produce intronic synthetic reads) on the synthetic reads, then restrict comparisons to cells common to all tools and drop genes with zero expression in any matrix. Compute six summary statistics against ground truth — gene-wise mean, variance, coefficient of variance, and zero proportion plus cell-wise zero proportion and library size (Fig. 4b) — and gene-wise and cell-wise Pearson correlation and Kendall's tau (Fig. 4c). Log-transform matrices, run PCA (top 30 PCs) on the ground-truth matrix, project deduplicated cells via the predict() function of the R umap package, and compute mean Euclidean UMAP distance per tool (Fig. 4d). Measure runtime at cell counts 1219, 2438, 4877, 9754, 19508 and sequencing depths 1.2M, 2.5M, 5.0M, 10.1M, 20.1M reads (Fig. 4a).

## Evaluation signals

- Results table must show STARsolo has the smallest runtime across all cell-number and sequencing-depth scaling settings
- UMI-tools must achieve the top accuracy (highest gene-wise and cell-wise Pearson correlations / Kendall's tau, smallest mean Euclidean UMAP distances) among the benchmarked tools
- All three tools' deduplicated matrices must be restricted to the common set of cells output by all tools, and genes with zero expression in any matrix removed before comparison
- Summary-statistic plots must reproduce the six statistics of Fig. 4b (gene-wise mean, variance, CV, zero proportion; cell-wise zero proportion, library size)
- Cellranger must be run with include-introns=false to avoid penalizing it for scReadSim's intronic synthetic reads

## Limitations

- The default implementation of scReadSim may generate intronic synthetic reads when extracting sequences from the reference genome, which can affect benchmarks like cellranger default mode
- scReadSim generates gene-level ground truths (UMI counts) only, not isoform abundance or alternative splicing events, so it cannot benchmark isoform-aware deduplication
- Multi-sample or multi-condition benchmarking requires supplying one BAM file per sample or condition
