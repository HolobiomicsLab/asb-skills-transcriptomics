# knn-nearest-neighbor-distance-calculation

## Summary

Scores single-cell-level agreement between semi-profiled and real-profiled datasets by averaging each cell's Euclidean distance to its K=1 nearest neighbor in a 100-principal-component space (Scikit-learn PCA), then normalizing as EN = (mean_difference - LB) / (UB - LB) with a random-pairing upper bound (UB) and a random-half lower bound (LB).

## When to use

Use when quantifying how closely inferred (semi-profiled) single-cell data matches real-profiled ground truth across representative counts, e.g. benchmarking scSemiProfiler against a selection-only baseline that merely copies each representative's cells.

## When NOT to use

- Input is bulk-only with no single-cell reference: the per-cell K=1 distance is undefined, and the paper notes the tool's single-cell level deconvolution requires a single-cell reference
- You only have cell-type-level deconvolution output (CIBERSORTx, Bisque, DWLS, MuSiC, NNLS, EPIC, Scaden, TAPE) - the paper states conventional methods are constrained to cell type level resolution, so per-cell distance cannot be computed
- Datasets are not cohort-paired (no target-sample-to-representative correspondence), since the random-pairing UB and random-half LB normalization is defined over paired cohort samples

## Inputs

- Real-profiled single-cell dataset (COVID-19 cohort, 124 samples) preprocessed with library size normalization and log1p transformation
- Semi-profiled single-cell data generated by scSemiProfiler (scprocess + scinfer VAE-GAN inference) for non-representative samples
- Selection-only baseline single-cell data (each target sample assigned its representative's cells without generative-model transformation)
- Representative counts n ranging from 4 to 28

## Outputs

- Mean K=1 nearest-neighbor Euclidean distance per paired sample in 100-PC space
- Normalized error EN = (mean_difference - LB) / (UB - LB) per method and per representative count
- error_curves.csv containing normalized error values for scSemiProfiler and the selection-only baseline across n = 4-28

## How to apply

For each representative count n (4 to 28 on the COVID-19 cohort), take the real-profiled single-cell data and the inferred data (scSemiProfiler scinfer VAE-GAN output, or the selection-only copy of the representative's cells for the baseline) and reduce both to 100 principal components using Scikit-learn PCA. For each cell in the paired dataset, compute the Euclidean distance to its K=1 nearest neighbor and average over cells to obtain the single-cell difference metric. Compute UB as the average single-cell difference of randomly paired samples from the PCA-reduced real-profiled data, and LB as the difference between two random halves of the comprehensive PCA matrix. Normalize as EN = (mean_difference - LB) / (UB - LB) so that EN is bounded between LB and UB and cohort-comparable within a fixed 100-PC representation. Save EN for both methods across n = 4-28 into error_curves.csv; the decision point is that scSemiProfiler's EN at each n (especially at 28 representatives) should be substantially lower than the selection-only baseline's, and EN should decrease as n increases.

## Examples

```
from sklearn.decomposition import PCA; from sklearn.neighbors import NearestNeighbors; Xp = PCA(n_components=100).fit_transform(X); d = NearestNeighbors(n_neighbors=1).fit(Xp).kneighbors(Xp)[0].mean()
```

## Evaluation signals

- The semi-profiling normalized error at 28 representatives is below the selection-only normalized error at 28 representatives
- EN values fall within [0, 1] by construction: LB (random-half difference) <= mean_difference <= UB (random-pairing difference)
- Semi-profiling EN decreases monotonically (or near-monotonically) as representative count increases from 4 to 28
- error_curves.csv matches the Fig. 2h Source Data file of the paper
- All distances are computed in the same 100-PC space (Scikit-learn PCA) for real, inferred, and baseline data, with K=1 neighbors

## Limitations

- EN is normalized with cohort-specific bounds (UB from random pairing, LB from two random halves of the comprehensive PCA matrix), so values are not directly comparable across cohorts or across different PCA dimensionality choices
- The metric requires a single-cell reference; the paper notes future modalities (e.g., proteomics) would need algorithm adjustments and comprehensive benchmarking before this evaluation applies
- No software versions for scSemiProfiler or its dependencies are stated in the article, so exact numeric reproduction may vary across library versions
