# grna-variant-calling-structure-annotation

## Summary

Call intact and mutant gRNA sequences from a single-cell CRISPR screen gRNA library by comparing per-UMI consensus sequences against the plasmid oligo pool reference, annotating each mutation's position with GiRAFR's CIGAR-like encoding and the cassette structure GTF. This is the mutation-aware core of GiRAFR that enables downstream gRNA-to-cell assignment.

## When to use

Use when processing a gRNA library bam file from a single-cell CRISPR screen (e.g., CROP-seq or Perturb-seq) and you need to detect mutant gRNAs that the default Cell Ranger pipeline labels as intact, prior to assigning gRNAs to cells.

## When NOT to use

- You only need gRNA-to-cell assignment from an already mutation-annotated variant table — use assign_gRNA.assign_gRNA_to_cell directly instead
- You are detecting CRISPR-Cas9-induced DNA editing effects in transcriptome data — that is GiRAFR's separate editing_effect mode, not the gRNA library mutation profiling workflow
- The gRNA library was already validated as mutation-free and you accept the default Cell Ranger annotation, though note Cell Ranger labels single-mutation (1 Hamming distance) gRNAs as intact

## Inputs

- gRNA library alignment bam file, filtered as gRNA.sorted.mapped.removedSecondaryAlignment.onlyMappedToGrnaChrom.bam (secondary alignments removed, reads mapped only to gRNA cassette chromosomes)
- consensus.sequence.gRNA.txt and consensus.bam from consensus_sequence.generate_consensus_sequence_gRNA (one consensus per UMI-cell barcode combination)
- Reference gRNA cassette fasta (oligo_pool_plasmid.fa), which may contain only the intact gRNA sequences
- Cassette structure annotation (oligo_pool_plasmid_structure.gtf, generated by prepare.py from oligo_pool.csv with oligo_name and sequence columns)

## Outputs

- consensus.sequence.gRNA.variant.txt — variant calls with mutation positions annotated using the CIGAR-like encoding
- consensus.sequence.matrix — consensus gRNA sequence matrix per cell barcode
- Mutation details added by assign_gRNA.add_variant_type and profile_MT_pattern.py for downstream analysis

## How to apply

First run utils.gRNA_bam_filter with samtools to remove secondary alignments and keep only reads mapped to gRNA cassette chromosomes, producing gRNA.sorted.mapped.removedSecondaryAlignment.onlyMappedToGrnaChrom.bam. Then run consensus_sequence.generate_consensus_sequence_gRNA to build one consensus sequence per UMI-cell barcode combination (keeping the most read-supported sequence per UMI; filter UMIs below min_reads=1). Call mutations with variant.call_gRNA_variant against the reference fasta oligo_pool_plasmid.fa and the structural annotation oligo_pool_plasmid_structure.gtf (both generated by prepare.py from an oligo_pool.csv with oligo_name and sequence columns), writing consensus.sequence.gRNA.variant.txt. The structure GTF lets mutations be annotated with their CIGAR-like positional encoding relative to the gRNA cassette; assign_gRNA.add_variant_type and profile_MT_pattern.py then add mutation details for downstream analysis. Supplying only intact gRNA sequences is sufficient: in the predesigned Perturb-seq test, 25 intact sequences sufficed to recover all 103 predesigned mutant gRNAs.

## Examples

```
variant.call_gRNA_variant('consensus.sequence.gRNA.txt', 'oligo_pool_plasmid.fa', 'oligo_pool_plasmid_structure.gtf')
```

## Evaluation signals

- The filtered bam named gRNA.sorted.mapped.removedSecondaryAlignment.onlyMappedToGrnaChrom.bam is produced with no secondary alignments and reads restricted to gRNA cassette chromosomes
- consensus.sequence.gRNA.txt contains exactly one consensus sequence per UMI-cell barcode combination, keeping the most read-supported sequence per UMI and dropping UMIs with fewer than min_reads reads
- In the predesigned Perturb-seq benchmark, supplying only 25 intact gRNA sequences recovered all 103 predesigned mutant gRNAs and 98.1% concordant cell assignment among 14,113 originally annotated mutant-gRNA cells
- consensus.sequence.gRNA.variant.txt encodes each mutation position in the CIGAR-like format annotated via the oligo_pool_plasmid_structure.gtf cassette structure
- Following assignment (min_umi=3, auto=True two-component mixed Gaussian with pool=True), mutant gRNA molecules should appear in cells.gRNA.txt rather than inflating the count of untransformed cells

## Limitations

- The most commonly used default tool (Cell Ranger) fails to detect mutant gRNAs; gRNAs with a single mutation (1 Hamming distance) are labeled as intact despite being dysfunctional
- Specific defined read depths need to be attained for accurate gRNA assignment and mutation detection; low gRNA UMIs can impair cell assignment and ambient vs endogenous discrimination
- A fine-grained appraisal of which gRNA mutation types and locations are tolerable or damaging was not performed and is beyond the scope of the study
- Ad hoc customized pipelines and fixed thresholds across published studies render head-to-head comparisons unfeasible
