# drug-repurposing-pipeline-benchmarking

## Summary

Benchmark single-cell drug-repurposing pipelines (ASGARD vs Alakwaa's and Guo's CLUE-based baselines) by computing per-cluster ROC/AUC on scRNA-seq case-control datasets, with ground-truth positives taken from drugs in advanced clinical trials. ASGARD's multi-cluster drug score is expected to significantly outperform cluster-level baselines.

## When to use

Use when comparing drug-repurposing pipelines on scRNA-seq case-control data (e.g. GSE123926/GSE113197 breast epithelial, GSE132509 Pre-T ALL, GSE145926/GSE158055 COVID-19 BALF) to assess whether a multi-cluster drug score beats cluster-level signature ranking.

## When NOT to use

- The disease lacks obtainable normal-tissue controls or no tissue-specific drug reference exists among the 98 LINCS L1000 cell lines — the article flags this as a substitute/rework scenario, not a benchmark case
- You need to predict drug responses for bulk patient samples (drug-response prediction via TRANSACT) rather than benchmark repurposing ranking pipelines on scRNA-seq
- The task is generating drug combinations or applying the multi-cluster drug score to a single already-annotated dataset (use TopDrug/DrugCombination steps) rather than comparing pipelines

## Inputs

- scRNA-seq case-control expression matrices from GEO (GSE123926, GSE113197, GSE132509, GSE145926, GSE158055)
- Tissue-specific drug reference generated by PrepareReference from GSE70138/GSE92742 LINCS L1000 Level5 gctx files (e.g. DrugReference/breast_rankMatrix.txt)
- Positive-case drug list from Supplementary Data 4 (drugs in advanced clinical trials or animal models for the target disease)

## Outputs

- Per-cluster AUC values for each pipeline-dataset pair (pROC ROC objects)
- Dataset-level mean AUC with 95% ranges per pipeline (e.g. ASGARD 0.83 [0.80-0.86] vs Alakwaa 0.76 [0.68-0.83] vs Guo 0.54 [0.47-0.56] over 8 breast cancer clusters)
- Results table of averaged per-cluster AUCs and Student's t-test P-values (P<0.05 expected for ASGARD advantage)

## How to apply

Preprocess each scRNA-seq dataset in Seurat (normalize, drop cells with <200 unique genes — for COVID-19 BALF also >6000 genes or >10% mitochondrial — keep the 2000 genes with highest standardized variance, integrate samples with FindIntegrationAnchors at dims 1:15/anchor.features=2000, regress out cell-cycle scores, cluster with Louvain at resolution 0.4 plus UMAP), and annotate clusters with SingleR against HumanPrimaryCellAtlasData. For every cluster compute case-vs-control DE with Limma (lmFit/eBayes on model.matrix(~0+type)), Seurat FindMarkers Wilcoxon, DESeq2, and edgeR glmLRT, omitting cell types with <3 cells per group and genes in <3 cells (Limma/consensus is the reference DE method — Limma (Bayes) had the best average AUC). Run ASGARD per cluster via GetDrug on a tissue-specific reference built with GetDrugRef from the GSE70138/GSE92742 LINCS L1000 gctx files (repurposing.unit='drug', connectivity='negative'), then aggregate with DrugScore across clusters per patient; run Alakwaa's and Guo's CLUE/LINCS bulk-signature-ranking baselines on each cluster's DEG list. Compute ROC/AUC per cluster-pipeline pair with pROC, using drugs in advanced clinical trials/animal models (Supplementary Data 4) as positive cases, then average per-cluster AUCs within each dataset and test the pipeline differences with a Student's t-test.

```

```

## Evaluation signals

- Averaged per-cluster AUCs match reported values: ASGARD 0.83/0.81/0.82 (breast cancer/leukemia/COVID-19); Alakwaa's 0.76 [0.68-0.83] and Guo's 0.54 [0.47-0.56] over the 8 breast cancer clusters
- Student's t-test across per-cluster AUCs gives P<0.05 for ASGARD vs both baselines
- Cluster counts match annotations: 8 breast cancer epithelial clusters, 4 Pre-T ALL clusters, 4 COVID-19 cell types
- Drug reference reproduces from GSE70138/GSE92742 gctx inputs (breast_rankMatrix.txt) without errors on a RAM>64GB machine
- Positive-case set equals the Supplementary Data 4 drug list (advanced trials/animal models), not an ad-hoc curated set

## Limitations

- Drug reference covers only 98 LINCS L1000 cell lines; no cell-type-specific reference may exist for the target disease
- DE method choice materially changes downstream AUC (Limma/Bayes best) — benchmarks must fix and report the DE method per dataset
- Sparsity and heterogeneity of single-cell data can cause false DE discoveries, affecting all pipelines
- No ASGARD software version is stated; building the drug reference requires >64GB RAM and >1 hour
