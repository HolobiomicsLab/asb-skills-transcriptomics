# ground-truth-deg-label-derivation

## Summary

Derives binary differentially expressed gene (DEG) ground-truth label files from Splatter-simulated scRNA-seq datasets by flagging genes whose differential expression factor (DEFac) differs from 1, enabling quantitative accuracy benchmarking of DEG prediction methods such as singleCellHaystack against clustering-based approaches.

## When to use

Use when benchmarking DEG prediction accuracy on artificial Splatter datasets: simulated count matrices exist but lack reference labels, and each gene's simulated DEFac value is available to define the DEG ground truth.

## When NOT to use

- Working with real scRNA-seq datasets (e.g., MOCA, Tabula Muris thymus) where no simulated DEFac ground truth exists and labels cannot be derived
- Simulations not generated by Splatter or that lack per-gene differential expression factor annotations, since the DEFac != 1 criterion is undefined
- Evaluating methods that need continuous (non-binary) expression-level ground truth; the derived labels only encode detection-style differential expression status

## Inputs

- Splatter simulation objects or counts matrices from splatSimulate (group mode, 10 settings x 10 replicates x 2 path conditions = 200 datasets)
- Splatter per-gene simulation metadata containing differential expression factors (DEFac) for each simulated dataset

## Outputs

- 200 binary DEG ground-truth label files, one per simulated dataset, with 1 marking genes where DEFac != 1
- Consistently named file pairs (count matrix + label file) encoding cells/clusters/replicate/path settings

## How to apply

For each of the 200 Splatter-simulated datasets (10 settings from 1000 cells/2 clusters to 10,000 cells/25 clusters, 10 replicates each, generated with splatSimulate in group mode and once with random paths connecting clusters via path.from/method='paths'), extract the counts matrix and the simulation metadata containing per-gene differential expression factors. Derive binary labels by assigning 1 to any gene with DEFac different from 1 and 0 to genes with DEFac == 1; this is justified because Splatter's cluster-based generative model gives cluster-based DEG methods an expected advantage, making it a fair ground truth for evaluating clustering-independent methods like singleCellHaystack. Write the labels as one file per dataset with naming that encodes cells/clusters/replicate/path settings, paired to the corresponding count-matrix file. singleCellHaystack operates on binary detection data, so the derived ground truth aligns naturally with the method's required input format.

## Related tools

- **Splatter** (Generates the artificial scRNA-seq datasets via splatSimulate; its per-gene differential expression factors (DEFac) supply the DEG ground-truth criterion)
- **R** (Implementation environment for running Splatter simulations, extracting counts and DEFac metadata, and writing label files)
- **singleCellHaystack** (Downstream DEG prediction method whose accuracy (and that of cluster-based competitors) is scored against the derived binary ground-truth labels) — https://github.com/alexisvdb/singleCellHaystack

## Examples

```
library(splatter); params <- newSplatParams(seed=42); sim <- splatSimulate(params, groupCells=1000, nGroups=2, method='groups'); labels <- as.numeric rowData(sim)$DEFac != 1
```

## Evaluation signals

- Exactly 200 label files exist, one paired with each of the 200 count-matrix files, with names encoding the cells/clusters/replicate/path settings
- Each label file has as many entries as genes in the paired count matrix and contains only binary values
- All positive labels correspond exactly to genes with a differential expression factor (DEFac) different from 1; spot-check several datasets against Splatter's returned gene metadata
- Label dimensions match the requested simulation setting (cells and genes) for each entry in the 10-setting parameter grid
- Both path conditions (default group structure and random paths via path.from/method='paths') are represented with 100 label files each

## Limitations

- The ground truth is only meaningful because Splatter's model generates clusters of cells, which favors cluster-based methods; results against this benchmark reflect that bias
- The labels are binary (DEFac != 1) and do not capture expression magnitude differences, consistent with singleCellHaystack's requirement of binary detection data and its acknowledged weak point of using a hard detection threshold
- Simulated dropout is not addressed: zero counts in single-cell data may reflect dropout events, which the underlying article notes would need imputation but this workflow does not apply
