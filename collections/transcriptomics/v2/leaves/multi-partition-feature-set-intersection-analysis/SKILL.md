# multi-partition-feature-set-intersection-analysis

## Summary

Recovers the discriminative position-specific gapped k-mer patterns for RNA 5hmC prediction by intersecting the mode-wise RF-selected feature sets (top 400 per selector) from all 25 training partitions of the 5-times 5-fold cross-validation, yielding 34 features consistently selected in every partition.

## When to use

Use when a repeated cross-validation feature-selection experiment (e.g., 5-times 5-fold, 25 partitions) must be reduced to the features selected in every partition, to expose partition-invariant discriminative sequence patterns.

## When NOT to use

- When the goal is to rank or score features by importance rather than find features consistently selected across all partitions (use the selector's feature_importances_ directly instead)
- When input is already a reduced, curated feature table and no cross-validation feature-selection runs exist to intersect
- When combining position-specific features with frequency-based features in single models — the authors found these do not work well together and deferred that to a future feature-subspace ensemble approach

## Inputs

- Dataset.csv (41-nt RNA benchmark sequences with 5hmC labels)
- All_Features_Dataset.csv (position-specific gapped k-mer features generated by Feature Generation.ipynb)
- 25 training partitions from 5-times 5-fold cross-validation

## Outputs

- selected_features.csv — table of the 34 partition-invariant features annotated with k-mer pattern and sequence position, plus descriptor-mode membership tally (27/34 from gapped modes B/C/D)

## How to apply

First generate the position-specific gapped k-mer features by executing 'Feature Generation.ipynb' on Dataset.csv (via Jupyter/Anaconda) to produce All_Features_Dataset.csv. For each of the 25 training partitions from the 5-times 5-fold cross-validation, train 4 mode-wise RandomForestClassifier selectors (scikit-learn) and retain the top 400 features per selector. Intersect the 25 sets of 400 selected features with numpy/pandas set operations and verify exactly 34 features survive in every set. Annotate each surviving feature with its k-mer pattern and sequence position relative to the 41-nt sequence (e.g., A-A-A at positions 22-26, G-G-G at positions 36-40), then tally descriptor-mode membership to confirm 27 of the 34 features originate from the proposed gapped modes B/C/D, and save the result as selected_features.csv.

## Evaluation signals

- The intersection across all 25 partition-wise selection sets must contain exactly 34 features
- The descriptor-mode tally must show 27 of the 34 surviving features drawn from the gapped modes B/C/D
- Each of the 25 per-selector feature sets must contain exactly 400 features before intersection
- Each surviving feature must resolve to a k-mer pattern plus position within the 41-nt sequence (e.g., A-A-A at positions 22-26, G-G-G at positions 36-40)
- All_Features_Dataset.csv must exist after running Feature Generation.ipynb before selection begins

## Limitations

- The 34-feature intersection is tied to this 41-nt RNA 5hmC benchmark and the specific top-400 cut-off per mode-wise selector; other thresholds or datasets are not validated
- The proposed position-specific features do not work well in conjunction with existing frequency-based counterparts; the authors deferred combining them to future work using a feature subspace ensemble approach
- Efficacy of the framework on other RNA modification site identification problems has not been evaluated
