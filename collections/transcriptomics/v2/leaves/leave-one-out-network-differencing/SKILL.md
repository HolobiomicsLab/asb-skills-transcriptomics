# leave-one-out-network-differencing

## Summary

A cell-specific network inference (CSNI) strategy that predicts a per-cell gene regulatory network by subtracting the leave-one-out (aggregate-of-all-other-cells) network from the whole-dataset network, as implemented by LIONESS and SSN. Applied on dyngen's 42 simulated single-cell datasets to quantitatively benchmark against cell-specific ground-truth GRNs.

## When to use

Use when benchmarking cell-specific network inference methods (e.g. LIONESS, SSN) against known per-cell ground-truth regulatory networks generated by dyngen, using AUROC/AUPR.

## When NOT to use

- When no per-cell ground-truth regulatory network is available for quantitative AUROC/AUPR evaluation, since quantitative assessment of CSNI performance was previously lacking for exactly this reason
- When the goal is aggregate (pooled) network inference rather than cell-specific network inference across individual cells
- When sensitivity to noise is critical — leave-one-out correlation differencing yields correlation differences that are mostly noise (SSN performed worse than LIONESS and pySCENIC)

## Inputs

- 42 dyngen-simulated single-cell datasets (14 backbones x 3 seeds) with per-cell expression matrices
- Per-cell cell-specific ground-truth regulatory networks from dyngen
- Normalized expression data as provided by dyngen, with no extra cell or feature filtering

## Outputs

- Per-cell predicted regulatory networks (top 10,000 interactions per cell with scores)
- Per-cell AUROC and AUPR scores against the ground-truth cell-specific GRN
- Per-dataset table of mean AUROC and mean AUPR for the differencing-method condition

## How to apply

Generate or load the 42 dyngen benchmark datasets, each built from one of 14 predefined backbones across three seeds, containing per-cell transcriptomics profiles and cell-specific ground-truth regulatory networks. For each dataset, compute a whole-dataset network and, for every cell, a leave-one-out network over all other cells; obtain the cell-specific network by subtracting the leave-one-out network from the aggregate, restricting the base inference method to Pearson correlation (as in the SSN implementation in R with tidyverse). Retain the top 10,000 predicted interactions per cell by score, then compare each cell's predicted network against its ground-truth cell-specific GRN to compute AUROC and AUPR. Average per-cell AUROC and AUPR within each dataset to get mean AUROC and mean AUPR, mirroring the dyngen CSNI evaluation. Be aware that in the published benchmark this differencing approach (SSN) performed poorly — correlation differences mostly reflect noise, worse than LIONESS and pySCENIC — so use it primarily as a benchmarked baseline.

## Related tools

- **dyngen** (Generates the 42 benchmark datasets with per-cell transcriptomics and cell-specific ground-truth GRNs used to evaluate the differencing approach) — https://github.com/dynverse/dyngen
- **R + tidyverse** (Implementation language for the leave-one-out Pearson-correlation differencing (SSN) following the same leave-one-out approach as LIONESS)
- **LIONESS** (Reference leave-one-out network differencing method whose approach the SSN implementation follows, using Pearson correlation as the base network inference method)

## Examples

```
Rscript analysis/usecase_network_inference/run_ssn.R  # computes leave-one-out Pearson-difference networks, top 10000 edges/cell, and mean AUROC/AUPR per dyngen dataset
```

## Evaluation signals

- Each of the 42 datasets yields a mean AUROC and mean AUPR value within [0, 1] computed over the top 10,000 interactions per cell
- The resulting scores table contains an entry for every dataset in the SSN condition (42 entries total)
- Per-cell predictions are capped at exactly the top 10,000 interactions by score before metric computation
- Mean AUROC and mean AUPR are computed by averaging per-cell AUROC/AUPR within each dataset, as in the dyngen CSNI workflow
- Relative ranking expectation: the differencing variant (SSN) should score worse than LIONESS and pySCENIC on this benchmark if implemented faithfully

## Limitations

- SSN's subtract-one-cell approach yields correlation differences that are mostly noise, performing worse than LIONESS and pySCENIC on the dyngen CSNI benchmark
- dyngen assumes cells are well-mixed and independent from each other, so cell-specific networks reflect this simplification
- No software version numbers are reported for the tools in the benchmark, hindering exact reproduction
- Evaluation is limited to simulated ground truth; results may not transfer to real datasets
