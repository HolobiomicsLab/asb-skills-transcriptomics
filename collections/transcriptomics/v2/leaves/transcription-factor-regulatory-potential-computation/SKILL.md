# transcription-factor-regulatory-potential-computation

## Summary

Computes a cell-specific transcription factor regulatory potential (TFRP) index from paired scRNA-seq and scATAC-seq data by combining TF activity, a peak-gene coupling prior, and chromatin accessibility, then fits a simple linear regression of TFRP on target gene expression per TF-TG pair and uses a likelihood-ratio statistic to test whether the P(TFRP|TG) regression model is the same across two linked subpopulations.

## When to use

Use when you have four single-cell datasets (one scRNA-seq + one scATAC-seq from each of two populations) with consistent cluster assignments, and you need to detect subpopulation-specific differential TF-target regulation.

## When NOT to use

- You have only one condition (no two linked subpopulations to compare) — the likelihood-ratio test requires a comparison across two conditions
- You need to incorporate bulk HiChIP data — the article states sc-compReg does not yet support this and the extension is planned
- You have multiple donors per condition — the discussion notes the method does not yet accommodate multiple donors under each condition

## Inputs

- sample1.rds and sample2.rds containing log2-transformed gene expression matrices (symbol1, symbol2), log2-transformed chromatin accessibility matrices (O1/E1, O2/E2), cluster indices (O1.idx, E1.idx, O2.idx, E2.idx), and peak names (peak.name1, peak.name2)
- PeakName_intersect.txt (peak.name.intersect.dir) generated by sc_compreg_process_data_.sh
- peak_gene_prior_intersect.bed (peak.gene.prior.dir) generated by sc_compreg_process_data_.sh
- Species motif prior: motif_human.rds or motif_mouse.rds (providing motif.name, motif.weight, match2)
- motif_file.rds loaded via mfbs_load(motif.target.dir)

## Outputs

- tf_<i>.txt — hub TF table per subpopulation i (tab-delimited, no row names, no quotes)
- diff_net_<i>.txt — differential TF-target regulatory edges with differential-regulation scores per subpopulation i
- compreg.output$n.pops — number of subpopulations compared

## How to apply

Load the scCompReg R package (R >= 3.6.0) and read the paired samples (sample1.rds, sample2.rds), the species motif prior (motif_human.rds or motif_mouse.rds), and motif_file.rds loaded via mfbs_load. Supply log2-transformed gene expression matrices (symbol1/symbol2) and log2-transformed chromatin accessibility matrices (O1/E1, O2/E2), cluster indices (O1.idx, E1.idx, O2.idx, E2.idx) from cnmf or another consistent clustering, and paths to the pre-generated PeakName_intersect.txt and peak_gene_prior_intersect.bed files produced by sc_compreg_process_data_.sh. Call sc_compreg with motif$motif.name, motif$motif.weight, motif$match2, motif.file, and sep.char=' '; inside sc_compreg, TFRP scores per TF, target gene, and subpopulation are computed by combining TF activity with the peak-gene coupling matrix and chromatin accessibility evidence, then a simple linear regression of TFRP on TG is fit per condition and a likelihood-ratio statistic tests the null hypothesis that the regression model is the same across the two conditions. Write compreg.output$hub.tf[[i]] to tf_<i>.txt and compreg.output$diff.net[[i]] to diff_net_<i>.txt for each subpopulation i in 1:compreg.output$n.pops using write.table with row.names=FALSE, quote=FALSE, sep='\t'.

## Examples

```
compreg.output = sc_compreg(sample1$O1, sample1$E1, sample1$O1.idx, sample1$E1.idx, sample1$symbol1, sample1$peak.name1, sample2$O2, sample2$E2, sample2$O2.idx, sample2$E2.idx, sample2$symbol2, sample2$peak.name2, motif$motif.name, motif$motif.weight, motif$match2, motif.file, peak.name.intersect.dir, peak.gene.prior.dir, sep.char=' ')
```

## Evaluation signals

- One tf_<i>.txt and one diff_net_<i>.txt file exist for every subpopulation i = 1..compreg.output$n.pops
- Each output file is a readable tab-delimited table written with row.names=FALSE, quote=FALSE, sep='\t'
- diff_net tables contain TF-target regulatory edges with their differential-regulation scores
- Input expression and accessibility matrices are log2-transformed, as sc_compreg requires
- PeakName_intersect.txt and peak_gene_prior_intersect.bed were generated by sc_compreg_process_data_.sh for the correct genome_version (one of hg19, hg38, mm9, mm10)

## Limitations

- Differential regulations discovered need to be replicated by additional patients and controls
- The approach does not yet accommodate multiple donors under each of the two conditions; extension pending data availability
- sc-compReg does not yet support analysis incorporating bulk HiChIP data; extension planned
- Requires R >= 3.6.0, Bedtools (Linux), and Homer (Linux)
