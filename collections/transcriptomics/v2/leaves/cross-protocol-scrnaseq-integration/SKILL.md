# cross-protocol-scrnaseq-integration

## Summary

Removes batch effects from multi-protocol scRNA-seq data (e.g. human pancreas profiled by CEL-seq, CEL-seq2, Fluidigm C1 and Smart-seq2) by running scMGCA's graph-embedding autoencoder to produce batch-merged cell clusters, benchmarked against DESC and related integration methods.

## When to use

Use when clustering scRNA-seq data generated by multiple scRNA-seq protocols where batch effects confound cell-type separation, and you need batch-corrected embeddings plus cluster assignments evaluated with silhouette metrics.

## When NOT to use

- Single-protocol scRNA-seq data with no batch structure — the clustering-only scMGCA workflow suffices and no batch-merging evaluation is meaningful
- Bulk RNA-seq or non-single-cell expression matrices — the cell graph / PPMI construction and dropout modeling are specific to scRNA-seq sparsity
- Datasets where batch labels and cell-type identity are confounded (e.g. each protocol captured a different tissue), where ASW-based batch mixing cannot be interpreted

## Inputs

- Combined human pancreas multi-protocol scRNA-seq count matrix (CEL-seq, CEL-seq2, Fluidigm C1, Smart-seq2) as an AnnData object
- Cell-level protocol/batch annotations
- Reference cell-type labels for cluster-separation checks

## Outputs

- scMGCA latent embeddings with batch-merged cells
- Cell-type cluster assignment labels per cell
- batch_correction_results.csv with silhouette-based batch-mixing metrics (e.g. ASW) and baseline comparisons

## How to apply

Load the combined multi-protocol expression matrix as an AnnData object, then with scanpy normalize the gene expression matrix and select highly variable genes. Build the cell graph by applying the random surfing algorithm on the KNN graph to compute the cell-PPMI matrix, then train the two-layer graph convolution autoencoder with the multinomial-based decoder on the batched data (divide datasets with >25,000 cells into multiple batches for learning). Perform self-optimized clustering via KL divergence on the latent representations, initializing cluster centers with the best strategy from K-means and spectral clustering, to obtain batch-merged cell-type assignments. Evaluate batch mixing with silhouette-based metrics (ASW) on the scMGCA embeddings and compare against a DESC baseline integration embedding; accept the result when the batch-mixing score matches or exceeds baseline methods (DESC, Harmony, MNN, scVI, Scanorama) while cell-type separation is retained. Write cluster labels and comparison metrics to batch_correction_results.csv.

## Related tools

- **scMGCA** (Primary graph-embedding autoencoder that builds the cell-PPMI graph and produces batch-corrected embeddings and cluster assignments; installed from PyPi with Python 3.6.8 conda environment and dependencies from requirements.txt (numpy, scipy, tensorflow, scikit-learn, pandas, scanpy, anndata)) — https://pypi.org/project/scMGCA
- **SCANPY** (Preprocessing: normalize the gene expression matrix and select highly variable genes on the AnnData pancreas object)
- **DESC** (Baseline deep-embedding integration method whose embedding is compared against scMGCA's batch-mixing score (ASW)) — https://github.com/eleozzr/desc

## Examples

```
import scanpy as sc; adata = sc.read_h5ad('pancreas_multiprotocol.h5ad'); sc.pp.normalize_total(adata); sc.pp.highly_variable_genes(adata); sc.pp.pca(adata)
```

## Evaluation signals

- scMGCA's ASW batch-mixing score on the multi-protocol pancreas data matches or exceeds baselines (DESC, Harmony, MNN, scVI, Scanorama) reported in the paper's Source Data
- Cell-type separation (silhouette on the corrected embeddings) is retained after batch merging
- UMAP of the merged embeddings shows cells from CEL-seq, CEL-seq2, Fluidigm C1 and Smart-seq2 intermixed within cell types
- Cluster assignments from KL-divergence self-optimization are stable across K-means vs. spectral-clustering initialization
- batch_correction_results.csv is produced with cluster labels and comparison metrics and has no missing per-batch scores

## Limitations

- Datasets with >25,000 cells must be split into multiple batches for learning, which can affect the learned graph representation
- Key hyperparameters are unspecified in the article: KNN neighbor count k for the cell graph, random-surfing restart parameter α, loss weights γ1/γ2/γ3, number of highly variable genes d, and the maximum iteration count for stopping
- Reproduction relies on the paper's Source Data file rather than explicit dataset accessions; sample data were only described as coming from public repositories
- Environment constraints from the workflow: conda Python 3.6.8 with dependencies pinned in requirements.txt (TensorFlow-based); no software version numbers are reported in the article itself
