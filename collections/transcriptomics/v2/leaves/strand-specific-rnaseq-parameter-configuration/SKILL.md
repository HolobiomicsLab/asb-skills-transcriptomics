# Strand-specific RNA-seq parameter configuration for genome-guided assembly

## Summary

Configure Tiglon's library-orientation and quality-filter parameters (-s strand flag plus default min_trans_length 500, min_average_frac 0.03, min_unbalance_frac 0.03, min_gap_length 200, min_trans_cov >0) so that BAM alignments from Hisat2/Star are assembled into GTF transcripts consistent with the sequencing library's strandedness.

## When to use

Use when running Tiglon (or evaluating its assembly) on Hisat2- or STAR-aligned BAM files and you must set the -s orientation flag to match the library type (paired-end first/second/unstranded or single-end single_forward/single_reverse/single_unstranded).

## When NOT to use

- Input alignments come from aligners other than Hisat(2)/STAR — the current Tiglon version only accepts BAM files generated by Hisat(2) and Star
- The RNA-seq data are long reads (PacBio or Oxford Nanopore) — the current version is not compatible with long-read RNA-seq datasets
- You need annotation-guided assembly using known transcript annotations — the current Tiglon version has no option for annotation-guided assemblies

## Inputs

- bamFiles_list text file listing Hisat2- and/or STAR-generated BAM alignment files, one per line
- Coordinate-sorted BAM alignments produced by Hisat2 or STAR
- Library-orientation metadata for the RNA-seq sample (paired-end vs single-end; forward/first, reverse/second, or unstranded)

## Outputs

- Tiglon.gtf assembly of candidate transcripts in Tiglon_outdir
- Assembled transcripts with expression levels gated by min_trans_cov and length gated by min_trans_length (default 500)

## How to apply

Build a bamFiles_list text file with one alignment BAM per line (Tiglon v1.1 accepts only BAMs generated by Hisat(2) and STAR), then invoke Tiglon with -B bamFiles_list and select -s to match the library orientation: <first>/<second>/<unstranded> for paired-end libraries and <single_forward>/<single_reverse>/<single_unstranded> for single-end libraries, keeping other parameters at defaults unless justified (min_trans_length 500, min_average_frac 0.03, min_unbalance_frac 0.03, min_gap_length 200, min_trans_cov >0). The rationale is that the labeled splice graph and paired-path extraction assume junctions are read with correct strand orientation, so a wrong -s value invalidates transcript reconstruction. Output is written with -o to Tiglon_outdir, whose Tiglon.gtf holds the assembled candidate transcripts, and -p 2 controls parallelism. Tiglon then builds the labeled splice graph (edges labeled 2 if captured by all employed aligners, 1 otherwise) and runs the label-based dynamic path extension to recover transcripts.

## Examples

```
Tiglon -B bamFiles_list -s first -o Tiglon_outdir -p 2
```

## Evaluation signals

- The -s value matches the sequencing library's orientation (first/second/unstranded for paired-end; single_forward/single_reverse/single_unstranded for single-end) — a mismatch would yield absent or reversed-strand transcripts in Tiglon.gtf
- Non-default filters are only changed deliberately: min_trans_length 500, min_average_frac 0.03, min_unbalance_frac 0.03, min_gap_length 200, min_trans_cov >0
- Output GTF exists at tiglon_outdir/Tiglon.gtf and contains assembled candidate transcripts for the sample
- Assemblies scored against NCBI RefSeq show correct-transcript counts and precision consistent with expected Tiglon behavior (e.g. human merged-alignment assemblies recover ~16.11%/13.98% more correct transcripts than Hisat2-only/Star-only runs)

## Limitations

- Tiglon currently accepts BAM files only from Hisat(2) and Star; other aligners' BAMs cannot be used
- Tiglon lacks an annotation-guided assembly option and is not compatible with long-read RNA-seq datasets (PacBio, ONT)
- No assembly option here produces quantitation in the Tiglon run itself — abundance estimates are internal to the min_trans_cov filter
