# differential-state-ground-truth-design

## Summary

Designs ground-truth benchmark data for differential state (DS) analysis by generating simulated multi-sample, multi-subpopulation scRNA-seq counts with muscat's simulation framework, which is anchored to a reference dataset (e.g., example_sce) and into which DE/DP/DM/DB-type differential state is injected with known gene sets and logFC magnitudes.

## When to use

Use when benchmarking DS analysis methods on multi-sample, multi-group scRNA-seq data and reproducible ground truth (which genes are DS, at what logFC) must be generated by simulation anchored to a real reference.

## When NOT to use

- The goal is to detect DS in real (non-simulated) data rather than to benchmark methods against known truth — use pbDS/mmDS instead
- The input SingleCellExperiment lacks sample_id/group_id/cluster_id structure, so sample-level multi-group simulation anchoring cannot be defined
- The benchmark requires an arbitrary number of groups or hierarchical-type genes, which the paper's simulation framework does not yet accommodate

## Inputs

- Reference SingleCellExperiment object (e.g., muscat's example_sce) with sample_id, group_id, and cluster_id metadata columns
- Simulation scenario parameters: samples per group, number of subpopulations, DS gene fraction, logFC magnitude
- Kang PBMC control samples or other openly available anchor datasets (via Bioconductor ExperimentHub)

## Outputs

- simulated_counts.rds containing the simulated multi-sample, multi-subpopulation count matrix
- Ground-truth annotation of DS genes, DS type (DE/DP/DM/DB), and induced logFC magnitudes

## How to apply

Load a reference SingleCellExperiment (e.g., data("example_sce") shipped with muscat) and estimate subpopulation- and sample-specific negative binomial means, per-gene dispersions, and sample-specific library sizes to anchor the simulation. Configure the scenario: number of samples per group, number of cell subpopulations, the fraction of genes designated as differential-state, and the logFC magnitude of the induced state changes. Run muscat's simData to generate simulated multi-sample, multi-subpopulation counts with the embedded DS genes, following the Korthauer-style differential distribution approach (DE, DP, DM, or DB changes). Save both the simulated count matrix and the ground-truth annotation of DS genes/parameters (e.g., simulated_counts.rds) so that downstream DS methods can be scored against known truth. The rationale is that a simulation anchored to a reference dataset mimics real scRNA-seq characteristics, making method-performance evaluation more faithful than fully synthetic data.

## Related tools

- **muscat** (Provides simData and the anchored NB-based simulation framework used to generate synthetic multi-sample scRNA-seq counts with embedded DS ground truth) — github.com/HelenaLC/muscat
- **R** (Implementation environment for the muscat simulation workflow and saving of .rds ground-truth outputs)
- **Snakemake** (Orchestrates simulation replicates across scenarios when benchmarking DS methods)

## Examples

```
data(example_sce); sim <- muscat::simData(example_sce, ns = 3, nk = 5, fc = 2, p_ds = 0.1)
```

## Evaluation signals

- Simulated data recapitulates the reference dataset's library-size and dispersion structure
- The fraction of simulated DS genes matches the configured gene fraction
- Induced logFC magnitudes in the simulated DS genes match the specified scenario values
- Ground-truth annotation (which genes are DS and their type: DE/DP/DM/DB) is consistent with the simulated count matrix
- Simulated object retains valid sample_id/group_id/cluster_id structure compatible with downstream pbDS/mmDS benchmarking

## Limitations

- The simulation framework does not yet accommodate an arbitrary number of groups or hierarchical-type genes
- Other simulation scenarios of interest (e.g., different percentages of DM mixtures) were not tested
- LogFC estimates can be attenuated depending on the scale of the data analyzed, affecting simulation-to-benchmark fidelity
