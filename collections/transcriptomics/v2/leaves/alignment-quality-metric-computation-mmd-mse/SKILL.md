# alignment-quality-metric-computation-mmd-mse

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Quantify cross-modal alignment quality by computing maximum mean discrepancy (MMD) for distribution matching and per-sample mean-squared error (MSE) for point-wise correspondence, as done in the scMMGAN TNBC xenograft evaluation across four scRNA-seq samples (primary tumor, lung, liver, lymph node).

## When to use

Use when two domain mappings (e.g. scRNA-seq to spatial transcriptomics) have been generated by GAN-based aligners and you must judge whether target distributions match (MMD) and whether point-wise correspondence with inputs is preserved (MSE).

## When NOT to use

- When the two domains share overlapping measurements that can be directly regressed with a supervised model — the adversarial mapping setting is assumed
- When only distribution-level comparison is needed and point-wise correspondence is not a requirement; MSE against original inputs is meaningless if inputs lack a known alignment
- When data has not been preprocessed (MAGIC dropout correction, zero-centering/unit scaling, 50-PC reduction) so MSE comparisons against baselines are not comparable

## Inputs

- Cross-domain mapped point sets (output_fake, output_fake2) from scMMGAN, CycleGAN, and CMAE models in original (unscaled) data space
- Preprocessed source and target datasets (MAGIC-smoothed, zero-centered, unit-scaled, reduced to 50 principal components)
- Per-sample groupings across four scRNA-seq samples: primary tumor, lung, liver, lymph node

## Outputs

- Per-model, per-sample MMD values quantifying target-distribution matching
- Per-model, per-sample MSE values quantifying point-wise correspondence
- Summary metrics table (e.g. table3_alignment_metrics.csv)

## How to apply

After training each alignment model (scMMGAN, CycleGAN, CMAE), generate the cross-domain mappings via the TensorFlow graph outputs `output_fake` and `output_fake2`, then invert any preprocessing scaling so values return to the original data space. For each model and each of the four scRNA-seq samples, compute MMD to assess whether the mapped points match the target domain distribution, and compute per-sample MSE against the expected correspondence to assess how minimally the mapping alters individual points. Interpret the two metrics together: distribution matching alone (low MMD) is insufficient because GANs suffer from mode collapse and instability, whereas low MSE alongside low MMD indicates the geometry-preserving correspondence loss retained point-wise structure. Write per-model, per-sample MMD and MSE values to a metrics table (e.g. table3_alignment_metrics.csv) and validate against expected ranges: scMMGAN per-sample MSE approximately 0.87-1.03, CycleGAN/CMAE approximately 1.6-2.1.

## Examples

```
output_fake, output_fake2 = sess.run([G_x2_to_x1, G_x1_to_x2]); compute MMD and per-sample MSE per model and write table3_alignment_metrics.csv
```

## Evaluation signals

- scMMGAN per-sample MSE falls in the approximately 0.87-1.03 range across the four samples (primary tumor, lung, liver, lymph node)
- CycleGAN and CMAE baseline per-sample MSE falls in the approximately 1.6-2.1 range, confirming the geometry-preserving loss improves alignment
- All three methods show reasonably low MMD, demonstrating that MMD alone cannot distinguish point-wise correspondence quality
- Output data has been returned to original scale by inverting the preprocessing (each input column mostly in [-10, 10] during training)
- Metrics table contains one MMD and one MSE value per model per sample, covering scMMGAN, CycleGAN, and CMAE

## Limitations

- GAN training instability means the model can deteriorate from effective to ineffective quickly across training iterations; metrics should be checked at early-stopped checkpoints
- GANs often suffer from mode collapse because they are not penalized by distribution-level losses, which MMD alone may not fully expose
- The geometry-based loss is not completely plug-and-play: it requires a choice of distance between data points
- Aligned results require continued evaluation through external verification measures beyond MMD/MSE
