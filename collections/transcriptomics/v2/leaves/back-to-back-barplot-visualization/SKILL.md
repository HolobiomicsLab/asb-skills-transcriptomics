# back-to-back-barplot-visualization

## Summary

Render InterCellar's back-to-back barplot in the cluster-verse to juxtapose total (autocrine + paracrine) ligand-receptor interaction counts per cell cluster between two conditions, e.g. critical vs moderate COVID-19 CellPhoneDB-derived CCI datasets, to expose cell types with altered communication.

## When to use

Use when two or more pre-computed CCI datasets from different conditions (e.g. CellPhoneDB output for critical vs moderate COVID-19) are loaded in InterCellar and the goal is to identify cell clusters with strikingly gained or lost interactions via per-cluster count comparison.

## When NOT to use

- Input is raw scRNA-seq count data rather than pre-computed, inferred ligand-receptor interactions — InterCellar's workflow builds on CCI data, not expression matrices
- Only a single condition/dataset is available, since the barplot is a between-condition comparison of multiple datasets
- The CCI data was generated by a tool outside InterCellar's supported input formats (CellChat, CellPhoneDB, ICELLNET, SingleCellSignalR)

## Inputs

- Three CellPhoneDB-derived CCI datasets (pre-computed inferred ligand-receptor interactions with source/target cluster annotations) for critical and moderate COVID-19 cases
- Annotated cell cluster labels per interaction (needed for autocrine/paracrine classification)

## Outputs

- Back-to-back barplot figure juxtaposing per-cluster interaction counts between conditions, exported as back_to_back_barplot.png
- Per-cluster total interaction counts (aggregated across autocrine and paracrine flows) for each condition

## How to apply

Upload the pre-computed ligand-receptor interaction datasets as CCI data into InterCellar (start the Shiny app with InterCellar::run_app(reproducible = TRUE) so results are reproducible across R sessions). In the cluster-verse, classify each interaction as autocrine (source cluster equals target cluster) or paracrine (source and target clusters differ), then aggregate total interaction counts per cell cluster across all interaction flows for each condition dataset. Render the back-to-back barplot that juxtaposes per-cluster counts between conditions, interactively filtering/subsetting clusters as needed since each universe offers interactive filtering options. Export the figure (e.g. as back_to_back_barplot.png) using InterCellar's download options for figures to ensure reproducible result collection.

## Evaluation signals

- The generated barplot reproduces the reported per-cluster count pattern: mast cells (MC) and proliferating NKT cells (NKT-p) gain interactions in critical vs moderate COVID-19
- Macrophage interaction counts are higher and T cell counts lower in critical versus moderate cases in the rendered figure
- Autocrine vs paracrine classification is consistent: autocrine interactions have source cluster equal to target cluster; paracrine have differing clusters
- Figure is successfully exported as back_to_back_barplot.png via InterCellar's download options
- App was launched with the reproducible = TRUE flag so per-cluster counts are stable across R sessions

## Limitations

- InterCellar currently supports only a limited set of input tools (CellChat, CellPhoneDB, ICELLNET, SingleCellSignalR); extension to other published tools is planned future work
- Predicted interactions await experimental validation (e.g., smFISH or flow cytometry co-occurrence), so barplot patterns are hypotheses rather than validated biology
- Analysis was a snapshot as of April 2021 benchmark context; results depend on the reference database and statistical assumptions of the upstream prediction tool
