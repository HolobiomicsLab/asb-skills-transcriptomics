# pathogen-genome-read-alignment

## Summary

Align host-unmapped 10x scRNAseq reads to a pathogen reference genome and quantify per-cell pathogen UMI counts with scPathoQuant, which integrates the counts back into the cellranger filtered/raw_feature_bc_matrix files for downstream Seurat analysis.

## When to use

Use when you have 10x scRNAseq data from an infected sample where cellranger count has already aligned reads to the host genome, and you need per-cell viral/bacterial counts in a single command.

## When NOT to use

- Input is raw FASTQ with no host-aligned 10x output — scPathoQuant expects the output folder generated by first running cellranger count
- You need de novo pathogen discovery rather than alignment to a known pathogen reference genome supplied as fasta/gtf
- You already have a per-cell pathogen count matrix — integration into Seurat can proceed directly via Read10X without re-alignment

## Inputs

- 10x cellranger count output folder (possorted_genome_bam.bam, filtered_feature_bc_matrix, raw_feature_bc_matrix) supplied via -10x
- Pathogen reference genome FASTA file in a folder supplied via -p2genome
- Optional pathogen GTF gene-annotation file (same -p2genome folder) to enable per-gene counts
- Test datasets from the Whitmore_scPathoQuant_testSets repository (Zenodo DOI 10.5281/zenodo.10463677)

## Outputs

- pathogen_al_counts.csv — total number of reads mapping to the pathogen in each cell
- pathogen_al_gene_counts.csv and pathogen_genes_al_sort_counts.sam — per-cell pathogen gene counts (only with a gtf)
- pathogen_al.bam, pathogen_al_mapped.bam, pathogen_al_mapped_sort.bam with .bai index, pathogen_al_mapped.fq.gz
- Overwritten filtered_feature_bc_matrix and raw_feature_bc_matrix with pathogen counts appended
- Violin-plot PNGs: pathogen_copy.png, pathogen_genes.png, coveragemap.png
- _tmp/ artifacts: unmmaped.bam/sam, barcodes_umi_read_table.csv, unmapped.fq.gz

## How to apply

Run cellranger count first so reads align to the host genome, then point scPathoQuant at that 10x output folder via -10x and give a pathogen reference folder (fasta, optionally a gtf) via -p2genome; simplify the fasta header (e.g. > SARS-CoV-2) since it is used for total pathogen read quantification. scPathoQuant uses samtools to pull all host-unaligned reads from possorted_genome_bam.bam into a _tmp/ working directory (recording barcodes and UMIs in barcodes_umi_read_table.csv), then aligns them with bbmap (default, e.g. --bbmap_params="--semiperfectmode") or bowtie2 (e.g. --bowtie2_params="--very-sensitive --non-deterministic"). It quantifies per-cell total pathogen reads with htseq (non-default --intersection-nonempty) into pathogen_al_counts.csv and, when a pathogen gtf is supplied, per-cell pathogen gene counts into pathogen_genes_al_sort_counts.sam. Finally it overwrites the filtered_feature_bc_matrix and raw_feature_bc_matrix with pathogen UMI and gene counts appended, emits pathogen_al.bam/pathogen_al_mapped_sort.bam(.bai) and pathogen_al_mapped.fq.gz for phylogenetic use, and generates violin-plot PNGs; pass --tmp_removal to delete the large _tmp/ directory.

## Related tools

- **scPathoQuant** (Python package that performs the single-command extraction, alignment, quantification, and 10x-matrix integration) — https://github.com/galelab/scPathoQuant
- **cellranger** (Upstream host-genome alignment producing the 10x output folder and possorted_genome_bam.bam that scPathoQuant consumes)
- **samtools** (Pulls all host-unaligned reads from possorted_genome_bam.bam into the _tmp/ working directory)
- **bbmap** (Default aligner used to map extracted unmapped reads to the pathogen genome)
- **bowtie2** (Alternative aligner selectable via -align bowtie2 with --bowtie2_params such as --very-sensitive --non-deterministic)

## Examples

```
scpathoquant -10x path/to/10x/sample -op path/for/results -p 8 -p2genome path/to/pathogen/fastafilefolder --tmp_removal
```

## Evaluation signals

- pathogen_al_counts.csv contains a per-cell pathogen read count for each cell barcode
- The pathogen-integrated filtered_feature_bc_matrix files load via Seurat Read10X with pathogen counts appended
- In the HBEC SARS-CoV-2 benchmark, SPQ bbmap and SPQ bowtie2 identify the same SARS-CoV-2-positive cells as CellRanger-based alignment (4,279 at 1 dpi, 13,998 at 2 dpi, 26,935 at 3 dpi)
- Kendall rank correlations between SPQ UMI counts and CellRanger UMI counts are high, with slightly higher correlation for SPQ bbmap
- pathogen_genes_al_sort_counts.sam is produced only when a pathogen gtf was provided

## Limitations

- The _tmp/ directory of intermediate files can be large and must be deleted explicitly with --tmp_removal if space is an issue
- The fasta header is used to quantify total pathogen reads, so complicated headers should be simplified (e.g. > HIV_virus)
- Per-cell pathogen gene counts are not produced if a pathogen/viral gtf is not provided
- htseq runs with the non-default --intersection-nonempty parameter rather than default htseq-count settings
