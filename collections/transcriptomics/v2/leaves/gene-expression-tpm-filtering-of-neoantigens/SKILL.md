# gene-expression-tpm-filtering-of-neoantigens

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

A filter step in the TSNAD v2.0 pipeline that removes candidate neoantigens arising from mutations in unexpressed genes, using a transcript-per-million (TPM < 1) cutoff computed from tumor RNA-Seq. It ensures retained peptide-MHC candidates are supported by detectable gene expression in the tumor.

## When to use

Use when TSNAD v2.0 has produced DeepHLApan-scored candidate neoantigens from WES/WGS and matched tumor RNA-Seq is available, so that neoantigens from genes with TPM < 1 must be removed before ranking high-confidence candidates.

## When NOT to use

- No tumor RNA-Seq data is available for the sample — the README marks RNA-seq as 'not necessary to provide', but without it TPM values cannot be computed and this filter cannot be applied
- The goal is T-cell receptor (TCR)-pMHC binding prediction — the article notes this is not yet part of the pipeline and no TCR-pMHC model is included
- Quantifying expression itself for differential analysis — StringTie here is used only to produce TPM values feeding the neoantigen filter, not for downstream expression statistics

## Inputs

- Tumor RNA-Seq FASTQ reads (matched to the WES/WGS sample)
- Mutant peptides of length 8-11 amino acids extracted from GATK Mutect2 SNV/INDEL calls with VEP amino-acid annotation
- DeepHLApan binding and immunogenicity scores per peptide-MHC pair
- Reference genome annotation for GRCh37 or GRCh38

## Outputs

- Filtered neoantigen candidate list retaining only peptides from genes with TPM >= 1
- High-confidence neoantigen table (immunogenic score >0.5, binding score top-20 per peptide length) written to results/deephlapan_results/

## How to apply

Quantify tumor gene expression from RNA-Seq by aligning reads with HISAT2 2.2.1 and assembling/quantifying transcripts with StringTie 2.1.6 (module 4 of TSNAD v2.0). Apply the expression filter that removes neoantigens generated by mutations in genes with TPM < 1, intersecting this with the DeepHLApan potential-neoantigen filter (binding score >0.5 and immunogenic score >0.5). Only after expression filtering, rank the remaining peptide-MHC pairs — peptides of length 8-11 amino acids — by binding score, taking the top 20 per peptide length with immunogenic score >0.5 as high-confidence neoantigens. The filter is orchestrated automatically when TSNAD is run with an RNA-Seq input directory, and final neoantigen results land in results/deephlapan_results/. The rationale is that a neoantigen cannot be presented if its source gene is not transcribed, so unexpressed-gene mutations are non-actionable candidates.

## Related tools

- **TSNAD v2.0** (Pipeline that couples the RNA-Seq expression module to the neoantigen filtering logic and writes final results) — https://github.com/jiujiezz/tsnad
- **StringTie 2.1.6** (Assembles and quantifies tumor RNA-Seq transcripts to produce the TPM values used in the TPM < 1 filter)
- **HISAT2 2.2.1** (Maps RNA-Seq reads to the reference genome prior to StringTie quantification)
- **DeepHLApan 1.1** (Upstream producer of the binding/immunogenicity scores whose candidate set is intersected with the TPM >= 1 filter)

## Examples

```
python TSNAD.py -I samples/ -R RNA-seq/ -V grch38 -O results/
```

## Evaluation signals

- Every neoantigen retained after filtering maps to a source gene with TPM >= 1 in the StringTie quantification of the matched tumor RNA-Seq
- Candidates from genes with TPM < 1 are absent from the final results/deephlapan_results/ output
- The retained set is a subset of DeepHLApan pairs with binding score >0.5 and immunogenic score >0.5
- The filter runs before, not after, the top-20-per-peptide-length binding-score ranking (peptide lengths 8-11 aa)
- Run was executed with the RNA-seq directory mounted into the biopharm/tsnad Docker container, producing expression values for all neoantigen source genes

## Limitations

- The TPM < 1 cutoff is a fixed threshold; no sample-specific normalization or alternative expression cutoffs are discussed in the article
- Without providing RNA-Seq, the filter is silently skipped since RNA-seq input is optional in TSNAD, potentially leaving unexpressed-gene neoantigens in results
- TCR-pMHC interaction modeling is not included, so expression-filtered candidates are not further validated for T-cell responsiveness
