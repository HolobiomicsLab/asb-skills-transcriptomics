# matrix-tri-factorization-retraining

## Summary

Second-stage scMoMaT retraining that encodes Leiden cluster labels as fixed binary cell factors and re-optimizes feature factors and association matrices via matrix tri-factorization, yielding per-cluster multi-modal bio-marker score matrices.

## When to use

Use when Leiden cluster labels are already available from the first-stage scMoMaT cell-factor KNN graph and you need per-cluster, per-modality marker scores (genes, ATAC regions, proteins) to annotate cell types.

## When NOT to use

- Clusters have not yet been computed — this skill requires labels_leiden from the first-stage KNN graph and Leiden clustering; without them there are no fixed cell factors to condition retraining on.
- Only an integrated cell embedding is needed — first-stage training and extract_cell_factors() alone suffice; retraining is required specifically for cluster-specific feature scoring.
- The counts matrices have not been preprocessed with utils.preprocess() or features have not been matched across batches (gene intersection / peak remapping) — retraining assumes aligned feature sets per modality.

## Inputs

- Fitted first-stage scmomat_model with extracted cell factors (zs)
- Preprocessed PBMC counts dictionary (nbatches, feats_name, per-modality lists with None placeholders)
- Leiden cluster labels (labels_leiden) from scmomat.leiden_cluster at resolution=0.9
- Torch device (cuda:1 if available, else CPU)

## Outputs

- Retrained scMoMaT model with re-optimized feature factors and association matrices
- Per-modality cluster-specific marker score matrices (score_feats) for genes, ATAC regions, and proteins, each column giving per-cluster marker scores

## How to apply

Take the first-stage scmomat_model (trained with K=30 latent dimensions, T=4000, lambda=0.001) whose cell factors were post-processed into a KNN graph (n_neighbors=30) and Leiden-clustered at resolution=0.9. Initialize the retraining model with scmomat.scmomat_retrain(model, counts, labels_leiden, device): the cluster labels are encoded as binary cell factors and held fixed, so only feature factors and association matrices are re-optimized. Train with model2.train(T=2000) using the default regularization lambda=0.001. Extract per-modality marker score matrices with model2.extract_feature_factors(), where each latent dimension (column) corresponds to one Leiden cluster. Optionally expand counts with additional feature types (e.g. chromVAR motif deviation matrices) before retraining, since scMoMaT extracts bio-markers from features generated by other methods.

## Related tools

- **scMoMaT** (Provides scmomat.scmomat_retrain and scmomat.scmomat_model for two-stage matrix tri-factorization and extract_feature_factors() for marker scoring) — github.com/PeterZZQ/scMoMaT
- **PyTorch** (Training backend; supplies the device (cuda:1 GPU or CPU) on which the retraining iterations run)
- **Leiden** (Produces labels_leiden (resolution=0.9) on the post-processed KNN graph; these labels become the fixed binary cell factors in retraining)

## Examples

```
model2 = scmomat.scmomat_retrain(model=model, counts=counts, labels=labels_leiden, device=device); losses = model2.train(T=2000); score_feats = model2.extract_feature_factors()
```

## Evaluation signals

- Training loss curve from model2.train(T=2000) decreases and stabilizes under the default lambda=0.001 regularization
- extract_feature_factors() returns one marker score matrix per modality (rna, atac, protein) with n_features rows and one column per Leiden cluster
- Gene-modality marker scores reproduce known PBMC biology: GNLY and NKG7 score highest in the NK cluster
- Gene-modality marker scores reproduce B-cell markers: MS4A1, CD79A, and CD37 score highest in the B cluster
- Marker-derived cluster annotations agree with the original Mimitou et al. cell type labels (GC, ARI, NMI benchmarks)

## Limitations

- The 2nd-stage lambda is optional but defaults to 0.001; non-default values are not benchmarked in the provided context.
- Number of retraining iterations is fixed at 2000 in the README; training the 5-batch MOp demo takes ~5 min on an NVIDIA A40 GPU, so CPU-only runs may be slow.
- Learning cross-modality relationships via feature representations is deferred to future work rather than addressed in this study.
- Retraining works with matched feature sets per modality (intersection of genes/proteins or remapped chromatin regions); mismatched features across batches break the factorization.
