# chimeric-rna-qclash-data-handling

## Summary

Method for manipulating, quality-checking, filtering, and fold-annotating hyb-format chimeric RNA hybrid records generated by qCLASH/CLASH proximity-ligation experiments, using the Hybkit Python3 API and its command-line toolkit with paired Vienna dot-bracket fold files.

## When to use

Use when input is hyb-format hybrid (chimeric) sequence data from qCLASH/CLASH experiments — e.g. GEO-derived GSE101978 data — that must be integrity-checked, filtered, evaluated for miRNA/segment types, or merged with predicted secondary structure in Vienna dot-bracket format.

## When NOT to use

- Input is raw sequencing reads (FASTQ) rather than hyb-format hybrid records — hybkit operates on the hyb format defined by the Hyb software package, not on raw reads.
- Data are not chimeric/hybrid RNA proximity-ligation products (e.g. plain RNA-seq expression counts), where segment-type evaluation and fold-merge logic do not apply.
- Fold information is already merged into the hyb records and no further hyb/Vienna pairing is needed — re-running HybFoldIter would duplicate fold annotation.

## Inputs

- hyb-format chimeric (hybrid) RNA record file (e.g. from qCLASH of GSE101978 data)
- paired Vienna dot-bracket predicted secondary-structure file (or CT file)
- miRNA reference identifiers (e.g. MIMAT0000078_MirBase_miR-23a_microRNA)

## Outputs

- quality-checked hyb file (hyb_check-style integrity validation)
- filtered hyb file subset (e.g. ribosomal-/mitochondrial-RNA hybrids removed, or any_seg_contains matches)
- fold-annotated hyb file (e.g. hyb_fold_merged.hyb) with dot-bracket fold patterns, Gibbs free energy, and mismatch flags
- analysis tables and plots (CSV plus charts, e.g. hybrid type pie chart)

## How to apply

Load the qCLASH hyb file with hybkit.HybFile and any paired Vienna dot-bracket file with hybkit.ViennaFile (Python3.8+ hybkit API). First run integrity checking in the style of hyb_check on every record, since each hybkit analysis performs quality control by checking data integrity before filtering artifactual ribosomal- and mitochondrial-RNA hybrids with hyb_filter (e.g. --filter any_seg_contains kshv, or duplicate filtration by HybRecord.id). Evaluate records with hyb_record.eval_types()/eval_mirna() to assign segment types and miRNAs against references such as MirBase. To integrate predicted structure, iterate paired hyb and Vienna files with hybkit.HybFoldIter, merging each FoldRecord's dot-bracket pattern and predicted Gibbs free energy into the matching HybRecord by identifier; sequence-mismatch checking between the hyb and fold records is enabled by default and can be disabled by setting mismatches to '-1'. Write results as tab-delimited hyb files (e.g. hyb_fold_merged.hyb) and verify they parse cleanly and carry fold/mismatch annotations consistent with the paired inputs.

- **Hybkit** (Python3 API and command-line toolkit (hyb_check, hyb_filter, hyb_eval, hyb_analyze) for parsing, checking, filtering, evaluating, and fold-merging hyb records) — github.com/RenneLab/hybkit

## Examples

```
hyb_filter -i my_hyb_file.hyb -f my_hyb_file.vienna --filter any_seg_contains kshv
```

## Evaluation signals

- hyb_fold_merged.hyb exists and parses without error under hybkit's record-parsing checks (hyb_check-style integrity checking).
- Every output HybRecord carries merged fold information (dot-bracket pattern, predicted Gibbs free energy) and mismatch flags consistent with its paired FoldRecord.
- hyb/fold sequence mismatch flags appear only on records whose HybRecord read sequence differs from the FoldRecord sequence (mismatches '-1' disables this check).
- Filtered outputs contain no records with ribosomal- or mitochondrial-RNA hybrids when that filter is applied, and identifier counts match expected subsets (e.g. 'kshv' matches).
- Type/miRNA analysis output (CSV table plus chart) reconciles with record counts after eval_types()/eval_mirna() annotation.

## Limitations

- hybkit is specific to the hyb file format defined by the Hyb software package; other chimeric-RNA formats require conversion.
- Mismatch checking between hyb and fold sequences flags but does not correct inconsistencies; disabling it (mismatches='-1') removes this safeguard.
- Hybkit requires Python3.8+ with matplotlib >= 3.7.1 and BioPython >= 1.79; the GPL v3.0+ license constrains redistribution.
- Filtering quality depends on reference-derived segment strings (e.g. MirBase identifiers); artifactual ribosomal/mitochondrial hybrids are only removed when explicitly filtered.
