# covid19-scrnaseq-cci-interpretation

## Summary

Interactive interpretation of COVID-19 single-cell cell-cell communication using InterCellar's gene-verse dot plots to detect chemokine (CXCL1, CXCL3, CXCL6, CXCL16, CXCL17) ligand-receptor enrichment between secretory/secretory-diff cells and neutrophils across disease and control conditions.

## When to use

Use when you have pre-computed ligand-receptor interactions (CCI data) from multiple COVID-19 scRNA-seq conditions and need to test whether a specific ligand family (e.g., chemokines) drives communication between defined cell-type pairs across conditions.

## When NOT to use

- Input is raw scRNA-seq count data rather than pre-computed ligand-receptor interactions — InterCellar builds upon pre-computed, inferred ligand-receptor interactions uploaded as CCI data
- The CCI data was generated by a tool outside InterCellar's supported set (CellChat, CellPhoneDB, ICELLNET, SingleCellSignalR) — InterCellar currently supports only a limited set of input tools
- The analysis goal is CCI inference or computation itself rather than downstream interactive interpretation and filtering of already-predicted interactions

## Inputs

- Pre-computed, inferred ligand-receptor interactions for three COVID-19 scRNA-seq datasets, uploaded as CCI data
- Cell cluster annotations including secretory, secretory-diff, and neutrophil cell types

## Outputs

- Gene-verse dot plots of interaction scores for CXCL-filtered int-pairs, one per dataset/condition
- Exported interaction score tables
- Cross-condition comparison showing chemokine-driven secretory-to-neutrophil communication enriched in COVID-19 and absent in healthy controls

## How to apply

Launch InterCellar in R/Shiny and upload the three COVID-19 pre-computed ligand-receptor interaction datasets as CCI data in the first workflow step. In the gene-verse, use interactive filtering to subset int-pairs to the chemokine ligand genes CXCL1, CXCL3, CXCL6, CXCL16, CXCL17, then restrict to cluster-pairs involving secretory and secretory-diff cell clusters. Render dot plots of interaction scores, one per dataset/condition, and compare them across the multiple conditions to highlight patterns uniquely found in each condition. The rationale is that condition-specific communication — chemokine-driven recruitment of neutrophils by secretory cells — is expected to appear in disease but be absent in healthy controls. Use InterCellar's download options to export the dot plot figures and the interaction score tables for reproducibility.

## Related tools

- **InterCellar** (R/Shiny app used to upload the three COVID-19 CCI datasets, interactively filter int-pairs in the gene-verse, render dot plots of interaction scores, compare multiple conditions, and download tables and figures) — https://github.com/martaint/InterCellar
- **R/Shiny** (Implementation framework in which InterCellar is launched and the interactive analysis is performed without programming skills)

## Examples

```
library(InterCellar); InterCellar::run_app(reproducible = TRUE)
```

## Evaluation signals

- The gene-verse dot plots show enrichment of chemokine ligand-receptor pairs (CXCL1, CXCL3, CXCL6, CXCL16, CXCL17) in secretory/secretory-diff to neutrophil cluster-pairs in the COVID-19 datasets
- The same chemokine-driven communication pattern is absent in healthy control dot plots
- Filtered int-pairs are restricted to the five selected chemokine ligand genes and to cluster-pairs involving secretory and secretory-diff clusters
- Dot plots and interaction score tables are exported via InterCellar's download options, enabling session-to-session reproducibility (run with reproducible = TRUE)

## Limitations

- InterCellar currently supports only a limited set of input tools; extension to other published tools is planned future work
- Predicted interactions require experimental validation (e.g., single-molecule fluorescence in situ hybridization or flow cytometry co-occurrence) before biological conclusions are definitive
- Findings depend on the ligand-receptor reference databases and statistical assumptions of the upstream prediction method; method choice is critical
