# subgroup-specificity-labelling-of-gene-links

## Summary

Labels significant gene-gene links from DEGGs differential networks by the specific subgroup (e.g. BRCA_Her2 vs BRCA_LumA) in which each interaction is active, yielding fine-grained subgroup-specific pairs such as KDR-FGF17 and SHC3-PDGFC in TCGA-BRCA breast cancer data.

## When to use

Use when a coarse pathway-level result (e.g. Ras signaling upregulation in HER2-positive BRCA) needs to be resolved to specific, subgroup-restricted gene-gene interactions from a DEGGs differential network.

## When NOT to use

- The DEGGs repository is no longer maintained — for new multi-omic analyses prefer multiDEGGs (get_diffNetworks / get_multiOmicsDiffNetworks) rather than the legacy DEGGs functions.
- Input is a single homogeneous group with no subgroup variable (e.g. no SUBTYPE annotation), since subgroup specificity cannot be assigned without contrasting groups.
- The goal is pathway-level enrichment rather than link-level gene-gene interaction specificity.

## Inputs

- Normalised RNA-seq count matrix (BRCA_normCounts from the DEGGs package, TCGA-BRCA data)
- Clinical metadata data frame (BRCA_metadata with a SUBTYPE column distinguishing BRCA_Her2 and BRCA_LumA)
- A DEGGs subnetworks object generated by generate_subnetworks

## Outputs

- Table of significant gene-gene pairs from extract_sig_deggs, each labelled by the subgroup in which the link is significant
- Subgroup-specific link list (e.g. HER2-positive-specific KDR-FGF17 and SHC3-PDGFC), exportable as deggs_links_table.csv
- Optional per-pair differential regression plots from print_regressions

## How to apply

Load the packaged TCGA-BRCA data from the DEGGs R package (BRCA_normCounts and BRCA_metadata), confirming colnames(BRCA_normCounts) matches rownames(BRCA_metadata) before analysis. Run generate_subnetworks with subgroup_variable = "SUBTYPE", subgroups = c("BRCA_Her2", "BRCA_LumA"), entrezIDs = TRUE, convert_to_gene_symbols = TRUE, and cores = 2; this tests each gene-gene link via robust linear regression with an interaction term to assign subgroup-specific significance. Call extract_sig_deggs on the subnetworks object to obtain a table of all significant gene-gene pairs across subgroups, then label each pair with the subgroup in which it is significant — pairs significant only in BRCA_Her2 are HER2-positive-specific. Optionally confirm the differential fit for a named pair with print_regressions (e.g. gene_A = "KDR", gene_B = "FGF17") before writing the labelled link table.

## Examples

```
subnetworks_object <- generate_subnetworks(normalised_counts = BRCA_normCounts, metadata = BRCA_metadata, subgroup_variable = "SUBTYPE", subgroups = c("BRCA_Her2", "BRCA_LumA"), entrezIDs = TRUE, convert_to_gene_symbols = TRUE, cores = 2); extract_sig_deggs(subnetworks_object)
```

## Evaluation signals

- colnames(BRCA_normCounts) is identical to rownames(BRCA_metadata) before running generate_subnetworks.
- extract_sig_deggs returns a non-empty table of significant gene-gene pairs, and each row can be attributed to one subgroup (BRCA_Her2 or BRCA_LumA).
- The KDR-FGF17 and SHC3-PDGFC pairs appear as significant only in the BRCA_Her2 (HER2-positive) subgroup, matching the reported case-study result.
- print_regressions for a labelled pair (e.g. KDR-FGF17) shows visibly different regression fits between the two subgroups, confirming the interaction is differential.
- The labelled result table (deggs_links_table.csv) contains the subgroup label column and only significant pairs.

## Limitations

- The elisabettasciacca/DEGGs repository is no longer maintained and will not receive further updates; the package has been moved and expanded into multiDEGGs.
- Gene-gene significance is derived from robust linear regression with an interaction term on normalised counts, so links depend on the chosen subgroup contrast and multiple-testing behaviour of extract_sig_deggs.
- Results are specific to the tested subgroup comparison (BRCA_Her2 vs BRCA_LumA); links labelled HER2-positive-specific may not generalise to other breast cancer subtypes.
