# cell-cell-interaction-label-aggregation

## Summary

Constructs consensus ground-truth labels (significant vs non-significant) for every ligand-receptor/cell-type pair by majority-voting across multiple constituent CCI-prediction methods, enabling supervised training and cross-validated evaluation of the DeepCCI ResNet+GCN interaction model.

## When to use

Use when training or benchmarking a supervised CCI inference model (e.g., DeepCCI's ResNet+GCN interaction model) and per-method significant-interaction calls must be merged into a single consensus label set for classification.

## When NOT to use

- Only one CCI-prediction method is available, so no cross-method vote can be taken — use that method's calls directly instead
- The goal is unsupervised CCI discovery from a new dataset rather than training/evaluating a supervised interaction model against consensus labels

## Inputs

- scRNA-seq dataset with cell-type labels (e.g., panc8) processed for DeepCCI's interaction model
- Per-method significant-interaction calls for ligand-receptor/cell-type pairs from constituent CCI-prediction tools
- Ligand-receptor pair feature file generated by DeepCCI Feature.py (SVD-reduced)

## Outputs

- Consensus significant/non-significant label per ligand-receptor/cell-type pair (majority vote)
- Labeled training set for the DeepCCI ResNet+GCN interaction model
- Cross-validated performance metrics (F1, Recall, ACC, Precision, AUC) aggregated over 100 runs

## How to apply

Run each constituent CCI-prediction method on the same scRNA-seq input (e.g., the panc8 dataset) to obtain per-method significant-interaction calls for every ligand-receptor/cell-type pair. For each pair, aggregate the binary calls across methods by majority vote to produce a single consensus significant/non-significant label; this handles disagreement among statistical tools and yields a usable supervised target. Use these consensus labels as ground truth when preprocessing pair features with DeepCCI's Feature.py (--label_mode True --species Human, with SVD dimensionality reduction of ligand-receptor pair features) and when training the interaction model with Focal loss to cope with class imbalance between significant and non-significant pairs. Finally, evaluate generalizability by running repeated 5-fold cross-validation (5 folds, 20 repetitions = 100 runs) via Interaction_inference.py --device cuda and computing F1, Recall, ACC, Precision, and AUC against the majority-vote labels.

## Related tools

- **DeepCCI** (Framework whose Feature.py (--label_mode True) ingests the consensus labels and whose Interaction_inference.py trains/evaluates the ResNet+GCN model via repeated 5-fold cross-validation) — https://github.com/JiangBioLab/DeepCCI
- **Python 3.7.4** (Runtime environment (conda env deepcciEnv) in which the label aggregation, model training, and cross-validation scripts are executed)
- **conda** (Creates the isolated python=3.7.4 environment used to run DeepCCI preprocessing and interaction inference)

## Examples

```
cd Interaction_model && python Feature.py --label_mode True --species Human && python Interaction_inference.py --device cuda
```

## Evaluation signals

- Every ligand-receptor/cell-type pair in the dataset receives exactly one consensus label after aggregation, with ties resolved consistently by majority vote
- Repeated 5-fold cross-validation (20 repetitions, 100 total runs) completes and the five metrics (F1, Recall, ACC, Precision, AUC) can be aggregated across all runs
- Reproduced metric means match the published Fig. 3h-i benchmarks for the interaction model
- Interaction_inference.py generates the predicted interaction outfile within the reported ~1-2 minute inference time
- Focal loss training handles the significant/non-significant class imbalance without collapsing to majority-class predictions

## Limitations

- Consensus labels inherit the biases of the constituent statistical CCI methods, which the paper notes 'ignore some key latent information contained in scRNA-seq data with high sparsity and heterogeneity'
- Significant/non-significant class imbalance requires Focal loss; naive training on the majority-vote labels may under-predict the significant class
- Interaction model inference timing (~1-2 minutes) and preprocessing (~10-20 minutes) depend on scRNA-seq file size
