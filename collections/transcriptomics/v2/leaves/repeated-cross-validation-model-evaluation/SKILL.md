# Repeated cross-validation model evaluation

## Summary

A protocol for rigorously benchmarking sequence-based machine learning classifiers (LR, SVM, GNB) by repeated 5-fold cross-validation, as used in iRNA5hmC-PS to report Accuracy, Precision, Sensitivity, Specificity, F1, MCC, AUROC, and AUPR on the RNA 5hmC benchmark dataset.

## When to use

Use when a new feature set (e.g. PSG k-mer, position-specific k-mer, GC-content) must be compared against baselines on a labeled sequence dataset, requiring averaged cross-validation metrics and ROC/PR curves rather than a single train/test split.

## When NOT to use

- The goal is independent-set generalization: the article reports independent-test results (Table 6) separately from cross-validation (Table 5), so use a held-out test evaluation instead.
- You want to test whether position-specific features combine with k-mer frequency features in one model — the authors note these do not work well together and defer combination to a feature-subspace ensemble approach.
- Input is a raw sequence file only — feature extraction must first be run (Feature Generation.ipynb) before cross-validation can be executed.

## Inputs

- Dataset.csv — benchmark RNA 5hmC labeled sequences from https://github.com/zahid6454/iRNA5hmC-PS
- All_Features_Dataset.csv — feature table generated by Feature Generation.ipynb (PSG k-mer, position-specific k-mer, GC-content features)

## Outputs

- cross_validation_results.csv — per-repetition and averaged Accuracy, Precision, Sensitivity, Specificity, F1, MCC, AUROC, AUPR with standard deviations
- AUROC and AUPR cross-validation curves (matplotlib figures)
- Comparison table of LR vs SVM vs GNB under 5-fold cross-validation

## How to apply

Load the labeled benchmark sequences (Dataset.csv) with engineered features (from All_Features_Dataset.csv) into a pandas DataFrame. Apply the group-wise Random Forest feature-importance selection to keep a small discriminative subset, then train scikit-learn classifiers (default-hyperparameter Logistic Regression as the proposed best model, plus SVM and GNB) under repeated 5-fold cross-validation (the reproduction protocol uses 10-times 5-fold; the article reports 5-fold CV results with standard deviations in parentheses). Record Accuracy, Precision, Sensitivity, Specificity, F1-score, MCC, AUROC, and AUPR per repetition and report means with standard deviations. Plot the AUROC and AUPR cross-validation curves with matplotlib. Accept the evaluation if averaged metrics reproduce the reference values — Accuracy ~78.3%, Sensitivity 80.0%, Specificity 79.5%, F1 0.78, MCC 0.56, AUROC 0.86, AUPR 0.86 — and LR outperforms SVM and GNB on most of the six metrics.

## Related tools

- **scikit-learn** (Provides the classifiers (Logistic Regression, SVM, GNB) and cross-validation machinery used to obtain the averaged performance metrics) — https://github.com/zahid6454/iRNA5hmC-PS
- **iRNA5hmC-PS** (Framework whose Model.ipynb executes the 5-fold cross-validation of LR/SVM/GNB and emits result tables plus AUROC/AUPR curves) — https://github.com/zahid6454/iRNA5hmC-PS

## Examples

```
from sklearn.model_selection import RepeatedKFold; from sklearn.linear_model import LogisticRegression; cv = RepeatedKFold(n_splits=5, n_repeats=10); clf = LogisticRegression()
```

## Evaluation signals

- Averaged LR cross-validation metrics fall within tolerance of Accuracy 78.3%, Precision 78.0%, Sensitivity 80.0%, Specificity 79.5%, F1 0.78, MCC 0.56.
- Per-repetition standard deviations are small (as reported in the article's Table 5), indicating stability across folds.
- LR outperforms SVM (75.5% Acc, 0.49 MCC) and GNB (76.7% Acc, 0.50 MCC) on at least four of the six metrics.
- All_Features_Dataset.csv exists after Feature Generation.ipynb and contains the complete feature columns before Model.ipynb runs.
- AUROC and AUPR curves are rendered in the notebook output cell just before the last cell, matching the README's described workflow.

## Limitations

- The reported scores depend on prior group-wise Random Forest feature selection; cross-validating on the full feature set or unselected features will not reproduce 78.3% accuracy.
- Position-specific features perform poorly when naively combined with frequency-based k-mer features in a single model, which the authors defer to a feature-subspace ensemble.
- The benchmark dataset is only referenced via the GitHub repository and is not accessioned elsewhere; reproduction requires the exact Dataset.csv sequences.
- Efficacy on other RNA modification problems has not been evaluated.
