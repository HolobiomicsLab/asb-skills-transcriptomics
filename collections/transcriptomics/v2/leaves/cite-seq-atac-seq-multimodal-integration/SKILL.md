# cite-seq-atac-seq-multimodal-integration

## Summary

Generate cell embeddings from multimodal single-cell omics data (CITE-seq RNA/protein, SHARE-seq/SNARE-seq RNA/ATAC) using SnapCCESS, an unsupervised ensemble deep learning framework that creates snapshots of variational autoencoder embeddings for consensus clustering, benchmarked against totalVI, MultiVI, MOFA+, and Jvis-learn.

## When to use

Use when clustering cells measured across multiple modalities (e.g. CITE-seq RNA+ADT, or SHARE-seq/SNARE-seq RNA+ATAC) and you need integrated unsupervised embeddings comparable to totalVI/MultiVI/MOFA+ methods.

## When NOT to use

- The tutorial does not recommend best parameters for your datasets — do not apply tutorial defaults to new datasets without consulting dataset-specific parameters from the published literature
- Single-modality data (RNA-only scRNA-seq) — SnapCCESS is designed for integrating multiple data modalities measured across the same cells

## Inputs

- CITE-seq datasets with RNA and ADT (protein) modality matrices measured across the same cells, arranged features-by-cells
- SHARE-seq / SNARE-seq datasets with RNA and ATAC modality matrices measured across the same cells
- Reference cell-type labels for ARI/NMI evaluation
- Tutorial data in tutorials/in/ with small CITE-seq RNA, ADT, and cell type files

## Outputs

- Cell embeddings generated by SnapCCESS snapshot-based variational autoencoder ensembling (and comparison methods totalVI, MultiVI, MOFA+, Jvis-learn)
- Consensus cell cluster assignments from k-means, SIMLR, and spectral clustering applied to the embeddings
- ARI and NMI benchmark table across all method-by-algorithm combinations (e.g. figure5_ari_nmi_benchmark.csv)

## How to apply

Install the snapccess Python package via pip ('pip install snapccess --index-url https://pypi.org/simple') or the R wrapper via remotes::install_github from the snapccess-r/SnapCCESS subdir, which calls Python through reticulate. Load each modality as a features-by-cells matrix (e.g. RNA and ADT for CITE-seq; RNA and ATAC for SHARE-seq/SNARE-seq) measured across the same cells, preprocess each modality, and follow the tutorial notebook 'an_example_of_generate_embedding_using_SnapCCESS_python_version.ipynb' to generate embeddings with the snapshot-based variational autoencoder ensembling approach. Take dataset-specific hyperparameters from the published paper (doi:10.1093/bioinformatics/btad382), not the tutorial defaults, since the tutorial does not recommend best parameters. Couple the resulting embeddings with clustering algorithms — k-means, SIMLR, and spectral clustering — to generate consensus cell clusters, and score against reference cell-type labels using ARI and NMI as in the Figure 5 benchmark. Expect SnapCCESS clustering to be significantly better than totalVI on CITE-seq datasets and MultiVI on SHARE-seq/SNARE-seq datasets in most cases, and expect the characteristically poor SIMLR-on-Jvis-learn combination as a sanity check.

## Evaluation signals

- SnapCCESS clustering performance (ARI/NMI) is significantly better than totalVI on CITE-seq datasets and MultiVI on SHARE-seq/SNARE-seq datasets in most cases
- SIMLR coupled with Jvis-learn embeddings shows characteristically poor clustering performance, matching the Figure 5 benchmark pattern
- SnapCCESS embeddings enable consensus clustering when coupled with multiple algorithms (k-means, SIMLR, spectral clustering)
- Embeddings are generated for all six multimodal datasets spanning CITE-seq and SHARE-seq/SNARE-seq modalities

## Limitations

- The tutorial only explains package usage and does not recommend best parameters; dataset-specific hyperparameters must be taken from the published paper (doi:10.1093/bioinformatics/btad382)
- The best hyperparameters can vary by dataset
- GPU acceleration is optional and depends on the local PyTorch/CUDA or PyTorch/ROCm installation
- If Python dependencies are managed through Conda, virtualenv, or cluster modules, reticulate must be configured to use that environment before loading the R wrapper
