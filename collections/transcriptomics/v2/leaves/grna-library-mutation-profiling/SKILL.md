# gRNA-library-mutation-profiling

## Summary

Profile intact and mutant gRNA molecules in single-cell CRISPR screen data using GiRAFR, which builds per-UMI consensus sequences, calls mutations against the gRNA cassette reference, and assigns gRNAs to cells in a mutation-aware manner.

## When to use

Use when analyzing single-cell CRISPR screen gRNA library BAM files where mutant gRNAs may go undetected by default Cell Ranger annotation, or when quantifying per-experiment mutant gRNA frequencies.

## When NOT to use

- You only need standard gene-expression processing; gRNA library annotation is out of scope for generic scRNA-seq pipelines
- You need a fine-grained appraisal of which gRNA mutation types and locations are tolerable or damaging — the article declares this beyond the scope of the study
- You want to detect CRISPR-Cas9-induced DNA editing in transcriptome data — that is a separate GiRAFR analysis mode (editing_effect), not the gRNA mutation-profiling workflow

## Inputs

- gRNA library alignment BAM file
- Filtered (unzipped) cell barcode list from the expression library
- Reference gRNA cassette FASTA (e.g. oligo_pool_plasmid.fa with oligo_name and sequence columns)
- Cassette structure GTF (e.g. oligo_pool_plasmid_structure.gtf, generated by prepare.py)
- ConfigFile for girafr gRNA_mutation pointing to BAM, barcodes, ref_fasta, and structure_gtf

## Outputs

- gRNA.sorted.mapped.removedSecondaryAlignment.onlyMappedToGrnaChrom.bam (filtered BAM)
- consensus.sequence.gRNA.txt and consensus.bam (per-UMI-cell barcode consensus sequences)
- consensus.sequence.gRNA.variant.txt (called mutations with CIGAR-like location encoding)
- cells.gRNA.txt, cells.gRNA.single.txt (gRNA-to-cell assignments)
- gRNA.umi.threshold.txt (per-gRNA UMI assignment thresholds)
- consensus.sequence.matrix and mutation type/location annotations from add_variant_type and profile_MT_pattern.py

## How to apply

Run the GiRAFR four-step pipeline: (1) filter the gRNA library alignment BAM with utils.gRNA_bam_filter (samtools) to remove secondary alignments and keep only reads mapped to the designed gRNA cassette chromosomes, producing gRNA.sorted.mapped.removedSecondaryAlignment.onlyMappedToGrnaChrom.bam; (2) construct a consensus sequence for each UMI-cell barcode combination with consensus_sequence.generate_consensus_sequence_gRNA, retaining UMIs supported by at least min_reads reads (default = 1); (3) call mutations with variant.call_gRNA_variant against the reference gRNA cassette FASTA (e.g. oligo_pool_plasmid.fa) and its structure GTF, annotating mutation locations as CIGAR-like strings; (4) assign gRNAs to cells with assign_gRNA.assign_gRNA_to_cell using min_umi = 3 or, with auto=True, a two-component Gaussian mixture threshold fitted over pooled intact and mutated UMIs (pool=True). Optionally run assign_gRNA.add_variant_type and profile_MT_pattern.py to add mutation type and location details for downstream analysis. The rationale is that Cell Ranger labels guides with a single mutation (1 Hamming distance) as intact, obscuring dysfunctional mutant gRNAs and inflating untransformed-cell and singlet estimates.

## Examples

```
pip install girafr; girafr gRNA_mutation --ConfigFile ConfigFile  # with gRNA bam, filtered barcode list, oligo_pool_plasmid.fa and structure gtf
```

## Evaluation signals

- cells.gRNA.txt exists and matches the expected GiRAFR output format
- Per-experiment mutant gRNA frequencies fall within the reported 2%–35% range of cells observed across public datasets
- In the Perturb-seq validation, all 103 predesigned mutant gRNAs are recovered from only 25 intact reference sequences and ≥98.1% of the 14,113 originally annotated mutant-gRNA cells are assigned concordantly
- Filtered BAM named gRNA.sorted.mapped.removedSecondaryAlignment.onlyMappedToGrnaChrom.bam is produced by step 1
- Assigned cells have UMI counts ≥ min_umi (default 3) or exceed the auto-fitted per-gRNA Gaussian-mixture threshold recorded in gRNA.umi.threshold.txt

## Limitations

- Head-to-head comparison between published studies is unfeasible due to ad hoc customized pipelines and fixed thresholds
- Specific defined read depths need to be attained for accurate gRNA assignment and mutation detection
- Inter-experiment differences in average gRNA UMIs may stem from low gRNA expression or low detection rates, detrimentally impacting cell assignment and singlet vs multiplet discrimination
- Design choices (multiplicity of infection, number of designed gRNAs, introduced mutations, cells per perturbation) influence assignment accuracy and require parameter finetuning
