# one-of-K-encoding-of-rna-sequence-and-structure

## Summary

Encodes RNA sequences and their RNAshapes-derived secondary-structure contexts as fixed-size one-of-K binary matrices (51×4 for sequence, 51×6 for structure dot-bracket classes) so that two parallel 1D-CNN branches of MU-PseUDeep can consume them.

## When to use

Use when preparing Ψ-site candidate fragments (uridine-centered, 25 nt flanks each side) as fixed-length categorical matrices for a dual-branch 1D-CNN classifier that reads both sequence and secondary-structure context.

## When NOT to use

- The downstream model accepts a single sequence-modality input only (e.g., a sequence-only CNN baseline) — the structure matrix is unnecessary and cannot be consumed
- Input fragments are not length-fixed at 51 nt or are not uridine-centered, so the matrices would be incommensurable with the trained MU-PseUDeep architecture
- The task involves protein sequences or other alphabets, for which the 4-channel nucleotide and 6-channel dot-bracket encodings do not apply

## Inputs

- Uridine-centered RNA fragments of length 51 (Ψ/uridine plus 25 nt upstream and 25 nt downstream)
- Secondary-structure dot-bracket notation generated by the RNAshapes package for the same 51-nt fragments

## Outputs

- One-of-K binary matrix of size 51×4 per fragment for the sequence branch
- One-of-K binary matrix of size 51×6 per fragment for the secondary-structure branch

## How to apply

First extract the uridine-centered fragment (25 bases upstream and downstream) and generate the abstract dot-bracket notation with the RNAshapes package. Then convert the sequence into a one-of-K binary matrix of size 51×4 (one channel per nucleotide) and the secondary-structure notation into a one-of-K matrix of size 51×6 (one channel per dot-bracket context class), as described in the MU-PseUDeep methods. Both matrices are fed to separate input branches, each processed by a pair of 1D CNN layers; the four conv outputs are concatenated into a 512-neuron softplus dense layer before the binary classification head. The rationale is that encoding both modalities lets the network learn sequence- and structure-specific convolutional filters, which improved accuracy/F1 by 3–4% and sensitivity by up to 9% over a sequence-only CNN.

## Related tools

- **MU-PseUDeep** (Consumer model whose two 1D-CNN branches require the 51×4 and 51×6 one-of-K matrices as inputs) — https://github.com/smk5g5/MU-PseUDeep
- **RNAshapes** (Generates the abstract dot-bracket secondary-structure notation that is one-hot encoded into the 51×6 matrix)
- **Keras** (Framework in which the dual-input architecture consuming the encoded matrices is instantiated (TensorFlow backend))

## Examples

```
X_seq = keras.utils.to_categorical(seq_idx, num_classes=4); X_sec = keras.utils.to_categorical(db_idx, num_classes=6)  # shapes 51×4 and 51×6
```

## Evaluation signals

- Sequence matrix must have shape 51×4 and structure matrix 51×6 per fragment, with exactly one active channel per position (valid one-of-K encoding)
- Every encoded fragment must have uridine at its center (position 26)
- The assembled Keras model must report 661,118 trainable parameters, matching the paper
- Model compiled with SGD (learning rate 0.0137) and binary cross-entropy trains without shape errors on the dual inputs
- Including the structure matrix should improve accuracy/F1 by roughly 3–4% and sensitivity by up to 9% versus the sequence-only CNN on the balanced dataset

## Limitations

- Encoding is tied to the 51-nt uridine-centered fragment definition; other window sizes or non-uridine centers break the fixed matrix shape
- The structure branch depends on RNAshapes predictions, so errors in predicted dot-bracket notation propagate into the 6-channel encoding
- Direct comparison to iPseU-CNN was impossible because no source code or webserver was available for that method
