# chi2-gene-cluster-feature-selection

## Summary

Selects the top 1000 gene cluster absence/presence features with chi2 statistics in scikit-learn before training bacLIFE random forest lifestyle classifiers for Burkholderia/Paraburkholderia and Pseudomonas genomes. This dimensionality reduction targets lifestyle-relevant gene clusters and feeds a 5-fold cross-validation scheme (70% training, 30% test).

## When to use

Use when training lifestyle-prediction classifiers on large gene cluster absence/presence matrices (e.g., bacLIFE output for Burkholderia/Paraburkholderia or Pseudomonas) and you need to reduce thousands of binary gene cluster features to the most informative subset before random forest classification.

## When NOT to use

- Input features are continuous or non-count-valued: chi2 requires non-negative count/binary features, so it is inappropriate for non-absence/presence matrices
- The feature table is already a reduced/curated candidate-gene set smaller than 1000 features, so selection would discard informative clusters
- The goal is identifying lifestyle-associated genes (pLAGs) by enrichment (70% group presence, >2 log2 fold change), not classifier feature reduction

## Inputs

- Gene cluster absence/presence matrix (binary feature table over genomes, from bacLIFE clustering module)
- Literature-based lifestyle metadata labels per genome (e.g., opportunistic human pathogen, plant pathogen, environmental)
- Species assignments used to hold out all genomes of a target species for leave-one-species-out validation

## Outputs

- Reduced feature matrix containing the top 1000 chi2-selected gene cluster features per lifestyle classifier
- Trained random forest lifestyle classifiers (n_estimators=50) with per-genome predicted lifestyle and tree-vote confidence values (Supplementary Datasets 2)

## How to apply

Start from the gene cluster absence/presence matrices generated by the bacLIFE clustering module (linclust at --min-seq-id 0.9 --cov-mode 0 -c 0.8, followed by MCL and diamond all-vs-all alignment with e-value cutoff 1e-5) and the literature-based lifestyle metadata for each dataset. Apply chi2 feature selection in scikit-learn to retain the top 1000 gene cluster features per lifestyle classifier, since chi2 scores capture association between binary gene cluster occurrence and lifestyle labels. Use the selected features in a 5-fold cross-validation scheme (70% training, 30% test) with a random forest classifier (n_estimators=50). Predictions are accepted as a lifestyle when the random forest probability confidence — the fraction of trees voting for a class — exceeds 0.8. The same selection step supports leave-one-species-out validation, where the forest is trained with all genomes of a target species (e.g., B. vietnamiensis) excluded to emulate novel-species prediction.

## Related tools

- **bacLIFE** (Generates the gene cluster absence/presence matrices that are the input to chi2 feature selection and random forest lifestyle prediction) — https://github.com/Carrion-lab/bacLIFE
- **scikit-learn** (Provides the chi2 feature selection (top 1000 features) and the random forest classifier with tree-vote probability confidence used for lifestyle prediction)

## Examples

```
from sklearn.feature_selection import SelectKBest, chi2; X_sel = SelectKBest(chi2, k=1000).fit_transform(X_gene_clusters, y_lifestyle)
```

## Evaluation signals

- The selected feature matrix contains exactly 1000 gene cluster features per lifestyle classifier
- 5-fold cross-validation on the selected features (70% training, 30% test) reproduces the reported lifestyle predictability
- Accepted lifestyle predictions have random forest probability confidence >0.8 (fraction of trees voting per class)
- Leave-one-species-out validation matches reference counts: 40/40 B. vietnamiensis genomes predicted opportunistic human pathogen at 90% tree votes, 92/124 P. fluorescens as environmental, and 30/35 P. cichorii as plant pathogen at >=70% tree votes
- Per-genome confidence values match those compiled in Supplementary Datasets 2

## Limitations

- Chi2 selection retains only 1000 of all detected gene clusters, so lifestyle-discriminative clusters outside the top 1000 are ignored by the classifier
- Leave-one-species-out results show uneven accuracy for species absent from training (e.g., only 92/124 P. fluorescens and 30/35 P. cichorii predicted correctly), reflecting reduced performance on truly novel species
- Feature selection is lifestyle-specific (top 1000 features per lifestyle classifier), so selected feature sets differ across lifestyles and are not interchangeable
