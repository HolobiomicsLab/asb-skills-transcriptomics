# single-cell-snp-genotyping

## Summary

Genotypes individual cells from a 10x single-cell RNA-seq mixture by calling SNPs with haplotype-based freebayes against a reference genome, filtering by depth/quality, and merging cells into per-cell genotype profiles that enable clustering of contributors.

## When to use

Use when you have a 10x possorted_genome BAM plus barcodes.tsv from a multi-person cell mixture and need per-cell SNP genotypes to genetically separate contributors into individual-specific clusters.

## When NOT to use

- The sample is single-source (no mixture) — standard genotyping/quantification suffices and cluster separation is unnecessary.
- Only dead/fixed cells are available — the 10x scRNA-seq platform used here 'requires live cells for successful genetic separation', so the input BAM cannot be produced.
- The goal is DNA profiling from bulk mixture traces (no single-cell data) — this skill operates on 10x scRNA-seq BAMs, not bulk forensic DNA profiles.

## Inputs

- possorted_genome_trimmed.bam (10x cell-ranger genome BAM of the cell mixture)
- barcodes.tsv / barcodes_reduced.txt (10x cell barcodes to retain)
- genome.fasta (human reference, e.g. hg19 or hg38)
- MT.fasta and MT_regions.txt (mitochondrial reference of the same build)
- regions.txt (parallel freebayes regions file, generated with fasta_generate_regions.py)
- config.yaml with pipeline parameters (dp, qual, thr_cell_1/2, threshold_coverage, UMAP settings)

## Outputs

- output/iter2/cells_merge_clusters.vcf (per-cluster VCF grouping cells by contributor genotype)
- Per-cell SNP genotype/coverage matrix from the Python cell-merging rule
- Cell clusters, one per contributing individual (validated to equal contributor count for 5-9 person mixtures)

## How to apply

Run the de-goulash Snakemake pipeline (geniderasmusmc/de-goulash:1 Docker image, input mounted at /single-cell, config.yaml, cores=4). Call SNPs on possorted_genome_trimmed.bam against genome.fasta with freebayes in parallel over the regions file generated by fasta_generate_regions.py, plus a separate mitochondrial (MT.fasta/MT_regions.txt) pass. Filter SNPs at dp=50 and qual=60, then apply per-iteration minimum SNP-per-cell thresholds thr_cell_1=10 and thr_cell_2=20; only cells with sufficient SNPs are retained. Merge cells in Python requiring threshold_coverage=10 total coverage of selected SNPs per cell, threshold_coverage_pos=5 coverage per selected SNP per cell, and threshold_base_calling=90. Finally run the clustering Rscript (UMAP, n_neighbors=5, n_components=300; clusters=0 skips nBclust prediction) to produce output/iter2/cells_merge_clusters.vcf whose clusters correspond to contributing individuals.

## Examples

```
docker run -it -v /current/directory/de-goulash/:/single-cell geniderasmusmc/de-goulash:1 output/iter2/cells_merge_clusters.vcf --snakefile Snakefile --configfile config.yaml --cores 1
```

## Evaluation signals

- For each in silico mixture, the number of deconvoluted cell clusters equals the known number of contributing individuals (e.g. the 9-person mixture M9 yields exactly 9 clusters).
- Clustered cells contain at least thr_cell_1=10 (iteration 1) and thr_cell_2=20 (iteration 2) filtered SNPs per cell, with each cell showing >=10x total coverage across selected SNPs and >=5x coverage per SNP with >=90% base-calling support.
- output/iter2/cells_merge_clusters.vcf is produced for each mixture and its clusters are consistent across the two-threshold iterations.
- Downstream step-2 analysis assigns each cluster the expected sex and bio-geographic ancestry of its contributing individual.

## Limitations

- Deconvolution of mixtures with more than nine individuals was not experimentally tested (only hypothesized feasible, depending on SNPs per cell cluster).
- The 10x scRNA-seq platform requires live cells, limiting application to biological mixtures containing living cells; fixed-cell platforms remain untested.
- Success depends on obtaining enough SNPs per individual cell cluster; deeper sequencing may be needed for very low cell numbers, and transferability to mixtures other than blood is not yet demonstrated.
- With clusters=0 in config.yaml, nBclust is not executed, so the number of clusters is not statistically predicted and must be validated against known contributor counts.
