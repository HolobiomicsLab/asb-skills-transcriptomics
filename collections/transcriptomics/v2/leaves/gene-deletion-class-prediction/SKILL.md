# gene-deletion-class-prediction

## Summary

Apply CLOUDe's machine-learning classifiers (NN, XGB, RF, SVM) to predict whether post-duplication gene deletion events are 'redundant' or 'unique' from absolute log10(x+1) expression values across m conditions in derived, survived, and lost genes. The neural network (2 hidden layers) is the optimal architecture for class discrimination.

## When to use

Use when you have a space-delimited expression file (N+1 rows, 3m columns: eD1-eDm, eS1-eSm, eL1-eLm) for gene deletion events and need to classify each event as 'Redundant' or 'Unique'.

## When NOT to use

- The goal is estimating evolutionary parameters (theta1, theta2, log10(sigmaSq/(2*alpha))) rather than class labels — use CLOUDePredict* predictor functions instead
- The input file lacks the 3-block eD/eS/eL column structure or the deletion-event per-row format (e.g., it is a raw species-gene expression matrix before aligning to deletion events)
- Only two-species relative expression is available without the three post-deletion genes (derived, survived, lost) CLOUDe requires

## Inputs

- Space-delimited input file with N+1 rows and 3m columns of absolute log10(x+1) expression values for derived (eD), survived (eS), and lost (eL) genes per deletion event (e.g., EmpiricalData.data: N=100 events, m=6 tissues)
- Training features and one-hot class files (training_prefix.features, training_prefix.classes) generated by GenerateTrainingData()
- Trained classifier model files (training_prefix.nn.num_layers.classifier.hdf5, xgb .classifier_cv outputs) for NN/XGB

## Outputs

- test_prefix.nn.num_layers.classifications (one 'Redundant'/'Unique' label per deletion event)
- test_prefix.nn.num_layers.probabilities (per-event class probabilities)
- Analogous .classifications and .probabilities files for xgb (max_depth), rf, and svm methods
- Summary accuracy/power table (e.g., classifier_accuracies.csv or noise_robustness_results.csv)

## How to apply

Simulate OU-process training data with GenerateTrainingData(m, Nk, training_prefix, logThetaMin, logThetaMax, logAlphaMin, logAlphaMax, logSigmaSqMin, logSigmaSqMax, empiricalFile), which emits p=3m features, one-hot classes, and standardization parameters. Tune and train the NN classifier with ClassifierCVnn (five-fold cross-validation over log10(lambda) in [-3,3] and gamma in [0,1], batch size 50, 50 epochs, 2 hidden layers) or XGB with ClassifierCVxgb at max_depth=4; RF and SVM train on-the-fly via ranger and liquidSVM. Apply CLOUDeClassifyNN(training_prefix, testing_prefix, num_layers=2) — plus CLOUDeClassifyXGB/RF/SVM for comparison — to write per-event classifications and probabilities files. Judge correctness by comparing predicted classes to known 'Redundant'/'Unique' labels: expect ~97.90% accuracy for the NN, ~96.10% XGB, ~93.60% RF, ~90.45% SVM, and ~85.75% for the LRT baseline, with high power retained even under added noise (SD 0.001–1) and under an alternative theta0 ancestral optimum.

## Examples

```
source("CLOUDe.R"); CLOUDeClassifyNN("ExampleFiles/Training", "ExampleFiles/EmpiricalData", 2)
```

## Evaluation signals

- Classification power (accuracy vs. true simulated labels) must remain high across all four noise SDs (0.001, 0.01, 0.1, 1) with NN best overall
- Balanced test-set accuracies match reported values: NN ~97.90%, XGB ~96.10%, RF ~93.60%, SVM ~90.45%, LRT ~85.75%
- Output .classifications and .probabilities files contain exactly one row per deletion event in the test set
- High power holds on the alternative-scenario test set where theta0 differs from theta1 and theta2 (Supplementary Fig. S3B)
- Shapley analysis should rank the eL (lost-gene) features eL1-eL6 as most important for class discrimination

## Limitations

- liquidSVM must be installed at the pinned version 1.2.0 via install_version("liquidSVM", "1.2.0") or the SVM path may fail
- NN and XGB require prior hyperparameter tuning (ClassifierCVnn/ClassifierCVxgb five-fold CV); RF and SVM only train on-the-fly at classification time
- CLOUDe is defined for two species and assumes classes are distinguishable only through the lost gene's expression optimum; the input must be absolute log10(x+1) expression values
