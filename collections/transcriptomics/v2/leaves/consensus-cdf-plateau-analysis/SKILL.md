# consensus-cdf-plateau-analysis

## Summary

Selects the optimal number of clusters (k) within each parallel run of Recursive Consensus Clustering (RCC) by reading the cumulative distribution function (CDF) plots generated by ConsensusClusterPlus and applying a plateau criterion, followed by cluster-quality gates (stability, overlap, DE genes) and recursive subdivision termination rules.

## When to use

Use when clustering transcriptome data (bulk or single-cell) with an unknown number of clusters and you must algorithmically decide the optimal k and when to stop subdividing clusters, as done inside RCC_clus.

## When NOT to use

- The number of clusters is already known and only needs to be imposed, so no best-k search or CDF plateau analysis is needed
- Input is not a transcriptomic (bulk or single-cell) expression matrix, since RCC's CDF-based k selection was designed and validated for such data
- Computational time is a hard constraint on very large datasets, given RCC's stated limitation that its runtime depends on the underlying consensus clustering with k-means base algorithm

## Inputs

- Gene expression matrix (x) loaded by RCC_clus(x, config_file)
- RCC configuration file (config_file)
- ConsensusClusterPlus consensus clustering results over candidate k values (k-means base algorithm)
- Empirical CDF plots of consensus distributions from ConsensusClusterPlus

## Outputs

- Selected best k per cluster/run satisfying CDF plateau, stability, overlap, and DE-gene criteria
- CDF/delta-area plots used for the k decision
- Cluster assignments at the selected k, feeding recursive subdivision or termination

## How to apply

Load the expression matrix (x) and configuration file exactly as consumed by RCC_clus(x, config_file). Generate consensus clustering results over candidate k values using the ConsensusClusterPlus base algorithm with k-means, as RCC does. Compute the empirical CDF of the consensus distributions for each candidate k and select the best k by requiring the delta-area plateau to satisfy line length >= 30 and slope < 10 degrees, since a plateauing CDF indicates cluster stability. At the selected k, evaluate quality gates: intra-cluster stability > 0.8 and inter-cluster overlap < 0.2, plus a differentially-expressed-gene criterion (e.g. via geneMarkers(inputDir, exprsFile, sampleOrd, outputDir)). Encode recursive subdivision termination so a cluster is no longer subdivided when no candidate k passes the CDF, stability, overlap, and DE-gene criteria. The rationale is that CDF plateau signals consensus stability, while the quality gates prevent biologically meaningless splits.

## Evaluation signals

- On a test expression matrix, the implemented best-k selector returns a k that satisfies the CDF plateau condition (line length >= 30, slope < 10 degrees)
- At the selected k, intra-cluster stability exceeds 0.8 and inter-cluster overlap stays below 0.2
- The differentially-expressed-gene criterion (e.g. via geneMarkers(inputDir, exprsFile, sampleOrd, outputDir)) is satisfied at the chosen k
- The recursion terminates without subdividing a cluster that fails none of the criteria
- The module and unit checks written to rcc_bestk_module.R run successfully on a sample input via RCC_clus(x, config_file)

## Limitations

- RCC's computational time is a limitation; it depends on the underlying base algorithm, which is currently consensus clustering with k-means
- Analysis of large integrated datasets with millions of cells is still a next step and has not yet been demonstrated
- Selection quality depends on CDF plateau heuristics and threshold gates; a cluster is only subdivided when all CDF, stability, overlap, and DE-gene criteria pass
