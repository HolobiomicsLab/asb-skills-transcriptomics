# negative-binomial-deep-boltzmann-machine-training

## Summary

Train a single-cell deep Boltzmann machine (scDBM) with negative binomial likelihood on small pilot scRNA-seq sub-samples (384–2304 cells) using scDBM.jl / BoltzmannMachines.jl in Julia, then generate synthetic counts via Gibbs sampling up to the original study size to support experimental design.

## When to use

Use when you need to generate synthetic scRNA-seq count data from a small pilot dataset (a few hundred to ~2300 cells) with a generative model that avoids the posterior-sampling bias amplification seen in scVI, e.g. for pilot-study-based power analysis.

## When NOT to use

- Data contains batch effects that need correction — the study examined all models without batch correction capabilities, and batch effects currently cannot be learned with scDBMs.
- The goal is dimensionality reduction or batch integration of existing cells (use scvi-tools for those tasks) rather than generating novel synthetic observations from a pilot study.
- The pilot sample may not be representative of the target population (e.g. experimental settings will change), since extrapolation from small to larger datasets relies on that assumption.

## Inputs

- Preprocessed scRNA-seq count matrix (PBMC4k: 4182 cells x 1000 HVGs; Segerstolpe: 2090 cells x 2000 HVGs) with gene names and cluster label files (CSV)
- Random sub-samples of 384, 768, 1152, 1536, 1920, or 2304 cells with 0.7 train/test split

## Outputs

- Trained scDBM model per pilot sub-sample
- Synthetic count matrix generated by Gibbs sampling at the original study's cell count (e.g. 1080 artifacts across 2 datasets x 6 pilot sizes x 30 repetitions in the study)
- UMAP/cluster-label mappings for downstream DBI, ARI, cluster-proportion, and per-gene distribution evaluation

## How to apply

Start from a preprocessed count matrix restricted to highly variable genes (e.g. PBMC4k with 1000 HVGs or Segerstolpe with 2000 HVGs) and optionally draw random sub-samples (each cell drawn with equal probability) at pilot sizes of 384–2304 cells, splitting each into train/test subsets with a 0.7 training proportion. Train the scDBM via the Julia package scDBM.jl (built on BoltzmannMachines.jl, Julia 1.5.0) using two hidden layers with latent dimensionality between two and four and a small learning rate. Refine the regularized Fisher-scoring estimate of the inverse dispersion parameter of the negative binomial likelihood every five epochs during training. After training, generate synthetic observations by Gibbs sampling until the original study's cell count is reached (e.g. 4182 cells for PBMC4k, 2090 for Segerstolpe), repeating over 30 random sub-samples per pilot size for robustness. The rationale is that scDBM showed much lower variability than scVI posterior sampling, which amplifies artifacts of small pilot datasets.

## Evaluation signals

- Confirm that every combination of dataset (2) x model (3) x pilot size (6) x repetition (30) yields a synthetic count matrix with the original study's cell count (1080 artifacts total).
- Assess clustering similarity to ground truth via adjusted Rand index and Davies–Bouldin index after mapping synthetic observations to the original data in UMAP space; scDBM should show low variability compared to scVI posterior sampling.
- Compare per-gene medians, interquartile ranges, coefficients of variation, and proportion of zero counts via mean absolute deviation (MAD) between original and synthetic data.
- Check that mean absolute differences in cluster cell counts between original and synthetic data decrease as pilot size increases from 384 to 2304 cells.
- Verify the inverse dispersion parameter is re-estimated with regularized Fisher scoring every five epochs during training.

## Limitations

- All approaches, including scDBM, overrepresented highly abundant cell types and missed less abundant cell types in the synthetic data.
- scDBM learned univariate gene distributions of most genes but had problems with bimodal gene distributions.
- Batch effects cannot be learned with scDBMs, and all models were examined without using potentially available batch correction capabilities.
- For sparser 10x Genomics datasets (e.g. PBMC4k), inference from small to larger datasets is more challenging than for Smart-seq2 data (e.g. Segerstolpe).
- Downstream label transfer relies on the unverified assumption that synthetic cells mapped to the original data are mapped to the correct clusters.
