# single-cell-multiome-subpopulation-linking

## Summary

A comparative single-cell workflow (sc-compReg) that performs coupled clustering and joint embedding of paired scRNA-seq and scATAC-seq data from two conditions, links subpopulations of the same cell type across conditions, and constructs differential regulatory networks to identify condition-specific hub regulators such as TOX2 in CLL-specific B cells.

## When to use

Use when you have four single-cell data sets (one scRNA-seq plus one scATAC-seq from each of two conditions, e.g. CLL donor vs healthy control) and need to identify and compare condition-specific subpopulations and their regulatory programs.

## When NOT to use

- You have multiple donors per condition — the method currently accommodates one scRNA-seq + one scATAC-seq per condition and does not yet support multiple donors
- Your data are single-condition or lack paired expression/accessibility from both conditions, since the comparative model requires four data sets from two populations
- You want to incorporate bulk HiChIP data into the analysis — sc-compReg does not yet support this (extension planned)

## Inputs

- sample1.rds / sample2.rds containing log2-transformed gene expression matrices (O1, O2) and chromatin accessibility matrices (E1, E2)
- Cluster indices for each sample (O1.idx, E1.idx, O2.idx, E2.idx), e.g. from cnmf clustering
- Gene symbol vectors (symbol1, symbol2) and peak-name files in chr-start-end bed format (peak.name1, peak.name2)
- Motif prior motif_human.rds (or motif_mouse.rds) from the prior_data directory
- MotifTarget.txt loaded via mfbs_load
- PeakName_intersect.txt and peak_gene_prior_intersect.bed generated by sc_compreg_process_data_.sh

## Outputs

- compreg.output with linked subpopulations across the two conditions
- compreg.output$hub.tf[[i]]: hub transcription factor rankings per linked subpopulation, exported as tf_i.txt (tab-separated, row.names=FALSE, quote=FALSE)
- compreg.output$diff.net[[i]]: condition-specific differential regulatory networks, exported as diff_net_i.txt
- Intermediate preprocessing files: PeakName_intersect.txt, peak_gene_prior_intersect.bed, MotifTarget.txt

## How to apply

Load the log2-transformed gene expression (O1/O2) and chromatin accessibility (E1/E2) matrices together with cluster indices (O1.idx/E1.idx/O2.idx/E2.idx) from sample1.rds and sample2.rds. Run the shell script sc_compreg_process_data_.sh on the two peak-name files (chr-start-end bed format) with the appropriate genome_version (hg19/hg38/mm9/mm10) against the prior_data directory, using Bedtools and Homer to generate PeakName_intersect.txt, peak_gene_prior_intersect.bed, and MotifTarget.txt. Load the human motif prior motif_human.rds via readRDS and the MotifTarget.txt via mfbs_load, then call sc_compreg with the O/E matrices, cluster indices, gene symbols, peak names, and motif inputs to fit the comparative regulatory model that links subpopulations across conditions. Identify the condition-specific subpopulation (e.g. CLL-specific B7) from the linked clusters and inspect compreg.output$hub.tf[[i]] and compreg.output$diff.net[[i]]; validate by testing hub TF expression differences across conditions (e.g. one-tailed two-sample t-test, TOX2 p=0.0013).

## Examples

```
bash sc_compreg_process_data_.sh path/to/peak_name1.txt path/to/peak_name2.txt hg19 path/to/prior_data
```

## Evaluation signals

- PeakName_intersect.txt, peak_gene_prior_intersect.bed, and MotifTarget.txt are produced by sc_compreg_process_data_.sh without errors for the chosen genome_version (e.g. hg19)
- sc_compreg returns subpopulation linkage across the two conditions such that the CLL-specific B7 subpopulation is matched to a corresponding healthy-control B cell cluster
- Exported tf_i.txt and diff_net_i.txt exist and contain the expected columns (verified via file checks after write.table with row.names=FALSE, quote=FALSE, tab separator)
- TOX2 is recovered as a hub TF for the tumor-specific B7 subpopulation in compreg.output$hub.tf[[i]], consistent with the published finding
- TOX2 is significantly highly expressed in the CLL group vs healthy control in both case-control studies (one-tailed two-sample t-test, p-value 0.0013)

## Limitations

- Differential regulations discovered by this analysis need to be replicated in additional patients and controls
- The approach does not yet accommodate multiple donors under each of the two conditions to be compared
- sc-compReg does not yet support analysis incorporating bulk HiChIP data (extension planned)
- Bedtools and Homer run on Linux only; R >= 3.6.0 required and large example data must be fetched via git lfs
