# label-based-dynamic-programming-path-extension

## Summary

Tiglon's transcript reconstruction mechanism: a newly developed label-based dynamic path extension program traverses the labeled splice graph (junction edges labeled 1, 2+, or 2-) to recover expressed transcripts, prioritizing high-confidence label-2 elements first and iteratively reweighting edges until full edge coverage.

## When to use

Use when transcript-representing paths must be recovered from a labeled splice graph whose junction edges are annotated by which aligners captured them (1, 2+, 2-), e.g., after integrating Hisat2 and Star BAM alignments.

## When NOT to use

- Input is long-read RNA-seq data (PacBio or Oxford Nanopore) — the current Tiglon version is not compatible with long-read datasets
- Annotation-guided assembly is required — the current Tiglon version has no option to use known transcript annotations to guide assembly
- Input is raw reads or BAMs from aligners other than Hisat(2)/Star — the current version only accepts BAM files generated by Hisat(2) and Star

## Inputs

- Labeled splice graph of a gene locus (nodes = exons, edges = junctions labeled 1, 2+, or 2-), built from integrated alignments
- BAM alignment files generated by different aligners, listed in an input file (Tiglon currently accepts BAMs from Hisat(2) and Star)

## Outputs

- Assembled candidate transcripts in GTF format (e.g., recovered_transcripts.gtf), filtered by min_trans_cov and min_trans_length thresholds

## How to apply

Load the labeled splice graph for each gene locus, where nodes are exons, edges are junctions, and edge labels record whether all employed aligners captured the junction (label 2, with 2+ for identical read patterns and 2- otherwise) or only some did (label 1). Initialize seed paths by descending label priority: paired paths labeled 2+ first, then 2- paired paths, 2+ edges, 2- edges, and finally label-1 elements. Extend each seed with the Exp/Pre/Suc dynamic programming path-extension procedure, choosing the best predecessor/successor continuation at each node of the labeled splice graph. After each extracted path, apply the fmin weight update to traversed edges and reset their labels to 1 so lower-priority elements become eligible in subsequent iterations. Iterate until all graph edges are covered by at least one predicted path, then filter the resulting transcripts with the output thresholds (min_trans_cov default >0, min_trans_length default 500) and write them to GTF.

## Evaluation signals

- Edge-coverage fraction equals 1: every graph edge (junction) is covered by at least one predicted transcript path
- All output transcripts pass the default filters: min_trans_cov > 0 and min_trans_length >= 500 bp
- Output is a well-formed GTF of assembled transcript structures with estimated expression levels
- Transcripts whose splice junctions are split between aligners (each junction captured by Hisat2 or Star but not both) are recovered, which single-aligner assemblers like StringTie2 and Scallop miss

## Limitations

- The current version of Tiglon does not have an option for annotation-guided assemblies
- The current version is not compatible with long-read RNA-seq datasets (e.g., Pacific Biosciences [PacBio] or Oxford Nanopore Technologies [ONT])
- Tiglon currently only accepts BAM files generated by Hisat(2) and Star
- Combining the integrating strategy with a borrowing strategy such as TransBorrow's is proposed future work, not implemented
