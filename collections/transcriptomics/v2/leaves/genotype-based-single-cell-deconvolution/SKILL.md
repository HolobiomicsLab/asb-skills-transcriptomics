# Genotype-based single-cell deconvolution

## Summary

Separates individuals in multi-person biological mixtures by genotyping each 10X scRNA-seq cell (via freebayes variant calling of expressed SNPs) and clustering cells by genotype with the de-goulash Snakemake pipeline, enabling downstream sex, ancestry, and individual identification of contributors.

## When to use

Use when you have 10X scRNA-seq data (possorted_genome_bam.bam + barcodes.tsv) from a multi-person blood mixture, with live cells, and need genotype-based single-cell separation of contributors — especially imbalanced mixtures at ratios up to 1:60.

## When NOT to use

- The mixture cells are fixed or non-living — the 10X Genomics platform requires live cells for successful genetic separation, and fixed-cell platforms have not been tested
- The goal is appearance-trait prediction from the separated contributors — the specific SNPs needed for appearance prediction were not obtained in this approach
- The mixture is from a non-blood tissue — transferability to biological mixtures other than blood has not yet been demonstrated

## Inputs

- 10X scRNA-seq possorted_genome_bam.bam (possorted_genome_trimmed.bam)
- barcodes.tsv from 10X containing the cells to use onwards
- Human reference genome FASTA (hg19 or hg38) and matching *MT.fasta
- regions.txt / MT_regions.txt generated by process_reference.py; freebayes region file via fasta_generate_regions.py
- config.yaml with Snakemake, SNP-filter, merging, and clustering parameters
- For step 2: exome_96_remmapedto38.vcf.gz, 1000G_populations.txt, 1000 Genomes 20130502 VCFs

## Outputs

- Genotyped, genotype-clustered cells per mixture as VCF (output/iter2/cells_merge_clusters.vcf)
- Per-cluster variant calls for downstream statistical analysis
- Forensic likelihood parameters, population/biogeographic ancestry assignment, haplogrep and Yleaf haplogroup results (step 2)

## How to apply

Clone genid/de-goulash and run its two Snakemake steps inside the Docker image geniderasmusmc/de-goulash:1, mounting the working directory at /single-cell. First run process_reference.py on the genome FASTA (hg19/hg38 plus matching *MT.fasta) to generate regions.txt, MT_regions.txt, and the freebayes region file (via fasta_generate_regions.py); point config.yaml at sample_bam, barcodes, genome.fasta, and regions, keeping default SNP filters (dp: 50, qual: 60) and two threshold iterations (thr_cell_1: 10, thr_cell_2: 20 minimal SNPs per cell) with parallel freebayes variant calling. Merge genotyped cells using threshold_coverage: 10 total coverage, threshold_coverage_pos: 5 per selected SNP, and threshold_base_calling: 90, then cluster with the Rscript UMAP rule (n_neighbors: 5, n_components: 300, clusters: 0). Target the final output cells_merge_clusters.vcf (e.g. output/iter2/cells_merge_clusters.vcf); expect clean contributor separation for balanced and imbalanced 2–9 person blood mixtures up to 1:60. For contributor identification and biogeographic ancestry, feed the per-cluster variant calls into Snakemake step 2 using the exome_96_remmapedto38.vcf.gz reference and 1000 Genomes (20130502) population data, plus Yleaf v2.2 (read_depth: 1, quality: 20, base_calling: 90) for paternal lineage.

## Examples

```
docker run -it -v /current/directory/de-goulash/:/single-cell geniderasmusmc/de-goulash:1 output/iter2/cells_merge_clusters.vcf --snakefile Snakefile --configfile config.yaml --cores 1
```

## Evaluation signals

- Final target file output/iter2/cells_merge_clusters.vcf is produced and contains per-cell genotypes plus cluster assignments
- Number of genotype clusters matches the known number of contributors; separated contributors yield correct sex and biogeographic ancestry (maternal, paternal, bi-parental) determinations
- On imbalanced 2-person in silico mixtures (datasets A2/A4), behavior matches the reported limits: clean separation at 1:10–1:40, minor bleed-through at 1:60 (about five minor-component cells misassigned), degraded assignment at 1:80, no separation at 1:99
- SNP calls survive the configured filters (dp: 50, qual: 60) and the per-cell thresholds (thr_cell_1: 10, thr_cell_2: 20 SNPs; merging thresholds coverage 10 / per-SNP 5 / base-calling 90) were applied
- Individual identification of separated contributors reaches court-acceptable statistical certainty when matched against de-novo whole-exome reference data

## Limitations

- The 10X Genomics scRNA-seq platform requires live cells, restricting application to biological mixtures containing living cells; fixed-cell alternatives are untested
- Clear single-cell separation was demonstrated for 2–9 person blood mixtures only up to 1:60; genotyping fails at extreme imbalance (1:99)
- Deconvolution of more than nine individuals is only hypothesized, and success from fewer than 150 cells with deeper sequencing awaits empirical confirmation
- No universal identity SNPs are used, so reference datasets must contain as many SNPs as possible; whole transcriptome sequencing of reference samples to increase identity SNPs was proposed but not done
