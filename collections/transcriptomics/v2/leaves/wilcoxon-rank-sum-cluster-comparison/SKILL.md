# wilcoxon-rank-sum-cluster-comparison

## Summary

SCISSORS' marker gene identification module: a candidate list is generated by Wilcoxon rank-sum differential expression of a target cluster or subcluster against background (rest-of-clusters or closely related subclusters), then filtered by expression percentile in non-target clusters to retain only genes of high specificity to the cell type.

## When to use

Use when a processed Seurat scRNA-seq object with cluster/subcluster labels (e.g. PBMC3k) needs a cluster-specific marker gene list, and genes shared with background clusters must be excluded.

## When NOT to use

- The Seurat object has no cluster or subcluster annotations, so no target-vs-background comparison can be defined
- The goal is reclustering or rare-cell discovery (use SCISSORS' silhouette scoring and semi-supervised reclustering steps, e.g. ComputeSilhouetteScores/getClusters, not marker filtering)
- Differential expression against a bulk or cross-dataset comparison is needed rather than a within-dataset cluster-vs-background contrast

## Inputs

- Processed scRNA-seq Seurat object with cluster annotations (e.g. PBMC3k from SeuratData, normalized and scaled with PCA/UMAP embeddings)
- Target cluster or subcluster label to test against background clusters

## Outputs

- Candidate gene list of positive Wilcoxon rank-sum markers for the target cluster
- Specificity-filtered marker gene table written to markers_filtered.csv

## How to apply

Load the processed Seurat object (PBMC3k prepared via NormalizeData, FindVariableFeatures with vst selection of 2000 features, ScaleData, RunPCA) and confirm the target cluster/subcluster annotation. Build the candidate marker list by running Wilcoxon rank-sum differential expression of the target cluster against background or closely related clusters using FindAllMarkers with test.use = 'wilcox' and only.pos = TRUE, so only positive markers enter the list. For each candidate gene, quantify its expression percentile across the non-target clusters. Remove any gene ranking within the top 10% (user-adjustable) expressed percentile of any non-target cluster, then write the specificity-filtered marker table to markers_filtered.csv. The rationale is the paper's claim that SCISSORS identifies 'marker genes of high specificity to the cell type', rather than merely significant DE genes.

```
markers <- FindAllMarkers(seu_pbmc, test.use = "wilcox", only.pos = TRUE)
```

## Evaluation signals

- Every gene in markers_filtered.csv ranks below the top 10% expressed percentile in every non-target cluster (threshold user-adjustable)
- The candidate stage returned only positive markers — no negative log2FC genes survive from the FindAllMarkers(test.use = 'wilcox', only.pos = TRUE) call
- Filtered genes show high specificity to the target cell type, consistent with the paper's stated goal for the marker module
- markers_filtered.csv exists with one row per retained marker and the target cluster/subcluster annotation matches the Seurat object's Idents

## Limitations

- The top-10% expression percentile cutoff is user-adjustable, so specificity-stringency results vary with the chosen threshold
- Filtering removes genes that are also highly expressed in any non-target cluster, which can discard valid markers shared by closely related subclusters
- Quality depends on the input cluster annotations — the workflow card shows the 2000-feature vst / 10-dimension PBMC3k preparation as the reference setup, and the paper warns that 'even small differences in analysis and parameter choosing can greatly alter clustering results'
