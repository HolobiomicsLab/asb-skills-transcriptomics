# marginal-resampling-null-embedding

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Generates data-driven null datasets for EMBEDR by marginal resampling — each gene's expression values are independently drawn with replacement from that gene's empirical distribution — preserving per-gene marginals while destroying inter-gene correlations, so embedding quality can be hypothesis-tested against signal-less data.

## When to use

Use when you need a biologically realistic null expectation for embedding quality (EMBEDR p-values) from single-cell omics data such as Tabula Muris scRNA-seq, before fitting data and null embeddings with a DRA like t-SNE or UMAP.

## When NOT to use

- The dataset is non-normalized — the article states EMBEDR's null-generation process has not been extended to non-normalized datasets
- The analysis requires preserving inter-gene (joint/correlation) structure in the null — marginal resampling deliberately destroys it
- You need parametric or theoretical null distributions — the article notes no theoretical description of the null tails or principled parameterization exists

## Inputs

- Preprocessed scRNA-seq count matrix (cells x genes, e.g. Tabula Muris FACS bone marrow from GEO GSE109774) as a numpy array
- High-dimensional data matrix (e.g. mnist2500_X.txt) when reproducing the MNIST example
- EMBEDR class parameters: project_dir, DRA ('tsne' or 'UMAP'), perplexity/nearest_neighbors (default 10% of samples), n_data_embed, n_null_embed

## Outputs

- Null data matrix of identical shape with preserved per-gene marginals (e.g. null_data_matrix.npy)
- Marginally-resampled null embeddings generated by the EMBEDR fit
- Empirical null EES distribution used to compute per-cell EMBEDR p-values
- Overlay plots of real vs. null per-gene marginal distributions (Figure 3B-style validation)

## How to apply

Load the preprocessed count matrix (e.g. ~4,800 Tabula Muris FACS bone marrow cells, cells x genes) into a numpy array. For every gene column independently, draw values with replacement from that column's empirical distribution to build a null data matrix of identical shape, which destroys inter-gene correlations while preserving per-gene marginals. Pass the data through the EMBEDR class (DRA='tsne', backed by openTSNE, with perplexity set to the default 10% of the number of samples and n_data_embed/n_null_embed of 3-10/1); EMBEDR generates the marginally-resampled null internally and caches intermediates in a projects directory. Validate the null by overlaying real and null per-gene marginal distributions (histograms/KDEs, Figure 3B) and by confirming the null matrix shape matches the input. The null EES distribution then supplies the empirical null against which per-cell EMBEDR p-values are computed.

## Related tools

- **EMBEDR** (Python package whose fit method generates the marginally-resampled null dataset and its embedding alongside data embeddings) — github.com/ejohnson643/EMBEDR
- **numpy** (Loading the count matrix and drawing each gene column's values with replacement from its empirical distribution)
- **openTSNE** (Backing implementation for t-SNE embeddings of the real data and the null dataset)
- **scipy** (Required dependency of the EMBEDR package used in the resampling/embedding workflow)

## Examples

```
from EMBEDR import EMBEDR; import numpy as np; X = np.loadtxt('./data/mnist2500_X.txt').astype(float); embObj = EMBEDR(project_dir='./'); embObj.fit(X)
```

## Evaluation signals

- Null matrix has the same shape as the input count matrix
- Real and null per-gene marginal distributions visually coincide (near-identical histograms/KDEs, as in Figure 3B)
- Joint (correlation) distribution of genes is altered in the null, confirming inter-gene correlations were destroyed
- Resulting per-cell EMBEDR p-values all lie within [0, 1]
- Null embeddings are generated once per fit (n_null_embed, default 1; 3-10 data embeddings recommended) and cached in the project directory

## Limitations

- p values have finite resolution since null distributions are computed empirically; the number of nulls bounds the lower limit of p values
- No theoretical description of the tails of the null distributions exists and no principled parameterization method is available
- The null-generation process has not been extended to non-normalized datasets
- Runtime depends on the speed of the DR algorithm implementations used to generate many null embeddings
