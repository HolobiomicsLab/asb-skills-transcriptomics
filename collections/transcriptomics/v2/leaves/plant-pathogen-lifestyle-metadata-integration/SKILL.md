# plant-pathogen-lifestyle-metadata-integration

## Summary

Integrates literature-curated lifestyle metadata (plant pathogen vs. non-plant-pathogen) with a BiG-SCAPE GCF absence/presence matrix at 0.70 distance, testing each GCF by Fisher's exact test with Benjamini-Hochberg correction to identify biosynthetic gene cluster families significantly associated with the plant pathogenic lifestyle in Burkholderia/Paraburkholderia and Pseudomonas.

## When to use

Use when a binary GCF presence/absence matrix (e.g., from BiG-SCAPE at 0.70 distance) must be tested for statistical enrichment against per-genome lifestyle labels to find lifestyle-associated biosynthetic clusters.

## When NOT to use

- When the analysis targets gene-level lifestyle association (pLAGs), which uses the >70% group presence / >2 log2 fold change threshold rather than the GCF-level Fisher test
- When the goal is lifestyle prediction/classification by random forest rather than enrichment testing of already-assigned lifestyle groups
- When the GCF matrix was clustered at a different BiG-SCAPE distance than 0.70, since the reported associations are tied to the 0.70 distance matrix

## Inputs

- GCF absence/presence matrix from BiG-SCAPE clustering at 0.70 distance
- Per-genome lifestyle metadata annotations collected from the literature (plant pathogen vs. non-plant-pathogen)

## Outputs

- plant_pathogen_associated_gcfs.csv — ranked table of significant plant-pathogen-associated GCFs with p-values, Benjamini-Hochberg adjusted p-values, group presence, and biosynthetic class annotations

## How to apply

Load the GCF absence/presence matrix generated by BiG-SCAPE clustering at 0.70 distance together with lifestyle metadata annotations collected for each genome from the literature. For each GCF, build a 2x2 contingency table of presence/absence versus plant-pathogen versus non-plant-pathogen genomes and compute an enrichment p-value with base R fisher.test(). Retain only GCFs meeting the >15% group presence threshold so associations are restricted to clusters reasonably represented in the lifestyle group, then correct per-GCF p-values with p.adjust() using the Benjamini-Hochberg method and flag GCFs significant at P < 0.01. Annotate significant GCFs with their biosynthetic class (e.g., NRPS, NRPS-PKS hybrid) so known families like syringofactin and syringomycin and the novel plant-pathogen-associated NRPS-PKS hybrid cluster can be identified in the ranked output.

## Related tools

- **bacLIFE** (Workflow generating the GCF absence/presence matrix and lifestyle annotations that feed the Fisher's exact test analysis) — https://github.com/Carrion-lab/bacLIFE
- **R (base fisher.test and p.adjust)** (Statistical testing: per-GCF 2x2 contingency Fisher's exact test and Benjamini-Hochberg multiple-testing correction)

## Examples

```
Rscript -e 'tab <- table(gcf_present, plant_pathogen); p <- fisher.test(tab)$p.value; padj <- p.adjust(p, method="BH")'
```

## Evaluation signals

- Output reproduces the associations reported in Supplementary Datasets 7-8
- The syringofactin and syringomycin NRPS families are recovered among the significant GCFs
- The novel plant-pathogen-associated NRPS-PKS hybrid cluster entry appears in the ranked table and its annotation contains the substring 'NRPS'
- All retained GCFs pass the >15% group presence threshold
- Adjusted p-values (Benjamini-Hochberg) for reported hits are below the P < 0.01 significance flag

## Limitations

- Restricting to >15% group presence excludes rare GCFs, so associations are limited to clusters reasonably represented in the lifestyle group
- Associations are computational predictions from absence/presence statistics; the paper notes such results serve for hypothesis generation and require experimental validation (e.g., site-directed mutagenesis and plant bioassays)
- Metadata labels depend on lifestyle annotations collected from the literature, and genomes were quality-filtered upstream (>90% completeness, <5% contamination by CheckM)
