# position-specific-gapped-kmer-feature-ablation

## Summary

Reproduces the iRNA5hmC-PS feature ablation: evaluating all 15 non-empty combinations of the four position-specific feature modes (A = Ps-k-mer, B = PsM(G)D, C = PsD(G)M, D = PsM(G)M(G)M) plus GC-content under 10-times 5-fold cross-validation with default scikit-learn Logistic Regression, after group-wise feature-importance selection.

## When to use

Use when benchmarking which subsets of position-specific (gapped) k-mer feature blocks contribute to classifier performance on 41-nt RNA sequences, e.g. reproducing a Table 3-style ablation with Accuracy/Precision/Sensitivity/Specificity/F1/MCC.

## When NOT to use

- Input is already a reduced/selected feature table from a different feature family (e.g. k-mer frequency features from a prior study) rather than position-specific blocks generated from raw 41-nt sequences
- The goal is benchmarking against an external predictor (e.g. iRNA5hmC) or evaluating on the independent test set, rather than internal feature-mode ablation
- Sequences are not 41 nt — the position-specific matching against consecutive-residue-groups and the webserver protocol assume 41-nt RNA sequences

## Inputs

- Dataset.csv — 41-nt RNA sequences with 5hmC site labels from the iRNA5hmC-PS GitHub repository
- All_Features_Dataset.csv — 19,877-column engineered feature matrix generated by Feature Generation.ipynb
- Feature-mode membership map defining blocks A (Ps-k-mer + GC-content), B (PsM(G)D, 7104 features), C (PsD(G)M, 7104 features), D (PsM(G)M(G)M, 2304 features)

## Outputs

- table3_ablation_results.csv — 15-row metrics table (Accuracy, Precision, Sensitivity, Specificity, F1-Score, MCC with standard deviations) per feature-mode combination
- Per-combination selected feature subsets from the group-wise importance strategy
- cross_validation_results.csv — full cross-validation metrics incl. AUROC/AUPR for the best combination

## How to apply

Load Dataset.csv, generate the feature blocks with the Feature Generation notebook logic (Ps-k-mer modes PsM/PsD/PsT with 164/640/2496 binary indicators, PSG k-mer modes PsM(G)D and PsD(G)M with 7104 each, PsM(G)M(G)M with 2304, plus a GC-content feature, totaling 19,877 columns in All_Features_Dataset.csv). For each of the 15 non-empty combinations of modes A, B, C, and D (always including GC-content), assemble the feature matrix and label vector, then apply the group-wise feature importance calculation strategy (Random Forest importances per feature group) to select a small discriminative subset. Train scikit-learn Logistic Regression with default hyperparameters under 10-times repeated 5-fold cross-validation per combination, computing Accuracy, Precision, Sensitivity, Specificity, F1-Score, and MCC with standard deviations. The rationale is to quantify each mode's marginal contribution; the paper's best combination is A+B+C+D, so the full-feature row serves as the anchor for validation.

## Evaluation signals

- The A+B+C+D combination row reproduces the reported values: Accuracy 78.3, Precision 78.0, Sensitivity 80.0, Specificity 79.5, F1-score 0.78, MCC 0.56 (within expected cross-validation variation)
- Feature counts per pattern type match Table 2: 164 (PsM) + 640 (PsD) + 2496 (PsT) + 7104 (PsM(G)D) + 7104 (PsD(G)M) + 2304 (PsM(G)M(G)M) + GC-content = 19,877 features per sequence
- Exactly 15 non-empty combinations of the four modes A–D are evaluated, each reported with mean and standard deviation for all six metrics
- AUROC and AUPR for the full combination are approximately 0.86 under 10-times 5-fold cross-validation
- The full combination A+B+C+D outperforms the other 14 combinations in the reproduced table, as reported in Table 3

## Limitations

- Position-specific features do not work well in conjunction with existing frequency-based counterparts; the authors defer combining both via a feature subspace ensemble approach to future work
- Cross-validation metrics vary between repetitions, so exact per-run values differ from the reported means; tolerance-based comparison is required
- Efficacy of the framework on other RNA modification site identification problems has not been evaluated
