# maximum-mean-discrepancy-computation

## Summary

Computes the maximum mean discrepancy (MMD) between real scRNA-seq cells and cells generated by simulation methods (scGAN, Splatter, SUGAR) to benchmark distributional fidelity, complemented by random-forest discrimination AUC (RF-AUC) as a realism check.

## When to use

Use when benchmarking synthetic or simulated scRNA-seq data (e.g. from scGAN, Splatter, SUGAR) against a real reference dataset such as Fresh 68k PBMCs (Donor A) to quantify how close the generated distribution is to the real one.

## When NOT to use

- The real-vs-generated comparison targets realism of t-SNE embeddings or trajectory structure rather than distributional fidelity metrics
- Only scGAN/cscGAN training or generation is needed without any benchmarking against Splatter or SUGAR baselines

## Inputs

- Pre-processed Fresh 68k PBMCs (Donor A) training cells in .h5 or .h5ad format
- Synthetic count matrices generated by Splatter from the same training cells
- Synthetic datasets generated by SUGAR (KrishnaswamyLab/SUGAR) from the same training cells
- scGAN-generated cells saved as .h5ad from a trained model checkpoint

## Outputs

- MMD values between real training cells and each method's generated cells
- RF-AUC values from random forest real-vs-generated discrimination per method
- Compiled benchmark table mmd_rf_auc_benchmark.csv

## How to apply

Load the pre-processed Fresh 68k PBMCs (Donor A) training cells in .h5/.h5ad format (converted and split into TFRecord via the scGAN `--process` flag), then generate a matched synthetic set with the trained scGAN model using `main.py --generate --cells_no ...` with a saved model checkpoint. Run Splatter and SUGAR (KrishnaswamyLab/SUGAR) on the same training cells to produce equally sized synthetic datasets. Compute the MMD between the real training cells and each method's generated cells, and additionally train a random forest classifier to discriminate real versus generated cells, recording the resulting AUC (RF-AUC). Compile the values into a benchmark table (mmd_rf_auc_benchmark.csv) and compare against the published references: scGAN MMD 0.87 / AUC 0.65, SUGAR MMD 59.45 / AUC 0.98, Splatter MMD 129.52, with real-data positive controls at MMD 0.03 and AUC 0.52 — low MMD and RF-AUC near 0.5 indicate realistic generation.

```
python main.py --param parameters. --generate --cells_no 1000 500 0 200 --model_path path/to/my/model --save_path scgan_cells.h5ad
```

## Evaluation signals

- scGAN-generated cells yield MMD ≈ 0.87 and RF-AUC ≈ 0.65 against the PBMC training cells (Supplementary Tables 2-3)
- Real-data positive control gives MMD ≈ 0.03 and RF-AUC ≈ 0.52; SUGAR baseline gives MMD 59.45 / AUC 0.98 and Splatter MMD 129.52
- The generated scGAN set is matched in size to the requested --cells_no counts (one int per cluster index) and saved as a readable .h5ad file
- All MMD and RF-AUC values compile into mmd_rf_auc_benchmark.csv without missing methods
- t-SNE plots produced from the validation set plus an equal number of generated cells visually overlap, consistent with the published non-conditional t-SNE reference

## Limitations

- MMD and RF-AUC reference values are specific to the Fresh 68k PBMCs (Donor A) dataset and the published scGAN/Splatter/SUGAR configurations; other datasets or hyperparameters will give different scales
- The mechanism enabling cscGAN to generate cells from very small subpopulations (e.g. 16 cells) is only speculated, not established, so benchmarks on tiny subpopulations may be unreliable
- Test set is not used by the scGAN pipeline by default; comparisons rely on the training/validation splits defined in parameters.
