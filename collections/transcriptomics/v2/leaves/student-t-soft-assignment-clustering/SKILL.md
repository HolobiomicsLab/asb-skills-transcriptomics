# student-t-soft-assignment-clustering

## Summary

DeepCCI's unsupervised cell-clustering step: an AE+GCN joint embedding is converted into soft cluster assignments Q via a Student's t-distribution kernel, refined against a target distribution P, and optimized end-to-end with KL-divergence losses to cluster single cells from scRNA-seq data.

## When to use

Use when scRNA-seq data (CSV or h5) must be clustered without cell labels and the goal is an unsupervised, graph-aware embedding with soft cell-to-cluster assignments.

## When NOT to use

- Cells already carry trusted labels — the Interaction model path (Feature.py --label_mode True) is the appropriate branch instead
- Input is a raw count matrix not yet preprocessed — run preprocess.py first to generate the model feature file
- Goal is CCI inference rather than cell clustering — the cluster model alone does not predict interactions

## Inputs

- Preprocessed scRNA-seq feature file generated by preprocess.py (from CSV or h5 input, e.g. Yan GSE36552 or Quake_10x_Limb_Muscle GSE109774)
- KNN cell graph (K=10) over cells
- Hyperparameters: epsilon=0.5 (balanced representations), pretrain_epoch=50, alpha=0.0001, beta=0.001

## Outputs

- Soft assignment matrix Q (Student's t-distribution) and target distribution P
- Joint AE+GCN layer-wise cell embedding
- cluster_assignments.csv containing cell cluster assignments

## How to apply

Preprocess the scRNA-seq file (e.g. Yan GSE36552 CSV or Quake_10x_Limb_Muscle GSE109774 h5) with preprocess.py to build the model feature file. Construct a KNN cell graph with K=10 and jointly train the autoencoder and GCN with balanced representations (epsilon=0.5), pretraining for 50 epochs on CUDA. Compute soft assignments Q using the Student's t-distribution kernel, derive the target distribution P from Q, and optimize the end-to-end loss L = alpha*L_clu + beta*L_gcn + L_res with alpha=0.0001 and beta=0.001 until assignments stabilize. The combined AE and GCN representations are merged layer by layer to obtain a more informative embedding, and the final cluster assignments are written to cluster_assignments.csv.

## Related tools

- **DeepCCI** (Framework whose Cluster.py implements the KNN graph, AE+GCN joint training, Student's-t soft assignment (Q), target distribution (P), and KL-divergence loss optimization) — https://github.com/JiangBioLab/DeepCCI
- **Python 3.7.4** (Runtime environment for Cluster.py and preprocess.py inside the deepcciEnv conda environment)
- **conda** (Creates and activates the deepcciEnv virtual environment with Python 3.7.4 and pip)
- **pip** (Installs DeepCCI requirements.txt dependencies)

## Examples

```
python Cluster.py --name Yan --pretain True --pretrain_epoch 50 --device cuda
```

## Evaluation signals

- cluster_assignments.csv is produced with one cluster label per cell
- Soft assignments Q converge toward the Student's-t target distribution P (KL-divergence loss decreases during optimization)
- Pretraining runs the specified 50 epochs on CUDA with epsilon=0.5 balanced representations before fine-tuning
- End-to-end loss respects the weighting L = alpha*L_clu + beta*L_gcn + L_res with alpha=0.0001 and beta=0.001
- Downstream clusters are biologically meaningful on benchmark datasets (e.g. Yan GSE36552 embryonic stages, Quake_10x_Limb_Muscle GSE109774)

## Limitations

- With pre-training, clustering takes about 25 minutes; without pre-training (using the pretain_model folder) it takes about 5 minutes, so users without a pretrained model must budget for pretraining
- Requires CUDA for the documented runtimes; preprocessing time scales with the size of the scRNA-seq file (about 5-10 minutes)
- The Python environment is pinned to Python 3.7.4 and R-side packages (Seurat, igraph, NMF, CellChat) are needed for downstream processing and visualization
