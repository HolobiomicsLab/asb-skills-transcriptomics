# mean-variance-fit-assessment

## Summary

Validates that simulated single-cell count matrices realistically reproduce the distributional properties of a real scRNA-seq reference by comparing them with countsimQC, focusing on the per-gene mean-variance relationship and the fraction of zeros per gene. In the CTMM paper this gate was applied before simulations were used to assess robustness to sequencing depth and number of cells.

## When to use

Use when single-cell counts have been simulated from a real scRNA-seq dataset (e.g., the Cuomo et al. 2020 iPSC differentiation data) and you must verify distributional realism — mean-variance trend and per-gene zero fraction — before trusting the simulation for benchmarking CTMM or similar variance models.

## When NOT to use

- Simulated data are bulk or pseudobulk aggregates rather than single-cell level counts — the per-gene zero-fraction criterion is specific to sparse single-cell count matrices.
- The real reference has not been quality-controlled and normalized, or lacks cell-level metadata (cell, individual, cell type), so there is no trustworthy baseline for the distributional comparison.
- The goal is to validate downstream statistical inference (e.g., CTMM test calibration, type I error, power) rather than the realism of the simulated input counts themselves.

## Inputs

- Quality-controlled, normalized single-cell counts of the real reference dataset (Cuomo et al. 2020 iPSC differentiation scRNA-seq)
- Cell-level metadata for the real data (cell, individual, cell type)
- Simulated single-cell count matrices generated by bin/sim and parameterized from the real data (per Supplementary Note Section 3.4)

## Outputs

- countsimqc_report.html — HTML comparison of simulated vs. real count distributions
- Per-gene mean-variance and zero-fraction concordance figures analogous to Supplementary Fig. 10
- An accept/reject decision on simulation realism before downstream CTMM robustness benchmarks

## How to apply

Load the quality-controlled, normalized single-cell counts and cell-level metadata (cell, individual, cell type) of the real reference — here the iPSC differentiation data of Cuomo et al. 2020 Nat Commun processed by the bin/cuomo scripts. Generate the simulated single-cell count matrices with the simulation scripts in bin/sim, orchestrated via the Snakemake Snakefile, parameterized from the real data as described in Supplementary Note Section 3.4. Run countsimQC in R, invoked through the Snakemake pipeline, so each simulated dataset is compared against the real iPSC reference on per-gene distributions. Inspect the countsimQC report for concordance between simulated and real data in (1) the mean-variance distribution and (2) the fraction of zeros per gene, and write the final HTML comparison to countsimqc_report.html. Accept the simulation only if the report shows the simulated counts closely matching the real data on both criteria, reproducing the agreement seen in Supplementary Fig. 10.

## Related tools

- **countsimQC** (R tool that generates the HTML comparison report of simulated vs. real single-cell count distributions (mean-variance, per-gene zero fraction))
- **Snakemake** (Orchestrates the simulation (bin/sim) and the countsimQC comparison step through the Snakefile)

## Evaluation signals

- countsimqc_report.html exists and contains side-by-side simulated-vs-real comparisons of the per-gene mean-variance distribution.
- The report shows concordance in the fraction of zeros per gene between simulated and real iPSC counts, matching Supplementary Fig. 10.
- Mean-variance spread of simulated counts overlaps that of the real iPSC reference across genes (no systematic over- or under-dispersion).
- Simulations were generated from the parameterization of the real data (Supplementary Note Section 3.4) via bin/sim under the Snakefile, not from arbitrary or unparameterized settings.
- The acceptance criterion is explicitly applied: simulation is only used for CTMM robustness assessment if the countsimQC fit is good on both criteria.

## Limitations

- The acceptance criterion covers only two distributional aspects — mean-variance relationship and per-gene zero fraction — other count-distribution features (e.g., cell-level library size distributions) are not gated by this check.
- Realism is established relative to a single reference (Cuomo et al. 2020 iPSC differentiation data); generalization to other tissues or cohorts is not verified by this comparison.
- The comparison is only as good as the upstream QC/normalization of the real data and the fidelity of the simulation parameterization in Supplementary Note Section 3.4.
