# tnseq-log2fold-change-threshold-filtering

## Summary

A data-driven filtering step from the Scorecard Python library that selects extreme (or moderate) expression variations in Tn-seq/RNA-seq pairwise comparisons by screening log2 fold changes and adjusted p-values, instead of preselecting genes. Applied to Staphylococcus aureus USA300 transposon insertion sequencing data it isolates quadrant-assigned genes such as VAN-linked down-regulated loci and over-expressed SAUSA300_RS03525, SAUSA300_RS04560, SAUSA300_RS08475.

## When to use

Use when a CSV of pre-computed log2 fold changes and adjusted p-values per gene must be screened for extreme variations across pairwise antibiotic-vs-control conditions (e.g., VAN, CPT, DEL, LZD vs untreated) using dual fold-change and significance cut-offs.

## When NOT to use

- The dataset lacks pre-computed fold-change and adjusted p-value columns — the README states 'your dataset should contain pre-computed fold change values (and related adjusted p-values) as columns in the CSV file'
- A standard four-way plot suffices and no extreme-value stratification is needed — 'multiplication factor' set to 1 'will produce a four-way plot, not the scorecard'
- Only one experimental condition is available, since the scorecard compares pairwise conditions and merges information across comparisons

## Inputs

- CSV file with one gene/gene-ID column (e.g., SAUSA300 gene IDs) and per-comparison columns of log2 fold changes and adjusted p-values, header-matched to the param_dict FC/padj column names
- param_dict generated by scorecard_functions.generate_parameters() with base_dir, filename, gene_name, FC cond x/y, padj cond x/y, th_fold_change, multiplication factor (1.5), th_significance (0.05), save_dir, CSV delimiter

## Outputs

- Per-comparison single-quadrant plots storing statistically significant entries per quadrant
- Reconstructed full scorecards per pairwise comparison (default fig_size)
- JSON outcome files per comparison in save_dir
- quadrant_gene_counts.csv from count_frequencies, tabulating entries/genes per quadrant per comparison

## How to apply

Build the parameter dictionary with scorecard_functions.generate_parameters(), setting base_dir/filename of the Dataset 1 CSV, the gene_name column, and the exact 'FC cond x/y' and 'padj cond x/y' column names for each antibiotic-vs-control pair. Set th_significance to 0.05 (padj <= 0.05) and use dual log2 fold-change thresholds between 2 and 3 via 'multiplication factor' 1.5 (setting it to 1 degenerates to a four-way plot, not a scorecard). Load the CSV as a Pandas DataFrame with data_loading, then run scorecard_functions.scorecard(df,param_dict) to assign statistically significant entries to single quadrants, reconstruct the full scorecard with reconstruct_scorecard, and tabulate genes per quadrant with count_frequencies. The rationale is to shrink the massive records of RNA-seq/Tn-seq data by screening both effect size and significance, bypassing experience-driven gene preselection.

## Related tools

- **scorecard_functions** (Python library providing generate_parameters, data_loading, scorecard, reconstruct_scorecard, scorecard_legend, count_frequencies used to apply the fold-change/padj threshold filtering) — github.com/m89p067/Scorecard
- **Pandas** (Loads the CSV of log2 fold changes and adjusted p-values into a DataFrame passed to the scorecard functions)

## Examples

```
import scorecard_functions; param_dict=scorecard_functions.generate_parameters(); df=scorecard_functions.data_loading(param_dict); scorecard_functions.scorecard(df,param_dict)
```

## Evaluation signals

- count_frequencies output (quadrant_gene_counts.csv) reproduces reported region-of-interest values, e.g., Q3 region D counts for VAN-vs-CPT/DEL/LZD and Q1 region A for CPT-vs-LZD, DEL-vs-CPT, DEL-vs-LZD
- All genes assigned to a region of interest have padj <= 0.05 and fold changes between the two thresholds (2 and 3 with multiplication factor 1.5)
- Comparison involving VAN mainly yields down-regulated genes in quadrant Q3, while non-VAN comparisons yield markedly over-expressed genes such as SAUSA300_RS03525, SAUSA300_RS04560, SAUSA300_RS08475
- JSON outcome files exist in save_dir for each of the four comparisons and the reconstructed scorecard matches the union of individual quadrant plots
- CSV header column names exactly match the 'FC cond x/y' and 'padj cond x/y' entries in param_dict

## Limitations

- No version number is stated for the Python library or Python itself, hindering reproducibility
- The CSV must already contain pre-computed log2 fold changes and adjusted p-values; the library does not compute them (dataset 1 values came from TRANSIT resampling with beta-geometric normalization and Benjamini-Hochberg correction)
- Setting 'multiplication factor' to 1 degenerates the scorecard into a standard four-way plot, losing the extreme-value stratification
