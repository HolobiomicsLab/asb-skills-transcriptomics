# PAGA force-directed graph visualization

## Summary

Recompute a partition-based graph abstraction (PAGA) with a force-directed layout on single-cell populations (e.g. the GSE72857 mouse bone marrow erythrocyte trajectory) to assess whether cellular-state structure is preserved — here, after restoring a downsampled erythrocyte population with scGAN-generated cells.

## When to use

Use when you need to reconstruct or validate a coarse-grained trajectory/pseudo-time graph over scRNA-seq clusters, e.g. to check that augmented or downsampled cell populations preserve the original topology of a differentiation graph.

## When NOT to use

- The analysis goal is generation of realistic scRNA-seq cells itself rather than trajectory/graph visualization — use the scGAN/cscGAN training and generation workflow instead
- Only raw mtx/tsv count matrices are available — they must first be converted to .h5/.h5ad with the provided Jupyter notebook before PAGA
- The population has no meaningful cluster structure or differentiation trajectory to abstract

## Inputs

- Augmented AnnData (.h5ad) containing real downsampled cells plus scGAN-generated cells (e.g. 13 real + 137 generated erythrocytes)
- Original full-population AnnData (.h5) reference trajectory (150 node-4 erythrocyte cells from GSE72857 mouse bone marrow)
- Cluster/cell-type labels used to build the PAGA partitions

## Outputs

- PAGA graph abstraction of the augmented population
- Force-directed layout embedding of the PAGA graph
- Figure comparable to Supplementary Fig. 17G-I showing restored pseudo-time topology

## How to apply

Take the augmented .h5ad AnnData — e.g. 13 real node-4 erythrocyte cells from GSE72857 mouse bone marrow plus 137 scGAN-generated cells restored to the original 150-cell population — and compute the PAGA graph and force-directed layout using theislab/paga (available via Scanpy tl.paga / pl.paga). Rationale: PAGA maps coarse-grained connectivity of the cell-state manifold, so the restored graph can be qualitatively compared against the original (Supplementary Fig. 17G-I); the downsampled 13-cell population alone loses the erythrocyte trajectory structure that augmentation is meant to restore. Prior to PAGA, cells were generated by training an scGAN on the downsampled data via the scGAN pipeline (main.py --process then --train, loss monitored with Tensorboard), and 137 cells generated with --generate --cells_no 137. Success is judged by visual comparison: generated cells should occupy the erythrocyte node region and the topology should reproduce the published panels.

## Related tools

- **theislab/paga** (Computes the partition-based graph abstraction and force-directed layout used to visualize and validate the restored erythrocyte pseudo-time trajectory) — https://github.com/theislab/paga
- **scGAN** (Trained on the downsampled bone marrow data to generate the 137 cells that augment the population prior to PAGA reconstruction) — https://github.com/imsb-uke/scGAN

## Examples

```
python main.py --param parameters. --generate --cells_no 137 --model_path path/to/my/model --save_path generated_cells.h5ad
```

## Evaluation signals

- The restored force-directed graph reproduces the topology of Supplementary Fig. 17G-I
- Generated cells occupy the erythrocyte node region of the graph
- The generated .h5ad file exists at the specified --save_path and contains 137 cells
- The augmented population restores the original 150-cell erythrocyte population size (13 real + 137 generated)
- Qualitative comparison of node connectivity against the original full-population PAGA graph

## Limitations

- Validation is qualitative — visual comparison to the published figure panels rather than a quantitative topology metric
- Generation quality depends on the downsampled training data; the mechanism enabling generation from very small subpopulations (e.g. 16 cells) is only speculated, not established
- The test set is unused in the scGAN pipeline and should be set to size 0 unless needed for custom experiments
