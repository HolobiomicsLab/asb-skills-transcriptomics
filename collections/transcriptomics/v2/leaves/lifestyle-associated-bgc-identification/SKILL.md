# lifestyle-associated-bgc-identification

## Summary

Identifies biosynthetic gene cluster families (GCFs) statistically associated with a bacterial lifestyle (e.g., plant pathogenicity) by applying Fisher's exact tests to a BiG-SCAPE GCF absence/presence matrix with Benjamini-Hochberg correction, as done in bacLIFE for Burkholderia/Paraburkholderia and Pseudomonas.

## When to use

Use when a BiG-SCAPE GCF absence/presence matrix at 0.70 distance is available together with lifestyle metadata per genome, and the goal is to rank GCF families significantly enriched in one lifestyle group (e.g., plant pathogens vs non-plant-pathogens).

## When NOT to use

- The input is a gene-cluster (homolog) absence/presence matrix rather than a BiG-SCAPE GCF matrix — use the gene-level lifestyle-associated gene (LAG) analysis with 70% group presence and >2 log2 fold change thresholds instead.
- GCFs are not yet clustered (only raw antiSMASH BGC annotations exist) — run BiG-SCAPE at 0.70 distance to build the absence/presence matrix first.
- The analysis goal is lifestyle prediction/classification via the random forest model rather than identification of associated BGCs.

## Inputs

- BiG-SCAPE GCF absence/presence matrix (clustering at 0.70 distance) over the input genomes
- Lifestyle metadata annotations per genome collected from the literature (e.g., plant-pathogen vs non-plant-pathogen labels)
- Biosynthetic class annotations for each GCF (e.g., NRPS, NRPS-PKS hybrid)

## Outputs

- plant_pathogen_associated_gcfs.csv — ranked table of significant lifestyle-associated GCFs with p-values, BH-adjusted p-values, and group presence
- List of significant GCFs annotated by biosynthetic class (e.g., syringofactin and syringomycin NRPS families, novel NRPS-PKS hybrid cluster)

## How to apply

Load the GCF absence/presence matrix generated by BiG-SCAPE clustering at 0.70 distance alongside lifestyle metadata annotations collected from the literature for each genome. For each individual GCF, construct a 2x2 contingency table of presence/absence versus the lifestyle contrast (plant-pathogen vs non-plant-pathogen) and compute an enrichment p-value with the base R fisher.test() function. Retain only GCFs meeting the >15% group presence threshold so associations are restricted to clusters reasonably represented in the lifestyle group, then correct per-GCF p-values with p.adjust(method='BH') and flag GCFs significant at P < 0.01. Annotate significant GCFs with their biosynthetic class (e.g., NRPS, NRPS-PKS hybrid) so known families like the syringofactin and syringomycin NRPS lipopeptide clusters — critical for pathogenicity — and novel hybrid clusters can be identified in the ranked table.

## Related tools

- **bacLIFE** (Workflow that generates the BiG-SCAPE GCF absence/presence matrix at 0.70 distance and lifestyle metadata used for the enrichment tests) — https://github.com/Carrion-lab/bacLIFE
- **R (base fisher.test and p.adjust)** (Performs the per-GCF 2x2 Fisher's exact enrichment test and Benjamini-Hochberg multiple-testing correction)
- **BiG-SCAPE** (Clusters BGCs into GCF families at 0.70 distance to build the absence/presence matrix)

## Examples

```
pvals <- apply(gcf_matrix, 1, function(x) fisher.test(table(x, lifestyle))$p.value); padj <- p.adjust(pvals, method="BH"); sig <- which(padj < 0.01)
```

## Evaluation signals

- The output reproduces the associations reported in Supplementary Datasets 7-8 of the bacLIFE paper.
- The ranked table recovers the syringofactin and syringomycin NRPS families in Pseudomonas, both known to be critical for pathogenicity.
- The novel plant pathogen-associated NRPS-PKS hybrid cluster entry contains the substring 'NRPS'.
- All reported GCFs pass the >15% group presence filter and have BH-adjusted P < 0.01.
- Each GCF p-value derives from a valid 2x2 contingency table of GCF presence/absence versus lifestyle group.

## Limitations

- Associations are restricted to GCFs present in >15% of the lifestyle group, so rare but potentially important clusters are filtered out.
- Statistical associations at BiG-SCAPE 0.70 GCF-family level do not by themselves prove functional involvement in pathogenicity; the paper resorted to site-directed mutagenesis and plant bioassays for validation of LAGs.
- Lifestyle labels depend on metadata collected from the literature, which may be incomplete or inconsistent across genomes.
- The 0.70 BiG-SCAPE distance threshold determines GCF granularity; results (family composition and enrichment) are sensitive to this cutoff.
