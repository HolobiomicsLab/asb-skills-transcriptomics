# splice-junction-linear-rna-normalization

## Summary

Quantifies linear RNA expression from ribosomal-RNA depleted RNA-seq by counting fragments mapped to canonical splicing junction (SJ) sites and normalizing them to FPB (fragments per billion mapped bases), so linear expression is on the same scale as circRNA BSJ-derived FPBcirc and the ratio CIRCscore = FPBcirc/FPBlinear is meaningful.

## When to use

Use when you need linear RNA expression estimates from ribo− RNA-seq that are directly comparable to circRNA expression at the same gene loci, e.g. to compute a CIRCscore from paired FPBcirc/FPBlinear values.

## When NOT to use

- Input is poly(A)−/ribo− or RNase R-treated RNA-seq: polyadenylated linear RNAs are largely depleted there, so SJ-based linear quantification and CIRCscore evaluation are inaccurate
- Input data is poly(A)+ RNA-seq, which depletes circRNAs and cannot support balanced circular-vs-linear comparison
- The goal is circRNA detection alone without a comparable linear expression background (plain CIRCexplorer2 suffices)

## Inputs

- HISAT2-mapped BAM from ribo− paired-end RNA-seq (hisat_aligned.bam, no unmapped reads)
- Circular RNA annotation file from CIRCexplorer2 (>=2.3.6)
- refFlat-format gene annotation file
- Paired-end FASTQ mates and hg38 genome FASTA, HISAT2 index, Bowtie1 index, and annotation GTF when starting from clear_quant

## Outputs

- Per-locus quantification table (output_dir/quant/quant.txt) with fields chrom, start, end, strand, readNumber, geneName, FPBcirc, FPBlinear, and CIRCscore
- Normalized FPBlinear values representing cognate linear RNA expression per gene locus

## How to apply

Start from the HISAT2-mapped BAM (hisat_aligned.bam) generated by clear_quant, ensuring unmapped reads were discarded before quantification. Using the CIRCexplorer2 circRNA calls and a refFlat gene annotation, collect RNA-seq fragments whose mapping spans linear RNA-specific canonical SJ sites within each circRNA locus, excluding fragments already attributed to the circRNA-specific BSJ. Normalize SJ fragment counts by locus size and library scale to obtain FPBlinear, and optionally apply the --threshold parameter (default 1) so only circRNAs with FPB above that cutoff are used to filter linear SJ, and the --ratio parameter (default 1) to adjust the circ-to-linear comparison; -l can be enabled to consider all reads' lengths. The resulting FPBlinear is written alongside FPBcirc and readNumber in the quantification table, and CIRCscore is computed as FPBcirc divided by FPBlinear. The rationale is that SJ-mapped fragments estimate the cognate linear RNA background so highly-expressed circRNAs with low linear expression become identifiable.

## Examples

```
circ_quant -c CIRCexplorer2_output.txt -b hisat_aligned.bam -r annotation.refFlat -o quant.txt
```

## Evaluation signals

- quant.txt exists and contains the expected schema fields chrom, start, end, strand, readNumber, geneName, FPBcirc, FPBlinear, and CIRCscore
- CIRCscore equals FPBcirc divided by FPBlinear for every locus in the output table
- FPBlinear values are positive and reflect SJ-mapped fragment counts normalized per locus and library scale
- The input hisat_aligned.bam contains no unmapped reads, as required by circ_quant
- Filtering behavior matches the --threshold (default 1) and --ratio (default 1) parameters supplied

## Limitations

- CIRCscore cannot be applied to poly(A)−/ribo− or RNase R-treated datasets because linear RNA quantification is unreliable there
- Most circRNAs overlap their cognate linear RNAs except at BSJ sites, so linear quantification depends on SJ sites shared with the circRNA locus
- The README does not state explicit software version numbers for CLEAR itself; CIRCexplorer2 >=2.3.6 and HISAT2 >=2.0.5 are the stated minimums
