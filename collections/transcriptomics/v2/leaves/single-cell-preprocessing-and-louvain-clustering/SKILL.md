# single-cell-preprocessing-and-louvain-clustering

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Standard scRNA-seq preprocessing and graph-based initial clustering as defined by scCAD: retain genes expressed in at least three cells, log-normalize with cell-specific size factors, project onto 40 PCs, build a k=15 KNN graph, and run Louvain to obtain initial (I-)clusters that serve as the starting point for downstream cluster decomposition.

## When to use

Use when raw scRNA-seq count matrices (cells x genes) need preprocessing and initial Louvain clustering prior to rare cell-type detection, e.g., as stage 1 of the scCAD cluster-decomposition workflow.

## When NOT to use

- Input is already a normalized/feature-selected expression matrix or a precomputed cluster assignment — re-filtering at 3 cells and re-normalizing would double-transform the data
- The goal is rare-type scoring alone with an existing trusted partition; then only scCAD's decomposition and isolation-forest steps are needed, not re-clustering
- Data are bulk RNA-seq or spatial-resolved assays without single-cell count structure (cells x genes with sparse expression)

## Inputs

- scRNA-seq count matrix (cells x genes), e.g., loaded from an .h5 file containing 'X' (expression), 'Y' (labels), 'gn' (gene names), 'cn' (cell names)
- Optional gene names and cell name vectors (auto-generated by scCAD if omitted)

## Outputs

- I-clusters: initial Louvain cluster label assignments for every cell (np.array[n cells])
- Normalized, gene-filtered expression matrix used for PCA and graph construction
- Per-cell sub-cluster labels and rare sub-cluster results for downstream anomaly scoring (result, score, degs_list)

## How to apply

Load the expression matrix (cells in rows, genes in columns; e.g., from an .h5 file with 'X', 'Y', 'gn', 'cn' arrays) and filter out genes expressed in fewer than three cells. Normalize via log-normalization with cell-specific size factors and a log2 transform after adding a pseudo-count of 1. Run PCA to retain the top 40 principal components, construct a nearest-neighbor graph with k=15, and apply Louvain clustering to produce I-clusters. These I-clusters feed scCAD's iterative decomposition (clusters larger than R=1% of cells) and merging (threshold THM = median of nearest-neighbor center distances). Rationale: one-time global clustering misses rare cell types, so this stage must faithfully preserve signal for later decomposition.

## Related tools

- **scCAD** (Primary implementation: its scCAD() entry point performs gene filtering, log-normalization, PCA, KNN graph, and Louvain initial clustering before cluster decomposition) — github.com/xuyp-csu/scCAD
- **Scanpy** (Dependency (v1.9.1 in requirements.txt) providing preprocessing, PCA, and graph-based clustering primitives)
- **Seurat** (Cited as the commonly used comprehensive clustering baseline that this preprocessing+Louvain stage parallels)

## Examples

```
result, score, sub_clusters, degs_list = scCAD.scCAD(data=data, dataName='Jurkat', cellNames=cellNames, geneNames=geneNames, save_path='./')
```

## Evaluation signals

- No genes expressed in fewer than three cells remain in the matrix after filtering
- PCA yields exactly the top 40 principal components and the KNN graph uses k=15 before Louvain
- Louvain returns non-trivial I-clusters covering all cells; in the scCAD benchmark these I-clusters show an average dominant-type occupy rate of 0.283 before decomposition
- The full demo on 1%Jurkat.h5 (1540 293T cells + 16 Jurkat cells) completes in roughly 40 seconds and returns result, score, sub_clusters, degs_list without errors
- Downstream merging with THM = median of nearest-neighbor center distances raises average rare-type dominant-cluster proportion from 0.283 (I-clusters) to 0.704 (M-clusters), confirming the initial clustering was suitable

## Limitations

- Default parameters (rare_h=0.01, merge_h=0.3, overlap_h=0.7, k=15, 40 PCs) were tuned for the 25 benchmark scRNA-seq datasets; other settings may need adjustment
- One-time global clustering can overlook rare cell types — the article notes 'these rare cell types may be overlooked during the clustering phase', which is why decomposition must follow
- Requires enough RAM for in-memory operations on the full cells x genes matrix; tested only on Linux (Ubuntu 16.04.7) and macOS (Monterey 12.6.3) with Python 3.7.13
