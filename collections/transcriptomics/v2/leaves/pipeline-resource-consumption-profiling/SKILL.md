# pipeline-resource-consumption-profiling

## Summary

Benchmarks the de-goulash Snakemake/Docker pipeline against deconvolution-only tools (ScSplit, Souporcell, Vireo) on identical in silico 10X scRNA-seq mixtures, recording donor-assignment accuracy alongside peak RAM usage and wall-clock time per tool per mixture.

## When to use

Use when comparing de-goulash's deconvolution accuracy and runtime/memory cost against ScSplit, Souporcell, and Vireo on the same in silico 2-person or 9-person scRNA-seq mixtures with known donor labels.

## When NOT to use

- The sample is not a multi-person single-cell mixture (the article's approach targets 2- to 9-person blood mixtures, not single-source samples)
- The 10X scRNA-seq input contains dead/fixed cells — the article notes the 10X genomics platform 'requires live cells for successful genetic separation'
- Only accuracy is needed with no resource comparison — then a direct deconvolution workflow without timing/memory profiling is sufficient

## Inputs

- possorted_genome_bam.bam from 10X for each in silico mixture (2-person 5000-cell and 9-person)
- barcodes.tsv from 10X listing the cells to use
- genome.fasta (hg19/hg38) with matching *MT.fasta, regions.txt and MT_regions.txt generated by process_reference.py
- region file for parallel freebayes generated with fasta_generate_regions.py
- config.yaml holding all deconvolution and analysis parameters (dp, qual, thr_cell_1/2, threshold_coverage, threshold_coverage_pos, threshold_base_calling, n_neighbors, clusters)

## Outputs

- output/iter2/cells_merge_clusters.vcf per mixture (cluster/genotype assignment of cells to contributing donors)
- Per-tool donor-assignment accuracies against known ground-truth donor labels
- Peak RAM usage and wall-clock time per tool per mixture
- pipeline_comparison_summary.csv aggregating accuracy and resource-consumption values

## How to apply

Populate config.yaml with the paper's parameters (SNP filtering dp=50, qual=60; iteration-1/2 minimum SNPs per cell thr_cell_1=10 and thr_cell_2=20; merging thresholds threshold_coverage=10, threshold_coverage_pos=5, threshold_base_calling=90; clustering n_neighbors=5, clusters=0), then execute the de-goulash deconvolution step through the geniderasmusmc/de-goulash:1 Docker container with Snakemake targeting output/iter2/cells_merge_clusters.vcf for each mixture, followed by the statistical analysis step via Snakefile_analysis. In parallel, run ScSplit and Vireo on the identical 2-person and 9-person mixture inputs so all tools see the same cell barcodes and reads. Compute donor-assignment accuracy for every tool against the ground-truth donor labels, and profile peak RAM usage and wall-clock time per tool per mixture. Assemble accuracy and resource-consumption values into pipeline_comparison_summary.csv; expected reproduction points include ScSplit failing to assign 45.16% of donor-1 cells in the two-person 5000-cell mixture and Vireo matching de-goulash accuracy for the 9-person mixture.

## Related tools

- **De-goulash** (Pipeline under benchmark; its Snakemake deconvolution step (run in Docker, freebayes-based genotyping with dp=50/qual=60, two iterations of thr_cell thresholds, then merging and UMAP clustering) is the accuracy and resource baseline being profiled) — https://github.com/genid/de-goulash.git
- **Docker** (Execution container (geniderasmusmc/de-goulash:1) in which each Snakemake run is launched, enabling consistent resource measurement across tools)
- **freebayes** (Haplotype-based variant caller invoked in parallel within the de-goulash step; its SNP calls (filtered at dp=50, qual=60) feed the cell clustering whose runtime is profiled) — https://github.com/nh13/freebayes
- **Snakemake** (Workflow manager that orchestrates the deconvolution (Snakefile) and analysis (Snakefile_analysis) steps whose per-run wall-clock time is measured)

## Examples

```
docker run -it -v /current/directory/de-goulash/:/single-cell geniderasmusmc/de-goulash:1 output/iter2/cells_merge_clusters.vcf --snakefile Snakefile --configfile config.yaml --cores 1
```

## Evaluation signals

- output/iter2/cells_merge_clusters.vcf is produced for each mixture without workflow failure
- Reproduced accuracy figures match reported values: ScSplit leaves 45.16% of donor-1 cells unassigned in the two-person mixture; Vireo accuracy equals de-goulash for the 9-person mixture
- pipeline_comparison_summary.csv contains, for every tool × mixture combination, an accuracy value plus non-negative peak-RAM and wall-clock-time entries
- All tools are run on the identical mixture inputs and de-goulash runs use the config.yaml parameters from the article (dp=50, qual=60, thr_cell_1=10, thr_cell_2=20, threshold_coverage=10, threshold_coverage_pos=5, threshold_base_calling=90, n_neighbors=5, clusters=0)
- All four tools successfully deconvolute the two-person 5000-cell mixture (assignment consistent with 2 ground-truth donors), per the paper's finding

## Limitations

- Only mixtures with up to nine individuals were tested; deconvolution of more than nine contributors was not experimentally confirmed
- The 10X genomics scRNA-seq platform requires live cells, limiting application to biological mixtures containing living cells
- Transferability to biological mixtures other than the blood mixtures used here was not demonstrated
- Successful deconvolution from fewer than 150 cells, or with deeper sequencing at very low cell numbers, requires future empirical confirmation
