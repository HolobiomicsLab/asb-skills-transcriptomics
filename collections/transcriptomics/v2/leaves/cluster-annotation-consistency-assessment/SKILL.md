# cluster-annotation-consistency-assessment

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

A method for quantifying how consistently an automatic annotation tool (e.g. scCATCH's findcelltype against CellMatch) recovers manually assigned cell type labels per cluster, and for exposing pseudo marker genes (genes significantly upregulated in at least two clusters) generated by one-against-all marker identification (e.g. Seurat's Wilcoxon rank-sum test) that impair annotation accuracy.

## When to use

Use when evaluating whether one-against-all cluster marker gene identification produces pseudo marker genes and how many clusters an automatic annotator (scCATCH/CellMatch) labels consistently with manual ground-truth labels on a clustered scRNA-seq dataset.

## When NOT to use

- When clusters have already been annotated via a paired-comparison scheme guaranteeing markers upregulated in only one cluster — pseudo marker gene impairment is not expected and consistency assessment adds little
- When the tissue of interest is poorly covered by the CellMatch reference database, since limited references — not pseudo marker genes — may drive incorrect annotation
- When the goal is to evaluate cell-based (per-cell) annotation methods such as SingleR or CellAssign rather than cluster-based marker gene annotation

## Inputs

- scRNA-seq count matrix with per-cell cluster labels (e.g. Gierahn PBMC dataset from scCATCH_performance_comparison tutorial materials)
- Manually assigned cell type labels per cluster (ground truth)
- CellMatch tissue-specific cell taxonomy reference database

## Outputs

- pbmc_marker_genes.csv — per-cluster marker gene table including flagged pseudo marker genes (CCL22, SWAP70, KLRF1)
- pbmc_annotation_consistency.csv — per-cluster annotation agreement summary and overall cluster consistency percentage

## How to apply

Load the clustered scRNA-seq count matrix (e.g. the Gierahn PBMC dataset from the scCATCH performance comparison tutorial) and build the analysis object with createscCATCH(data, cluster). Run one-against-all paired cluster comparisons with Seurat's Wilcoxon rank-sum test via findmarkergene(), keeping genes with log10 fold change >= 0.25, p < 0.05, expressed in >= 25% of cells; then flag pseudo marker genes significantly upregulated in at least two clusters rather than one (e.g. CCL22, SWAP70, KLRF1). Annotate each cluster with findcelltype() against the CellMatch reference (353 cell types, 686 subtypes, 184 tissue types) and record which clusters match the manually assigned cell type labels. Write the marker gene table (pbmc_marker_genes.csv) and the per-cluster annotation agreement summary (pbmc_annotation_consistency.csv); compute cluster consistency as the fraction of clusters whose automatic annotation agrees with the manual label (e.g. 2/5 = 40% on Gierahn PBMC, with only cluster 2, T cells, and cluster 5, monocytes, correctly annotated).

## Related tools

- **scCATCH** (Provides createscCATCH() to build the analysis object, findmarkergene() for one-against-all marker identification, and findcelltype() for automatic annotation against CellMatch used to measure annotation consistency) — https://github.com/ZJUFanLab/scCATCH
- **Seurat** (Supplies the one-against-all Wilcoxon rank-sum marker gene identification whose pseudo marker gene output is being assessed for impact on annotation accuracy)

## Examples

```
obj <- createscCATCH(data = sc_data, cluster = sc_cluster); obj <- findmarkergene(obj, species = 'Human', marker = cellmatch, tissue = 'PBMC', cancer = 'normal'); obj <- findcelltype(obj)
```

## Evaluation signals

- pbmc_annotation_consistency.csv reproduces 40% cluster consistency with only clusters 2 (T cells) and 5 (monocytes) correctly annotated on the Gierahn PBMC dataset
- pbmc_marker_genes.csv contains the pseudo marker genes CCL22, SWAP70, and KLRF1, each significantly upregulated in at least two clusters
- All retained marker genes meet the filter log10 fold change >= 0.25, Wilcoxon p < 0.05, and expression in >= 25% of cells
- Every cluster receives a top-1 cell type assignment from findcelltype() scored against CellMatch
- Annotation agreement is computed per cluster against the manually assigned cell type labels, so the consistency fraction is verifiable cluster by cluster

## Limitations

- scCATCH performance majorly depends on the reference database; a limited CellMatch reference potentially led to incorrect annotation of cell types
- Inadequate clustering analysis (too many or too few cells per cluster) would introduce errors into cell type annotation
- Pseudo marker genes arising from one-against-all comparisons may lead to incorrect cell type annotation
