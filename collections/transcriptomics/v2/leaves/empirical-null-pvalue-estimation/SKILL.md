# empirical-null-pvalue-estimation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

EMBEDR-style empirical hypothesis testing for dimensionality reduction: a null distribution of an embedding-quality statistic (EES) is generated by marginal resampling, and each sample receives an empirical p value indicating whether its embedding reflects real high-dimensional structure rather than algorithm-induced noise.

## When to use

Use when you need per-sample empirical p values that separate real structure in a DR embedding (t-SNE/UMAP) from algorithm-induced distortions, e.g. on Tabula Muris bone marrow scRNA-seq.

## When NOT to use

- Input is a non-normalized dataset — the article notes EMBEDR's null-generation process has not been extended to non-normalized data
- A single global DR-quality estimate suffices and per-cell/local error estimates are unnecessary
- You need very small p values (below ~1/n_null_embed) — empirical nulls give finite p-value resolution bounded by the number of null embeddings

## Inputs

- High-dimensional data matrix as a numpy array (e.g. FACS-sorted Tabula Muris bone marrow scRNA-seq counts for ~4,800 cells from GEO GSE109774, or MNIST mnist2500_X.txt)
- Optional per-cell type annotations (e.g. Tabula Muris data_ingest metadata from czbiohub tabula-muris) for grouping p-value trajectories

## Outputs

- Per-cell EMBEDR p-value table (all values within [0, 1])
- t-SNE/UMAP embedding colored by EMBEDR p value (e.g. embedr_pvalue_embedding.png)
- Per-cell-type median/90th-percentile p-value summaries across a perplexity/kEff sweep (e.g. figure6_celltype_summary.csv/png)

## How to apply

Generate a signalless null dataset via marginal resampling and embed both the data and the null with the chosen DRA (e.g. openTSNE-backed t-SNE, FIt-SNE-accelerated), setting perplexity to ~10% of the number of samples and n_data_embed=3-10, n_null_embed>=1; the EMBEDR class caches kNN graphs and affinity matrices in a projects directory. For each cell, compute the neighborhood-correspondence EES in the original high-dimensional space vs. the projection, then take the fraction of null EES* statistics smaller than the observed EES as the empirical p value, averaging across the Nembed data embeddings to yield a single per-cell quality metric p_i. Render the embedding colored by these p values (embObj.plot()), or run an EMBEDR_sweep over perplexity/kEff values and summarize with sweep_boxplot/sweep_lineplot to find per-cell-type or sample-wise optimal scales via fit_samplewise_optimal. p values are bounded to [0, 1]; their resolution is set by the number of null embeddings generated.

## Related tools

- **EMBEDR** (Python package implementing marginal-resampling null generation, EES-based empirical p-value computation, and p-value-colored embedding plots via the EMBEDR/EMBEDR_sweep classes) — https://github.com/ejohnson643/EMBEDR
- **openTSNE** (Backend DRA (custom variation) used to generate the data and null t-SNE embeddings compared against the null EES distribution)
- **FIt-SNE** (Fast t-SNE implementation used when fftw is installed, accelerating the many data/null embeddings the empirical test requires) — https://github.com/KlugerLab/FIt-SNE

## Examples

```
from EMBEDR import EMBEDR; embObj = EMBEDR(project_dir='./'); embObj.fit(X); embObj.plot()
```

## Evaluation signals

- All per-cell EMBEDR p values lie within [0, 1]
- The p value equals the fraction of null EES* statistics smaller than the observed EES, averaged across the Nembed data embeddings
- Output figure (e.g. embedr_pvalue_embedding.png) exists and coloring matches the computed per-cell p values
- Re-running with more null embeddings increases the resolution (lowers the bound) of reported p values
- Sweep summaries reproduce known qualitative patterns (e.g. macrophages best embedded near kEff~150, granulocytes and B cells near kEff~1200)

## Limitations

- Finite resolution of calculated p values: null distributions are empirical, so the number of nulls bounds the lower limit on attainable p values
- No theoretical description of the tails of the null distributions or principled parameterization exists
- EMBEDR's null-generation process has not been extended to non-normalized datasets
