# differential-regulatory-network-inference

## Summary

Infers condition-specific gene regulatory networks from paired scRNA-seq and scATAC-seq of two conditions using the sc-compReg comparative model, which links subpopulations across conditions and tests differential regulatory relations to nominate hub TFs (e.g., TOX2 for the CLL tumor-specific B7 B cell subpopulation).

## When to use

Use when you have one scRNA-seq plus one scATAC-seq sample from each of two conditions (e.g., a CLL donor vs a healthy control, as log2-transformed O/E matrices with cluster indices) and need subpopulation-specific differential regulatory networks and hub TF rankings.

## When NOT to use

- You have multiple donors per condition — the method was developed for one scRNA-seq + one scATAC-seq sample per condition, and the authors note that extending to multiple donors is a next step pending data availability.
- You need to incorporate bulk HiChIP data — sc-compReg does not yet support this type of analysis.
- Your environment is Windows or lacks Linux Bedtools and Homer — the peak-to-gene and motif preprocessing shell scripts require Bedtools (Linux) and Homer (Linux).

## Inputs

- log2-transformed scRNA-seq expression matrices (O1, O2) and scATAC-seq accessibility matrices (E1, E2) for two conditions
- cluster indices for expression and accessibility cells (O1.idx, E1.idx, O2.idx, E2.idx) from cnmf joint clustering
- gene symbol vectors (symbol1, symbol2) and peak name files in chr-start-end bed format
- human or mouse motif prior (motif_human.rds or motif_mouse.rds from prior_data)
- MotifTarget.txt with motif names, weights, and matches, loaded via mfbs_load
- PeakName_intersect.txt and peak_gene_prior_intersect.bed generated by sc_compreg_process_data_.sh

## Outputs

- linked (matched) subpopulations of the same cell type across the two conditions
- hub TF rankings per subpopulation (compreg.output$hub.tf[[i]], exported as tf_i.txt)
- condition-specific differential regulatory networks per subpopulation (compreg.output$diff.net[[i]], exported as diff_net_i.txt)
- likelihood-ratio test statistics for differential regulation with p-value computation and FDR control

## How to apply

Load sample1.rds and sample2.rds containing log2-transformed gene expression and chromatin accessibility matrices (O1/E1, O2/E2), cluster indices (O1.idx, E1.idx, O2.idx, E2.idx), gene symbols, and peak names. Run the shell script sc_compreg_process_data_.sh on the two peak-name files (chr-start-end bed format) with genome_version in {hg19, hg38, mm9, mm10} against the prior_data directory, using Bedtools and Homer, to generate PeakName_intersect.txt, peak_gene_prior_intersect.bed, and MotifTarget.txt. Load motif_human.rds via readRDS and the MotifTarget.txt file via mfbs_load, then call sc_compreg with the O/E matrices, cluster indices, symbols, peak names, motif names/weights/matches, motif.file, and the paths to the intersect/prior files to fit the comparative regulatory model and link subpopulations across the two conditions. For each linked population i, inspect compreg.output$hub.tf[[i]] and compreg.output$diff.net[[i]], and export them via write.table as tf_i.txt and diff_net_i.txt with row.names=FALSE, quote=FALSE, and tab separator.

## Examples

```
bash sc_compreg_process_data_.sh path/to/peak_name1.txt path/to/peak_name2.txt genome_version path/to/prior_data
```

## Evaluation signals

- The preprocessing script produces the three expected files: PeakName_intersect.txt, peak_gene_prior_intersect.bed, and MotifTarget.txt.
- Exported tf_i.txt and diff_net_i.txt exist for each linked population i and contain the expected columns (row.names=FALSE, quote=FALSE, tab separator).
- TOX2 is recovered as a hub regulator of the CLL-specific B7 tumor-specific B cell subpopulation, consistent with the published result.
- TOX2 expression is significantly higher in the CLL group vs healthy control (one-tailed two-sample t-test, p-value 0.0013) in both independent case-control comparisons.
- Differential regulatory relations carry computed p-values with FDR control over the likelihood-ratio statistic.

## Limitations

- Differential regulations discovered this way need to be replicated by additional patients and controls.
- The method does not yet accommodate multiple donors under each of the two conditions to be compared.
- sc-compReg does not yet support analysis incorporating bulk HiChIP data.
- Bedtools and Homer are Linux-only dependencies, and example data require git lfs to download.
