# Enriched-term interpretation for RNA modification genes

## Summary

Interprets a gene list carrying predicted RNA modification sites (here pseudouridine/Ψ sites predicted by MU-PseUDeep at >0.99 precision) by running GO, pathway, and disease over-representation enrichment with clusterProfiler, quantifying GO semantic similarity with GOSemSim, and visualizing term-gene relationships as a ClueGO network in Cytoscape.

## When to use

Use when you have a gene list derived from transcriptome-wide prediction of modification sites (e.g. 2441 genes with MU-PseUDeep-predicted Ψ sites) and need to identify which molecular functions, pathways, or diseases are over-represented.

## When NOT to use

- The input is already a set of enriched terms rather than a gene list — term-similarity network construction (GOSemSim/ClueGO) alone would be appropriate, not a new over-representation run.
- The predicted-site gene list has not been filtered by a defined confidence threshold (here precision >0.99), making the gene set unstable across parameter choices.
- The organism is not human and no protein-coding background universe for that species is available, since the paper uses the human protein-coding transcriptome as background.

## Inputs

- Gene list containing predicted Ψ sites (e.g. from Supplemental_table2.csv, MU-PseUDeep human transcriptome scan at >0.99 precision)
- Background universe gene list (human protein-coding transcriptome)
- GO ontology database accessible via GOSemSim/clusterProfiler (e.g. org.Hs.eg.db)

## Outputs

- GO / pathway / disease over-representation results table (enriched terms, p-values, gene counts)
- Pairwise GO semantic similarity score matrix between enriched genes (GOSemSim)
- Cytoscape/ClueGO gene-gene network with edges weighted by GO semantic similarity (e.g. Fig. 6-style figure)

## How to apply

Load the gene list (e.g. genes containing predicted Ψ sites from Supplemental_table2.csv, generated by scanning the human transcriptome with a precision threshold of >0.99) and run over-representation enrichment using clusterProfiler for GO terms, pathways, and diseases, with the human protein-coding transcriptome as the background universe rather than all genes. Next, compute pairwise GO semantic similarity scores between enriched genes using GOSemSim to quantify functional relatedness beyond simple term overlap. Construct a gene network in Cytoscape with the ClueGO plugin where each edge weight is the GO semantic similarity score, allowing clusters of functionally coherent genes to emerge. Validate the result by checking that enriched terms reproduce known biology for the modification — here, nucleotide and protein binding GO categories plus neurodegeneration-related pathways.

## Related tools

- **MU-PseUDeep** (Upstream producer of the predicted-Ψ-site gene list that serves as the enrichment input) — https://github.com/smk5g5/MU-PseUDeep
- **clusterProfiler** (Runs GO, pathway, and disease over-representation enrichment on the predicted-Ψ-site gene list against the human protein-coding background)
- **GOSemSim** (Computes pairwise GO semantic similarity scores between enriched genes for network edge weights)
- **Cytoscape** (Hosts the gene network built from GO semantic similarity edges)
- **ClueGO** (Cytoscape plugin used to construct and visualize the gene network with GO semantic similarity edges)

## Examples

```
Rscript -e 'library(clusterProfiler); ego <- enrichGO(gene = psi_genes, universe = pc_genes, OrgDb = org.Hs.eg.db, ont = "MF")'
```

## Evaluation signals

- Enriched GO terms include nucleotide-binding and protein-binding categories (e.g. 'guanyl-nucleotide exchange factor activity', 'DNA-binding', 'Protein-binding' as in Fig. 6).
- Enriched pathways include neurodegeneration-related terms, matching the abstract's finding.
- The background universe equals the human protein-coding transcriptome, not the whole genome or all GENCODE entries.
- Every edge in the Cytoscape/ClueGO network carries a GOSemSim semantic similarity score as its weight.
- The input gene count matches the number of genes with predicted Ψ sites (2441) derived from the >0.99 precision threshold scan.

## Limitations

- Findings depend on the upstream prediction quality: MU-PseUDeep predictions are computational, and only 284 genes already had experimentally validated Ψ sites documented in RMBase, so enrichment may partly reflect prediction bias.
- No source code or webserver was available for the comparison method iPseU-CNN, so alternative prediction sets could not be cross-validated for enrichment consistency.
- Detailed per-gene genomic-region information is only available in the supplemental file, so the enrichment input cannot be fully reconstructed from the main text alone.
