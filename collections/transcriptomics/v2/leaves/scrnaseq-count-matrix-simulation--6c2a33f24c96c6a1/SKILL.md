# scrnaseq-count-matrix-simulation

## Summary

Reproduce the pLDA package's simulation example, which generates a simulated scRNA-seq count matrix where genes are words, cells are documents, and latent topics represent biological functions, then fit the penalized LDA model to it. This provides a controlled testbed for validating topic-word and cell-topic estimation before applying pLDA to real scRNA-seq data.

## When to use

Use when you need a simulated scRNA-seq gene-by-cell count matrix to validate penalized Latent Dirichlet Allocation (pLDA) topic modeling, or to sanity-check topic-word probability estimation on data with known latent structure.

## When NOT to use

- The input is already an unstructured document corpus (plain-text bags of words) — the pLDA adaptation here is specific to scRNA-seq counts with genes as words and cells as documents
- The goal is clustering cells by existing annotations rather than estimating latent topics — pLDA's topics are meant to be interpretable with biological functions, not predefined labels
- You cannot build the package vignettes (build_vignettes=TRUE fails), since the simulation example is only accessible via browseVignettes('pLDA')

## Inputs

- Simulated scRNA-seq count matrix generated by the pLDA vignette code (genes as words, cells as documents)
- pLDA R package installed from GitHub (wuxiaotiankevin/pLDA) with vignettes built

## Outputs

- topic_word_matrix.csv — estimated topic-word probability matrix (genes × topics)
- cell_topic_proportions.csv — per-cell topic proportion matrix (cells × topics)

## How to apply

Install the pLDA package from GitHub with devtools::install_github("wuxiaotiankevin/pLDA", build_vignettes=TRUE) so the vignettes are built, then load it with library(pLDA). Open the simulation example via browseVignettes('pLDA') and execute the vignette code that generates the simulated scRNA-seq count matrix, structured with genes as words, cells as documents, and latent biological functions as topics. Fit the penalized LDA model to this matrix, which estimates topic-word probabilities and per-cell topic proportions; the penalty increases the robustness of the estimation. Export the fitted topic-word probability matrix as topic_word_matrix.csv and the per-cell topic proportion matrix as cell_topic_proportions.csv. Validate that both CSVs exist, are non-empty, and that their dimensions match the number of simulated genes/topics and cells/topics respectively from the vignette example.

## Related tools

- **pLDA** (R package that implements the penalized Latent Dirichlet Allocation model; provides the simulation example vignette and the fitting routine that estimates topic-word probabilities and per-cell topic proportions) — github.com/wuxiaotiankevin/pLDA
- **devtools** (Used to install pLDA from GitHub with build_vignettes=TRUE so the simulation example vignette is available)
- **R** (Execution environment for loading pLDA, running the vignette simulation, fitting the model, and exporting the CSV outputs)

## Examples

```
library(devtools); install_github("wuxiaotiankevin/pLDA", build_vignettes=TRUE); library(pLDA); browseVignettes('pLDA')
```

## Evaluation signals

- Both topic_word_matrix.csv and cell_topic_proportions.csv exist and are non-empty
- Dimensions of topic_word_matrix.csv match the number of simulated genes × number of topics from the vignette example
- Dimensions of cell_topic_proportions.csv match the number of simulated cells × number of topics from the vignette example
- Rows of each topic-word and cell-topic matrix can be interpreted as probability distributions (non-negative entries consistent with topic-word probabilities and per-cell topic proportions)
- The fitted topics are interpretable with biological functions, as pLDA is designed to produce

## Limitations

- The simulation example is only accessible through the package vignettes (browseVignettes('pLDA')), so the vignettes must be built at install time (build_vignettes=TRUE)
- The pLDA model is adapted from the LDA generative probabilistic model originated in natural language processing; its assumptions (genes as words, cells as documents) may not suit all scRNA-seq analysis goals
- The README notes the package is maintained by Xiaotian (Kevin) Wu with contact at Brown University; the paper was listed as 'in preparation' in the README, so methodological details may live primarily in the published article (DOI 10.1007/s12561-021-09304-8)
