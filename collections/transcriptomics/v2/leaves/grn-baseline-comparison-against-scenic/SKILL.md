# grn-baseline-comparison-against-scenic

## Summary

Benchmark regulon-like gene modules (RGMs) from CEFCON against pySCENIC regulons on the hESC, mESC, and mHSC lineage datasets, scoring both by GO_BP/KEGG enrichment precision and NMI of AUCell-based cell clustering to demonstrate CEFCON's superiority in gene module identification (Fig. 5b-d).

## When to use

Use when a GRN/gene-module method needs a functional benchmark against SCENIC regulons on single-cell lineages, comparing enrichment precision and NMI of clustering.

## When NOT to use

- Input GRNs or driver regulators have not yet been generated by an upstream CEFCON run (the benchmark assumes precomputed lineage-specific GRNs with edge_threshold_avgDegree=8)
- The data do not contain a developmental cell lineage trajectory with reference cell-type labels, since NMI cannot be computed without ground-truth labels
- The goal is GRN edge-level accuracy benchmarking (e.g., against GENELink-style supervised methods) rather than gene module functional quality

## Inputs

- Precomputed cell-lineage-specific GRNs and driver regulators for hESC, mESC, and three mHSC lineages (CEFCON run with edge_threshold_avgDegree=8)
- Single-cell expression matrices (adata) for the five lineages (e.g., hESC dataset with 1,000 highly variable genes from zenodo.org/record/7564872)
- Reference cell-type labels per dataset
- pySCENIC regulons detected on the same five datasets

## Outputs

- Per-lineage RGMs.csv (CEFCON regulon-like gene modules) and SCENIC-equivalent regulon sets
- AUCell_mtx.csv per-cell RGM/regulon activity matrix
- Per-dataset GO_BP and KEGG enrichment precision (fraction of modules significant at BH-adjusted p <= 0.05)
- NMI of hierarchical clustering on AUCell activity against reference cell-type labels
- Compiled CEFCON-vs-SCENIC comparison table reproducing Fig. 5b-d

## How to apply

Load the precomputed cell-lineage-specific GRNs and driver regulators for hESC, mESC, and the three mHSC lineages from the upstream CEFCON run, with GRN edges selected using edge_threshold_avgDegree=8. For each of the five lineages, detect regulon-like gene modules involving the identified driver regulators via cefcon_results.RGM_activity(), writing each lineage's modules to RGMs.csv. Compute per-cell AUCell activity of the RGMs (AUCell_mtx.csv) using the aertslab AUCell scoring scheme, perform GO_BP and KEGG enrichment on each module, and define precision as the fraction of modules significant at BH-adjusted p <= 0.05. Hierarchically cluster cells from the AUCell RGM-activity matrix and compute normalized mutual information (NMI) against reference cell-type labels. Run the pySCENIC (>= 0.12.0) regulon-detection baseline on the same five datasets, repeat steps 3-5 on its regulons, and compile the per-dataset precision and NMI comparison.

## Evaluation signals

- Compiled comparison table shows CEFCON attaining higher GO_BP/KEGG enrichment precision than pySCENIC on all five tested datasets
- Compiled comparison table shows CEFCON attaining higher NMI than pySCENIC across hESC, mESC, and mHSC lineage datasets, consistent with Fig. 5b-d
- Each lineage's RGMs.csv and AUCell_mtx.csv are produced with the expected per-lineage module and cell-by-module structure
- Enrichment precision is computed as the fraction of modules significant at BH-adjusted p <= 0.05 for both methods under identical GO_BP/KEGG settings
- NMI is computed from hierarchical clustering of the AUCell activity matrix against the same reference cell-type labels for both CEFCON and SCENIC modules

## Limitations

- Benchmark conclusions depend on the upstream CEFCON GRN edge selection parameter (edge_threshold_avgDegree=8); other thresholds are not validated here
- Comparison is limited to the five tested lineages (hESC, mESC, and three mHSC lineages); ground-truth label datasets for broader supervised evaluation are often lacking, especially for specific cell types or lineages
- CEFCON can only handle one cell lineage at a time, so the benchmark is per-lineage and cannot cover multiple fate trajectories with bifurcations simultaneously
