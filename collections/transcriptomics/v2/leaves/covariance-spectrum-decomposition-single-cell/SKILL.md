# covariance-spectrum-decomposition-single-cell

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Decomposes a sparse single-cell expression matrix via its covariance-matrix eigen-spectrum into three fractions: eigenvalues compatible with random matrix theory (RMT) universality, sparsity-induced spurious signal identified by a label-permutation control, and residual true biological signal. Grounded in Aparicio et al. 2020, where ~95% / ~3% / ~2% was recovered for the 95% sparse Kang et al. PBMC matrix.

## When to use

Use when a single-cell count matrix is heavily sparse (e.g. ~95% zeros) and you need to quantify how much of the covariance eigen-spectrum departs from Marchenko-Pastur/Tracy-Widom expectations and partition that departure into sparsity artifacts versus biological signal.

## When NOT to use

- Input has already been imputed or denoised with methods like MAGIC, scImpute, ZIFA, or scVI — the RMT noise model assumes the raw sparse matrix, and prior imputation would destroy the noise structure being measured
- Input is dense, low-sparsity data where sparsity-induced eigenvector localization is not a confound and the permutation control adds no information
- Goal is direct cell-type annotation or differential expression rather than quantifying the noise/signal composition of the spectrum

## Inputs

- Sparse cell-gene expression/count matrix (e.g. 95% sparse matrix of 6,573 human PBMCs from Kang et al.)
- Randomized control matrix generated by permuting cell labels independently for each gene

## Outputs

- Eigen-spectrum of the covariance matrix with each eigenvalue classified as RMT-universality-compatible, sparsity-induced, or biological
- Eigenvector localization statistics for the original and randomized datasets
- eigenvalue_fraction_report.csv containing the three fractions (~95% RMT-compatible, ~3% sparsity-induced, ~2% biological)

## How to apply

Compute the covariance-matrix eigen-spectrum of the cell-gene expression matrix (e.g. the 6,573-cell human PBMC matrix from Kang et al.) using the Randomly library in Python 3. Classify each eigenvalue against RMT universality predictions — the Marchenko-Pastur bulk and Tracy-Widom edge statistics — labeling values that deviate as candidate signal. Build a sparsity-only randomized control by permuting the cell labels independently for each gene, then recompute its eigen-spectrum and eigenvector localization statistics; deviating eigenvalues that also localize in the control are spurious, non-biological sparsity effects. Apply the feature-selection step that discards the genes responsible for localized eigenvectors in the randomized case, so the residual deviating eigenvalues (localized eigenvectors = groups of correlated cells) can be interpreted as true biological signal. Report the three fractions (RMT-compatible, sparsity-explained, biological residual) and write them to eigenvalue_fraction_report.csv.

## Evaluation signals

- The three computed fractions reproduce the reported decomposition — ~95% RMT-compatible, ~3% sparsity-induced spurious signal, ~2% true biological signal — within a small tolerance of the Figure 2E / abstract values
- Eigenvalues classified as compatible fall within the Marchenko-Pastur bulk and pass Tracy-Widom edge statistics
- Deviating eigenvalues in the original data are matched by deviating/localizing eigenvalues in the per-gene label-permutation control, confirming they are sparsity-induced rather than biological
- eigenvalue_fraction_report.csv exists, parses correctly, and its three fractions sum to 1
- After the feature-selection step, previously localized eigenvectors attributable to sparsity no longer dominate the residual signal

## Limitations

- The RMT model treats the data as a random matrix plus a low-rank perturbation; departures from universality are interpreted as signal, so non-biological structure not captured by the sparsity control could be misassigned
- No version or release information is provided for the publicly available algorithm code, complicating reproducibility
- The method requires a randomization control per dataset; without it, spurious eigenvector localization from sparsity can be falsely identified as meaningful directions in the data
