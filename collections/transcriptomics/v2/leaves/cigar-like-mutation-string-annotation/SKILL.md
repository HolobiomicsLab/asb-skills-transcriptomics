# cigar-like-mutation-string-annotation

## Summary

Annotates gRNA sequence variations from per-UMI consensus sequences by calling GiRAFR's variant.call_gRNA_variant against the reference gRNA cassette (oligo_pool_plasmid.fa) and localizing each mutation relative to the structure GTF, encoding differences as CIGAR-like strings (digits = exact matches, letters = mutated bases, bracketed counts for insertion/deletion/substitution events).

## When to use

Use when consensus gRNA sequences (consensus.sequence.gRNA.txt) must be compared to a designed gRNA-cassette reference and each mutation pinpointed relative to annotated cassette structures, producing a variant table for downstream mutation-aware cell assignment.

## When NOT to use

- You only need intact-gRNA feature counts from a standard Cell Ranger feature barcoding pipeline — this skill specifically recovers mutant gRNAs that such pipelines miss.
- You want to detect CRISPR-Cas9 editing effects (indels at the cutsite in transcriptome data) — use GiRAFR's separate editing_effect mode instead of the gRNA_mutation variant-calling step.
- Your input BAM has not been filtered by utils.gRNA_bam_filter (secondary alignments and reads off the designed gRNA-cassette chromosomes still present).

## Inputs

- consensus.sequence.gRNA.txt (per-UMI consensus gRNA sequences from consensus_sequence.generate_consensus_sequence_gRNA)
- consensus.bam (BAM of consensus gRNA reads)
- oligo_pool_plasmid.fa (reference gRNA cassette FASTA generated by prepare.py)
- oligo_pool_plasmid_structure.gtf (cassette structure annotation generated by prepare.py)

## Outputs

- consensus.sequence.gRNA.variant.txt (variants per consensus sequence in CIGAR-like string format with semicolon-separated, structure-annotated mutations)
- all.MT.txt (mutation-detail file for downstream profiling via profile_MT_pattern.py)

## How to apply

Run variant.call_gRNA_variant(consensus_seq_file, ref_fasta, structure_gtf) on the consensus sequences produced by consensus_sequence.generate_consensus_sequence_gRNA from the filtered BAM (gRNA.sorted.mapped.removedSecondaryAlignment.onlyMappedToGrnaChrom.bam). Differences are recorded in a CIGAR-like string: digits denote exact matching bases, nucleotide characters denote substituted bases, and bracketed counts denote insertion/deletion/substitution events, with hard-clip tokens excluded. Mutation positions are annotated against oligo_pool_plasmid_structure.gtf, where a digit in the annotation represents the distance to a structure start and events are comma-separated within semicolon-separated structures. The rationale is that transcriptome-aligners (Cell Ranger) treat mutant gRNAs as mismatches and miss them, so a dedicated reference-comparison step recovers both intact and mutant gRNAs before assign_gRNA_to_cell uses the variants for cell annotation.

## Related tools

## Examples

```
variant.call_gRNA_variant('consensus.sequence.gRNA.txt', 'oligo_pool_plasmid.fa', 'oligo_pool_plasmid_structure.gtf')
```

## Evaluation signals

- consensus.sequence.gRNA.variant.txt exists and every mutation annotation is a well-formed CIGAR-like string consistent with oligo_pool_plasmid_structure.gtf (no hard-clip tokens; bracketed counts match the number of inserted/deleted bases).
- Intact gRNAs are represented by pure digit strings (exact matches to oligo_pool_plasmid.fa) while mutant gRNAs contain letter characters or bracketed I/D/S events.
- Structure annotations in the variant file are semicolon-separated per structure, with comma-separated mutation events and a digit giving distance to the structure start.
- Downstream, add_variant_type / profile_MT_pattern.py should attach mutation type and location details without errors from malformed variant strings.
- Comparing per-cell calls against Cell Ranger-based annotation should reveal mutant-gRNA cells Cell Ranger missed (e.g. 481 of 1198 mutant-gRNA cells in the A549 CROP-seq validation).

## Limitations

- The article does not appraise which specific mutation types or locations are tolerable versus damaging; such fine-grained appraisal is beyond the study's scope.
- Accurate variant calling requires adequate gRNA read depth; specific defined read depths need to be attained for accurate gRNA assignment and mutation detection.
- UMIs supported by fewer than min_reads reads (default 1; 2 for error filtering in the per-UMI consensus module) are discarded, so low-support true variants may be lost with sequencing-error-free strictness.
