# tpm-gene-expression-table-generation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Generates transcript- and gene-level expression values (TPM) from tumor RNA-Seq data by combining HISAT2 read mapping with StringTie assembly/quantification, as embedded in the TSNAD v2.0 RNA-Seq analysis module.

## When to use

Use when tumor RNA-Seq FASTQ reads must be aligned and quantified into a TPM table so downstream neoantigen filtering can exclude genes with TPM < 1.

## When NOT to use

- Input is WES/WGS DNA sequencing data from tumor-normal pairs — use TSNAD's somatic mutation (Mutect2) module instead of the RNA-Seq expression module
- The goal is gene fusion detection from RNA-Seq — TSNAD v2.0 uses STAR 2.7 plus Arriba 1.1.0 for that, not HISAT2/StringTie
- RNA-Seq data is not available (the TSNAD README notes RNA-seq 'is not necessary to provide') — expression filtering on TPM < 1 cannot then be applied

## Inputs

- Tumor RNA-Seq FASTQ files
- Human reference genome GRCh37 or GRCh38
- HISAT2 SAM alignment output

## Outputs

- Sorted BAM alignment file
- Transcript-level TPM values
- Gene-level TPM values (e.g., gene_expression_results.tsv)

## How to apply

Take the tumor RNA-Seq FASTQ files supplied with the TSNAD v2.0 distribution and align them to the human reference genome (GRCh37 or GRCh38) with HISAT2 v2.2.1. Convert the HISAT2 SAM output to sorted BAM using SAMtools v1.13 to reduce storage footprint. Assemble the alignments into potential transcripts and quantify expression with StringTie v2.1.6, reporting transcript and gene TPM values. The resulting expression table feeds TSNAD's module 4 filter, which removes neoantigens generated by mutations in unexpressed genes (TPM < 1). Correct application is judged by obtaining a parseable expression table containing TPM values for transcripts and genes suitable for that TPM < 1 thresholding step.

## Examples

```
docker run -it -v samples/:/home/tsnad/samples -v RNA-seq/:/home/tsnad/RNA-seq -v results/:/home/tsnad/results biopharm/tsnad:latest /bin/bash; python TSNAD.py -I samples/ -R RNA-seq/ -V grch38 -O results/
```

## Evaluation signals

- gene_expression_results.tsv exists and is a parseable table
- The table contains TPM values for transcripts and genes, enabling downstream filtering at the TPM < 1 unexpressed-gene threshold
- RNA-Seq reads were aligned against GRCh37 or GRCh38 as selected via the TSNAD -V flag, matching the reference used for variant calling
- HISAT2 SAM output was converted to sorted BAM with SAMtools v1.13 before StringTie v2.1.6 assembly

## Limitations

- Expression quantification depends on RNA-Seq being supplied; without it the TPM < 1 unexpressed-gene filter cannot be applied
- The reference genome version (GRCh37 vs GRCh38) must match the rest of the pipeline; TSNAD v1.0 only supported GRCh37
- Expression values are used purely as a neoantigen filter in TSNAD, not as a stand-alone differential expression analysis
