# sequencing-substitution-error-introduction

## Summary

Introduces Illumina-style substitution errors into synthetic single-cell reads generated by scReadSim, so that downstream aligners/UMI deduplication tools are benchmarked against error-bearing FASTQ/BAM rather than clean reads.

## When to use

Use when scReadSim has produced synthetic scRNA-seq reads and you need realistic sequencing-error profiles added before benchmarking read-level tools such as UMI deduplication or alignment.

## When NOT to use

- The input reads are real scRNA-seq/scATAC-seq data that already carry sequencing errors — this step only applies to scReadSim's synthetic reads.
- The goal is to benchmark count simulators (scDesign2/scDesign3) or produce ground-truth UMI count matrices rather than read-level data; error introduction is part of the read-generation stage only.
- The task is benchmarking isoform or alternative splicing tools — scReadSim provides gene-level ground truths only, so the error-bearing read output would not support it.

## Inputs

- Synthetic paired-end FASTQ files (*.read1.bed2fa.fq and *.read2.bed2fa.fq) from scRNA_BED2FASTQ
- Reference genome FASTQ/BAM input (e.g. mm10 chr1) with bowtie2 index for prior alignment via AlignSyntheticBam_Pair
- Picard-created reference dictionary for the reference genome
- Synthetic BAM file from scRNA_GenerateBAM.scRNA_GenerateBAMCoord / AlignSyntheticBam_Pair

## Outputs

- Error-introduced synthetic scRNA-seq BAM aligned to the reference
- Error-bearing paired-end FASTQ derived from the synthetic reads
- Downstream-benchmarkable reads retaining ground-truth UMI counts (*.scDesign2Simulated.txt) and synthetic cell barcodes (synthetic_cell_barcode.txt)

## How to apply

First convert the combined foreground/background BED to paired-end FASTQ with scRNA_BED2FASTQ (bedtools getfasta + seqtk, sort_FASTQ=True) using the mm10 chr1 reference, then optionally align the synthetic FASTQs to the bowtie2-indexed reference with AlignSyntheticBam_Pair. Apply the error module via scReadSim's scRNA_ErrorBase function, which uses fgbio to introduce Illumina-style substitution errors and requires a Picard-created reference dictionary for the reference genome. Error introduction is an optional final step of scReadSim's third stage (synthetic read generation), after the synthetic coordinates (read_len=90, jitter_size=5, CB_len=16, UB_len=10) are sampled from the real BAM. Judge success by the presence of error-bearing synthetic BAM/FASTQ in the output directory.

## Related tools

- **scReadSim** (Provides scRNA_ErrorBase, the function that introduces Illumina-style substitution errors into the synthetic BAM) — https://github.com/JSB-UCLA/scReadSim
- **fgbio** (Engine used by scRNA_ErrorBase to introduce the substitution errors)
- **Picard** (Creates the reference dictionary required by the fgbio-based error-introduction step)
- **bowtie2** (Aligns the synthetic paired-end FASTQs (via AlignSyntheticBam_Pair) before error introduction)

## Examples

```
pip install scReadSim
```

## Evaluation signals

- Upstream validation: *.read1.bed2fa.fq and *.read2.bed2fa.fq paired-end FASTQ files exist in the output directory before error introduction.
- A Picard-created reference dictionary for the reference genome (e.g. mm10) is available and accepted by the fgbio call.
- The synthetic BAM exists and is aligned to the bowtie2-indexed reference before scRNA_ErrorBase is applied.
- The error-introduced output retains the scDesign2-simulated ground truth (*.scDesign2Simulated.txt) and synthetic_cell_barcode.txt so UMI deduplication benchmarks can still be scored.
- Substitution-only profile (no indels) matching the Illumina-style error model is observed in the error-bearing output.

## Limitations

- Error introduction is an optional step; skipping it yields clean synthetic reads that may unrealistically flatter read-level tools.
- The default scReadSim implementation may generate intronic synthetic reads when extracting sequences from the reference genome, which can affect downstream benchmarks such as cellranger default mode.
- scReadSim provides gene-level ground truths (UMI counts) only, not isoform-level ground truths including isoform abundance and alternative splicing events.
