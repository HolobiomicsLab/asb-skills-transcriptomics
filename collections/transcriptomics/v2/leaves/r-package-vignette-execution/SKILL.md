# r-package-vignette-execution

## Summary

Executes an R package's bundled vignette example end-to-end — installing with build_vignettes=TRUE, locating the vignette via browseVignettes, running its code, and exporting the resulting matrices — to validate that a method's documented simulation workflow reproduces its stated outputs.

## When to use

Use when an R/Bioconductor method package ships a simulation or worked-example vignette and the task is to reproduce that example and export its fitted outputs (e.g. topic-word distributions) as artifacts.

## When NOT to use

- The package has no vignette or build_vignettes=TRUE fails, leaving no documented example to execute
- The goal is to fit pLDA to real experimental scRNA-seq data with biological annotation, not to reproduce the package's simulation example
- The task targets a non-R package (Python/CLI) where browseVignettes and R library installation are not applicable

## Inputs

- R environment with devtools installed
- GitHub-hosted R package source (wuxiaotiankevin/pLDA) including vignette sources
- Simulated scRNA-seq count matrix generated by the vignette (genes as words, cells as documents)

## Outputs

- topic_word_matrix.csv — estimated topic-word probability matrix (genes × topics)
- cell_topic_proportions.csv — per-cell topic proportion matrix (cells × topics)
- Executed vignette confirming the simulation example runs to completion

## How to apply

Install the package from GitHub with devtools::install_github passing build_vignettes=TRUE so the example documents are compiled locally (for pLDA this is devtools::install_github("wuxiaotiankevin/pLDA", build_vignettes=TRUE)). Load the library with library(pLDA) and open the simulation example with browseVignettes('pLDA'). Execute the vignette code step by step: it generates a simulated scRNA-seq count matrix where genes are words and cells are documents, then fits the penalized Latent Dirichlet Allocation (pLDA) model, which estimates topic-word probabilities and per-cell topic proportions with a penalty that increases estimation robustness. Export the fitted topic-word probability matrix as topic_word_matrix.csv and the per-cell topic proportion matrix as cell_topic_proportions.csv. Validate by checking that both CSVs exist, are non-empty, and their dimensions match the number of simulated genes/topics and cells/topics respectively from the vignette.

## Related tools

- **devtools** (Installs the pLDA package from GitHub with build_vignettes=TRUE so the simulation example vignette is available locally) — github.com/wuxiaotiankevin/pLDA
- **pLDA** (The R package under test; provides the penalized LDA model fitted to the simulated scRNA-seq counts in its vignette) — github.com/wuxiaotiankevin/pLDA
- **R** (Runtime environment in which the package is loaded (library(pLDA)) and the vignette code is executed)

## Examples

```
library(devtools); install_github("wuxiaotiankevin/pLDA", build_vignettes=TRUE); library(pLDA); browseVignettes('pLDA')
```

## Evaluation signals

- Both topic_word_matrix.csv and cell_topic_proportions.csv exist and are non-empty
- topic_word_matrix.csv dimensions match the number of simulated genes × number of latent topics from the vignette
- cell_topic_proportions.csv dimensions match the number of simulated cells × number of topics
- Row-wise topic-word probabilities and row-wise per-cell topic proportions each sum to 1 (Dirichlet model constraint)
- browseVignettes('pLDA') lists the compiled simulation example, confirming build_vignettes=TRUE succeeded during install

## Limitations

- The vignette is a simulation example only; topics fitted there reflect simulated latent structure, not real biological functions until applied to actual scRNA-seq data
- Package installation from GitHub via devtools requires network access and the vignette build depends on build_vignettes=TRUE being passed at install time
- The pLDA article/README was described as 'In preparation' at the time, so documentation beyond the README and vignettes is limited; questions go to the maintainer xiaotian_wu at brown dot edu
