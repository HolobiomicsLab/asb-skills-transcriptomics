# cellphonedb-statistical-analysis

## Summary

Runs CellPhoneDB (v2) statistical analysis separately on each condition group of the Chua et al. COVID-19 scRNA-seq data to infer ligand-receptor interactions between annotated cell types, producing condition-specific CCI datasets that serve as input for InterCellar.

## When to use

Use when you need to infer cell-cell interactions from a preprocessed scRNA-seq expression matrix with cell-type annotations, and must generate one CCI dataset per condition (e.g., control vs moderate vs critical) for downstream InterCellar analysis.

## When NOT to use

- The CCI dataset has already been generated by an InterCellar-supported tool (CellChat, ICELLNET, or SingleCellSignalR) — upload it directly instead of re-running inference
- You need an interactive downstream analysis or interpretation tool — that is InterCellar's role, not CellPhoneDB's
- The dataset is bulk RNA-seq or lacks cell-type annotations, since ligand-receptor interactions are inferred between annotated cell types

## Inputs

- Preprocessed Chua et al. COVID-19 scRNA-seq expression matrix (counts)
- Cell-type annotations / metadata (meta) mapping cells to clusters, split by condition (control, moderate, critical)
- CellPhoneDB v2 with its default ligand-receptor interaction database and default statistical parameters

## Outputs

- Three condition-specific CCI datasets (control, moderate, critical), each comprising CellPhoneDB output files: means, p-values, and significant means of inferred ligand-receptor interactions
- Validated per-condition CCI input files matching the reference deposits in martaint/InterCellar-reproducibility for InterCellar upload

## How to apply

Load the preprocessed Chua et al. expression matrix and cell-type annotations from the martaint/InterCellar-reproducibility repository, then split the data into three condition groups: 5 controls (2,966 cells), 8 moderate and 11 critical patients each subsampled to 10,000 cells. Run CellPhoneDB v2 statistical analysis with default parameters independently on each condition group to infer ligand-receptor interactions between cell types. Collect the per-condition output files (means.txt, pvalues.txt, significant_means.txt) as the three condition-specific CCI datasets. Finally, validate each generated CCI dataset against the corresponding reference CCI deposit in the InterCellar-reproducibility repository, since InterCellar ingests pre-computed ligand-receptor interactions uploaded as CCI data in the first workflow step.

## Related tools

- **CellPhoneDB** (Statistical inference of ligand-receptor interactions per condition group, producing the CCI input files)
- **InterCellar** (Downstream interactive analysis of the generated CCI datasets; the reproducibility repository supplies the input data and reference outputs) — https://github.com/martaint/InterCellar-reproducibility

## Evaluation signals

- Each of the three condition-specific CCI datasets exists and matches the corresponding reference CCI deposit in the martaint/InterCellar-reproducibility repository (output_matches_reference)
- CellPhoneDB produced all three expected output files per condition (mean expression, p-values, significant means)
- Condition group sizes match the design: 5 controls with 2,966 cells; 8 moderate and 11 critical patients each subsampled to 10,000 cells
- Inferred interactions are restricted to pairs of annotated cell types and ligand-receptor pairs from CellPhoneDB v2's database
- The resulting files load successfully as CCI data in InterCellar's first workflow step (upload pre-computed ligand-receptor interactions)

## Limitations

- InterCellar currently supports only a limited set of input tools; results must come from a supported format (CellChat, CellPhoneDB, ICELLNET, SingleCellSignalR)
- Predicted interactions are computational and await experimental validation (e.g., smFISH or flow cytometry co-occurrence)
- Prediction methods rely on different reference databases and statistical assumptions, so CellPhoneDB-derived results may differ from CellChat or ICELLNET on the same data (the reproducibility repo includes a cellchat_comparison)
