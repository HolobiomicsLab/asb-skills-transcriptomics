# r-bioconductor-workflow-execution

## Summary

Reproduce the decoupleR manuscript's R/Bioconductor benchmark workflows by installing the saezlab repositories (decoupleRBench, decoupleR_manuscript), pulling benchmark data from Zenodo, and running the scripted RNA/phospho-proteomic perturbation benchmark pipelines.

## When to use

Use when the goal is to reproduce published benchmark results from an R/Bioconductor manuscript repository by executing its install → get_data → run_bench → plot scripts verbatim.

## When NOT to use

- You are working in Python with the scverse decoupler package — the benchmark scripts are R-only (Rscript) and depend on the saezlab R repositories
- You need a bespoke benchmark design rather than reproducing the manuscript's fixed perturbation experiments (use decoupleRBench's vignette pipeline with your own input tibble instead)

## Inputs

- Holland et al. 2020 transcriptomics perturbation count table plus metadata (fetched from Zenodo record 5645208)
- DoRothEA gene regulatory network (prior-knowledge resource via OmniPath)
- R environment with devtools for GitHub package installation

## Outputs

- Per-method AUROC/AUPRC performance table (e.g. rna_bench_performance.csv) matching Supplementary Table S3
- Performance figure matching Supplementary Fig. S3 generated by R/plot/supp_fig_*.R
- Concatenated response/predictor vectors over all experiments for downsampling-based AUROC/AUPRC evaluation

## How to apply

Install the benchmark companion package with devtools::install_github('saezlab/decoupleRBench'), which builds on the decoupleR R package and its decouple wrapper. Retrieve all required data by running Rscript R/process/get_data.R, which pulls the Holland et al. 2020 perturbation collection from Zenodo record 5645208. Execute the benchmark scripts (Rscript R/process/run_rna_bench.R and run_php_bench.R) so that decoupleR's 11 methods (AUCell, fast GSEA, GSVA, ORA, ULM, VIPER, etc.) compute TF activity scores against the DoRothEA gene regulatory network; expect long runtimes for the noise and scalability scripts (~6 h and ~2 h for the noise runs). Score sensitivity by each method's ability to rank the experimentally perturbed TF among top regulators, then regenerate figures with the R/plot/supp_fig_*.R scripts and validate that the top-ranked methods match the published consensus, multivariate linear model and ULM ranking.

## Related tools

- **decoupleRBench** (R package that evaluates biological activity inference methods on perturbation experiments, wrapping decoupleR's decouple function) — https://github.com/saezlab/decoupleRBench
- **decoupleR_manuscript** (Repository of R scripts (R/process/*.R, R/plot/*.R) that reproduce the manuscript's benchmarks and figures) — https://github.com/saezlab/decoupleR_manuscript
- **decoupleR** (R/Bioconductor package whose statistical methods (AUCell, GSEA, GSVA, ORA, ULM, VIPER, mlm, consensus) are benchmarked) — https://www.bioconductor.org/packages/release/bioc/html/decoupleR.html
- **OmniPath** (Meta-resource of prior knowledge networks leveraged by decoupleR as the source of regulators and interaction weights)

## Examples

```
Rscript R/process/run_rna_bench.R
```

## Evaluation signals

- Top three ranked methods in the RNA benchmark output are consensus, multivariate linear model and ULM, matching Supplementary Table S3 / Fig. 1C
- get_data.R completes and the Holland et al. 2020 perturbation collection is present locally (Zenodo record 5645208)
- run_rna_bench.R produces a performance table and figure that reproduce Supplementary Table S3 and Supplementary Fig. S3
- AUROC/AUPRC for each method are computed over concatenated response/predictor vectors with the downsampling strategy of equal negative classes per permutation

## Limitations

- Noise analysis scripts are slow: run_rna_noise.R takes ~6 hours and run_php_noise.R ~2 hours; scalability analysis also 'might take a while'
- True positive classes are limited by the regulators covered in the perturbation experiments, requiring downsampling of negative classes for AUROC/AUPRC
- The R decoupler package is deprecated in favor of the Python scverse/decoupler implementation, so the R benchmark scripts target the legacy R API
