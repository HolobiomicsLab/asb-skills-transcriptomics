# gaussian-graphical-model-simulation

## Summary

Simulates sparse single-cell expression data with known Gaussian graphical model topologies (power-law and hub-based) to benchmark network inference methods such as scLink, glasso, PIDC, GENIE3, and thresholded Pearson/Spearman correlation.

## When to use

Use when benchmarking gene co-expression network inference methods on synthetic data where the ground-truth adjacency matrix must be known, especially for sparse scRNA-seq-like data with simulated dropouts.

## When NOT to use

- The goal is real-data network inference without a known ground-truth adjacency matrix to score against — use the inference skill directly rather than this simulation benchmark
- The input is a single real expression matrix rather than simulation parameters; this skill generates synthetic data and cannot evaluate methods on data lacking a true network
- Benchmarking methods designed for time-series or directed regulatory networks — scLink's edges are undirected statistical dependencies, so the simulation only supports undirected co-expression evaluation

## Inputs

- Per-gene expression means and standard deviations estimated from a single-cell count matrix (e.g., GEO GSE114727)
- Ground-truth connectivity matrices with power-law and hub-based topologies generated by ldstatsHD
- Simulated multivariate Gaussian expression matrices with induced zero counts at dropout rates rho = 0.07, 0.10, 0.13, 0.16 and a no-extra-sparsity control

## Outputs

- Per-repeat AUPRC and AUROC values for each inference method and simulation condition
- Aggregated AUPRC/AUROC summary table (e.g., simulation_auprc_auroc.csv) over 50 repeats per condition
- Simulated expression matrices paired with their true block-diagonal connectivity matrices

## How to apply

Estimate per-gene means and standard deviations from a real single-cell count matrix (e.g., GSE114727) so simulations reflect realistic gene-level intensity. Use ldstatsHD to generate block-diagonal connectivity matrices with power-law and hub-based topologies, and sample multivariate Gaussian expression data for 50 repeats per setting. Introduce excess zeros at dropout rates rho in {0.07, 0.10, 0.13, 0.16}, plus a no-extra-sparsity control where the zero-introduction step is skipped. Infer networks on each simulated dataset with all candidate methods (sclink_net, glasso, PIDC, GENIE3, thresholded Pearson/Spearman), compare inferred adjacency matrices to the true connectivity matrix, and compute AUPRC and AUROC per repeat, then aggregate per condition.

## Related tools

- **scLink** (Reference method under evaluation; sclink_net infers the sparse network whose AUPRC/AUROC should dominate in power-law and hub-based conditions) — https://github.com/Vivianstats/scLink
- **R** (Environment for the simulation loop, ldstatsHD topology generation, and baseline method calls)
- **ldstatsHD** (Generates block-diagonal power-law and hub-based ground-truth connectivity matrices for sampling multivariate Gaussian expression data)

## Examples

```
Rscript -e 'library(scLink); fit <- sclink_net(expr = sim_counts, ncores = 1, lda = seq(0.5, 0.1, -0.05))'
```

## Evaluation signals

- scLink attains the best AUPRC in every power-law and hub-based condition, reproducing the Figure 2C-D and Figure S3 pattern
- Generic glasso does not outperform thresholded Pearson correlation in the simulated conditions
- All methods, especially Pearson/Spearman correlation baselines, improve on the no-extra-sparsity control relative to dropout conditions
- Each condition aggregates exactly 50 repeats before summarizing AUPRC/AUROC
- simulation_auprc_auroc.csv contains one AUPRC/AUROC row per method, topology, and dropout rate combination

## Limitations

- scLink's edges are based on statistical dependencies and do not have directions, so the simulation evaluates undirected co-expression recovery only; distinguishing regulatory, co-regulatory, and functionally coordinated edge types is not feasible from expression data alone
- Results are tied to Gaussian graphical model assumptions and the specific dropout rates (0.07–0.16) tested; other noise models or sparsity regimes may reorder method rankings
- Baseline methods designed for bulk data (e.g., glasso) may perform poorly on imputed or simulated sparse single-cell data because imputed data can remain much sparser than bulk data
