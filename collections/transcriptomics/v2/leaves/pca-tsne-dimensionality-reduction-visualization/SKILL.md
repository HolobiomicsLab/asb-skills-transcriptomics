# pca-tsne-dimensionality-reduction-visualization

## Summary

Visualizes imputed scRNA-seq matrices (e.g., LATE/TRANSLATE outputs from PBMC_G949_10K) by first projecting with PCA and then embedding in 2D with t-SNE (MulticoreTSNE), coloring cells by known cell-type labels to assess whether imputation preserves cell-type separation.

## When to use

Use when you have an imputed single-cell expression matrix and known cell-type labels, and need a 2D embedding (t-SNE after PCA) to visually and quantitatively check cell-type separation.

## When NOT to use

- No cell-type labels or ground truth exist (e.g., the mouse brain dataset example_mouse_brain_10x.h5, where the ground truth is set to the input itself) — separation cannot be quantified against true clusters
- Data are raw unimputed count matrices on the linear scale — the workflow expects the log10(count+1)-transformed imputed output, not raw counts

## Inputs

- Imputed expression matrix in hd5 format (step2/imputation.step2.hd5), log10(count+1) scale
- Ground-truth expression matrix (example.hd5, 10,000 genes x 10,000 cells)
- Cell-type labels for the 10 PBMC cell types

## Outputs

- 2D t-SNE plots colored by cell type, saved with matplotlib/seaborn
- BCSS and WCSS values per imputation method, tabulated across the 10 cell-type clusters
- Eval/ analysis folder generated by example_analysis.py (mode='analysis')

## How to apply

After imputation (e.g., LATE/TRANSLATE output stored as step2/imputation.step2.hd5 on the log10(count+1) scale), load the imputed matrix, reduce dimensionality with PCA, then embed the PCA output in 2D using MulticoreTSNE. Color the 2D embedding by the 10 labeled cell types of the 10x Genomics PBMC dataset and save plots with matplotlib/seaborn. Quantify separation by computing the between-cluster sum of squares (BCSS) and within-cluster sum of squares (WCSS) across the 10 cell-type clusters, comparing each imputation method to the ground-truth embedding. Accept results when methods like LATE, TRANSLATE, DCA and scVI yield high BCSS and low WCSS (t-SNE resembling ground truth), while SAVER, scImpute, MAGIC and ALRA do not.

## Related tools

- **MulticoreTSNE** (Provides the parallel t-SNE implementation used to embed PCA-projected imputed data in 2D) — https://github.com/audreyqyfu/LATE
- **sklearn** (Used for PCA projection prior to t-SNE embedding)
- **matplotlib** (Renders the 2D t-SNE scatter plots colored by cell type)
- **seaborn** (Styling/plotting of the t-SNE visualizations)

## Examples

```
python example_analysis.py -mode='analysis' -infile='../data/example.msk90.hd5'
```

## Evaluation signals

- LATE and TRANSLATE (and DCA/scVI) imputed embeddings show a t-SNE plot similar to the ground truth with high BCSS and low WCSS across the 10 cell-type clusters
- SAVER, scImpute, MAGIC and ALRA fail to separate cell types (lower BCSS, higher WCSS), matching Figure 5's reported pattern
- Imputed matrix retains the same layout (genes x cells) as the input and is on the log10(count+1) scale before embedding
- t-SNE is applied after PCA projection, as specified in the workflow

## Limitations

- LATE is incompatible with TensorFlow 2; a virtual environment with TensorFlow 1.x (e.g., 1.15) and pandas 0.25.1 is required for the upstream imputation feeding this visualization
- LATE/TRANSLATE assume all zeros are missing values (technical dropouts) and impute zeros with nonzero values; biological zeros are not distinguished, which can affect downstream clustering visuals
- In the current LATE version, code must be run where it is stored locally (cd scripts/), and datasets may be stored elsewhere via paths like ../data/
