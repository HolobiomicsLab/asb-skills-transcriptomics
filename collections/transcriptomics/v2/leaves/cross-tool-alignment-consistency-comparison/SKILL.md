# Cross-tool alignment consistency comparison

## Summary

Validates pathogen detection robustness in 10x scRNA-seq by running the same sample through multiple alignment strategies (CellRanger with an integrated pathogen genome vs. scPathoQuant with bbmap vs. scPathoQuant with bowtie2) and quantifying agreement in per-cell pathogen-positive calls and UMI counts.

## When to use

Use when a 10x scRNA-seq sample has been analyzed for pathogen reads by more than one alignment strategy and you need to verify that EGFP+/pathogen+ cell calls and per-cell UMI counts are consistent across methods.

## When NOT to use

- Input is a single-method analysis with no alternative alignment strategy available — no cross-method comparison can be computed
- Data are not 10x single-cell outputs (e.g. bulk RNA-seq or non-UMI data), since CellRanger barcodes/UMIs and pathogen_al_counts.csv per-cell counts are the comparison units
- The goal is absolute quantification benchmarking against other packages (ViralTrack, Venus, PathogenTrack) rather than internal consistency of CellRanger vs. scPathoQuant aligners

## Inputs

- 10x Genomics output folders (filtered_feature_bc_matrix, raw_feature_bc_matrix, possorted_genome_bam.bam) generated by cellranger count against the host genome
- CellRanger output generated against the host reference with the pathogen genome computationally integrated (e.g. GRCh38 + EGFP HIV genome)
- Pathogen reference genome fasta folder (fasta plus optional gtf) passed via -p2genome

## Outputs

- Per-cell pathogen count tables (pathogen_al_counts.csv) from each alignment strategy
- Cross-tabulation of cell classes (e.g. EGFP+HIV+, EGFP-HIV+) per method per donor
- Overlap fraction of pathogen-positive cells across the three methods (expected 100% for EGFP+HIV+ cells)
- Kendall rank correlation of per-cell pathogen UMI counts versus CellRanger integrated-genome calls, per donor

## How to apply

For each sample, first run CellRanger count against the host reference (e.g. GRCh38) and against a host reference with the pathogen genome computationally integrated (e.g. GRCh38 + EGFP HIV genome). Then run scPathoQuant twice on the host-only CellRanger outputs: once with the default bbmap aligner (-p 8, -p2genome pointing to the pathogen reference fasta folder) and once with -align bowtie2 --bowtie2_params="--very-sensitive --non-deterministic". Extract per-cell pathogen counts from pathogen_al_counts.csv of each scPathoQuant run and cross-tabulate cells as pathogen-positive/negative (e.g. EGFP+HIV+, EGFP-HIV+) against the CellRanger integrated-genome calls. Compute the fraction of pathogen-positive cells classified consistently across the three methods and the Kendall rank correlation of per-cell pathogen UMI counts versus CellRanger for each donor; in the HIV comparison, all three methods showed 100% overlap in EGFP+HIV+ cells (3653 cells in donor 1, 183 in donor 2).

## Related tools

- **scPathoQuant** (Remaps CellRanger host-unaligned reads to the pathogen genome with bbmap (default) or bowtie2 and writes per-cell counts to pathogen_al_counts.csv) — https://github.com/galelab/scPathoQuant
- **cellranger** (Generates the 10x outputs by aligning reads to the host genome and to a host reference with the pathogen genome integrated, providing the integrated-genome calls used as the comparison baseline)
- **bbmap** (Default scPathoQuant aligner used for one arm of the comparison)
- **bowtie2** (Alternative scPathoQuant aligner run with --very-sensitive --non-deterministic for the second arm of the comparison)

## Examples

```
scpathoquant -10x path/to/10x/sample -op path/for/results -p 8 -p2genome path/to/viral/fastafilefolder -align bowtie2 --bowtie2_params="--very-sensitive --non-deterministic"
```

## Evaluation signals

- EGFP+HIV+ cell overlap across the three alignment methods is 100% in each donor sample
- Per-donor counts match published values: 3653 EGFP+HIV+ and 8133 EGFP-HIV+ cells in donor 1; 183 EGFP+HIV+ and 712 EGFP-HIV+ in donor 2
- Kendall rank correlation of per-cell HIV UMI counts versus CellRanger integrated-genome calls is computable and reported for both donors
- pathogen_al_counts.csv exists for each scPathoQuant run and its barcodes can be cross-tabulated against the CellRanger integrated-genome cell calls
- The bowtie2 run used the documented parameters --very-sensitive --non-deterministic and the bbmap run used scPathoQuant default parameters

## Limitations

- Consistency was assessed only on the two Bradley et al. 2018 HIV donor samples; agreement may differ for other pathogens or samples
- scPathoQuant depends on reads left unaligned by CellRanger host alignment, so pathogen reads that spuriously align to the host reference (unless the pathogen genome is integrated) are not recovered
- The temporary _tmp/ directory of intermediate files can be large and must be removed with --tmp_removal if space is an issue
