# clonal-tree-inference-mtdna-variants

## Summary

Reconstruct clonal substructure from single-cell mtDNA variants using the cellSNP-MQuad-VireoSNP pipeline: pile up mitochondrial reads into SNP-by-cell AD/DP matrices, select clonally informative variants with MQuad's binomial mixture model, and assign cells to mtDNA clones with vireoSNP, optionally integrating with nuclear SNV clones.

## When to use

Use when analysis-ready single-cell RNA/DNA/ATAC-seq BAM files are available and the goal is to call clone-discriminative mtDNA variants and assign cells to mitochondrial clones or subclones within nuclear-inferred clones.

## When NOT to use

- The aim is donor demultiplexing from common nuclear SNPs (e.g. pooled multiplexed scRNA-seq with vireo alone) rather than somatic mtDNA clonal substructure discovery
- Variants are nuclear SNVs requiring a diploid context — MQuad's binomial mixture model is built for the non-diploid mitochondrial genome, and nuclear SNV callers like Monovar/Conbase are the wrong model here, not MQuad
- Input is bulk sequencing without single-cell barcodes/annotation, since informative variants and clone assignments are defined per single cell

## Inputs

- Analysis-ready BAM files from single-cell sequencing (scRNA-seq, scDNA-seq, or mtscATAC-seq), duplicates marked/removed with Picard MarkDuplicates
- Cell barcode list (for 10x-style data) or per-cell BAM list with sample IDs (for Smart-seq2, using --UMItag None)
- SNP-by-cell AD (alternate-allele count) and DP (depth) matrices generated by cellsnp-lite pileup of the mitochondrial chromosome

## Outputs

- List of clonally informative mtDNA SNVs selected by MQuad with ΔBIC scores at the Kneedle knee-point cutoff
- Cell-to-clone assignment table from vireoSNP variational inference (mitochondrial clone labels)
- Per-clone mean allelic frequency table for each detected mtDNA SNV
- Confusion matrix cross-tabulating mtDNA clone assignments against Cardelino nuclear clone labels, with mtDNA subclones placed in the nuclear clonal tree

## How to apply

Preprocess scRNA-seq FASTQs by aligning to the UCSC hg19 reference with STAR (default parameters) and removing PCR duplicates with Picard MarkDuplicates (v2.18.9). Pile up mitochondrial reads with cellsnp-lite (v1.2.1) to generate SNP-by-cell alternate-allele count (AD) and depth (DP) matrices. Run MQuad (v0.1.6), which fits a two-component binomial mixture model per variant against a one-component null, computes ΔBIC = BIC(M0) − BIC(M1), and selects informative SNVs at the Kneedle knee point of the cumulative ΔBIC distribution (kneed package); explicitly drop false-positive variants in error-prone rCRS regions 302–315, 513–525, and 3105–3109 (Xu et al.). Assign cells to mtDNA clones with vireoSNP (v0.5.3) variational inference on the selected SNPs, then cross-tabulate assignments against Cardelino nuclear clone labels to build a confusion matrix and place mtDNA subclones (e.g. MT0/MT1 within nuclear clone 1 in the joxm fibroblast Smart-seq2 dataset). Tabulate mean allelic frequency of each mtDNA SNV per clone to confirm clone-specific variants such as 11196G>A and heteroplasmy-drifted 2619A>T.

## Examples

```
cellSNP -s $BAM -b $BARCODE -O $OUT_DIR -p 22 --minMAF 0.1 --minCOUNT 100 --chrom chrMT
```

## Evaluation signals

- On the joxm healthy fibroblast Smart-seq2 dataset the run recovers approximately 24 informative SNVs assigning 77 cells into 3 mtDNA clones, with nuclear clone 3 completely identical to mitochondrial clone 2
- ΔBIC cutoff sits at the Kneedle knee point of the cumulative ΔBIC distribution, and variants in rCRS regions 302–315, 513–525, 3105–3109 are excluded
- Cross-tabulation against Cardelino nuclear labels resolves two mtDNA subclones (MT0, MT1) nested within nuclear clone 1 with distinct mtDNA mutation profiles
- Per-clone allelic frequency table confirms the clone-specific 11196G>A variant and the heteroplasmy-drifted 2619A>T variant in the 2691 region
- Two-component binomial mixture fits beat the one-component null (positive ΔBIC) for every retained variant

## Limitations

- Frequent false-positive variants arise in error-prone rCRS regions 302–315, 513–525, and 3105–3109 and must be explicitly removed
- cellSNP mode 2 relies on pysam pileup(), which filters duplicates and orphan reads by default and may cause unexpected coverage reduction; for scRNA-seq with UMItag, duplicate filtering must be tuned (maxFLAG), and cellsnp-lite is recommended for mode 2
- Whole-genome pileup without a candidate SNP list can output somatic or RNA-editing false positives that confound inference
- Subclonal structure inferred from coverage-based CNVs may be less dynamic than subclones shown by propagation of true point mutations; mtDNA variants complement rather than replace nuclear SNV/CNV inference
